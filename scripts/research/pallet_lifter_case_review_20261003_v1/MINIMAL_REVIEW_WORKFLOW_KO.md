# 리프터 필수 사람 검수: 입력 부담 축소

2026-10-04 사용자가 제외한 5장은 이 작업 목록에서 제외한다. 원본 manifest 120장/반복 24장과 평가기는 보존하며, `USER_EXCLUSIONS.json`의 입력 해시·프레임 ID를 검증한다. 실제 작업은 **115장 + 같은 표본 중 반복 23장**이다. 제외를 사람이 코너까지 검수한 것으로 만들거나 frozen120/24 완료로 기록하지 않는다.

실제 원본 이미지가 기존 `scripts/annotate/annotate.py`에 먼저 표시된다. 프레임 ID·팔레트 치수·중심점·검수자 이름은 타이핑하지 않는다. 첫 저장의 이력 확인에는 기계 도움·이전 예측 노출·이전 주석 노출에 해당하는 항목만 체크하고 확인한다. 자동 별칭은 이 확인 후에만 사람 검수자로 기록되며, 다음 프레임부터 재사용한다. 다른 사람이 작업하거나 이력 답변이 달라지면 `--change-reviewer`를 사용한다. 다른 사람이 작업할 때만 ‘지난 검수자와 다른 사람이 작업함’을 체크하여 새 별칭을 만든다.

첫 화면은 원영상 전체가 제목/하단 안내에 가려지지 않는 범위에서 약1.6배로 확대한다. 저장 좌표는 원래 이미지 픽셀 좌표이며 확대에 따라 바뀌지 않는다. 첫 확인창과 확인 버튼은 conda Tk의 한글 폰트 유무와 관계없이 공통 Noto/Pillow 렌더링을 사용한다.

/home/minjae/anaconda3/envs/pallet-yolo26/bin/python scripts/research/pallet_lifter_case_review_20261003_v1/open_existing_annotation.py

1. 우측 도식 또는 상태 행에서 번호를 고른다. 키 `0`–`7`도 된다.
2. 그 번호의 실제 물리 꼭짓점이 보이면 원영상에서 클릭한다. 다음 미입력 번호로 자동 이동한다.
3. 보이지 않는 점은 우측 버튼 또는 키 `E 외부 가림 / I 자체 가림 / O 화면 밖 / U 판단 불가`로 상태만 표시한다. 없는 좌표를 추측해서 찍지 않는다.
4. 8개 상태를 입력하면 자동 저장하고 다음 이미지로 넘어간다. `S` 또는 저장 버튼도 저장/다음이다. **한 점만 보여도 저장할 수 있으며 PnP 성공을 요구하지 않는다.**

`Z` 또는 되돌림 버튼은 최근 클릭·좌표 수정·가시성 변경·삭제·초기화를 실제 직전 상태로 되돌린다. `D`는 선택 코너의 좌표와 가시성 상태를 지운다. `R`은 현재 프레임을 초기화하며 `Z`로 되돌릴 수 있다. `Shift+S`는 아직 미입력 코너가 있는 상태를 초안으로 저장한다. `P` 이전, `N` 다음, `+/-` 확대/축소, `H/J/K/L` 이동이다. 저장된 프레임 수정은 이전 이력을 보존하며 수정 사유 타이핑을 요구하지 않는다.

직접 클릭은 해당 물리 코너와 프레임의 대상 대응을 사람이 확인한 행동으로 기록한다. 직접 클릭 없이 모두 가림/판단 불가로 입력한 프레임은 대상 존재를 `uncertain`으로 저장하며 대상 확인을 만들어내지 않는다. 같은 프레임의 예측 객체와 참조 대상이 같은지 확인하는 별도 검수는 이 작업만으로 완료되지 않는다. `Shift+U` 일괄 판단 불가는 실제로 남은 점을 판단할 수 없는 경우의 한 번 확인이 필요하다.

번호는 계약의 물체 축 기준이다. 도식의 0–3은 계약상 가까운 면을 표시하는 설명이며, 이미지 시점에 따라 그 면이 화면 뒤로 보일 수 있다. 화면 좌우에 맞춰 번호를 새로 매기거나 임의로 순서를 섞지 않는다. 물리 대응이 불명확하면 `U`로 남긴다. PnP 자동 채움·외삽·모델 점 복사 기능은 이 직접 가시 참조에 사용하지 않는다.

저장 파일은 `data/pallet/results/pallet_lifter_case_review_20261003_v1/review/annotations_in_progress.json`과 `native_annotations/`이다. `LIFTER_REFERENCE_REVIEWED.json`은 제출한 범위만 내보내고, 별도 `requested_use`에는 제외와 115/23 진행률을 기록한다. 기존 전체120/24 완료 여부를 덮어쓰지 않는다. 재실행하면 완료 프레임은 다시 요구하지 않는다. 반복 검수에는 최초 검수 좌표를 불러오지 않으며, 같은 사람 반복을 독립 두 사람 검수로 기록하지 않는다.

첫 설정의 노출 답변을 모든 프레임에 그대로 복사하지 않는다. 동일한 검수자의 동일 프레임 기존 검수 기록이 실제로 있으면, 그 프레임의 `previous_annotation_exposure`는 `true`로 기록한다. 최초 좌표를 반복 화면에 미리 채우지 않아도 본인이 먼저 주석한 사실은 없어지지 않는다. `actual_annotation_exposure_provenance`에 그 근거의 pass·revision·기록 시각·원본 이미지 해시를 남기며 최초 설정 파일 자체는 바꾸지 않는다. 다른 검수자의 주석이 존재한다는 이유만으로 그 사람이 노출됐다고 기록하지 않는다. 기존 validator에는 본인 과거 주석을 노출에서 제외한다는 정의가 없다.

## 검산
