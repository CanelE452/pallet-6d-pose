첨부 pallet_point_line_v5_bundle.zip을 새 경로에 풀고 README_KO.md, docs/METHOD_AND_CONTRACT_KO.md, CLI_INSTRUCTIONS_KO.md를 읽어.

제공된 plpose_v5 코어를 새로 쓰지 말고 실제 pallet-6d-pose의 source/GT/object frame/치수/대칭/카메라/feature 경로를 확인한 뒤 연결해. 기존 camera-facing 번호와 새 object-frame 번호를 섞지 마. 네트워크는 새 point head이며 기존 YOLO point head 재사용/parity를 주장하지 마.

verify_bundle.py와 테스트를 먼저 실행하고, 실제 하나의 forward에서 features와 predictor 전체 출력의 provenance를 검증해. GT projection 산술만 아니라 실제 raw-image/feature alignment도 검사해. C4는 확인된 asset에만 허용하고 현재 표본0이면 C4_NOT_EVALUATED로 기록해.

지시문의 상류·기하·초기값 게이트가 충족되고 source/config가 동결된 경우에만 합성 prepared-feature P/direct/Hough ×3seed, 각2000step의 bounded pilot을 실행해. 실사 새 평가·online 전체학습·FINAL·GT수정·새 렌더·self-training·commit/push·외부 알림은 이번 범위 밖이야. 기존 v4 결과/판정은 그대로 보존해.

실험이 막히면 정확한 이유와 실제 완료 단계까지 보고해. 테스트 통과를 성능 성공으로 바꾸거나 GT선 oracle을 실제 예측성능으로 보고하지 마. 완료 시 perframe 수치/원점수/소스/진행판정/실패를 포함한 pallet_point_line_v5_review.zip을 만들어줘.
