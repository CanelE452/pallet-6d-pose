# GT audit of the point–line decoder pilot

Read-only audit requested 2026-09-09. See [PURPOSE.md](PURPOSE.md) for the protocol
and [Korean interpretation](../../../_docs/notes/pallet_dht_gt_audit.md) for results.

Baseline pooled-point P90 is exactly reproduced as 41.48732863482036px on the
original 2,738 observations/309 matched frames of DEV319. This establishes numerical
consistency, not that all manually annotated GT is accurate. Visible/source/manual
review subsets, off-image masks, GT field differences and actual GT-only inspection
are recorded separately. No GT, model, or completed pilot outputs were overwritten.

Run from the repository root with Python, numpy, scipy, Pillow and matplotlib:

```bash
python -m scripts.research.pallet_dht_gt_audit_v1.numeric_audit --help
python -m scripts.research.pallet_dht_gt_audit_v1.mask_policy_diagnostic --help
python -m scripts.research.pallet_dht_gt_audit_v1.gt_review_report --help
```

Outputs are under `data/pallet/results/pallet_dht_gt_audit_v1/`:

- `NUMERIC_AUDIT.json` and `.csv`: independently reconstructed errors and denominators,
  visibility/source/session/resolution/prior-review strata, provenance and bounds.
- `MASK_POLICY_DIAGNOSTIC.json`: fixed original predictions and matching, grouped by
  actual image-coordinate support; diagnostic subsets do not replace full-set results.
- `ROOT_GT_VISUAL_REVIEW.json` and `specialist_gt_review.json`: actual agent review
  coverage and uncertainties, not human approval or independent pixel measurements.
- `GT_REVIEW_QUEUE.json`: image-grounded re-review and provenance/visibility questions;
  no automatic invalid-GT denylist, canonical edits, or verified replacement coordinates.
- `AUDIT_CONCLUSION.json`, `gt_review.html`: interpretation and GT-first interactive
  review. Raw/GT/optional saved predictions and native-resolution point crops are distinct.
- `INPUT_SNAPSHOT.json`: preserves the 646 initial input hashes including all319 labels
  and raw images and the completed pilot artifacts.

The two script-generated audits are reproducible from their bound inputs. Qualitative
review records cannot be regenerated by rerunning a renderer: they record images that
agents actually inspected. Source hashes in the final completion receipt bind the code
that produced the artifacts. No new model inference/training or independent FINAL was
used. Contact sheet creation by itself is not a visual GT certification.
