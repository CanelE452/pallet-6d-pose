# V27: 8.78px은 이미지에서 어느 정도인가

**8.78px은 실제 모델의 성능이 아니라, GT로 후보와 이동량을 최적 선택한 전체 평균(8.780843px)이다.** 실사 잘림20%의 검출된 화면 밖 유효점558개/시드에서 구하고3시드를 평균했다. 아래는 시드1의 특정 점 사례이며, 개별 점 오차와 전체 평균을 구분한다.

8.78px은 원본 이미지 좌표에서 GT와 예측점 사이 직선거리다. 확대 화면에서는 더 크게 보이므로 각 그림의 **10px 눈금**을 기준으로 본다. 실제 길이mm로 바꾸려면 거리와 카메라/평면 정보가 필요하다.

**표시:** 녹색×=GT, 파랑○=기존 V12점, 빨강□=실제 V27 출력, 자홍★=GT oracle. 주황/보라/청록 선=L1/L2/L3(Hough 분기가 만든 선 중 해당 점과 association이 높은3개). 이는 새 Canny/HoughLines 실행이나 attention heatmap이 아니다. 선의 순위가 GT 정확도나 보정 효용 순위를 뜻하지 않는다.

**실선**은 입력 이미지 안의 예측 선, **점선**은 이미지 밖으로 연장한 선이다. 회색 영역은 실제 입력에서 잘려 나간 부분이다. 점선은 그 위치의 edge를 실제로 관측했다는 뜻이 아니다. 원본 패널은 상황 설명용이고 모델은 잘린 입력만 봤다. GT oracle는 점 후보도 선택할 수 있으며, 그 결과가 반드시 Hough 선 위에 놓이는 것은 아니다.

## 실제 모델도 개선한 사례

실제 모델도 점 오차를 줄인 예다. GT oracle는 두 선 교점 방향의 후보를 선택하면 더 줄일 수 있음을 보여준다. 실제 모델의 개선 전부가 선 덕분이라는 뜻은 아니다.

원본 `forklift_v4_173507_manual_gt/001980`, 점 ID3. 선택 후보: **L1 + L2 intersection**. GT 최적 이동 비율 1.000, 실제 모델의 해당 후보 이동 비율 0.004, 혼합 가중치 0.369%. 이동 비율은 제한된 후보 벡터에 곱하는 값이며 가중치는 검증된 확률이 아니다.

## 8.78px과 비슷한 오차

이 점의 oracle 오차8.79px이 전체 평균8.78px과 거의 같다. 자홍 별과 녹색× 사이의 점선 거리를10px 눈금과 비교하면 크기를 알 수 있다. 이 사례가 전체 데이터의 대표 이미지라는 뜻은 아니다.

원본 `forklift_v4_174925_manual_gt/000300`, 점 ID2. 선택 후보: **L1 normal**. GT 최적 이동 비율 1.000, 실제 모델의 해당 후보 이동 비율 0.030, 혼합 가중치 0.221%. 이동 비율은 제한된 후보 벡터에 곱하는 값이며 가중치는 검증된 확률이 아니다.

## 좋은 선 후보를 모델이 놓친 사례

선 후보와 적절한 이동량이 있어도 실제 모델이 그것을 선택하지 못한 경우다. GT oracle는 맞추지만 실제 빨간점은 크게 벗어난다. 회색 영역의 점선은 화면 밖으로 연장한 예측 선이다.

원본 `forklift_v4_20260904_144733_manual_gt/000546`, 점 ID0. 선택 후보: **L3 normal**. GT 최적 이동 비율 0.383, 실제 모델의 해당 후보 이동 비율 0.047, 혼합 가중치 0.000%. 이동 비율은 제한된 후보 벡터에 곱하는 값이며 가중치는 검증된 확률이 아니다.

![좋은 선 후보를 모델이 놓친 사례](figures/missed.png)


## 최적 후보로도 오차가 크게 남는 사례

GT로 최적 후보와 이동량을 선택해도 큰 오차가 남는 경우다. 현재 후보의 위치/방향/이동 범위가 이 점을 충분히 복원하지 못한다. 수동 GT를 새로 검증한 사례는 아니므로 GT 자체의 완전한 정확성을 인증하지 않는다.

원본 `forklift_v4_173507_manual_gt/003690`, 점 ID5. 선택 후보: **L1 normal**. GT 최적 이동 비율 1.000, 실제 모델의 해당 후보 이동 비율 0.015, 혼합 가중치 0.157%. 이동 비율은 제한된 후보 벡터에 곱하는 값이며 가중치는 검증된 확률이 아니다.

![최적 후보로도 오차가 크게 남는 사례](figures/oracle_bad.png)

## 선택 기준과 검증

좋은 사례는 선 후보 oracle<3px이고 실제 모델도 개선한 점 중 최대 개선, 평균 근처는8.78px에 가장 가까운 점, 선택 실패는 oracle<5px에서 실제와 oracle 차이가 가장 큰 점, oracle 실패는 oracle 잔차가 가장 큰 점을 골랐다. 모두 **결과를 기준으로 고른 설명용 사례**이며 분포를 대표하는 무작위 표본이나 새 평가가 아니다.

저장된 V27 후보·GT에서 oracle 평균을 다시 계산해 이전 결과와 일치함을 검사했다. 표시한 Hough 선의 실제 캐시와 점 ID를 맞췄고, 선택된 법선/교점 후보의 기하를 독립 재계산했다. 실제 모델의 점은 저장된10개 후보·이동량·혼합 가중치에서 재현했다. 원본 이미지와 잘림 좌표를 함께 보존했다. 새 학습이나 평가 수치 변경은 없다.
