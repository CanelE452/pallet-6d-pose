# 런타임 수치 일치 실패 진단

**기존 `atol=1e-4` 검사는 실패합니다. 허용치를 바꾸거나 parity PASS로 처리하지 않았습니다.**

동일한 고정 feature로 실행한 CUDA sparse HT와 역투표에서 비결정적인 부동소수 누적 차이를 재현했습니다. 고정 입력을 받은 reduce/Hough convolution/line head/spatial mix는 각각 200회 반복에서 정확히 같았습니다. sparse HT·역투표는 200회 모두 달랐으며 normalized 결과 차이는 각각 최대 2.38e−7, 3.58e−7입니다. `deterministic_algorithms=True`로도 이 변동이 사라지지 않았습니다.

CuDNN TF32를 끈 보조 실험에서 전체 Hough block 변동은 8.37e−6에서 4.77e−7로 작아졌지만 sparse 연산 자체의 변동은 유지됐습니다. 이 설정은 진단 과정에만 사용했습니다.

전체 26장×9모델×3회(702회), 별도 warmup234회를 수집했습니다. 모든 관측에서 후보 수와 score 순서는 정확히 같고, box 최근접 대응도 같은 후보 순서였습니다. Point-only는 모든 필드가 정확히 일치했습니다.

최대 사례는 `hough_features_seed2`, `eval_pallet07:1778652125245035520`, candidate0, point5/6의 x입니다. 정확도 캐시 대비 최대 0.006103515625px 차이이며 score는 같았습니다. 같은 이미지의 full predictor 100회 반복에서도 같은 크기 차이가 재현됐고 기존 기준은54회 실패했습니다. 원본 실패 로그에는 arm/frame 정보가 없어 당시 최초 실패 대상 자체를 소급 확정할 수는 없습니다.

**최소 조치 제안:** 원래 strict parity 실패와 정확도 캐시를 유지하고, 시간 측정 수집 완료와 수치적 일치 여부를 분리해 보고합니다. 관측 최대값을 근거로 임의의 새 허용치를 만들지 않습니다. Sparse 연산 또는 TF32 설정을 교체하려면 새 추론 버전으로 분리하고 정확도 전수 평가를 다시 연결해야 합니다.

실제 GPU 진단은 종료했습니다. 학습/평가/프로토콜/원본 runtime 및 모든 입력 SHA는 유지됐습니다. 개별 좌표와 반복별 근거는 `OBSERVATIONS.jsonl`, `OPERATOR_ISOLATION.json`, `FINDINGS.json`에 있습니다.
