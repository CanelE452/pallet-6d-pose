**6대조×3시드·18모델·실제36,000업데이트 완료. 전체 안정성+추가 선 이득 동시 기준: 미통과.**

## 이번에 바꾼 것

![구조](figures/architecture.png)

V32와 같은 물리 경계/끝점 감독, 공간 특징, 최종 점 head를 유지했다. 바꾼 부분은 선·끝점 특징을 점에 전달하는 방식이다. 원래 점과 강한 복원점 각각의 영상 패치·좌표·점 번호로16개 query를 만든다. 각 query는 해당 점에 연결된3개 cuboid 역할의 선/끝점 token에만 attention을 줄 수 있다. 상태 이름이나 GT는 forward에 없다.

선은 역할별 Hough 상위4bin, 총48후보다. 원래24각도×48ρ를 유지했으며 top4는 이웃 중복을 제거한 NMS가 아니다. 각 선 주변 실제 관측 영역의 예측 경계 확률을 적분해 support 중심·접선 표준편차·영상 특징을 얻는다. 법선·거리·중심·범위·확률과 역할을 token에 보존하고, 각 점과의 법선/접선 거리로 attention을 조정한다. 그림의 ±2표준편차는 관측 support 요약이지 실제 선의 정확한 양끝이 아니다.

끝점은 역할별8×8 공간 셀, 총768개다. 각 셀 안의48×48 예측 끝점 확률로 중심좌표를 계산해 작은 위치 차이를 보존한다. query와의 상대 변위·거리도 사용한다. 두 부모의 attention 결과를 합쳐 기존128차원 선/끝점 입력을 대체한다. 근거를 사용하지 않는 null token도 넣었다. 최종점은 V32와 같은 signed mix+대각선15% 이내2D잔차이며, 정확한 부모 보존이나 법선 이동만을 강제하지 않는다.

6대조는 전역 pooling / 점별 전체 대응 / 명시적 위치 관계 제거 / 선만 / 끝점만 / 경계 보조 감독만이다. 선만·끝점만은 반대 특징 전달 경로를 끈 상태로 처음부터 학습했다. 이 대조도 기존 점·영상 입력과24채널 경계/끝점 보조 감독을 모두 유지한다. 즉 선만 대조는 점 보정에 선 특징만 추가하는 모델이다. 모든 대조는 같은 파라미터 집합396,925개·초기값·배치·손실·2000업데이트를 사용하지만 실제 활성 용량과 계산량은 다르다. 위치 관계 제거는 명시적인 좌표 token/상대 거리 입력을0으로 만들며, 역할과 support 기반 영상 특징은 남아 있어 모든 암묵적 기하를 제거한 대조는 아니다.

Hough bin 선택 위치는 이산적이다. 선택된 vote·support/끝점 중심·attention을 통한 gradient는 전달되지만 top-k 인덱스 자체는 미분하지 않는다. 사전검사에서 점 손실이 각 대응 모듈까지 전달되고, 한 끝점 픽셀의 셀 중심이 정확히 복구되며, pooled 경로가 원래 V32 forward와 동일함을 확인했다.

## GT와 데이터의 범위

V32의 원본·실제 변형 영상·고정 부모 출력·물리 경계/끝점 라벨을 그대로 사용했다.153합성 원본의 기존 관측8개와 새 렌더 관측8개를 배치마다 섞었다.2CAD자산240RGB·600요청 관측 중436검출, 외관16학습/8확인 그룹이며 같은 자산이 양쪽에 있다. 물리적 CAD 체인은 실제지만, 가까운 평행 cuboid 경계에 역할을 붙이는 규칙이므로 완전한 인간 의미 경계 GT는 아니다. 체인 끝점과 평가하는 가상 cuboid 점도 동일하지 않다.

수동 클릭의 valid 여부·원본 해시·crop 좌표 변환을 다시 감사했고 GT를 수정하지 않았다. 이전 결과/입력 해시도 확인했다. 새 자산/자연 실사 가림·잘림에 대한 독립 평가라고 주장하지 않는다. 물리 패널 가림에서는 가상 corner의 hidden GT가 없어 가림점 성능으로 해석하지 않는다.

## 이번 결과로 수정한 판단

**점별 선·끝점 대응으로 바꾸는 것만으로는 안정화되지 않았다.** 잘림20에서 query 15.004px는 같은 전역 pooling 14.714px보다 나쁘고, 명시적 위치 관계를 제거한 대조14.869px보다도 좋지 않았다. 위치 관계 대조와의 차이95%구간은[-0.231,0.528]px로, 명시적 기하 입력의 유효한 추가 이득을 확인하지 못했다.

**선 경로 자체의 가능성과 선·끝점의 공존은 다른 결과다.** Query는 끝점만15.800px보다 세 시드 모두 개선했고, 선을 추론 중 끄면16.624px로 악화됐다. 그러나 처음부터 선만 학습하면14.090px로 전체 융합보다 세 시드 모두 좋았다. 추가 탐색 비교에서 선만은 전역 pooling 대비6.947/2.048/3.556% 개선,9세션 차이95%구간[-0.861,-0.359]px였다. 보조 감독만15.408px 대비도 모든 시드 개선했다. 이 결과는 이번 후보 중 선 단독 경로를 후속 검증할 근거이며, 전체 융합 성공이나 독립 최종 검증 통과는 아니다. 선 단독도 V12 기준12.372px/V30 13.385px에 못 미친다.

**잘 맞는 선을 기하적으로 사용한다는 증거는 여전히 약하다.** Query의 다른 세션 경계맵 교체는15.004→14.994px로 거의 변하지 않았고, 차이95%구간[-0.055,0.073]px였다. Seed1 잘림20에서 교체 전후 맵의 평균 절대차는0.067이고, 역할별 Hough top4 bin 집합의 겹침은13.3%였다. 단순히 같은 선 후보여서 변화가 없었다고 설명하기도 어렵다. 다만 수신 이미지의 영상 특징은 token에 남기므로 이 개입이 모든 선/영상 정보를 제거한 것은 아니다. 현재 선 경로의 이득이 특정 선 위치의 제약보다 영상 특징 요약이나 보정의 기준값 제공에서 나왔을 가능성이 남는다. Attention 활성도나 경로를0으로 만든 악화만으로 순수 Hough 기하 효용을 확정하지 않는다.

**기존 이득 보존도 해결되지 않았다.** 코너 가림에서 query13.596px는 강한 점 복원11.907px보다 나쁘다. 큰 잘림은18.452px로 강한 점19.382px보다 평균이 좋지만, 가림·약한 잘림·원본 일부 시드의 보존 기준을 동시에 통과하지 못했다. 두 부모를 query에 남기는 것과 좋은 부모를 실제로 지키는 것을 구분해야 한다.

## 재현 변동과 gradient surgery에 관한 근거

같은 초기 공통 가중치·데이터·배치·손실의 전역 대조를 재학습했으나 V32의14.343px와 이번14.714px가 완전히 같지는 않았다. 공통 초기 가중치 해시와 첫 손실은 일치했고, 전역 대조는13/32/34step부터 약7e-9~1.5e-8의 손실 차이가 나타났다. 최종 개별 예측의 최대 좌표 차이는 두 반복 대조 전체에서23.891px였다. 현재 FP32 실행은 deterministic algorithms 강제가 꺼져 있었다. 이는 작은 수치 차이에 따른 학습 경로 변동과 부합하지만 단독 원인을 완전히 분리한 실험은 아니다.

별도 단일 CUDA grid_sample backward는 deterministic algorithms를 켠 상태에서도 실행됐다. 따라서 결정적인 실행이 이 환경에서 불가능하다고 주장하지 않는다. 전체 학습을 결정적으로 재실행해 두 번의 일치와 성능 분산을 검증한 것은 아니며, 다음 개선 판정에는 이 검증을 포함해야 한다. 이번 내부6대조는 같은 절차로 학습했고 모든 시드를 보고했지만, 작은 평균 차이를 안정적인 구조적 성과로 과장하지 않는다.

공유 trunk의 고정 첫 혼합 배치에서 점/경계 손실 gradient cosine은 query의3시드 평균+0.309였다. 이 표본은 gradient 충돌이 필수적인 직접 원인이라는 가설을 지지하지 않는다. 한 배치이므로 학습 전체의 충돌이 없다는 증명도 아니다. PCGrad를 적용하면 개선된다는 근거는 아직 없고, 이번에는 실행하지 않았다.

## 원인 가설과 다음 우선순위

1. **위치 관계를 전달하는 것과 그것으로 보정하는 것은 다르다.** 이번 모델은 거리를 입력받아도 자유로운2D head가 다른 영상 특징과 부모 점으로 예측할 수 있다. 기하 제거/다른 세션 교체의 작은 변화는 이 경로의 실제 효용을 먼저 입증해야 함을 보여준다.
2. **물리 체인 끝점과 가상 cuboid 점의 대응이 불완전하다.** 근접 평행 경계 역할은 실제 점까지의 이동량을 보장하지 않는다. 선 단독에 끝점을 합쳐 악화된 것은 이 의미 차이와 최적화/표현 경쟁 가능성을 남긴다. 현재 결과만으로 그중 하나를 확정하지 않는다.
3. **다음은 선 단독을 기준으로 좁힌다.** 먼저 결정적 반복 학습과 동일 실험 반복으로 수치 변동을 측정한다. 그다음 같은 선 단독 모듈에서 실제 선 위치를 유지/이동/교체했을 때 보정 방향이 따라가는지 반사실 검사를 한다. 이미지별 선 기하 효용이 확인되기 전에는 새로운 adaptive gate를 추가하지 않는다. 끝점은 가상 점과의 역할·offset 대응을 검수한 뒤 하나의 요인으로 다시 추가하는 것이 낫다.

이번 실험으로 점·선 융합 자체가 불가능하다고 결론 내릴 수는 없다. 다만 **전역 압축만 바꾸면 해결된다는 가설은 이번 데이터·예산에서 지지되지 않았고, 선 단독의 부분 효과를 안정적으로 재현하고 기하 효용과 연결하는 일이 먼저**다.
