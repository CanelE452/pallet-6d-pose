# deep_hough_side_v1

합성 학습만으로 팔레트 좌우 측면 외곽 8개를 예측하는 Direct8와 특징 집계 DHT8의 비교 실험이다. 같은 고정 VGG 특징·데이터·격자·손실·학습 예산을 사용한다. 후보 선을 따라 특징을 모으는 구조가 실사 선 정확도에 도움이 되는지 확인한다.

본학습 전 고정한 설계는 [실험 프로토콜](../../../../_docs/experiments/deep_hough_side_v1/README.md)에 있다. 실행 설정과 이 문서가 다르면 실행 기록을 확인하고 차이를 보고해야 한다. 이 파일에는 아직 학습 성능 결과를 기록하지 않았다.

대상은 기존 cuboid 정답의 구조적 측면 외곽선이며, 가려진 선도 포함한다. 카메라를 향한 면의 선은 기하적 보조 집합이며 물리적 가시성 정답이 아니다. 기존 실사 DEV52를 사용하며 새로운 독립 최종 테스트가 아니다. 백본의 합성 사전학습 원본과 평가셋의 전체 중복은 미검증이다.

계획: 합성 2,048장 학습, 256장 검증, 256장 동일 생성 계열 평가, 128장 다른 합성 평가, 실제 DEV52 평가. seed 1·2·3, 각 구조 6,000 step, batch 12. 별도 sanity는 DHT seed 101, 합성 32장, 1,500 step이다.

`target_audit/TARGET_AUDIT.json`과 네 정답 그림은 본학습 전 생성한 기하 감사이다. 선 오차나 지도 시각화를 해석할 때 학습 성능과 구분한다.

본학습 전 검토에서 기존 연속 격자와 실제 VGG 특징 픽셀 중심의 반 픽셀 차이를 보정했다. 최종 좌표는 `(original_xy+pad+0.5)*50/padded_image_size-0.5`를 사용한다. 수정 전 실행은 `preliminary_continuous_grid_sanity/`에 보관하며, 수정된 좌표로 검증·sanity를 다시 실행한다. 이전 예비 결과를 최종 결과와 혼합하지 않는다.
