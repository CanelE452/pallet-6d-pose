# GATE D — 융합 pseudo-target 의 품질 (학생 학습 전 감사)

TARGET_UNLABELED 에는 GT 가 없다. 그래서 **완전히 같은 규칙**을 DEV_EVAL 에 적용해
target 이 R0 보다 나은지를 학생을 학습하기 **전에** 잰다.
GT 는 채점에만 쓰고 target 생성에는 들어가지 않는다.

abstention 은 METHOD_LOCK 에 사전등록돼 있다 — 교사 불일치가 τ 를 넘으면 그 keypoint 에
real loss 를 주지 않는다. 따라서 품질은 **usable 부분집합**에서 재고 coverage 를 함께 싣는다.

## 판정

```
DISTILL_TARGET_QUALITY = FAIL
결과: METHOD_LOCK 규칙에 따라 student 학습을 하지 않는다.
```

전부 0 을 포함한다. 정확히 말하면 **"융합이 R0 보다 나쁘다" 가 해소된 것이 아니라
"융합이 R0 보다 낫다는 증거가 없다"** 이고, 점추정은 모두 나쁜 쪽이다.
게이트는 target 이 R0 보다 **최소한 같기라도** 할 것을 요구하므로 FAIL 이다.

## 왜 이렇게 되는가 — 세 결과가 한 방향을 가리킨다

```
Gate A   교사 하나당 R0 gross 의 8~9% 를 구제하고 합집합이 30.3% 다 (상보성 실재)
Gate A   그런데 파라미터 없는 융합(F1/F2)은 p90 을 43.9 -> 70~73 으로 악화시킨다
Gate D   불일치로 걸러낸 usable 부분집합에서는 R0 자신이 이미 좋다
         (median 6.97 -> 5.80, p90 60.31 -> 20.14)
```

즉 합의 필터는 **R0 가 이미 맞힌 자리**를 고른다. 정답이 다른 교사에게 있는 자리는
정의상 교사들이 불일치하는 자리이고, 그런 자리는 abstain 된다.
"어디가 틀렸는지" 는 알지만(불일치 AUC 0.79) "무엇이 맞는지" 는 여전히 모른다 —
그리고 pseudo-label 은 후자를 요구한다.

## 사후 조정하지 않은 것

- τ 를 늘려 coverage 를 올리지 않았다 (그러면 usable 부분집합의 품질이 더 나빠진다).
- 세 검사 중 하나만 통과하면 되도록 완화하지 않았다.
- `USABLE_visible_only` 에서 F1 의 p90 이 R0 보다 약간 낮다는 점을 근거로
  primary 부분집합을 바꾸지 않았다.
