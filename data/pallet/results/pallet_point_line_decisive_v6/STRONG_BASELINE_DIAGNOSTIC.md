기존 강한 YOLO를 잊고 새로운 약한 점 head만 이기는 결과를 성공으로 오인하지 않기 위해,
원래 R0의 같은 505 matched instance 추론을 별도 확인한다. 이 진단은 새 모델의 평가 결과를
읽기 전에 추가했다. 고정 main gate·학습·checkpoint 선택을 변경하지 않는다.

YOLO는 camera-dynamic ID, 공동 자세는 fixed object-frame ID이므로 단순 같은-ID 뺄셈이
불가능하다. 양쪽에 동일하게 8코너의 최적 일대일 공간 대응을 **평가에서만** 적용한 오차를
보고한다. 이것은 번호 오류를 면제한 기하 진단이며 실제 번호 보정 아키텍처나 main metric이
아니다. 새로운 모델의 기하 오차조차 원래 모델보다 크면 원래 성능을 개선했다는 주장을
할 수 없다는 보조 확인에만 사용한다.
