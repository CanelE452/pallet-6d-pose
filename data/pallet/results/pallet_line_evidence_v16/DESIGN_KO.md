# V16: 후보별 선 구간의 영상 근거와 경계 역할

V15의 큰 선 후보는 GT로 최선을 고르면 추가 개선 여지가 있었지만, 실제 평가기는 좋은 보정과 나쁜 보정을 구별하지 못했다. V16은 후보 집합을 고정한 상태에서 후보별 선 구간의 영상 근거와 보조 역할 학습이 선택을 개선하는지 검증한다.

## 구조

입력 이미지 → 고정 YOLO → 고정 점 보정/복원 및 Deep Hough → 점별 8개 후보 → 후보별 선 특징 평가 → 유지 또는 보정 선택.

기존 5후보(유지, 복원 0.5/1, 작은 선 보정 0.5/1)에 상위 3개 Hough 선의 법선 방향 보정을 더한다. 큰 선 후보는 상자 대각선의 5% 이내로 이동한다. GT로 후보를 거르는 추론 필터나 self-training은 사용하지 않는다.

후보마다 점과 연관된 상위 3개의 예측 선에 내린 수선의 발을 중심으로, 상자 대각선 ±35% 길이에서 7개 위치와 선 양옆 ±1.5% 위치를 샘플링한다. 기존 YOLO의 192×24×24 특징을 8채널로 투영하여 선 위/주변을 읽는다. 실제 이미지나 ROI 밖 샘플은 0으로 마스킹한다. 이 구간은 예측 선을 읽는 유한한 창이며 GT로 정한 선의 끝점이 아니다. 기존 특징의 수용 영역에는 반사 패딩의 영향이 남을 수 있다.

각 샘플은 해당 꼭짓점에 연결된 긴 경계/높이 경계, 다른 경계, 배경의 4종 역할을 예측한다. 샘플 토큰과 역할 확률을 후보별로 집계해 기존 점 기반 후보 점수에 더한다. 최종 보정량 자체를 GT에 강제 투영하지 않는다.

## 보조 GT의 범위

카메라 기준 0123 규약은 `challenge/yolo_pose_one_model/paper_generic_pipeline/build_eval_manifest.py`의 `_object_points`로 확인했다. 0–3 앞면, 4–7 뒷면이며 높이선은 1–2, 3–0, 5–6, 7–4이다. 12개 유한한 cuboid 경계와 샘플 중심의 거리가 2.5px 이내인 경우 역할을 부여한다. 인공 가림 영역과 화면 밖은 영상 지지가 없는 배경으로 둔다. 8점 모두 유효하지 않은 합성 프레임은 보조 역할 손실에서만 제외하며, 유효점의 보정 손실은 유지한다.

이것은 원래 점 GT에서 유도한 **기하적 경계 역할의 대리 정답**이다. 실제 목재 표면의 edge, mesh 가시성, 자연 self-occlusion 또는 실루엣의 완전한 정답이 아니다. 추론 입력에는 GT, 가림 정답, 조건명이 들어가지 않는다.

## 통제 실험

| 모델 | 선 구간 특징 | 보조 역할 손실 | 보정 손실 |
|---|---|---|---|
| control | 후보 점수 입력 0 | 없음 | tau 0.2 |
| strip | 사용 | 없음 | tau 0.2 |
| role | 사용 | CE ×0.25 | tau 0.2 |
| balanced_role | 사용 | CE ×0.25 | tau 0.2 + V15 사례 균형 |
| median_role | 사용 | CE ×0.25 | tau 0.5 |

모든 구조는 같은 파라미터 초기화, 같은 8후보와 학습 순서로 비교한다. 보조 CE 클래스 가중치는 합성 학습 샘플 빈도의 역제곱근으로 정한다. `strip-control`은 특징 입력, `role-strip`은 보조 학습 효과를 분리한다. balanced/median은 손실도 달라지므로 그 차이를 선 특징만의 효과로 해석하지 않는다.

각 3시드, 2000업데이트, batch16, AdamW 3e-4, weight decay 1e-4, float32, gradient clip5, 마지막 체크포인트를 고정한다. 총 30,000업데이트. 기존 YOLO/점/복원/DHT 부모는 고정한다. 부모에서 분리했던 합성 253장, 6조건의 검출 관측 1462개만 새 평가기 학습에 쓴다. 이 실험은 저비용의 고정 특징 구조 검증이며 전체 end-to-end 재학습은 아니다.

## 평가와 기준

실제 297장·9세션·수동 1251점 및 합성 505장의 재사용 DEV, 8조건을 그대로 쓴다. 자연 가림은 unknown이다. 인공 가림/잘림, 원래 점 번호, 검출 실패, reflect100 입력을 보존한다. crop10/30은 학습하지 않은 비율이다. 실제 GT는 학습·시드 선택·임계값 선택에 사용하지 않는다.

모든 시드에서 원본과 잘림10/20/30% 오차가 기준의 101% 이하이면서, 코너 가림 및 잘림40%에서 기존 amodal 복원 이득의 80% 이상을 유지해야 전체 안정성 통과다. 선 특징의 추가 이득은 동일 손실 대조군에 대해 모든 시드 1% 이상 개선 및 실제 9세션 paired bootstrap 95% 상한이 0 미만인지 확인한다. 여러 조건의 탐색 결과이며 다중 비교 보정 없는 구간이다.

같은 `role` 모델에서 후보를 유지한 채 선 특징 임베딩만 끄거나 다른 이미지의 특징으로 바꾼다. 이 개입은 입력 분포 밖 진단이므로 이것만으로 실제 유용성을 입증하지 않는다. 독립 좌표/지표 재계산, 보조 GT float64 재검산, 통합 추론과 캐시 일치, 선 위 샘플 및 역할 확률 시각화를 함께 확인한다.
