# V15: 악화 억제와 어려운 조건 개선을 함께 유지할 수 있는가

사용자 요청: 안정적으로 개선되려면 무엇이 필요한지 생각하고 실제로 실험한다.

V14에서는 예상 보정 이득의 부호가 실제와 맞지 않았고, 선 후보의 이동량 및 추가 oracle 이득도 작았다. 이번에는 과도하게 낙관적인 후보 선택과 약한 후보 생성 문제를 구분한다. 결과에 따라 실제 평가용 임계값을 조정하거나 모델을 고르지 않는다.

## 고정한 대조 실험

1. median_old: 기존5후보, 중앙값(pinball tau0.5) 개선량 학습.
2. risk_old: 동일 후보·모델·데이터에서 하위 분위수(tau0.2)로 변경.
3. balanced_old: 보수적 손실에 합성 악화·중립·개선 사례의 가중치 균형 추가.
4. balanced_rich: 위 설정에 DHT 선에서 직접 제안한3개 이동 후보 추가.

4구조 모두8후보 슬롯을 갖는 같은 모델로 초기화하고, 기존 후보 대조군은 마지막3개를 비활성화한다. 같은 합성253장/1462관측, 동일 batch순서와2000업데이트, 각3시드로 총24000업데이트. 모든 부모 네트워크는 고정한다. 기존 V14는 추가 비교 기준이며 초기화·손실이 동일한 대조군은 아니다.

과대평가를 더 강하게 벌점화하는 pinball 손실만 사용하며 V14의 후보선호 CE는 사용하지 않는다. 부호 균형은 합성 노출 상태와 후보별로 gain<-0.25px / 중립 / gain>0.25px의 역빈도 가중치(최대10)를 준다. 유효 학습점을 제거하지 않는다. 균형을 준 분포에서 학습한 보수적 점수는 자연 실사에서의 보장된20% 분위수나 성공확률이 아니다.

새 선 후보는 기존 DHT가 출력한 상위3개 점별 연관 선을 사용한다. 기준점을 각 선의 법선 방향으로 이동시키되 최대 이동량은 관측상자 대각선의5%다. 최종점을 선에 강제로 맞추지 않고 유지 후보와 함께 선택한다. 선을 맞게 선택했을 때의 추가 개선 여지는 사후 GT oracle로만 분석한다.

## 안정성의 정의

세 시드 모두 원본과 약한 잘림에서 기존 V12 억제 기준 대비 악화1% 이내, 코너 가림·심한 잘림에서 기존 V12 복원 이득80% 이상 유지. 보정을 전부 끄는 모델은 어려운 조건의 이득 유지 기준에서 실패한다.

추가로 학습에 없던 crop10/crop30 비율을 원래 합성505장/실제297장에 적용해 새로 YOLO 추론한다. 이때 화면 밖 점도 기준 대비1% 이내여야 전체 안정성 기준 통과다. 새 비율은 사전 등록했지만 원래 이미지들이 재사용되므로 새 독립 장면/현장 검증은 아니다.

개선량·시드·세션별 오차, 해로운 보정 비율, 놓친 개선, 큰 악화, P90/PCK/검출 실패 포함 지표를 함께 기록한다. 선 추가 이득은 balanced_rich가 balanced_old보다 해당 대상에서 모든 시드1% 이상 개선하고9세션 bootstrap95%구간 상한이0 미만일 때 인정한다. 기존6조건에는 선 제거·다른 영상 선 대조군도 사용한다.

기존 합성 calibration253장은 V14부터 학습용이며 평가로 사용하지 않는다. 실제 직접 클릭GT는 학습·정상 추론에 넣지 않는다. 수동 클릭 오차 재측정, 자연 가림 라벨, 최종6D 성능의 검증은 별개다.
