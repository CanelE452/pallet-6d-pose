# V22 점 거리 손실과 부모 문맥 검증

전체 안정성 미달 · 이번 수정도 큰 이득 유지와 악화 억제를 동시에 해결하지 못함

기존 실패를 손실 목표와 부모 문맥 의존이라는 두 가설로 나눴다. 동일 합성 데이터·초기값·배치에서 BCE/점 거리 손실 × 부모64D 문맥 유지/제거의2×2와 선 토큰을 제거한 두 국소 대조를 실행했다. 초기18모델·36,000업데이트에, 결과 확인 후 BCE 사전학습 상태에서 손실을 전환하는 후속6모델·12,000업데이트를 추가했다. 총24개 최종 모델이며 실제 실행한 업데이트는48,000회다. 후속 모델은 초기 BCE의2000업데이트를 공유한다.

## 가장 직접적으로 확인한 실패 구조

모델이 합성에서 평균 오차를 줄이는 보정 정책과 실제에서 필요한 정책이 약한 잘림에서 반대였다. 기존 학습 데이터의 모든 점에 공통 적용률 하나만 준다고 가정하면 최적값은100%였다. 점별로 구분하지 못해도 전부 보정하는 방향으로 학습 평균 오차를 줄일 수 있다.

실제 유효점의8개 ID 구성비까지 맞춘 잘림20% 진단에서는 합성 최적 공통 적용률97.9%, 실제0%였다. 잘림40%는 합성100%, 실제97.8%였다. 즉 합성에서는 약한/큰 잘림 모두 거의 전부 보정해도 유리한데, 실제 약한 잘림에서는 이미 잘 맞는 점을 움직여 평균 오차가 늘어난다. 실제 점별 최적 적용률을 알면0% 공통 정책보다 더 좋아질 수 있으므로 모든 실제 점을 무조건 멈춰야 한다는 뜻이 아니다.

| 조건 · 점 ID 구성 일치 | 합성 최적 공통 적용률 | 실제 최적 공통 적용률 |
|---|---:|---:|
| 잘림20% 화면 밖 점 | 97.9% | 0.0% |
| 잘림40% 화면 밖 점 | 100.0% | 97.8% |

이 값은 GT를 사용하는 사후 진단이다. 학습 가중치나 추론 규칙으로 사용하지 않았다. 자세·질감·크기까지 맞춘 비교가 아니므로 이 차이가 모든 실패의 유일 원인이라는 증명은 아니다. 다만 단순히 학습 손실을 더 잘 최소화하면 실사도 좋아질 것이라는 가정이 현재 조건에서 성립하지 않는다는 직접적인 증거다.

## 가설을 수정해서 확인한 결과

손실의 목표가 문제인지 검사하기 위해 최적 적용률 BCE 대신 최종 점 거리로 학습했다. 코너 가림은12.899→12.147px로 개선했지만 잘림20%는14.279→14.939px, 잘림40%는20.803→21.283px로 악화했다. 합성 학습의 화면 밖 점 중91.8%가 적용률99%를 넘었고, 나쁜 보정에도96.4%, 좋은 보정에는98.2%를 적용했다. 실제 점 거리 목표를 쓰는 것만으로는 점별 판단이 좋아지지 않고 거의 전부 보정하는 해로 굳었다.

부모64D 문맥에 의존하는 것이 문제인지도 별도로 확인했다. 문맥을 제거하고 처음부터 BCE로 학습하면 코너 가림13.010/잘림20%14.571/잘림40%20.857px였다. 원래 BCE보다 모두 소폭 나빴다. 문맥 제거와 점 거리 손실을 함께 적용해도 잘림20%15.649px로 악화했다. 기존 모델이 문맥에 민감한 것은 맞지만 문맥이 해롭거나 제거하면 해결된다는 가설은 지지되지 않았다.

점 거리 손실에서 조기에 포화되는 문제를 줄이기 위해, BCE로 이미 학습한 특징과 적용률에서 점 거리 학습을 이어가는 후속을 추가했다. 합성 화면 밖 점의99% 초과 적용률 비중은 처음부터 거리 학습91.8%에서52.6%로 줄었다. 나쁜/좋은 보정 적용률도96.4%/98.2%에서65.7%/90.5%로 분리됐다. 초기 포화는 일부 완화할 수 있었다.

후속의 실제 결과는 코너 가림12.178/잘림20%14.236/잘림40%21.500px였다. 처음부터 거리로 학습한 것보다 잘림20%가0.703px 개선됐고 모든 시드1% 이상 개선과9세션95%구간[-1.285,-0.249]px를 통과했다. 그러나 같은 추가 학습량의 BCE 연장 대조군은12.725/13.783/21.195px였다. 거리 전환은 이 대조보다 코너 가림을0.547px 개선하면서 잘림20%를0.453px 악화했다. 학습 순서 수정도 큰 이득 보존과 약한 잘림 보호를 동시에 해결하지 못했다.

## 무엇이 아직 해결되지 않았는가

현재 구조는 고정 보정 벡터의 적용률만 고른다. 잘림20%의558개 검출 유효 대상점 중, 보정이 정답 반대 방향인 점은 시드 평균326.7개였다. 방향이 틀리면 이 구조가 할 수 있는 일은 멈추는 것이다. 정답으로 최적 적용률을 고르면 동일 벡터에서도14.279→10.972px까지 줄일 수 있어 방향 제한만이 원인은 아니다. 현재 모델이 멈춰야 할 점을 실제에서 충분히 구분하지 못하는 부분이 크다.

선 토큰 유무의 추가 효과는 이번에도 모든 시드1% 이상 개선과 세션 구간 기준을 함께 통과하지 못했다. 점 거리 학습으로 코너 가림이 좋아진 것을 Hough의 새로운 이득으로 주장하지 않는다. 선을 읽는 경로가 동작하는 것과, 그 선이 보정 여부를 판단하는 데 유용한 것은 다르다.

현재 증거가 지지하는 원인은 합성에서 유리한 보정 정책과 실제 약한 잘림에서 필요한 정책의 차이, 그리고 이를 넘어설 점별 판단을 충분히 배우지 못하는 것이다. 점 거리 손실의 포화는 여기에 추가되는 학습 문제였고 사전학습으로 일부 완화됐다. 문맥 제거와 손실 교체만으로 해결된다는 가설은 이번 대조에서 실패했다. GT 좌표나 기울기 계산의 구현 오류는 검사 범위에서 발견하지 못했다.

## 학습 프로브는 무엇을 보여줬는가

현재 가중 BCE는 GT로 구한 최적 적용률을 맞춘다. 점별로는 실제 거리와 최적점이 같지만, 서로 다른 점의 실제 오차 증가량을 똑같이 반영하지는 않는다. 예를 들어 길이10px인 수평 보정에서 GT가 기준점에 있으면 전체 이동의 악화는10px이고, GT가 수직20px 떨어져 있으면 악화는2.361px이다. 두 사례의 최적 적용률0과 BCE 가중치10은 같다.

이 차이가 실패의 주원인인지는 별개다. 실제 합성 학습 프로브에서 두 손실 기울기의 부호가 반대인 유효점은0개였고, 기존 BCE 기울기 상위20%가 실제 점 거리 기울기의 큰 비중도 차지했다. 따라서 프로브만으로 심한 목표 충돌이나 거리 손실의 우월성을 주장하지 않았다.

## 정확히 바꾼 것

점 거리 손실은 최종점과 원래 GT 사이의 raw-pixel Euclidean 거리 평균이다. 원래 유효점을 모두 사용하며 새 그룹 가중치·악화 벌점·GT 필터·self-training은 추가하지 않았다. 원래 BCE와 동일2000업데이트, AdamW3e-4, weight decay1e-4, float32, gradient clip5, 마지막 체크포인트로 비교했다. 학습 데이터는 기존 합성253장/1462검출 관측/6조건이다.

후속은 초기 unit_bce의 최종 상태를 양쪽에 똑같이 불러온 뒤 optimizer를 동일하게 초기화하고 같은2000배치를 추가한다. BCE를 유지하는 대조와 점 거리로 전환하는 모델을 비교한다. 초기 결과를 본 뒤 추가한 탐색적 실험이다. 원래 체크포인트를 덮어쓰지 않았다.

문맥 제거는 rep.context64D만0으로 만든다. 부모의 가시성 확률·전체 복원 차이·점 ID·YOLO 영상 특징·좌표·보정 방향과 길이는 유지한다. 완전히 부모 정보를 없앤 실험은 아니다. 추가 선 토큰을 제거한 국소 대조군도 기존 부모의 선 학습 영향을 공유한다.

최종점=p0+sigmoid(logit)×고정 V18 보정 벡터d. 손실과 입력 문맥을 바꾼 학습 가능한 적용률 모듈이며 YOLO/DHT 전체 end-to-end 재학습이나 새로운 방향의 보정은 아니다. 이번 단계에 PCGrad를 함께 추가하지 않아 손실/문맥 변경 효과와 구분했다.

선 샘플의 유효성은 화면과 검출박스의 교차로 정한다. 화면 안의 가림 영역이나 배경도 포함할 수 있으며 실제 파렛트 경계를 검증한 것은 아니다. 이 가시성 문제를 수정한 실험으로 해석하지 않는다.

## GT·기울기·통합 검증과 한계

실제 수동 클릭 source/ID/유효점과 조건별 좌표 이동을 재검산했다. 총293,558예측 프레임 행의 지표 최대 재계산 차이는1.07e-14, 보정 재구성 최대 차이는0.00006071px다. 원래 기준점·벡터·검출 누락을 유지했다. 거리 손실 기울기는 독립 float64 유한차분 검사에서 최대 차이6.47e-10였다.

문맥 제거 모델은 문맥을 바꿔도 출력이 정확히 같았다. 선 부호 불변성과 추가 선 투영층의 기울기 경로를 확인했고, 통합24모델×6조건×4프레임의 좌표가 캐시와0.001px 이내로 일치했다. 48,000업데이트의 손실·기울기가 유한했고 BCE 대조군은 이전 모델을0.001px 이내로 재현했다.

실제297장·9세션·1251수동점, 기존 합성505장과 V21 확인용253장을 재사용한 탐색적 평가다. 마지막253장도 이번에는 이미 확인한 데이터이며 원래 YOLO 검증 풀 출신이다. 새 최종 holdout이나 자연 가림 GT를 확보한 것은 아니다. 코드가 클릭을 정확히 사용했음을 확인했지만 수동 클릭의 물리적 오차0을 인증하지는 않는다. 운영 모델을 교체하지 않았고 실사 성능으로 시드나 체크포인트를 선택하지 않았다.
