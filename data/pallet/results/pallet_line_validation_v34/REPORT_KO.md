# V34 반복 재현성과 선 위치 반응 검증

**총24모델·48,000업데이트 검증 완료. 수정 경로 반복 가중치/trace 일치=True, 예측 일치=True. 전체 성능 안정성+추가 선 이득=False. 선 위치 반응/효용 기준=False.**

같은 구조를 유지하고 재현성을 방해하는 구현을 분리했다. 최종 잘림20 점+선은 13.674px, 같은 수정 연산의 전역 대조는 15.937px, 기존 기준점은 12.372px다. 재현성 성공과 정확도 개선은 별개 판정이다.

## 같은 학습이 정말 반복됐나

초기12모델은 strict deterministic algorithms, cuDNN deterministic, CUBLAS workspace :4096:8, TF32 off, FP32를 사용했다. CUDA adaptive_avg_pool2d backward가 지원되지 않아 첫 업데이트 전에 멈췄다. 정확히 나누어지는 격자만 사용하는 것을 확인하고 같은 평균을 계산하는 고정 avg_pool2d로 바꿨다. 첫 실패는 업데이트0회이며 원본 코드·로그를 보존했다.

그러나 같은 가중치/입력의 반복 backward에서도 grid_sample 입력 gradient가 달라졌다. 개별 연산 검사에서 최대1.19e-7 차이였고, forward는 같았다. 결정적 옵션이 켜져 있다는 사실만으로 실제 재현성이 검증된 것은 아니었다. 다른 연산들의 동시 원인이 전혀 없다는 주장과 구분한다.

두 번째12모델은 고정된 샘플링 좌표의 bilinear/zero-padding/align_corners=True 연산을 dense 선형 연산자로 구성해 bmm으로 계산했다. 출력과 입력 gradient의 float64 동등성, float32 반복 gradient 일치를 확인했다. 기존 점/영상/라벨/초기값/배치/손실/2000업데이트를 유지했다. 학습 아키텍처를 새로 설계한 비교가 아니라 동등한 수학 연산의 구현을 수정한 검증이다. Grid 좌표에 대한 학습은 지원하지 않으며 현재 고정 부모 좌표에서만 사용한다. 이 dense 구현의 메모리·속도는 별도 최적화하지 않았으므로 운영용 교체로 채택한 것이 아니다.

## 선 위치를 바꾸면 보정 방향이 따라가나

각 점의 두 부모 query attention을 평균해 가장 큰 선 token을 GT 없이 골랐다. 그 선의 법선 방향으로 offset과 support 중심만 ±4/±8px 이동했다. 법선, 역할, confidence/질량/범위, 영상 특징과 다른 token, 점 부모, 원본 이미지는 고정했다. 입력 선을 옮긴 만큼 점이 반드시1:1로 따라야 한다는 가정은 하지 않는다.

응답률은 `(점(+h)−점(−h))·선 법선/(2h)`다. 양수는 선 이동 방향으로 반응,0은 무반응, 음수는 반대다. 사전 기준은 활성 query(top-token attention≥.01)의 시드별 중앙 응답률>.02 및 양의 반응 비율>.60을4/8px 모두 만족하는 것이다. 1e-4 이하의 양수는 수치 미세변화로 제외했다. 전체/활성/화면 밖·가림 하위군을 모두 저장했으며 이 수치는 실무 판정 기준이고 물리 법칙이 아니다.

## 분모·GT·해석 범위

검출 실패 포함 원본 대각선 정규화 오차, P90/PCK 및 모든 조건의 분모는 SUMMARY.json에 저장했다. 점 평균은 검출된 유효점에 대한 값이다. 원래 수동 클릭 GT의 valid·파일 해시·crop 좌표를 재감사했고 수정하지 않았다. 이는 라벨 전달 오류가 없다는 검사이며 손으로 찍은 모든 점이 실제 정답에 정확히 놓였다는 증명은 아니다. 클릭 오차의 크기를 이번에 새로 측정하거나 교정하지 않았다. V32의153원본+물리 렌더 관측/라벨을 그대로 사용했으며2CAD 자산이 렌더 학습/확인에 공유된다. 물리 체인 끝점과 가상 cuboid 점 역할의 의미 차이는 이번 연산 수정으로 해결되지 않는다.

신뢰구간은3시드를 먼저 평균하고 세션/합성 그룹을 묶어 재표집했다. fresh_check는2개 원천 그룹뿐이므로 해당 그룹 구간을 강한 일반화 근거로 보지 않는다. 이미지별 선 feature 반사실은 실제 이미지 재렌더와 다르고, 방향 반응을 보이는 것과 올바른 점을 복원하는 것은 별개다.

## 최종 판단과 다음 결정

**재현성 문제는 해결했지만, 선의 기하로 점을 안정적으로 보정하는 구조는 이번에도 검증되지 않았다.** 점+선이 전역 pooling보다 좋은 부분 효과는 세 시드에서 재현됐다. 이를 전부 우연으로 취급할 근거는 없지만, 정확한 선 위치가 보정 방향을 알려줘서 얻은 개선이라고 부를 근거도 없다.

- **해결:** 같은 장비·라이브러리·초기값·배치에서 두 반복의 가중치, 2000step 전체 기록, 평가 예측이 모두 정확히 일치한다. 첫12모델의 변동과 최종12모델의 일치를 모두 보존했다. 결정적 옵션만 켠 상태와 실제 반복 결과를 구분했다.
- **부분 효과:** 잘림20 화면 밖 점에서 점+선13.674px는 같은 연산의 전역 대조15.937px보다 세 시드 각각15.36/7.76/18.67% 좋다. 9세션 차이95%구간[-2.927,-1.628]px. 그러나 기준점12.372px에는 못 미치고 가림14.145px도 강한 점11.907px보다 나쁘다. 큰 잘림17.996px는 강한 점19.382px보다 평균이 좋지만 모든 조건의 안정성을 뜻하지 않는다.
- **남은 실패를 좁힌 증거:** 잘림20 활성 유효점에서 선 token을 ±4px 이동했을 때 점 이동 중앙값은 시드별 약0.00008~0.00026px에 그쳤다. 법선 방향 반응률의 중앙값도 거의0이다. ±8px에서도 결론이 같다. 원천 V33 가중치에서도 같은 경향이었다.
- **geometry와 영상 특징의 차이:** 다른 세션 geometry만 넣으면 잘림20 화면 밖 오차 변화+0.00027px,95%구간[-0.00204,+0.00203]px. 영상 특징만 교체하면+0.16986px,[+0.03575,+0.33774]px이고 세 시드 모두 악화됐다. 현재 모델은 검사한 명시적 위치 정보보다 선 token의 영상 특징에 훨씬 민감하다. 다만 영상 특징에도 간접적인 기하가 담길 수 있고 역할·확률·질량 및 다른 경로는 고정했으므로 모든 선 정보를 무시한다는 뜻은 아니다.
- **선 끄기의 해석:** 선 경로 전체를 끄면+1.33651px 악화되지만 이 변화 전체를 정확한 선 기하의 기여로 해석할 수 없다. 영상 요약·역할·확률·분기의 보정 기준값을 함께 제거하는 개입이다.

**현재 가장 지지되는 원인 가설:** 자유로운 최종 좌표 head가 선 token을 추가 영상 요약으로 이용하고, 명시적 선 위치와 점 이동 사이의 관계를 거의 사용하지 않는 학습 경로를 택했다. 코드에는 선 거리/방향 입력이 있어도 최종 이동이 그 기하를 따르도록 보장하지 않는다. 물리 CAD 체인과 가상 cuboid 점의 역할·offset 불일치가 이를 더 어렵게 할 가능성은 남지만, 이번 실험이 그 원인을 독립적으로 확정한 것은 아니다. 점과 선이 본질적으로 양립 불가능하다는 결론은 아니다.

**다음 판단:** 현재 자유로운 token→좌표 head에 gate를 하나 더 붙이거나 시드를 더 돌리는 것을 우선하지 않는다. 작은 분리 합성 집합에서 실제 경계와 가상 점의 역할·offset을 확인하고, 대응을 아는 선과 예측 선을 분리해 점 법선 잔차를 설명하는지 먼저 검증한다. 선만으로 정해지지 않는 접선 성분과 관측 불가능한 점은 별도로 남겨야 한다. 그 검사에서 성립한 관계만 제한된 보정 경로로 전달하고 좋은 점 부모 보존을 따로 대조한다. V30에도 법선 제한 경로가 있었으므로 단순 법선 투영을 새로운 해결책으로 반복 제안하는 것은 아니다. 이 후속 구조/학습은 V34에서 실행하지 않았다.

Gradient surgery는 이번에 사용하지 않았다. 수치 재현 오류는 충돌 gradient를 투영하는 문제와 다르고, 명시적 기하를 거의 사용하지 않는 현상이나 잘못된 역할 대응을 PCGrad가 자동으로 고친다고 볼 근거도 없다. 지속적인 점/선 손실 충돌을 먼저 측정한 뒤 별도 대조해야 한다.

위 결론은 재사용DEV와 고정 특징 개입에 대한 것이다. 선의 geometry만 움직인 입력은 실제 영상과 불일치할 수 있고 최고 attention 후보 하나의 국소 민감도가 모든 선 조합의 효용을 측정하지는 않는다. 새 자연 가림/잘림 실사나 미지 자산에서의 최종 일반화 성공, 수동GT 클릭 오차의 해소는 주장하지 않는다.
