# 팔레트 점·선 v4 독립 검토

검토일: 2026-09-09. 대상: 사용자가 업로드한 `pallet_point_line_v4_review.zip`.

## 1. 판단과 검토 목적

최상위 목적은 합성으로 학습한 점·선 아키텍처가 원래 좋은 점을 보존하면서 오류를 교정하는지 판단하는 것이다. 소비처는 실험 확대·아키텍처 채택 결정이다. 이번 검토는 추가 설계나 학습이 아니라, 실행 계약과 저장된 결과를 대조하고 성능·원인 주장의 범위를 확인하는 작업이다.

**[확인] 저장된 결과의 핵심 숫자와 합성 단계 중단 판정은 재현됐다. [판정] 전체 무결성 완전 통과와 보고서의 모든 원인 해석까지 승인하는 것은 아니다.**

- 학습 실행 증거: 12개 군·seed의 각 2,000 step 기록, 초기 상태·batch 계획·loss/gradient와 최종 상태 SHA 기록이 서로 정합한다. 가중치 파일이 제외됐으므로 실제 tensor 재로딩과 학습 재실행은 하지 않았다.
- 독립 수치 재계산: GT 파일 2,560개 SHA, 저장된 12개 군의 선택 좌표와 프레임/점 지표, score→선택 index를 검사했다. 모든 검사 431건이 통과했다. 이 개수는 제한된 재계산 assertion 수이며 전체 연구 무결성 인증 점수가 아니다.
- 원본 픽셀 8점/9점 요약 및 프레임 평균 오차: 보고값 대비 최대 차이 0.0.
- 사전 H 판정: seed1 실패, seed2/3 통과 → `NO_SYNTHETIC_ADVANCEMENT_SIGNAL` 유지.
- 실사 DEV·FINAL·전체 네트워크 학습: 새로운 결과는 없다. 조건부 실행 계약상 이번에 실행하지 않은 것이 맞다. 이는 실제 GPU/전체 파일 접근 로그의 독립 인증이 아니라 제출 자료와 소스에서 확인한 범위다.

예상되어야 했던 결과는 H가 P와 원래 출력보다 안정적으로 좋아지면서 정상 점을 보존하는 것이다. 관측 결과는 한 프레임의 교정과 다른 소수 프레임의 파국적 번호 변경이 seed별 손익을 바꿨다. 따라서 제한된 선택기 가설의 안정적 성공을 지지하지 않으며, 실사 우월성으로 이어지지 않는다. 단순 구현 완료나 작은 평균값 감소로 목표를 바꾸지 않는다.

## 2. 확인 범위와 재현 방법

실제 수행: 안전한 ZIP 해제, 정적 소스·계약 비교, PyTorch `weights_only=True`로 제공 GT tensor 읽기, NumPy 기반 점 오차/선택/학습 trace 재계산. **새 신경망 forward 0, optimizer update 0, 원본 입력·GT·checkpoint 수정 0.**

입력 ZIP SHA-256: `60736d6495bb393e85d8336931583a85517815eee8c4884a5e215f34d5768999`.

재계산 결과: `INDEPENDENT_REPLAY.json`; 추가 기존 C4 후보 진단: `ADDITIONAL_C4_DIAGNOSTIC.json`.

주요 확인:

- 제공했던 32개 파일은 CLI에서 바꾸지 않았고, 잠근 코어 13개 파일의 SHA도 일치한다.
- train/calibration/validation frame ID는 1792/256/512로 분리됐다. ID 비중복과 이미지 내용 비중복은 다른 검사이며 원본 image bytes는 이번 ZIP에 없다.
- 24,000개 trace의 batch 인덱스를 seed RNG로 새로 만들어 전부 대조했다. 같은 seed의 네 군은 같은 plan이다. 실제 매 step의 감독 코너 수와 GT mask도 일치했다.
- loss·gradient 기록은 유한하고, 학습률/손실 성분 합/최종 단계 수는 계약과 맞는다.
- 학습 로그상의 최종 상태 SHA 12개는 모두 다르다. 가중치 자체로 SHA를 독립 확인한 것은 아니다.
- P4 전체 2,560개 exact parity는 원래 export 기록에서 확인되며, 본 검토 환경에는 특징 cache가 없어서 재실측하지 않았다.
- 합성 calibration 전체 grid의 후보 좌표가 없어서 모든 grid 오차를 새로 계산하지는 못했다. 저장된 grid의 적격성/최소값 선택과 각 margin의 변경 건수는 검증했다.

**중요한 한계:** 원본 observation tensor가 빠져 있어 prediction-valid mask·raw 대각선·모든 후보 좌표는 직접 읽지 못했다. 제공 GT의 supervised/matched와 baseline 유한성으로 재구성한 관측 mask가 보고된 분모를 정확히 재현한다. 정규화 주 지표는 저장된 baseline 정규화 비율과 독립 원본 픽셀 오차의 일관성을 확인한 것이며, 실제 이미지 크기의 독립 검증은 아니다.

## 4. 실제 손익을 만든 두 사례

### 4.1 f7377: 번호 재배정의 이득과 선 보정의 이득은 다르다

기존 같은-ID 평균 오차133.606121px → 이미 bank에 있는 순수 번호 재배열 후보1은5.024358px → H가 선택한 후보28은5.339696px.

기존 point cloud에 허용된 C4 번호 재배열만 적용해도 큰 오차가 사라진다. H 후보는 그 배치에서 코너4를9.103686px 추가로 옮겼고, 평균 오차를0.315338px 늘렸다. S1/S3는 순수 후보1을 선택했다. 이는 실제 선택된 한 후보를 분해한 사후 진단으로, 별도의 재학습 ablation 또는 Hough 전체 효과 제거 실험이 아니다.

**[판정] 이 한 장의 개선을 선 교점 위치 보정의 성공이라고 주장할 수 없다. 역할 배치 선택을 도운 Hough 점수의 기여까지 부정되는 것은 아니다.**

원보고서는 최적 재대응 후 잔여 오차3–5px를 실제 이동량처럼 설명했다. 잔여 정답 오차와 좌표 이동량은 다른 양이다. f7377의 실제 추가 이동은 한 코너9.104px이며, f5154는 한 코너1.716px다.

### 4.3 안전 조건의 한계 — 제공한 계획도 보완 대상

원래10px 이하3743개 코너 중 H1이10px를 넘긴 코너는8개(0.2137%)라 1% 기준은 통과했다. S2도13개(0.3473%)로 통과한다. 그런데 해당 프레임 오차는150px 이상이다.

[판정] 내가 제공한 비율 기반 안전 조건은 드문 프레임의 손상 크기를 충분히 제한하지 못했다. 주 평균 기준이 H1을 탈락시켰으므로 현재 중단 판정은 유지된다. 결과를 보고 문턱을 바꿔 이번 결과를 재승격하지 않는다. 후속 설계에서 실패 건수와 오차 크기를 구분해야 한다는 근거로 남긴다.

## 5. 후보/랭킹/수락을 구분한 추가 진단

### 5.1 후보를 선호하는 것과 최종 출력을 바꾸는 것은 다르다

P1/P2/P3의 raw score는512장 중498/501/499장에서 identity보다 다른 후보를 선호했다. 하지만 calibration에서 identity-only 정책을 골라 모든 결과를 보존했다. H1도494장에서 비identity를 선호했으나 margin을 넘은3장만 채택했다.

따라서 원보고서의 '1~5장만 바꿨으니 점수 함수가 나은 후보를 싫어했다'는 해석은 부정확하다. 학습된 후보 순위와 calibration으로 정한 수락 규칙을 분리해야 한다. raw argmin의 nonidentity 건수만으로 그 대안이 실제로 좋은지도 알 수 없다.

전체509장 첫4후보 진단에서 H1/H2/H3의 GT최선 후보와 불일치는8/9/8장이다. 대부분의 정상이 쉬워 전체 정답률이 높게 보이는 불균형 상황이다. 항상 identity를 택해도501/509가 맞으므로 그 비율을 모델의 강점으로 강조하면 안 된다. 반대로 전체를 '4지선다 동전던지기'라고 부를 근거도 없다.

### 5.3 훈련 oracle42.19%는 검증 headroom이 아니다

42.19%와159프레임은 **train1792 중 관측1791**의 oracle 진단이다. validation512에 같은 수치를 가져와 모든 실패가 ranking이라고 확정할 수 없다. 원본 전체 후보 tensor가 없으므로 validation 전체64후보 oracle은 이번에 독립 계산하지 않았다.

훈련 oracle의 가능한 normalized 개선량 중 상위10프레임이50.75%, 상위20프레임이77.96%를 차지했다. [추정] native-only 감독에서 드문 큰 번호 오류와 그 반대의 파괴 사례가 의사결정을 불안정하게 할 가능성이 있다. 그러나 이 숫자만으로 데이터 부족이나 특정 loss가 원인이라고 확정할 수 없다.

| 전체 정책 동결 순서 | 각 군마다 cal→policy→val 실행 | 원래 12개 정책 모두 동결 후 val 규칙과 다름. val기반 재튜닝 증거는 없음 |
| 새 특징과 기존 출력의 결합 | 새 P3/P4, 기존 점/confidence/선/교점 | P4 exact가 전체 반환값 exact를 증명하지 않음. 실제 불일치 원인 미확정 |
| 좌표 검사 | affine 역행렬 왕복·자체 선식 검사 | 내부 산술 정합성은 확인. 물리적 영상-feature 정렬 독립 인증 아님 |
| 데이터 분리 | frame ID 비중복, image SHA disjoint는 상류 boolean | 원본 이미지 수준 새 전수 검증 미확인. 중복 발생 증거는 없음 |
| GT 미사용 검사 | 8 observation 로딩 경로만 감시, score JSON에는0 상수 | 실제 전체 scoring 계측으로 과장 금지. 정적 코드상 GT 전달 경로는 보이지 않음 |
| 후보 계약 | 별도 CANDIDATE_CONTRACT.json 없음 | 유사 내용은 분산 보존. required=[] 전체완료 주장에 한계 |
| 원본 변경·외부 알림 | broad folder 제외로 변경 감사, 범위 밖 알림 기록 | 전면 불변 보증/승인 범위는 별도 확인 필요. 성능 숫자와 분리 |

이 중 `supervision_files_opened=0` 선언과 파국을 놓치는 안전 문턱은 **원래 내가 준 코어·계획의 한계도 포함**한다. 실행자만의 잘못으로 돌리지 않는다.

`official_metric_parity_checked=false`는 이번에 새로 발견된 실행 실패가 아니다. canonical6D 대조를 예정했던 실사 단계에 들어가지 않아 미실행으로 남긴 것이 맞다. 또한 모델 가중치/특징 자체가 없으므로 기록상의 신경망 실행을 여기서 전부 재현했다고 말하지 않는다.

## 7. 원보고서에서 바꿔야 할 해석

1. 'C4 위상은 동전던지기': 드문 번호 대응 오류가 있다는 관찰과 무작위/영상 식별 불가능성은 다른 주장이다. 반례 없는 확정이 아니라 미검증 가설로 낮춘다.
2. '정답 순열 후보가 동률이면 어떤 검증기도 풀 수 없다': GT 좌표에 대한 후보 오차가 동률인 것은 RGB 관측에서 식별 가능한지 검사한 결과가 아니다. 유일한 GT를 붙여도 영상이 모호할 수 있고, 여러 후보의 점 오차가 비슷해도 외관 단서는 있을 수 있다.
3. 'H−HA 효과 없음': 현재 설정에서 안정적 이점이 확인되지 않았다고 적는다. 부재/동등성의 증명이 아니다.
4. 'calibration 값0.005327 → validation0.005789이므로 calibration 부족': 서로 다른 모집단의 절대오차를 직접 차감하면 안 된다. 각각의 baseline 대비 손익을 비교해야 하며, 이 결과만으로 calibration 표본 부족을 단정할 수 없다.
5. '공통 affine이라 군간 차이를 만들 수 없다': 공통 변환이라도 endpoint-only와 interior sampler의 query 위치가 달라 오차와 상호작용할 수 있다. 이 실험의 실패 원인이라고 확정하는 것도 금지한다.

기존 저장소의 camera_dynamic_0123_v4는 카메라 기준 앞/뒤·상/하 번호 규약이다. 정사각 물체의 절대 yaw 대칭과 같은 문제가 아니다. 모든 합성 물체가 실제 C4 대칭이라는 계약도 이번 기록에서 확인되지 않았다.

공식 BOP는 관측된 가시 부분의 차이(VSD)와 사전에 식별한 물체 대칭을 반영한3D/투영 오차(MSSD/MSPD)를 구분한다. 이런 대칭-aware 평가는 근거가 정해진 과제 정의이며, 이번 모델이 번호를 틀렸다는 이유로 같은-ID metric을 사후 교체할 허가는 아니다.

출처: BOP 공식 tasks `https://bop.felk.cvut.cz/tasks/`; 저장소 pinned `scripts/research/pallet_dht_structured_v2/SEMANTICS.md`, `proposals.py`, ref6a68452ea9a17a69860981fea1c5a3dc234e3dfa. 웹 문헌은 위 대칭 정의의 근거이며 본 실험 성능의 근거가 아니다.

## 8. 이번 결과가 남기는 연구 판단

**지지됨:** 고정 표현·고정 후보에서 일부 잘못된 번호 배치를 선택해 교정할 수 있다. 그러나 현재 head는 희귀한 교정과 정상점 파괴를 안정적으로 구분하지 못한다. 순수 번호 재배열만으로 가능한 이득과 선분/교점 보정의 이득은 구분해야 한다.

**미확립:** 유한 선분 내부의 안정적 증분 효과, 명시적 Hough의 추가 효과, same-ID reference 제거의 안정적 효과, 실사 개선, 전체 네트워크 우월성.

**잘못된 확대 해석:** 모든 point-line 방법의 불가능, 모든 팔레트의 C4 등가, 해당 실패의 원인은 GT가 틀려서라는 확정, 학습이 전혀 수행되지 않았다는 주장.

다음 안건은 새 학습 확대가 아니라, 이번에 좁힌8개 순열-복구가능 사례와 정상에서 파괴된 사례에서 **실제 renderer/annotation의 앞면 선택 규칙과 후보 점수의 선호가 어디서 어긋나는지** 확인하는 제한된 진단이다. GT 오차 동률만 세어서 영상 식별 가능성을 결정하는 계획은 사용하지 않는다. 이 문서는 그 새 진단의 실행 지시가 아니며 추가 훈련·실사 추론을 수행하지 않았다.

수정할 최종 결론 문장:

> 동일 고정 backbone과 후보 bank에서 네 증거 읽기 구조를 비교했다. 모든 제한된 학습과 합성 평가는 완료됐으며 주요 수치는 저장 좌표에서 재현됐다. 일부 번호 재배정에 의한 개선은 있었지만 한두 정상 프레임의 큰 손상이 seed별 손익을 바꿔 사전 합성 진입 기준을 만족하지 못했다. 선분·Hough 증거 또는 같은-ID reference 제거의 안정적 이점은 확인되지 않았다. 이 결과는 현재 선택기의 한계를 나타내며 영상 기반 번호 식별 불가능성이나 점·선 결합 일반의 실패를 증명하지 않는다. 실행 순서 및 무결성 검사 범위의 제한은 별도로 보존한다.
