### paired bootstrap 10,000 (seed 분리, 3 population)

**80개 비교 중 CI 가 0 을 배제한 것은 2개뿐이고, 둘 다 손상이다.**

```
★ seed2 BROAD_UNSEEN T3 translation  -66.36%  CI[-139.37, -24.16]  P=0.001
★ seed2 DEV_SMALL    T4 rotation      -7.00%  CI[ -13.90,  -1.15]  P=0.010
```

T3 손상은 **미사용 population 에서 재현**됐다(DEV_SMALL 에서 −67.41%, P=0.027 →
BROAD_UNSEEN 에서 −66.36%, P=0.001). seed1 도 같은 방향이다(BROAD_UNSEEN T3 t
−10.76%, DEV_SMALL T3 frs −24.41%). 즉 **저앙각 정면 손상은 우연이 아니다.**

회전은 여전히 대체로 양수지만(seed1 T1 +18.3 P=.897, T3 +14.6 P=.841, T4 +8.9 P=.961,
NEW N1 +12.5 P=.954, N2 +16.1 P=.952) **어느 것도 CI 가 0 을 배제하지 못하고**,
seed2 에서는 같은 항목들이 +6.7 / −8.5 / −8.0 으로 약하거나 음수다.

## 4. 판정

```
A) robust gain        아님 — 표본을 2~4배로 키워도 확립되는 이득이 0건
B) no gain            해당
C) frontal harm       해당 — T3 translation 손상이 unseen 에서 P=0.001 로 재현
```

`VCTRL` 은 실행하지 않는다. V_vis confound 를 분리할 이득 자체가 없다.

### 다음은 balanced LA curriculum 이다

canonical yaw 기준으로 다시 계산한 필요량:

```
E0 <8|Yc >=30   30.60px x3.63   현재  931장(2.76%)  → 신규 2,316장
E0 <8|Ya <15    13.01px x1.54   현재  706장(2.09%)  → 신규 2,563장
                                                      신규 합계 4,879장
```

즉 지금 5K 와 **겨냥이 다르다** — `Yb 15-30`(거의 정상)에 2,500장을 쓰는 대신
`Ya <15`(저앙각 정면)를 채워야 하고, curriculum 은 정면 노출을 **줄이지 않는**
형태여야 한다(현재는 corner batch 의 12.5% 를 비정면으로 대체해 정면을 굶겼다).

⚠ 이 재계산은 `CORNER_LA_RENDER_TARGETS.md`(폐기된 yaw 기준)를 **대체**한다.

## 한계

- 재판정도 3,000 step × 2 seed 결과를 다시 읽은 것이다. 학습 예산 자체는 그대로다.
- T2 의 seed 충돌(−54.6% vs +8.5%)은 설명되지 않았다. seed 2개로는 못 가른다.
- NEW_UNSEEN 은 LA 도메인 안의 미사용 프레임이라 "이 도메인에서 좋아졌나" 만 답한다.
  BROAD 일반화를 대신하지 못한다.
- 회전이 4/4~5/6 양수인 것은 계속 관찰되지만 확립된 적이 한 번도 없다. 검정력을
  더 키우려면 표본이 아니라 **예산·seed 수**를 늘려야 한다(dev target 은 이미 소진).
