## 읽기

### 1. 부분 가시성이 지배적이다 — 그러나 coverage 문제가 아니다

`V<=6` 은 모든 elevation 에서 파국이다. 5cm5deg 가 0.000~0.023 이고,
scale gap 0.106~0.189, front_rear_shift 1.8~2.7 — V=8 대비 2~5배.

```
PARTIAL_VISIBILITY_RISK_SUPPORTED = True
```

**그런데 `V<=6` 은 학습셋의 22.58% (7,621 / 33,758) 다.** 희소하지 않다. 즉 이건
노출 부족이 아니라 표현·과제 정책 문제이며, 과거 truncation 진단이 이미 같은
방향을 가리켰다. **resampling 으로 시험할 수 있는 가설이 아니다.**

### 2. 저앙각은 모든 V 에서 나쁘고, 실제로 희소하다

V=8 안에서 `>=30` → `<8` 로 갈 때:

```
scale gap   0.025 → 0.082     3.3배
frs         0.53  → 0.96~1.01 1.9배
t           0.14  → 0.36~0.53 2.5~3.6배
5cm5deg     0.17  → 0.09/0.05 절반 이하
```

```
LOW_ANGLE_RISK_SUPPORTED = True
```

그리고 저앙각은 학습 7.66% vs 실제 94% 로 **coverage 격차가 실재**한다.

### 3. 상호작용 — translation 에서 초가법적 (seed1 강, seed2 약)

t 를 가법 예측과 비교하면:

```
seed1  base >=30|V=8 0.143  +저앙각 0.221  +부분가시 0.114  → 가법 예측 0.478
       실제 <8|V<=6 0.769                                    1.6배 초과
seed2  base 0.150  +0.383  +0.117 → 가법 0.650  실제 0.716   1.1배 초과
```

scale gap 은 거의 가법적이다(가법 0.163/0.170 vs 실제 0.155/0.189).

```
LOW_ANGLE_X_PARTIAL_INTERACTION_SUPPORTED = True   (translation 축, seed1 강 seed2 약)
```

### 4. theta-only 의 이득이 가장 큰 곳이 가장 나쁜 곳과 겹친다

rotation 상대 이득은 `V<=6` 에서 가장 크다(>=30|V<=6 에서 +52.7% / +25.7%,
15-30|V<=6 에서 +41.9% / +27.8%). 브리프 §8.3 이 물은 네 가지 —
frs 증가 · scale 오차 증가 · PATH-C R/t 악화 · theta-only 상대 이득 증가 — 가
**같은 cell 에서 동시에 나타난다.**

```
LOW_ANGLE_RISK_SUPPORTED                    = True
PARTIAL_VISIBILITY_RISK_SUPPORTED           = True   (단, coverage 문제 아님)
LOW_ANGLE_X_PARTIAL_INTERACTION_SUPPORTED   = True   (translation, seed1 강)
```

상관이지 인과가 아니다. 인과 시험은 PHASE 10 의 resampling 이다.

## PHASE 10 대상 — 돌리기 전에 고정

학습셋 cell 개수를 먼저 셌다.

```
<8 전체      2,587   7.66%     ← 유일하게 실제로 희소 (real 94%)
V<=6 전체    7,621  22.58%     ← 희소하지 않음, resampling 대상 부적합
<8 x V<=6      867   2.57%     ← 24,000 노출이면 28회 반복, 암기 시험이 됨
```

따라서 단일 대상은 **저앙각(<8도)** 으로 고정하고 `DANGLE` 한 arm 만 만든다.
`DANGLE_PARTIAL` 은 쓰지 않는다 — 상호작용 신호는 있으나 그 cell 이 867 프레임뿐이라
resampling 으로는 coverage 가설을 시험할 수 없다.
