# 연구 결과 공개 기본 방침

2026-09-21 사용자의 명시적 지시: 이 연구 작업은 완료 결과·설명·이미지를 Markdown으로 정리하고 `main`에 commit/push한다. 첨부 실행 지시문에 관행적으로 적힌 “push 금지”보다 이 방침을 우선한다. 이후 사용자가 직접 중단·비공개·push 보류를 요청하면 그 최신 요청을 따른다.

관련 결과와 이미지의 링크를 검증하고 해당 작업 파일만 선별한다. checkpoint, 비공개 검토 매핑·사람 응답, 민감한 감사 메타데이터 및 관련 없는 미추적 작업을 일괄 공개하지 않는다. 공개에 추가 승인이 필요한 자료는 제외하거나 확인한다. 원본 실험·annotation·동결 결과를 덮어쓰지 않고 공개본을 분리한다.

push 후 local HEAD와 origin/main SHA 일치를 확인하고 사용자에게 보고서 링크와 커밋을 전달한다. 이 방침은 새 학습·sweep·추가 실험 실행 권한을 넓히지 않는다.
