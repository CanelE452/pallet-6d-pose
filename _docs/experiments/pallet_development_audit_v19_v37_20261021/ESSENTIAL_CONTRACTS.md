## Confirmed and not inferred

- Geometry documents `P_cf[i] = A @ P_canonical[perm[i]]`, `R_canonical = R_cf @ A`, unchanged translation. W/D parity alone does not determine the sign of physical axes. The selector API returns multiple signed canonical candidates; the downstream pose primitive applies its fixed physical representative and the declared synthetic basis transform. Do not equate a camera-facing index with an independently annotated real physical owner.
- N3 has 221 nonzero displacement positions (13 angles x17 radial positions to0.08 times box diagonal) and one learned null/zero displacement. The decoder uses a temperature-scaled softmax expectation, not argmax. Actual retained N3 seed1 inference uses temperature1, lambda1, and the existing1% original-image-diagonal move cap, followed by the existing native SubPix/total-base cap. The centroid slot is preserved. Finite/box/patch support is algorithmic validity, not actual visibility truth.
- `local_phase` chooses one whole-object proper-group branch for TRAIN/calibration supervision; it is not called during inference. The target is not a collection of independently chosen nearest GT corners. Generic loss is supported-corner cross entropy averaged per supported frame. N3 receives canonical dimension context5; the8-dimensional metadata arms are different variants.
- The actual D1 producer uses P1 and two WD0 families, numeric G10 family selection, then typed G13 refinement and the G10-selected family E0 readout. H1 can subsequently choose another complete candidate. `solver.generate_candidates` alone is not the entire original D1 producer.
- H1 uses31 signed-log scalars+31 validity bits, local62, bank mean62, bank max62, log-count and N0 flag (188 total). Own TRAIN-only normalization is bank-specific. Ineligible original journal entries do not enter the eligible action set. Missing N0/E0 feature evidence is explicitly invalid; no pose is fabricated. Min-energy family context discards some alternative-family evidence.
- Audit scalar metrics use fixed C2 (I and180deg proper yaw), inclusive joint T<=5cm/R<=5deg, full success denominator including no-pose. Gate epsilon1e-7 is a numerical comparison tolerance, not a widened success threshold. PRIMARY192 physical appearance C2/C4 sublabels remain UNKNOWN;90deg was not relabelled correct.

The confirmation that the decoder uses an expectation does NOT establish that expectation averaging causes the measured W/D errors. Actual visible/self-hidden/external-occluded point error strata were NOT independently separated in v36. Its renderer-native point error counts pool all8 corners. They are sufficient to identify output transitions, not to reconstruct image geometry or execute the2x2 diagnostic.
