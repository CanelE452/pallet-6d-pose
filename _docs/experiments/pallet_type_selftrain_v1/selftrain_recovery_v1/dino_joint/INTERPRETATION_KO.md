# 전체 코너 묶음 선택 실험과 후보 생성 병목 — 2026-09-20

## 결론

실험·검증은 완료했지만 **미채택이며 전체 목표는 미완료**다. 8개 코너를 서로 다른 보정안에서 부분적으로 섞지 않고, 하나의 완전한 묶음으로 고르는 모델을 학습했다. 하지만 합성 기준설정에서 안전한 적용 기준을 찾지 못해 실제194장 출력은 모두 R0와 동일하다. 손상0개/복구0개를 개선이라고 보고하지 않는다.

중요한 후속 근거: 모든 기존 R0 점이 정답에서40px 초과 떨어진64코너 중, 원래 모델과 두 영상 보정 모델의 **어느 native 점도 정답10px 이내에 없는 코너가56개**다. 이 세 점 집합만 재배열·선택하는 방식은 해당56개를 복구할 수 없다. 이 한계는 현재 후보 집합에 대한 것이며, 새로운 위치를 생성하는 모델이나 다른 학습 방법의 불가능성을 의미하지 않는다.

새 수작업 정답·태그·깊이·CAD·프레임 제외·새 기하 필터는 사용하지 않았다. 기존 최종 모델, 라벨, split, 기존 결과도 바꾸지 않았다.

## 구현한 비교

후보는 총12개다.

1. R0의 전체8코너 묶음.
2. 고정 `dino_wide_visual` SYN의 전체 묶음.
3. 같은 MIX의 전체 묶음.
4. 위 각 묶음의 native/half/quarter/three-quarter 역할 배치4종.

Quarter 배치는 실제 예측 편집이며, 평가 정답 대칭을 C4로 넓힌 것이 아니다. 일반 플라스틱 평가의 공식 C2는 그대로다. 두 영상 후보는 새 위치를 포함하므로 단순 R0 재배열만의 실험은 아니다. 한 묶음을 고르는 것은 부분 혼합을 막지만, 묶음 자체의 물리적 올바름까지 보장하지 않는다.

후보당98개의 영상/예측 특징(두 heatmap의 위치별 근거, 원래 위치와의 차이, 정규화 위치·이동량, 후보간 거리, 불확실성 등)을 받아 공유 MLP가 안전한 평균 오차 감소 가능성을 학습한다. GT는 추론 특징에 없다. 기하량은 학습 특징으로만 쓰며 X자/면 모양 판정으로 프레임을 탈락시키지 않는다.

합성1,412장 학습,32장 기준설정,32장 별도검사를 유지했다. 각 source 영상의 원본+이전5-view 중 인공 오류4개+원본 quarter 오배치의6개 입력을 사용했다. 총8,856개 source 사례,각12개 후보다. 기존 source별 공식 대칭은 GT 학습 표적 계산에만 사용했다. 평가 대칭이나 정답 좌표를 수정하지 않았다.

학습 표적은 후보가 평균 코너 오차를5px 초과 줄이면서 원래<5px였던 코너를>10px로 망가뜨리지 않는가다. 98→64→32→1 MLP,seed20261002,AdamW,고정1,000 step,마지막 모델만 사용했다. 기준 후보0은 원래 float64 좌표 그대로의 fallback이며 학습 후보에서는 제외했다. 학습 후보93,192개 중 양성18,612개다.

## 실패는 어디서 발생했나

사전 고정한 확률 기준 grid에서 원본이 아닌 후보를 적용하면서 합성 안전 조건을 만족하는 기준은 없었다. 0.99에서도 기준설정의 원래 입력에서 정상210코너 중7개를 망가뜨렸고, clean+인공 사례의 선택 정밀도는86%로 요구95%에 못 미쳤다. 따라서 적용하지 않는 기준1.01을 선택했다.

사후 **합성 데이터만**으로 실제 점수의 모든 비어 있지 않은 선택 경계를 확인해도 조건을 만족하지 못했다. 단순히0.01 grid가 거칠어서 놓친 안전한 기준이라는 설명은 지지되지 않는다. 이 진단으로 원래 기준·출력은 바꾸지 않았다.

실사194장 모두 R0 유지:

- PCK20 77.86%,중앙7.51px,P90 43.64px.
- >20→≤10px 복구0/281,정상 손상0/511.
- >40/80/100px 복구 모두0.
- 실제 큰 위치64코너 복구0.

## GT를 이용한 사후 후보 가능성 진단 — 실제 모델 성능 아님

모든 실제 출력이 잠긴 뒤, 고정된12개 후보 중 정답을 아는 사람이 고를 수 있는지를 점검했다. 이 선택을 출력·학습·수도레이블에 사용하지 않았다.

매칭186장 중 평균 오차를5px 초과 줄이는 후보가 있는 프레임은25장이다. 감독 가능한 모든 코너가20px 이내인 프레임은 R0의102장에서, 정답으로 후보를 골랐을 때 최대126장까지 가능했다. 이는 숨겨진 코너까지 모두 맞은 포즈나 실제 학습 모델 성능이 아니다.

원래 요청 사진 `eval_pallet07:1778652166837872128`에는 R0 quarter 후보가 있다. 정답으로 채점한 평균은264.90→23.16px지만 학습 모델은 이를 선택하지 못했다. 이 후보도 감독 코너 전체20px 조건은 만족하지 못한다. 이 사진에서 영상 SYN/MIX 후보들의 사후 최저 평균은 각각115.996/139.745px로 R0 quarter 후보보다 나빴다(역할 배치 후보들 중 사후 최솟값). 이 수치들은 실제 적용 결과가 아니다.

`HEADROOM_DIAGNOSTIC.json`의 `far_spatial_any_candidate_any_branch_available` 필드명은 정확히는 각 완전 후보를 공식 최소-평균 C2 분기로 평가한 경우의 합집합이다. 임의의 branch 선택을 허용했다는 의미가 아니다. 역할을 완전히 무시하고 세 모델의 모든 native 점에 대해 최근접 거리까지 따로 계산한 `SPATIAL_SUPPORT_DIAGNOSTIC.json`에서도64개 중8개만10px 이내 점이 있었고56개에는 없었다. 따라서 원래 위치와 새 위치를 고르는 문제뿐 아니라 **새 위치 후보 자체의 부족**이 실제 공간 오류에서 중요한 병목이다.

## 다음 의사결정

현재 후보만 재선택하는 기준을 더 조정해 전체 복구를 해결하려 해서는 안 된다. 선택기로 고를 수 없는 새 공간 위치56개가 있기 때문이다. 다음 실험은 기존 합성 정답/기존 허용 실사 자료 안에서 영상 보정기의 위치 생성 능력을 직접 개선·검증해야 한다. 역할 오류도 남으므로 위치 후보 개선만으로 목표가 자동 완료되는 것은 아니다.

이 결과는 추가 어노테이션이 필수라는 결론이 아니다. 후보 생성 모델의 학습량·표현력·후보 추출 방식은 아직 별도 원인 검증이 필요하다. 미세 개선이나 코너 번호 교환만으로 전체 목표를 축소하지 않는다.
