# 큰 인공 입력 오류를 학습한 영상 신뢰도 선택기 — 2026-09-20

## 결론

합성 입력 오류의 크기를 넓히자 기존 선택기가 거절했던 일부 큰 수정이 통과했다. 그러나 **큰 코너 오차 복구 목표는 여전히 미완료**다. 100px초과 동일-GT 코너 오류의 감소와 실제 새로운 공간 위치 발견, 프레임 전체 포즈 복구를 구분해야 한다.

새 사람이 그린 정답·태그·깊이·CAD를 추가하지 않았다. 프레임 기하 필터, GT 기반 후보 선택, 기존 최종 모델 교체도 하지 않았다. 전체194장, 기존 라벨/split/원본 예측/기존 결과를 보존한다.

## 통제한 변화

이전 `dino_evidence_gate`와 같은1,412장 합성 학습,32장 합성 기준설정,32장 합성 별도검사를 사용했다. 후보 영상 모델과 정답 좌표/감독 마스크,16개 특징,MLP,초기 seed,500 step,학습 순서,기준 선택 규칙은 동일하다.

각 source 영상의5개 입력 중0=원본,1/2=기존 박스 대각선5~15% 오류를 그대로 보존했다. 3=정답에서 대각선25~60% 떨어진 무작위 방향으로 한 코너,4=같은 범위로 모든 감독 코너를 이동시켰다. 입력만 틀리고 정답·이미지·crop은 바꾸지 않는다. 범위 밖으로 나간 입력을 강제로 잘라 맞추지 않는다.

학습뿐 아니라 기준설정의 인공 오류 표본도 같은 규칙으로 변경되므로 단순 threshold만의 효과를 분리한 실험은 아니다. 고정25~60% 범위의1회 비교이며 실사 GT로 radius를 탐색하지 않았다.

양성(후보≤10px이며 기존보다5px 초과 개선) 학습 표본 중 이동량30%초과 비중은 SYN235/13,230→9,041/17,256, MIX207/13,034→8,910/17,026으로 늘었다. 대략1.6~1.8%에서52% 수준이다. 이는 후보 생성 능력 자체가 좋아졌다는 뜻이 아니다. 영상 모델은 완전히 고정됐다.

## source 확인 및 해석

기준설정 결과 threshold는 SYN0.94, MIX0.93이다. 별도 source32장256코너의 PCK10 91.02%,P90 7.69px,정상206개 중 손상0개는 원본과 같다. 그러나 자연적으로 잘못된14개 큰 오류 복구도0개다. 자연 오류 일반화가 입증됐다고 말하지 않는다.

큰 이득 이동의 학습 비중을 늘리면 일부 실제 큰 후보를 수락할 수 있다는 제한적인 근거는 얻었다. 하지만 후보 생성과 코너 역할의 공동 일관성 문제가 남으며, 단순히 큰 인공 오류 표본을 늘리는 것만으로 해결되지 않았다.

이전 문서의 영상만 SYN6/64·MIX3/64는 무조건 적용했을 때의 관측 성능이지, 모든 부분 조합·대칭 분기를 포함한 수학적 oracle 상한이 아니다. 선택기와 후보 생성의 한계를 혼동하지 않는다.
