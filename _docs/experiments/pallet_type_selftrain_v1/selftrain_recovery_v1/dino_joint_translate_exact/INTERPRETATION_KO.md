# 전체 점 묶음 정렬 — 기준 범위 정정 후 실사 검증

## 결론

**정정된 source 기준으로도 실사에서 적용된 보정은 0장이었다. 또한 기준을 제거한 proposal 진단에서도 실제 큰 위치 오차 복구는 0/64였다. 이 방식은 미채택이고 전체 목표 미완료다.**

기준을 완화하면 해결된다는 결론을 내리지 않는다. 영상 확률에 원래 점 묶음을 통째로 정렬하는 제한된 방식으로는 실제 큰 코너 위치를 충분히 찾지 못했다. 전체 이동·index 변경만 가능하므로 상대적인 형상 변형이나 특정 코너만의 큰 오차를 복구하는 능력도 제한된다.

## 정정한 것 / 유지한 것

최초 calibration의 0~16 gain grid가 유효한 source 조건을 누락한 문제를 정정했다. 모든 고유 source gain 경계와 0/null을 사용하며, 선택 precision 95%, raw source normal 보존 조건, 최대 복구 수 및 동률 규칙은 바꾸지 않았다.

같은 동결 SYN/MIX head·DINO 특징·전체 점 정렬 수식·32 calibration/32 test·CPU에서 생성한 320개 source proposal을 그대로 사용했다. 추가 신경망 학습, 레이블·태그·새 프레임 필터, 평가 GT 기반 기준 선택은 없다. 원래 결과는 보존했다.

최종 기준은 **16.976975560188293**이다. Source calibration의 인공 오류 포함 view에서는 25/160개 case를 선택하고 96% 개선 precision 및 175개 코너 복구를 기록했지만, 원래 raw calibration 32장과 raw test 32장에서는 각각 변화/복구가 0이었다. 인공 오류 복구를 자연적인 큰 오류 복구라고 표시하지 않는다.

인공 오류를 포함한 별도 source test 160개 case에서는 35개를 선택했고 개선 precision 100%, >20→≤10px 복구 269개였다. 그러나 원래 입력의 test 32장에서 복구는 0개였다. 인공 이동을 되돌리는 성능과 실제 모델의 자연 오류를 복구하는 성능이 다르다는 점을 보여준다.

## 실사 GPU 검증

별도 GPU 평가 작업이 종료된 뒤 전체 194장의 image likelihood와 registration proposal을 생성하고 고정한 다음 GT를 채점했다. 최초 null shortcut phase와 달리 이 정정 phase는 실제 GPU proposal 추론을 수행했다.

|---|---:|---:|
| PCK20 | 77.86% | 77.86% |
| 코너 중앙 오차 | 7.51px | 7.51px |
| P90 | 43.64px | 43.64px |

실사 proposal의 최대 gain은 **3.3231**로 source 기준 16.977보다 훨씬 작았다. 인위적으로 크게 이동·재배열한 source 입력에서 기준을 만족하는 것이 자연적인 실사 오류로 이어지지 않았다.

## 적용되지 않은 후보의 사후 진단

저장된 GT-free proposal을 **채택 기준을 무시하고 GT로 채점한 분석**이다. 실제 output이나 새 선택 기준이 아니며, 결과를 보고 threshold를 실사에 맞추지 않았다.

- >20→≤10px 복구: 32/281.
- 원래 <5px였던 정상 코너가 >10px로 손상: 51/511.
- 모든 원래 R0 점이 정답에서 >40px 떨어진 실제 큰 위치 오류 복구: **0/64**.

총 136/194개 프레임에서 원래 좌표와 다른 proposal이 생성됐지만 적용되지는 않았다. 처음 요청한 의자·표지판 사진은 proposal 자체가 permutation 0, 이동 0px, gain 0으로 원래 R0와 같았다. 이 사진에서는 threshold 때문이 아니라 영상 점수가 원래 잘못된 점 묶음을 더 선호하는 문제가 남았다.

따라서 32개 일반 복구를 큰 공간 이동 복구로 부풀릴 수 없다. 역할/index 재배열이나 비교적 작은 위치 이동을 포함한다. 실제 큰 위치를 생성하지 못한 이상, 현재 점수 기준만 바꾸거나 더 느슨한 필터를 붙이는 것으로 요청한 문제를 해결했다고 할 수 없다.

## 검사 및 제한

- 회귀검사 42개 통과.
- 기존 CPU source 320개와 정확히 같은 proposal을 재사용하고 전체 score 경계 calibration을 독립 재계산.
- 실사 GPU proposal 194개 및 최종 prediction 194개 재추론 결과 정확 일치. 최대 좌표 차이 0px.
- 적용 여부, 원래 점과의 상대 배치, 중심점·검출 metadata 보존을 확인.
- 실제 R0 fallback 출력과 적용되지 않은 proposal 채점 결과를 별도 파일로 분리.
- 반복 DEV이며 독립 확증이 아니다. 기존 MIX teacher의 과거 수동 학습 3장 평가 중복 한계는 그대로다.
- 최종 모델·수도레이블·학생·논문 표 변경 및 push 없음. GREEN/WOOD 개선 주장 없음.
