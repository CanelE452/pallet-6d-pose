# 합성-only 8,192장: 5,000 → 20,000스텝 정정 없는 연속 학습

결론: 학습량 확대만으로 큰 코너 복구 문제를 해결하지 못했다. 최종 모델에 적용하지 않는다.

| 일반 PLASTIC 전체 194장 | R0 | SYN 5,000 | SYN 20,000 |
|---|---:|---:|---:|
| PCK20 (%) | 77.86 | 71.32 | 69.86 |
| 관측 코너 오차 중앙값 (px) | 7.51 | 7.19 | 7.77 |
| 관측 코너 오차 P90 (px) | 43.64 | 83.65 | 84.71 |
| >20px → ≤10px 복구 / 281 | 0 | 67 | 54 |
| <5px → >10px 손상 / 511 | 0 | 68 | 68 |
| 기존 어떤 점에서도 >40px 떨어진 정답 복구 / 64 | 0 | 3 | 2 |

5,000스텝의 모델 및 AdamW 상태를 그대로 이어받았다. 같은 합성 8,192장, 학습률, loss, frozen DINO, 좌표 힌트 없는 head, seed와 이어지는 표본 순서를 사용했다. 새 수동 레이블·태그·실사 학습·필터·평가 제외는 없다. 마지막 20,000스텝만 실사에서 평가했다.

공통 합성 train probe의 PCK10은 81.73% → 91.16%로 개선됐으나 held64는 78.24% → 77.84%였다. 학습 데이터 적합 개선이 검증 일반화로 이어지지 않았다. 이것은 다른 구조/표현도 불가능하다는 증거가 아니다.

원래 의자/콘 사진의 프레임 평균 오차는 R0 264.90px, SYN5k 119.07px, SYN20k 182.80px다. 평균 감소만으로 전체 자세가 복구됐다고 해석하지 않는다. 64개 실제 큰 위치 오류 중 새 출력의 어떤 점이라도 정답 10px 이내에 존재하는 것은 3개뿐이다(이것도 역할을 무시한 사후 후보 존재 진단이지 모델 성공률이 아니다).

30개 회귀검사 통과. 모델·optimizer 복원, 표본 순서 5,000스텝 prefix, target/mask/cache 불변성을 검사했다. 다음 10스텝 loss는 허용오차 1e-5 내 재현했으며 전체 CUDA 학습 궤적의 bit-exact 재현을 주장하지 않는다. 전체 194장 최종 GPU 추론은 0px 차이로 재현했다. 자세한 근거는 같은 폴더의 COMPLETION_AUDIT.json, FIT_SYN.json, RESULTS.json에 있다.

반복 DEV 결과이며 독립 확증이 아니다. 합성만으로 학습했지만 설계 동기는 이전 실사 결과를 본 후 정했다. 평가 GT는 점수·사후 원인 분석에만 사용했다. 큰 코너를 복구하면서 정상 코너와 전체 자세를 보존한다는 최상위 목표는 미완료다.
