# 영상 근거를 학습한 코너별 선택 보정 — 2026-09-20

## 현재 판정

**실험은 완료했지만 큰 코너 오차 복구 목표는 미완료다.** 정상 점 손상을 크게 줄이며 일부 코너를 복구했다. 그러나 80px·100px 초과 오류 복구는 0개다. 기존의 느슨한 bounded screen은 두 조건 모두 통과하지만, 이것을 사용자의 전체 목표 달성이나 논문 최종 개선 증거로 바꾸지 않는다. 자동 채택·최종 모델 교체·push는 하지 않았다.

추가 수작업 어노테이션, 새 태그, 깊이/CAD, 프레임별 기하 필터를 사용하지 않았다. 모든 일반 플라스틱194프레임을 유지했고, GREEN/WOOD에 대한 개선을 주장하지 않는다.

## 무엇을 학습했나

이미 학습된 `dino_wide_visual` SYN/MIX 영상 모델은 고정했다. 각 모델이 제안한 새 위치에 대해, 같은 영상에서 기존 위치보다 더 믿을 만한지 판단하는 작은 신뢰도 모델을 각각 학습했다. 두 영상 모델은 상관된 모델이지 독립 증거가 아니다.

입력은 기존/새 위치의 heatmap 확률 질량과 비율, heatmap 불확실성, 두 모델의 후보 위치 차이, 이동량/박스 대각선 등16개다. 추론 입력에 GT는 없다. 학습 정답은 **기존 합성 정답**으로 계산한 후보의 이득 여부다. 새 사람이 그린 정답이나 태그가 아니다.

- 기존 합성 학습1,412장, 각 이미지의 원래 입력+기존 방식의 인공 오류4종.
- 긍정 학습 표본: 후보 오류≤10px이고 기존 오류보다5px 초과 개선되는 코너.
- 16→32→16→1 MLP, 고정500 step, 마지막 모델만 사용. 영상 모델 재학습 없음.
- 기존 분리 합성64scenario를 hash로32장 기준설정/32장 별도검사로 나눔.
- 기준설정32장의 원래 입력에서 PCK10 하락≤1%p, P90≤1.1배, 정상 손상≤1%; 원래+인공 오류 표본에서 이득 정밀도≥95% 조건 아래 복구 최대화.
- 기준은 SYN0.81, MIX0.93. 실사 GT로 정하거나 바꾸지 않았다.
- 거절한 코너는 float64 R0 좌표를 bit-exact 유지한다. 적용한 코너는 고정 영상 모델의 원래 후보 그대로이며 크기를 줄이거나 재배열하지 않는다.

## 큰 복구 후보를 왜 남기지 못했나: 사후 진단

무조건 영상 보정에서80px초과→10px이내였던 SYN16개/MIX14개의 native 후보는 모두 선택기에서 거절됐다. 이 중4개/3개는 전체 C2 평가 분기도 달라졌다. 코너별 수락 하나만으로 무조건 적용의 전체 대칭 분기 효과가 재현되는 것은 아니다.

학습의 이득 표본 중 이동량이 박스 대각선의30% 초과인 표본은 SYN235/13,230(약1.78%), MIX207/13,034(약1.59%)뿐이다. 반면 위 실사 큰 복구 후보의 이동량 중앙값은44.42%/43.59%다. 인공 이득 표본의 중앙값은 약10%다. **큰 이동을 동반한 올바른 수정의 학습 빈도가 낮다는 가설**을 뒷받침하지만, 이 분포 차이만으로 인과관계를 증명하지는 않는다.

다음 검증 후보는 원래 합성 정답은 유지한 채 인공 입력 오류의 크기 분포를 넓히는 통제 실험이다. 현재 gate/threshold/실사 예측을 사후 수정하지 않는다. 새 정답 요구나 실사 GT로 이득 코너를 고르는 방식으로 대체하지 않는다. 후보 생성 자체도 실제 큰 위치64개 중 최대6개 수준이므로, 선택기만으로 전체 문제가 해결된다고 가정하지 않는다.
