# 기존 합성 정답의 학습 범위 확대 — 2026-09-20

## 결론

**새 어노테이션·태그 없이 일반화는 개선됐지만, 큰 코너 복구와 정상 코너 보존을 함께 해결하지 못했다. 미채택이며 전체 목표는 미완료다.**

기존 합성 1,412장을 반복한 5,000-step 모델보다 검증 및 실사 결과는 나아졌다. 그러나 실사에서 원래 맞던 점도 많이 손상시키므로 R0를 교체하거나 이 출력으로 학생을 추가 학습하지 않았다. 추가 수동 정답이 필수라는 결론으로 해석하지 않는다.

## 변경 범위

- 기존 사용 1,412장을 모두 유지하고, 같은 합성 train partition의 6,780장을 오류 점수와 무관하게 선택해 총 8,192장으로 확대했다. 8,024개 scenario이며 원래 1,412장은 1,411개 scenario였다.
- 사용 가능한 기존 합성 train은 55,915장이다. 새 이미지 생성이나 새 레이블 작성은 하지 않았다.
- 각 이미지를 4~5번, 총 40,000회 노출하는 고정 순서로 5,000 step을 수행했다. 추가 이미지 선택 seed 20261003, epoch 순서 seed 20261004를 학습 전에 고정했다.
- 같은 영상 전용 head와 초기 가중치, frozen DINO, 넓은 crop, loss, AdamW lr .001 / weight decay .0001, microbatch 4, seed 20260929를 유지했다. 두 조건의 초기 state hash는 이전 모델과 동일하다.
- SYN은 합성 8장, MIX는 같은 합성 8장+기존 실사 수도레이블 8장을 동등한 branch 가중치로 학습했다. 실사 학습 217장·확인 32장과 정답·trust mask·split은 바꾸지 않았다.
- 분리 합성 검증 64장과 실사 평가 194장은 고정했다. 마지막 5,000 step만 실사에 적용했다. 원래 300-step 소수 샘플 반복에서 전체 pool epoch 순회로 바뀌므로 이미지 수와 노출 분포/순서의 효과를 따로 분리하지 않는다.
- 특징은 1,725항목을 byte-exact 재사용하고 합성 6,780개만 추가 추출했다. RAM feature LRU는 128항목, 약 220.5MiB로 제한했다.

64개는 모든 원래 R0 점이 해당 정답 위치로부터 40px 초과 떨어진 코너다. 복구는 최종 해당 정답 코너 오차가 10px 이내인 경우다. 일반 >20px 복구와 실제 새 위치 복구를 혼동하지 않는다. 코너 수이며 이미지 수가 아니다.

두 새 모델의 단일 출력점과 R0를 모두 합쳐 역할을 무시해도, 이 64개 중 53개에는 10px 이내 점이 없다. 나머지 11개는 **후보 존재에 관한 GT 사후 진단**이지 실제 선택기의 성능이 아니다. 서로 다른 모델이 복구한 점의 합집합을 한 모델의 성능으로 보고하지 않는다.

처음 요청한 의자·표지판 사진(`eval_pallet07:1778652166837872128`)의 평균 오차는 264.90→SYN 119.07 / MIX 218.57px다. 직접 시각 확인했으며, MIX가 의자 쪽으로 점을 옮기고 두 모델 모두 역할/연결이 잘못되어 전체 자세 복구에 실패했다. [전체 194장 전후 비교](../../../../../outputs/pallet_type_selftrain_v1/selftrain_recovery_v1/dino_source_diversity/index.html)의 첫 번째에 해당 사진을 배치했다. 정상 코너 손상 사례도 모두 포함했다.

해당 사진에서도 SYN G2는 5.35px까지 접근했다. 같은 GT 역할의 R0 오차는 286.44px였지만, 다른 모든 R0 점까지 포함한 최근접 거리는 40.87px였다. 따라서 이 사례는 실제 위치 복구를 포함하되 **286px 전체를 새로운 공간 이동 복구라고 부풀리지 않는다**. 정답으로 출력을 옮긴 것이 아니라 GT 없는 모델 추론 결과이며, 한 점의 성공으로 사진 전체 실패를 덮지 않는다.

학습 probe는 비교 가능한 원래 1,412장으로 고정했으며 전체 8,192장의 학습 정확도라고 표시하지 않는다. 검증 수치는 source 고정 채널 오차이며 실사 C2 평가와 동일하지 않다.

추가 source-only 진단에서 각 샘플의 공식 대칭을 허용해도 위 검증 PCK10은 모든 모델에서 동일했다. GT를 보고 임의의 일대일 점 매칭까지 허용한 낙관적 진단은 새 SYN 82.55%, MIX 80.00%였다. 따라서 현재 source 실패를 코너 번호/공식 대칭 채점 문제만으로 설명할 수 없다. 임의 매칭 결과를 새 모델의 실제 성능으로 쓰거나 예측에 적용하지 않았다.

다음에 구분해야 할 것은 **heatmap에 올바른 대안 위치가 있는데 최고점 선택이 틀린지**, 아니면 **대안 후보에도 올바른 위치가 부족한지**다. 현재 53/64의 단일 출력점 부재만으로 전체 heatmap에 영상 근거가 없다고 단정하지 않는다. 고정 모델의 다중 peak 진단을 먼저 수행할 수 있으며, 추가 수동 어노테이션이나 평가 GT로 출력을 선택하는 방식은 필요하지 않다.

## 검증과 제한

- 회귀검사 28개 통과.
- 합성 train/held의 scenario 및 이미지 hash 분리 확인. 기존 real pool records·순서·마스크 보존.
- 원래 canvas GT와 R0 box로 합성 8,256개 target·matrix·입력 좌표를 독립 재계산하여 저장 캐시와 정확히 비교했다.
- 새 특징 16개를 고정 난수로 골라 GPU 재추출한 결과 bit-exact 동일했다. 이는 6,780개 특징 전체의 재추출이라고 주장하지 않는다.
- 두 모델의 실제 5,000-step 이력·최종 optimizer step·checkpoint/resume 일치와 원래 초기 state 일치를 확인했다.
- 전체 194장×2 저장 예측을 GPU 재현해 최대 차이 0px. 동일 이미지의 DINO 특징도 부모 실험과 동일 hash다.
- 독립 오차 재계산, 원래 박스·신뢰도·중심점·비선택 검출 보존 확인.
- 모든 출력 고정 후 GT 채점. 반복 DEV이며 독립 확증 아님. 기존 MIX teacher 수동 학습 3장의 과거 평가 중복 한계 유지.
- 프레임 필터 추가, 최종 모델 교체, GREEN/WOOD 성능 주장, 논문 표 교체 또는 push 없음.
