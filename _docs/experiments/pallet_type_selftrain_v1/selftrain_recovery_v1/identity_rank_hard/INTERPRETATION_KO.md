# 큰 코너 대응 오류 학습 — 새 정답 없이 확인한 가능성과 실패

2026-09-20. 목표는 큰 오류의 실제 복구이며, 이번 결과로 완료 처리하지 않는다.
새 수동 어노테이션/태그 레이블은 0개다. 기존 평가 데이터와 최종 모델은 보존했다.

## 1. 먼저 수행한 작은 표본 실험

`../identity_rank`에서 합성 512장과 검증128장으로 절대 후보 점수 학습기를
학습했다. R0의 고정 P3/P4 이미지 특징을 각 코너와 측면에서 읽는다.
원래 번호인지 재배정 번호인지 표시하는 입력, 원래 R0 번호와의 차이,
GT/camera/depth/CAD는 학습기의 입력에 없다. 공식 C2의 두 점수는 평균한다.

SYN은 합성만, MIX는 합성+기존 실사 수도레이블217장을 사용했다.
두 모델 모두 800 optimizer step, 고정 마지막 가중치다.
합성 검증 정확도99.2%였지만 실사194장에서는 둘 다 원래 대응을 선택했다.
임계값0.95 때문만은 아니다. 재배정 후보 확률의 최댓값도 각각0.451/0.402였다.

학습 source에는 실제 원래 번호가 틀린 경우가6/512뿐이고, 실사 수도레이블에는
이 대응을 고쳐 주는 사례가0/217이었다. 따라서 이 결과를 실사 오류 해결로
해석하거나, 단순히 임계값을 낮추어 구제하지 않았다.

## 2. 기존 합성60,000개 캐시에서 자연 오류 발굴

기존 GT와 고정 R0 출력만 읽어 다음 조건의 실제 실패를 발굴했다.

- 매칭된 C2 물체, 감독 가능한 코너6개 이상.
- 원래 번호 평균오차 > 예측 상자 대각선의10%.
- 전체90도 번호 재배정 후 평균오차 < 대각선의3%.
- 개선 > 대각선의2%.

GT 좌표를 입력 후보로 넣거나 오류 좌표를 새로 합성하지 않았다.
실제 고정 R0 출력에서 번호만 재배정하는 두 후보를 비교했다.

학습 split에서297개의 실제 혼동과297개의 정상 대조 사례를 사용했다.
검증은 보류 split의 적격1,468장 전체로, 어려운 사례만 골라 검증하지 않았다.
이 중 강한 자연 오류는15장이다. train/heldout scenario와 이미지 해시의 교집합은0.
기존 R0 개발 노출은 있으므로 이를 새로운 전역 독립 시험이라 부르지 않는다.

SYN/MIX를 같은 구조·800step·optimizer로 다시 학습했다. 새 실사 이미지를
추가하거나 기존217장의 수도레이블을 GT로 치환하지 않았다.

기존 helper의 진행 출력에 `/640`이 남아 있지만 실제 처리량은
`source.npz`의2,062행 = 학습594 + 검증1,468이다. 프로토콜/배열로 검증했다.
역사적 해시 바인딩을 바꾸지 않기 위해 helper는 수정하지 않았다.

## 3. 실제 채택 출력: 양쪽 모두 R0 유지

합성 보류 평가에서 안전 조건을 만족하는 임계값이 없었다.
가장 높은 사전 후보0.999에서도 정상 코너 손상은 다음과 같다.

- SYN:205/9,900 = 약2.07%.
- MIX:123/9,900 = 약1.24%.

기준은1% 이하이므로 두 모델 모두 `threshold: null`로 비활성화했다.
실제 실사194장 출력은 R0와 동일하다. 최종 모델, 수도레이블, 학생 학습에
새 선택기를 적용하지 않았다.

## 4. 원시 후보 진단: 무엇을 배웠는지 확인하되 채택 결과와 구별

학습기의 argmax 자체는 다음 후보를 제안했다. 이 결정은 GT를 읽기 전에
저장된 확률에서 결정적으로 얻었다. 실사 GT로 임계값을 고르거나 여러
임계값 중 좋은 것을 선택하지 않았다. 별도 `UNDEPLOYED_*` 자료로만 보존한다.

| 미적용 후보 | 번호 변경 이미지 | >20→≤10 복구 | 이 중 >100→≤10 | <5→>10 손상 | PCK20 |
|---|---:|---:|---:|---:|---:|
| SYN |34|46/281|31|85/511|69.33%|
| MIX |32|46/281|31|74/511|70.39%|

R0의 PCK20은77.86%다. 따라서 원시 후보를 그대로 적용하면 전체 성능이 나빠진다.

사용자의 의자·콘 사진 `eval_pallet07:1778652166837872128`에서는
원래 평균264.90px에서 미적용 후보23.16px로 감소했다. 이 후보를 선호한 확률은
SYN0.965/MIX0.886이었다. **GT를 보고 고른 후보가 아니라 학습기 자체의 판단**이다.
그러나 안전 기준을 통과하지 않아 실제 출력에는 적용하지 않았다.

여기서는 새 물리적 꼭짓점 위치를 찾은 것이 아니라, 같은8개 위치의 역할 번호를
바로잡은 것이다. wireframe의 위치 집합은 같고, 남은23px 수준의 위치 오차도
해결되지 않았다. 번호 문제와 위치 문제를 같은 개선으로 포장하지 않는다.

## 현재 결론

추가 레이블 없이도 일부100px 이상 코너 대응 오류를 바로잡는 판단은 학습했다.
하지만 정상 대응까지 바꾸는 오판이 많아 **해결책으로 채택할 수 없다**.
문제는 이번에는 '큰 이동을 전혀 못 만든다'가 아니라 '바꿔야 할 때와
그대로 둬야 할 때를 안전하게 구별하지 못한다'이다.
이 결론으로 새 어노테이션이나 태그를 필수조건이라고 주장하지 않는다.

검사7개 통과. 점수의 C2 불변성,90도 후보 교환 등변성, 원본 입력 보존,
padding 특징 차단, 정답 그룹 정의, 보류 calibration의 기권 동작,
자연 오류 발굴에서 C4/복구불능 사례 제외를 검사했다.
추가 calibration 검사에서 대칭 fixture의 두 잘못된 분기가 동점일 때
코너별 벡터까지 동일해야 한다는 부적절한 테스트 가정을 고쳤다.
실제 학습/추론 코드는 그 수정으로 바꾸지 않았다.

## 파일

- `PROTOCOL.json`, `SOURCE_COMPLETE.json`: 학습/검증 명단 및 특징 해시.
- `FIT_SYN.json`, `FIT_MIX.json`: 학습과 합성 보류 calibration.
- `DECISION_LOCK.json`, `OUTPUTS_LOCK.json`: 실사 GT 채점 전 고정 결과.
- `RESULTS.json`: 실제 허용된 출력, 즉 R0 유지 결과.
- `UNDEPLOYED_ARGMAX_DIAGNOSTIC.json`: 미적용 원시 후보의 별도 진단.
- `outputs/pallet_type_selftrain_v1/selftrain_recovery_v1/identity_rank_hard/index.html`:
  의자·콘 사진 및 전체194장의 원래 출력/미적용 후보 비교. 성공·손상 모두 포함.
