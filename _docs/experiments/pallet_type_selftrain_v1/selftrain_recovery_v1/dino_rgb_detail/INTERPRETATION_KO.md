# 원본 RGB 세부정보 경로 추가: 합성-only 5,000스텝

결론: 추가 어노테이션·태그 없이 학습과 검증을 완료했지만, 큰 코너 복구 문제의 해결책으로 채택하지 않는다. 최종 모델·수도레이블 풀·필터는 변경하지 않았다.

## 같은 일반 PLASTIC 194장 비교

| 지표 | R0 | 기존 DINO SYN5k | RGB 경로 추가 SYN5k |
|---|---:|---:|---:|
| PCK20 (%) | 77.86 | 71.32 | 70.98 |
| 관측 코너 오차 중앙값 (px) | 7.51 | 7.19 | 7.05 |
| 관측 코너 오차 P90 (px) | 43.64 | 83.65 | 83.55 |
| >20px → ≤10px 복구 / 281 | 0 | 67 | 62 |
| <5px → >10px 손상 / 511 | 0 | 68 | 64 |
| 기존 어떤 점에서도 >40px 떨어진 정답 복구 / 64 | 0 | 3 | 4 |

중앙값 개선만으로 채택하면 안 된다. R0 대비 큰 오차 영역이 악화되고 정상 코너의 12.52%를 손상시켰다. 실제 큰 위치 복구 4개도 전체 자세 복구를 뜻하지 않는다. PCK는 미검출/매칭 실패 벌점을 포함한 1,513개 분모이고, 관측 코너 통계와 복구/손상은 매칭된 1,459개에서 계산했다.

실제 큰 위치 복구 4개:

- `eval_outside:1778651650570397184` G5: 45.06 → 8.35px.
- `eval_pallet07:1778652126319943168` G4: 72.56 → 8.81px.
- `eval_pallet09:1778653806958839552` G5: 60.11 → 4.07px, G6: 60.59 → 4.91px. 각각 기존 어떤 점에서도 58.35px / 58.80px 떨어져 있었다.

원래 의자/콘 사진의 평균 오차는 R0 264.90px → 기존 SYN5k 119.07px → RGB SYN5k 124.87px였다. 저장된 비교 이미지에서 여전히 코너 역할과 연결이 잘못되며, 원래 요청 사례를 해결하지 못했다. 위 마지막 복구 사례도 오른쪽 두 코너의 복구이지 전체 프레임 성공이 아니다.

역할을 무시하고 새 출력 8개 중 어떤 점이라도 정답 10px 안에 있는지 확인해도 큰 위치 오류 64개 중 5개에 불과하다. 이것은 평가 GT를 이용한 사후 후보 존재 진단이지 적용 가능한 성능이 아니다. 출력 선택에 사용하지 않았다.

## 무엇을 바꿨는가

기존 frozen DINO 의미 특징 경로에 원본 RGB 경로를 추가했다. 같은 R0 예측 박스로 만든 768×576 crop에 Gaussian(5×5, sigma1)을 적용하고 crop 좌표 (4x,4y)에서 표본화한 RGB를 사용한다. 3→16→32→32 convolution 경로를 거쳐 원래 출력 가중치로 9개 heatmap에 더한다. 추가 경로의 초기 출력은 정확히 0이고, 원래 파라미터의 초기값도 일치한다. 좌표 힌트·이동 제한·새 기하 필터는 없다.

같은 합성 train 8,192장, held64, 5,000스텝의 표본 순서, GT/지원 mask, DINO feature, loss, decoder, seed, AdamW 0.001/0.0001을 유지했다. 실사/수도레이블 학습 분기는 사용하지 않았다. RGB 정보와 파라미터 수가 동시에 바뀌므로 정보만의 순수 인과 효과라고 주장하지 않는다. 마지막 5,000스텝만 평가하며 중간 checkpoint 선택은 하지 않았다.

합성 held64 PCK10은 기존 78.24% → 78.82%, P90은 55.16 → 49.86px였다. 기존 R0의 90.20% / 9.50px 보존 기준에는 크게 못 미친다. 학습 후 RGB 분기만 끄는 사후 진단에서 PCK10은 78.63%, P90은 48.78px였다. 이는 별도로 학습한 ablation이 아니지만, 이 작은 세부정보 경로가 큰 위치 오류를 해결했다는 근거도 아니다.

## 검증·보존

- 30개 회귀검사 통과, 합성 입력 8,256개의 기존 feature/target/mask 보존 확인.
- RGB 표본화 좌표·정규화·영상 gradient·좌표 힌트 비의존성 검사.
- 최종 모델의 전체 194장 GPU 출력 재현: 최대 차이 0px.
- 카메라/깊이/새 CAD/수동 레이블/태그 추가 없음. 평가 GT는 점수와 사후 분석·표시에만 사용.
- 초기 입력 준비 프로세스는 원인 미상의 SIGTERM(143)으로 한 번 종료됐다. 실제 종료 확인 후 동일 입력을 재검증하며 재개했고, 최종 학습은 5,000스텝 전부 완료됐다. GPU 학습 약 162초. 시스템/드라이버/재부팅 변경 없음.
- 근거: `PROTOCOL.json`, `FIT_SYN.json`, `RESULTS.json`, `SOURCE_DETAIL_ABLATION.json`, `COMPLETION_AUDIT.json`.
- 전체 이미지: `outputs/pallet_type_selftrain_v1/selftrain_recovery_v1/dino_rgb_detail/index.html`. 원래 요청 사진을 첫 번째로 두고 194장을 모두 포함한다. `000.jpg`와 `003.jpg`를 직접 확인했다.

반복 DEV 실험이며 독립 확증이 아니다. 단순 학습량 증가에 이어 작은 RGB 경로 추가도 충분하지 않았다는 결과다. 더 느슨한 필터로 이 출력을 채택하지 않는다. 추가 수동 레이블이 필수라는 결론도 아니다. 올바른 위치와 코너 역할을 함께 생성하고 정상 코너를 보존하는 목표는 미완료다.
