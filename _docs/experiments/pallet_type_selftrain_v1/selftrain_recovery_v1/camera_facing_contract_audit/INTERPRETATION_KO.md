# 옛 면적 기반 번호 규칙 감사의 해석

과거 converter와 현재 학습/평가 레이블의 불일치를 확인한 읽기 전용 감사다.
현재 레이블이 틀렸다는 판정도, 모델 보정 결과도 아니다.

합성60,000장 중 완전 감독57,348장에서 옛 규칙의 exact identity는
36,287장(63.28%)이었다. G38과 P0/TEX 사이 큰 차이를 발견했으나,
이것만으로 소스 간 정답 모순이라고 단정하지 않았다.
실사 PLASTIC194장에서는 완전 감독175장 중162장이 이 규칙과 일치했다.
일치 여부로 실사 GT를 고치거나 프레임을 평가에서 제외하지 않았다.

후속 `../renderer_front_visibility_audit/INTERPRETATION_KO.md`에서 합성
원본을 전수 확인했다. 모든 소스의60,000장에서 물체 중심 기준
카메라 방향과 가장 정면인 면이 기존 앞면과 일치했다. 옛 면적 규칙의
불일치는 높은 시점에서 크게 늘었다. 따라서 그 규칙을 현재 생성기의
정답 규칙으로 취급하여 재번호 지정하는 접근은 채택하지 않는다.

앞면 선택의 일치만 검증한 것이며, 모든 레이블의 정확성·실사로의
일반화·큰 코너 위치 오류의 해결을 입증한 것은 아니다.
추가 어노테이션이나 태그가 필수라는 결론도 내리지 않는다.
