# 다중 위치 후보 진단 — 2026-09-20

## 결론

최고점 하나만 보는 것보다 대안 위치는 더 남아 있다. 그러나 **후보 증가를 실제 복구 성능으로 사용할 수 없으며, 단순한 코너별 선택기만으로 해결된다는 근거도 부족하다.** 모델·수도레이블·최종 예측은 바꾸지 않았다.

동결된 `dino_source_diversity` SYN/MIX 모델의 각 코너 heatmap에서 5×5 국소 최대점을 찾고, grid 8px(원래 crop 32px) 이내 중복을 제외한 상위 5개를 생성했다. 각 최대점 주위 기존 5×5 기대 좌표 decoder를 그대로 썼다. 1순위 실사 출력 388개는 기존 저장 예측과 정확히 같다. 모든 후보를 고정한 뒤 GT 사후 진단을 수행했다.

## 실제 큰 위치 오류 64개에 대한 후보 존재

64개는 모든 R0 예측점이 정답에서 40px 초과 떨어진 코너다. 아래는 두 모델의 **모든 채널**과 R0를 합친 후보 중 정답 근처 점이 하나라도 있는 개수다. 코너 역할·같은 프레임의 일관된 대응·일대일 사용을 요구하지 않는 낙관적 진단이다.

| 모델당 채널별 후보 수 | 정답 10px 이내 존재 /64 | 20px 이내 존재 /64 |
|---|---:|---:|
| 1 | 11 | 17 |
| 2 | 15 | 27 |
| 3 | 17 | 30 |
| 5 | 30 | 50 |

상위 5개에서 모델별 10px 후보 존재는 SYN 15개, MIX 24개다. 합집합 30개를 어느 한 모델이 복구한 성능으로 표시하지 않는다. 기존 모델의 실제 전체 출력에서 해당 코너를 복구한 수는 여전히 SYN 3개/MIX 6개다.

## 낙관적인 해석을 막기 위한 추가 확인

- 추가된 19개는 모두 `eval_pallet09` 세션의 8장에 몰렸다. 사용자 최초 의자·표지판 사진에서 새로운 10px 후보를 추가로 찾은 결과가 아니다.
- 기존 R0 프레임 대칭 대응에서 해당 **코너 채널**만 허용하면 상위 5개 후보의 존재는 15/64다. 두 공식 대칭의 채널을 코너별로 자유롭게 허용해도 16/64다. 이것도 프레임 전체가 하나의 대칭을 일관되게 쓰도록 제한한 실제 추론 성능이 아니다.
- 새로 지원된 19개에서 GT에 가장 가까운 peak의 5×5 확률 질량 중앙값은 약 0.0000657이다. 범위는 약 7.2e-8~0.0212다. 이는 GT 사후 선택으로 찾은 peak의 질량이며 성공 후보 중 최고 confidence라고 가정하지 않는다.
- R0+두 모델의 1순위는 그대로 두고 추가 후보만 같은 수의 무작위 위치로 바꾼 32회 참고 비교를 수행했다. 넓은 출력 영역 균등 샘플은 10px 지원 평균 13.44개(범위 11~17), R0 box 균등 샘플은 18.47개(15~22)였다. 실제 peak 30개는 이 참고치보다 많지만, 후보 수가 증가하면 우연한 근접도 증가한다. 이를 정식 유의성 검정으로 해석하지 않는다.
- 하나의 후보가 가까운 여러 GT 코너를 동시에 지원할 수 있다. 따라서 30개의 지원을 30개 코너를 동시에 복구하는 완전한 자세로 볼 수 없다.

## 기존 합성 검증 64장, 510개 코너

같은 채널의 후보만 고려한 10px 지원은 SYN 1순위 399→상위 5개 450, MIX 387→434였다. 일부 올바른 대안 위치가 heatmap에 있으나 최고점 선택에서 버려진다는 증거다. GT를 보고 선택한 후보를 새 정답이나 실제 추론 출력으로 적용하지 않았다.

다음 bounded 검증은 **서로 다른 코너를 임의로 이어 붙이지 않고, 기존 8개 점의 상대 배치를 유지한 전체 정렬**이다. 두 동결 모델의 영상 확률을 함께 사용하고, 적용 기준은 합성에서만 정한다. 평행이동·전체 index 재배열만으로 상대 형상 변형까지 복구할 수 없다는 제한은 유지한다. 이 진단만으로 전체 목표를 완료 처리하지 않는다.

## 검증

- 회귀검사 33개 통과.
- 실사 194장×2 및 합성 64장×2의 모든 후보·확률 질량·최대점 위치·유효 마스크를 GPU 재현해 정확히 비교.
- 실사 유효 peak의 국소 최대 조건 및 분리 간격을 독립 검사. 확률 질량을 CPU float64로 재계산해 허용 오차 2e-6으로 비교.
- 합성 1순위 지원 수는 기존 fixed source probe와 동일.
- 학습 0 step, 새 레이블·태그·프레임 필터·모델 승격·원본 예측 변경 없음.
- 반복 DEV이며 독립 확증 아님. MIX teacher의 과거 3장 평가 중복 이력 유지.
