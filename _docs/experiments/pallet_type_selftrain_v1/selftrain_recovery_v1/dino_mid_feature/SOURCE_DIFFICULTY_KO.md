# 기존 합성 정답에서 실제 큰 위치 오류를 얼마나 학습·검증했는가

새 수동 레이블이나 태그가 필요한지와 별개로, 기존 합성 정답의 활용 구성을 점검했다. 실사 평가 정답은 이 집계에 쓰지 않았다. 현재 실험의 표본·정답·loss·필터도 변경하지 않았다.

여기서 큰 위치 오류는 **지원되는 합성 정답 코너에서 유효한 기존 R0 코너 8개 중 어느 점까지의 거리도 40px를 초과**하는 경우다. 따라서 단순 코너 번호 교환으로 해결할 수 없는 위치 오류를 센다. 좌표는 원래 prepared 합성 RGB 픽셀 단위다. 예측 박스 기반 wide crop 안의 기존 GT 지원 mask만 사용한다.

| 구분 | 이미지 수 | 큰 위치 오류가 있는 이미지 | 해당 코너 수 | 전체 지원 코너 |
|---|---:|---:|---:|---:|
| 현재 학습 풀 | 8,192 | 31 | 77 | 64,911 |
| 현재 고정 source 검증 | 64 | 0 | 0 | 510 |
| 기존 eligible 합성 train 전체 | 55,915 | 196 | 460 | 442,827 |
| 기존 eligible 합성 held 전체 | 1,978 | 13 | 36 | 15,657 |

현재 학습 풀의 해당 코너 비율은 약 0.119%다. 고정 5,000스텝 표본 순서에서 전체 코너 노출 316,941회 중 해당 코너 노출은 364회다. 이는 표본 노출 수이며, microbatch별 loss 분모가 달라 정확한 loss 가중치 비율은 아니다.

## 해석

- 고정 source64의 clean 성능은 정상 코너 보존과 일반 위치 정확도 검사에는 쓸 수 있지만, 위 정의의 실제 큰 위치 복구를 직접 검증하지 못한다. 이전 source-gate 통과/실패를 큰 오류 복구의 검증으로 확대 해석하면 안 된다.
- 기존 정답 안에도 학습용 196장·검증용 13장의 실제 큰 오류 사례가 있다. 새 어노테이션 없이 학습 노출 비중과 검증 커버리지를 개선할 여지가 있다.
- 이것만으로 실패 원인이 확정된 것은 아니다. 현재 DINO head는 원래 점 좌표를 입력으로 사용하지 않고 영상에서 정답 위치를 배우므로, R0가 맞았던 이미지도 유효한 위치 학습을 제공한다. 희소한 R0 실패 사례의 비중을 늘리는 효과는 별도의 통제 실험으로 확인해야 한다.
- 전체 합성 풀에는 여러 팔레트 형태·재질이 섞여 있다. 절대 픽셀 임계값과 이미지 크기/도메인도 고려해야 하므로, 실사 일반 플라스틱으로의 전이를 보장하지 않는다.
- 원본 row 순서에서 처음 6개 train 사례를 시각화해 실제 가림·내부 구조·외곽 코너 위치 오류가 존재함을 확인했다. 이 육안 확인으로 학습 이미지를 추가 선택하거나 삭제하지 않았다.

## 검증

`SOURCE_DIFFICULTY_AUDIT.json`은 이전 wide cache 좌표에서 집계했다. `FULL_SOURCE_DIFFICULTY_AUDIT.json`은 원래 detector 입력 좌표·박스·gain에서 wide support를 독립 재구성했다. 두 계산의 선택된 8,256장별 지원 수, 정상 수, >20px 오류 수, 실제 큰 위치 오류 수가 모두 일치했다. 단위 변환·평행이동/배율 불변성·무효 입력점 제외·crop 밖 정답 제외의 회귀검사 4개도 통과했다.

시각화: `outputs/pallet_type_selftrain_v1/selftrain_recovery_v1/dino_mid_feature/source_tail_contact.jpg`.

후속 통제 실험의 근거일 뿐, 현재 모델의 개선 결과나 목표 달성 증거는 아니다. 추가 수동 어노테이션·태그를 요구하는 결론도 아니다.
