# 기존 점 위치 힌트를 뺀 영상 기반 보정 — 2026-09-20

## 결론

새 레이블이나 태그 없이 실제 큰 위치 이동을 일부 학습할 수 있었다. 그러나 **영상 재검출 결과로 기존 점을 모두 덮어쓰는 방식은 실패**했다. 큰 오차 복구와 정상 점 보존을 동시에 달성하지 못했으므로 미채택이다. 큰 코너 오차 복구라는 전체 목표도 미완료다.

이는 추가 수작업 어노테이션이 필수라는 증거가 아니다. 아래와 같이 기존 합성 학습 데이터에서도 정상 코너 손상이 발생한다. 현재 문제를 실사 정답 부족 하나로 단정할 수 없다.

## 변경한 것 / 변경하지 않은 것

입력의 9개 keypoint hint 채널을 0으로 고정하고, 출력 Gaussian prior를 제거했다. 넓은 시야 DINO head와 parameter 모양·초기값, 학습 특징 1,725항목, GT/pseudo 좌표와 마스크, 학습 순서·seed·optimizer·각 1,000 step·decoder는 동일하다. 두 경로를 함께 제거했으므로 어느 경로 하나만의 효과로 분해하지 않는다.

합성 학습 1,412장·분리 검증 64장, 실사 수도레이블 학습 217장·일관성 확인 32장. 기존 corruption 생성기는 호출되지만 생성된 점 좌표는 이번 head가 사용하지 않는다. R0 예측 박스는 여전히 crop을 정한다. 원래 invalid 코너와 중심점 보존 규칙도 그대로다. 따라서 R0 전체에서 완전히 독립된 검출기는 아니다.

초기 zero-head 출력은 uniform heatmap이며 identity가 아니다. 이 비교는 deployable residual refiner라고 가정하지 않고, 위치 힌트 없이 영상 특징이 새 위치를 찾는지 검증하기 위한 것이다.

## 검사와 제한

- 회귀검사 22개 통과.
- 1,725개 학습 캐시를 확장 시야 실험에서 byte-exact 재사용.
- 두 모델 각각 1,000 step의 실제 갱신 및 14개 state tensor 변화 확인.
- 전체 194장×2 출력 재추론 최대 차이 0px, 같은 영상 특징 hash 확인.
- 학습된 모델에 점 좌표를 1,000px 이동시키고 valid mask를 뒤집어도 388개 logits가 bit-exact 동일함을 검사. 실제로 점 힌트를 제거했다.
- 기존 박스·confidence·중심점·비선택 검출 보존. 새 프레임 필터·GT 기반 출력 선택 없음.
- 모든 출력 저장 후 GT 채점/사후 분해. 반복 DEV이며 독립 확증 아님. 기존 MIX pseudo teacher의 수동 학습 3장 중복 이력은 여전히 한계다.
- 최종 모델, 필터, 원본 라벨, split, 논문 표를 교체하지 않았다. GREEN/WOOD에 대한 개선 주장을 하지 않는다.
