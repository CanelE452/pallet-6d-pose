이전 MLP의 과신 가능성을 시험하기 위해 C2 후보 특징 차이에 선형 모델을

좌표 보정과 다르다. 기존 평가 대칭 C2를 C4로 바꾸지 않았다.

후자의 큰 숫자를 실사 큰 오류 복구 능력으로 해석하면 안 된다.
