# 동일 영상 보정기의 1,000→5,000 step 연속 학습

## 결론

**더 오래 학습하는 것만으로는 큰 코너 오차 복구와 정상 코너 보존을 함께 해결하지 못했다. 미채택이며 전체 목표 미완료다.** 추가 수동 레이블이나 태그가 필수라는 뜻은 아니다.

부모 `dino_wide_visual`의 1,000 step 모델과 AdamW 상태를 그대로 이어서 각 5,000 step까지 학습했다. 합성 학습 1,412장·분리 검증 64장, 기존 수도레이블 학습 217장·확인 32장, 모델 구조·특징·정답·학습률·원래 300-step 샘플 순환은 유지했다. 중간 점수가 아닌 고정 마지막 5,000 step만 실사에 적용했다. 원래 최종 모델과 이전 결과는 교체하지 않았다.

64개는 모든 R0 점이 해당 정답 위치에서 40px 넘게 떨어진 코너다. 번호·대칭 대응 변경만으로 생기는 개선과 분리했다. 한 코너의 복구를 전체 자세 복구로 간주하지 않는다. 두 모델과 R0의 모든 native 출력점을 합쳐 정답 역할을 무시해도, 이 64개 중 54개에는 10px 이내 점이 없다. 나머지 10개는 GT 사후 후보 존재 진단이지 실제 선택기의 성능이 아니다.

원래 의자·표지판 사진의 프레임 평균 오차는 R0 264.90px→SYN 139.24px / MIX 224.90px다. 직접 시각 확인 시 팔레트 코너 일부가 의자 위로 이동하고 역할 혼동도 남아 있어 성공이 아니다. [전체 194장 전후 비교](../../../../../outputs/pallet_type_selftrain_v1/selftrain_recovery_v1/dino_visual_long/index.html)의 첫 번째 사진으로 배치했다. 손상 사례도 제외하지 않았다.

## 합성 학습 상태

| 모델 | 학습 PCK10 1,000→5,000 | 분리 검증 PCK10 1,000→5,000 |
|---|---:|---:|
| SYN | 81.44%→96.46% | 71.76%→68.04% |
| MIX | 80.61%→96.99% | 72.94%→68.43% |

고정 1,412장에 대한 적합도는 크게 좋아졌지만 다른 합성 장면과 실사에서 좋아지지 않았다. 이 조건에서는 과적합/일반화 문제가 드러난다. 모델 용량이나 실사 정답 부재 중 하나만을 유일한 원인으로 확정하지 않는다. 다음 검증 대상은 이미 정답이 있는 합성 학습 영상의 다양성이다. 평가 GT로 좋은 이미지를 고르거나 새 수작업 레이블을 요구하지 않는다.

## 재현 검사 및 제한

- 회귀검사 24개 통과. 캐시 1,725항목과 이전 1,000-step 이력 보존.
- 원래 모델·optimizer 상태를 정확히 복원하고 두 번의 다음 10개 업데이트를 저장 loss와 절대오차 1e-5 이내에서 확인했다. 실제 최대 오차와 반복 차이는 `COMPLETION_AUDIT.json`에 기록했다.
- 최초 감사의 GPU 학습 bit-exact 가정은 잘못이었다. 동일 상태로 반복해도 두 번째 업데이트부터 약 1e-7 수준 차이가 나타났다. 검사만 정정했으며 학습 결과·체크포인트·예측은 수정하지 않았다. 1,000개 업데이트 궤적이 bit-exact라고 주장하지 않는다.
- 최종 checkpoint와 resume_5000 모델은 정확히 동일하고 optimizer step은 모두 5,000이다.
- 194장×2 저장 예측은 GPU 재추론 최대 차이 0px. 영상 특징도 부모 실험과 동일 hash. 박스·신뢰도·중심점·비선택 검출 보존.
- 출력 고정 후 GT 채점·사후 분해. 평가 정답을 학습/선택에 사용하지 않았다. 반복 DEV이고 독립 확증이 아니다. MIX teacher의 과거 수동 학습 3장 중복 한계는 유지한다.
- 새 레이블·태그·프레임 필터·자동 모델 승격 없음. GREEN/WOOD 개선 주장 없음.
