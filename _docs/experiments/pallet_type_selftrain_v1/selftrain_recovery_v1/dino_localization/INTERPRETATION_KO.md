# DINOv2 영상 특징 기반 큰 위치 보정 — 미채택

2026-09-20. 추가 수동 어노테이션·태그 없이 GPU 학습/평가/출력 재현을
완료했다. 큰 코너 오류를 안전하게 복구하는 사용자 목표는 **미완료**다.
기존 최종 모델·수도레이블·평가 집합은 변경하지 않았다.

## 이번에 실제로 한 것

이전 번호 선택기는 기존8개 점의 번호만 바꿀 수 있었다. 이번에는 이미지
내용으로 검출 영역 전체에서 새 위치를 출력하는 보정기를 만들었다.
공식 [DINOv2](https://github.com/facebookresearch/dinov2)의 ViT-S/14 가중치를
고정하고, 별도의 작은 heatmap head만 학습했다. 공식 모델 자체가
팔레트 보정을 보장하는 것은 아니며 이번 head/실험은 프로젝트에서 추가했다.

소스 commit `7764ea0f912e53c92e82eb78a2a1631e92725fc8`, 가중치 SHA256은
`b938bf1bc15cd2ec0feacfe3a1bb553fe8ea9ca46a7e1d8d00217f29aef60cd9`다.
외부로 이미지를 보내지 않고 가중치만 내려받아 로컬 GPU에서 실행했다.
환경 패키지·드라이버·시스템은 변경하지 않았다.

R0의 예측 box로만 만든384×288 crop을392×294로 변환해
384×28×21 patch 특징을 얻었다. ImageNet 정규화를 사용했다.
특징과 기존 점의Gaussian 지도·위치 좌표로96×72 heatmap을 출력한다.
고정 Gaussian log-prior는 sigma12crop_px, 하한-6이다. head 마지막 층은
0으로 초기화한다. 전체 crop의 최대값 주변 고정5×5 기댓값을 읽는다.
변위 상한이나 새로운 프레임 탈락 필터는 없다.

단위 검사에서는100px 이상 떨어진 목표에도 gradient가 전달되고 출력
이동이 가능함을 확인했다. 이는 모델이 실제 실사 오류를 고쳤다는
증거와 다르며, 실제 성능은 아래 실사 평가로만 판단한다.

## 학습 자료와 통제

- 합성: 이전 source 학습 순서에 등장한 고유1,412장, 보류64장.
- 실사: 기존 수도레이블217장, 나머지32장은 수도레이블 일치도 probe.
- SYN: 합성8장/batch.
- MIX: 같은 순서의 합성8장+기존 실사8장, source/real loss 각각0.5.

양쪽 모두 동일한 새 head 초기화, AdamW lr.001/weight_decay.0001,
seed20260929,1,000step, micro4, 고정 last1000을 사용했다.
이전300step 입력 순서를 순환하여1,000step으로 늘렸다.
입력 점은50% 그대로,25% 한 코너,25% 감독 가능한 모든 코너를 기존
목표 주변 box diagonal의.05–.15 범위로 교란했다. 목표 좌표와 원래
신뢰 마스크는 변경하지 않았다. 중심점·unknown/PnP-only 점은 감독하지 않았다.
loss는 microbatch의 감독 코너에 대한 bilinear heatmap CE 평균이다.

신규 수동 라벨은0이며, 예전에 저장한 실사1장을 이번 학습에 새로 넣지도
않았다. 과거 수동 자료의 PLASTIC3장은 현재 평가와 겹쳐 직접 학습에
재사용하지 않았다. 다만 MIX 수도레이블의 기존 Replay teacher에는
그 역사적3장 중복이 남아 있다. SYN은 real supervision을 사용하지 않는다.

원래 PoseFix와는 특징·head·loss·학습 이력이 함께 바뀐 묶음 실험이다.
개선/악화를 DINO 하나의 효과로 인과적으로 귀속하지 않는다.

실사 GT로 checkpoint·임계값·출력 후보를 고르지 않았다.

복구/손상 코너는 기존 matched186장, 감독1,459코너 기준이다.
PCK 및 나머지 표 지표는 기존 평가 함수를 그대로 사용했다.
40px 이상 복구도 SYN4/MIX9개로, 이번의 큰 오류 복구는 모두100px
초과 사례였다. 작은 중앙값 개선만으로 성공을 선언하지 않는다.
정상 손상률6.85%/9.78%로 기존1% 기준을 크게 넘었다.

이미 고정된 저양각 제외159장에서도 SYN15개 복구/29개 손상,

Pose MAIN IoU3D median도 SYN0.4966/MIX0.3768로 낮았으며,
translation median은12.35/15.09cm였다. 키포인트 일부 개선을 전체 pose
개선으로 바꾸어 보고하지 않는다.

## 100px 복구를 어떻게 해석해야 하나

SYN4개 중3개, MIX9개 중7개는 정답10px 안에 **다른 R0 점이 이미 있던**
사례다. 나머지는 다음과 같다.

| 모델/사례 | 해당 코너 오차 | 기존 모든 점 중 정답에 가장 가까운 거리 |
|---|---:|---:|
| SYN / eval_night09:1779449638581035008 G2 |132.03→6.23px|10.03px|
| MIX / 같은 사진 G3 |144.96→6.83px|13.80px|
| MIX / eval_pallet07:1778652166837872128 G4 |271.89→9.49px|12.64px|

따라서 '100px 떨어진 완전히 새로운 물리적 꼭짓점을 발견했다'고
과장할 수 없다.10.03px는 특히 진단 경계에 걸친 수치다.
반대로 실제 출력 좌표가 이동하고 대응 오차가 줄어든 사실은 보존한다.

추가 사후 거리별 분해에서도, 기존 어떤 점도 정답20px 안에 없으면서
원래 해당 코너 오차가40px를 넘던76코너의 복구는 양쪽 모두0이었다.
기존 어떤 점도40px 안에 없던64코너도 모두0이었다.
이 거리 구간은 진단일 뿐, 새 gate나 평가 제외 조건으로 사용하지 않았다.
20px 초과 전체에서는 최근접 기존 점도20px 밖이던191코너 중
SYN16/MIX20개가 복구되어 중간 크기의 실제 위치 보정은 나타났다.

사용자가 처음 제시한 의자·콘 사진의 프레임 평균은
264.90→SYN236.32/MIX237.27px다. MIX에서G4 하나가9.49px가 되었지만
다른 코너는 여전히 잘못 대응되어 전체는 크게 틀렸다.
전체 이미지 대조에서도 여러 출력 채널이 같은 꼭짓점 근처로 모이는
문제가 보였다. 한 코너를 복구한 것을 프레임/팔레트 전체 복구로 세지 않는다.

## 수도레이블 일치도와 실제 정답은 다르다

보류32장의 인위적 입력 교란에서 기존 수도레이블로 되돌리는 비율은
SYN28/69, MIX61/69였다. MIX의 수도레이블 PCK10은94.07%로 높았다.
그러나 이 결과는 평가 GT 정확도가 아니다. MIX의 실제 실사 성능은
표와 같이 정상 손상50개/PCK20 하락이었다. 같은 수도레이블을 잘 따라
학습하는 능력과 잘못된 실사 정답 방향을 복구하는 능력을 구분한다.

합성 보류64장에서도 R0 PCK10=90.91%, P90=7.69px에 비해
SYN88.93%/12.27px, MIX86.76%/14.37px로 보존 기준에 실패했다.
인위적 큰 입력 교란의86/123·83/123 복구를 자연 오류의 개선으로
대신 주장하지 않는다.

## 검증 및 자료

- 회귀검사14개 통과: 원래 점 prior 초기화, 원거리 gradient/출력,
  unknown/중심점 감독 제외, 이전 perturb/decoder 동작.
- 캐시1,725장의 좌표·목표·마스크·crop 행렬을 기존 입력으로 재계산했다.
- 합성 train/heldout scenario 분리, 새 실사217장과 평가 exact-hash 중복0.
- 두 head 초기 상태 동일, 각각1,000 실제 optimizer step과 가중치 변화 확인.
- DINO 원본 code/weight hash 불변, 모든 backbone 파라미터 동결.
- hash로 선택한8개 캐시를 원본 RGB에서 재추출했다.
- 실사194장×2개 모델=388개 출력을 모델 forward부터 다시 계산하고
  보존 계약·코너 오차도 재확인했다. GT는 forward에 사용하지 않았다.
- 비교 HTML에는 좋은 사례만 고르지 않고 전체194장을 포함했다.

영상 특징 저장은 약41.95초, head 학습·probe는 SYN9.80초/MIX18.14초였다.
모델 다운로드/데이터 준비/평가/검증/갤러리는 이 시간에서 제외했다.
전체 backbone을 재학습한 시간이 아니다. GPU 학습 관측 온도는 약57–60°C였다.

현재 결정: 실패 결과를 보존하고 **최종 모델·수도레이블에 적용하지 않음**.
