# 큰 코너 복구: 실사 정답 확인 후보 준비

## 현재 판단

목표는 아직 미완료다. 자동 후보 합의는 큰 오류 23개를 복구했으나
정상 코너 24개를 훼손했다. GT로 후보를 고른 106개 복구는 진단용
상한이며 자동 모델 성능이 아니다. 이 결과로 수도레이블을 재생성하거나
학생을 재학습하지 않았다. 합성 선택기는 protocol 준비 단계이며,
현재 상태를 학습 완료로 보고하지 않는다.

사용자에게 제안한 다음 경로는 소량의 직접 확인된 실사 코너를 통해
실제 입력 오류를 학습하고, 보정기의 복구/훼손을 별도로 검증한 뒤
self-training으로 진행하는 것이다. 이 제안에 대한 어노테이션 수행
및 새 실사 학습 사용 확정은 아직 받지 않았다.

## 이번에 실제 완료한 것

- 기존 실사 풀 1,000장의 메타데이터·예측을 재사용했다. 이 숫자는
  팔레트가 매 장면에 있다는 의미가 아니다. 배경 프레임도 포함한다.
- 최초 불확실도 기반 후보에는 배경이 섞였음을 이미지로 확인했다.
  해당 `real_support_review` 결과를 지우지 않고 v2로 정정했다.
- v2는 검출 점수 0.5 이상, 예측 상자 대각선 120px 이상,
  유한한 8점 등 어노테이션 대상 조건을 통과한 485장에서 30장을 제안했다.
  이 조건은 기존 pseudo/평가 필터 변경이 아니며 정답 보장도 아니다.
- 제안 학습 20장: 주간 10장·야간 10장, 5개 촬영 그룹.
- 제안 검증 10장: 주간 5장·야간 5장, 다른 2개 촬영 그룹.
- 기록 그룹 별칭과 부분 중복의 전이 관계 및 이미지 해시를 확인했다.
  고정 평가 스냅샷과 중복 0, 제안 학습/검증 간 중복 0이다.
- 검증 후보는 예측 오차/불확실도 순위로 고르지 않고 시간 구간의
  중앙 프레임으로 정했다. 단, 검출 대상 조건은 동일하게 적용한다.
- 기존 풀은 과거 연구에 노출되었다. 새로운 전역 독립 시험이 아니다.
- 해당 야간 세션의 legacy JSON 45개는 투영점 혼입 가능성 때문에
  자동으로 직접 관측 정답으로 취급하지 않았다.
- 생성 정답 0, 학습 실행 0, 기존 평가/최종모델/pseudo 변경 0.

갤러리:

목록:

후보/중복 감사:

## 다음 단계의 필수 확인

1. 사용자와 실사 정답 확인·학습 사용 범위를 확정한다.
2. 보이는 코너만 직접 확인하며 코너 번호, 가시성, 출처를 기록한다.
   가린 점, 추정점, PnP 투영점을 직접 관측 정답으로 가장하지 않는다.
3. 현재 후보가 원거리·정면·야간에 치우친 한계가 있다. 사용자가
   문제 삼은 45도/뒤쪽 큰 오류를 충분히 포함하는지는 수동 검토로
   판단해야 한다. 20장이라는 수만 맞추어 학습 시작하지 않는다.
4. 실제 정답이 생긴 뒤 입력 R0의 오류를 측정해 큰 오류 학습 사례가
   존재하는지 확인한다. 입력 좌표를 임의로 흔든 성능만으로
   실제 오류 복구를 주장하지 않는다.
5. 검증 촬영 그룹을 학습/수도레이블/threshold 조정에 섞지 않고,
   큰 오류 >20px → <=10px 복구와 정상 <5px → >10px 훼손을 함께 본다.
6. 검증을 통과한 보정기만 수도레이블 생성에 사용한다. 별도 독립
   확인이 없으면 논문상 새로운 독립 성능 향상으로 주장하지 않는다.

## 검사

`test_real_support_review.py` 및 `test_real_support_review_v2.py`: 4개 통과.
전이 중복 차단, 검증 선별의 불확실도 독립성, 정상 후보 혼합,
대상 검출 조건을 검사한다. 정답 정확도나 학습 효과를 검증한 테스트가 아니다.

`check_real_support_review.py`: 사용자 브라우저와 분리한 임시 프로필로
30개 이미지, 20/10/30 필터 및 실제 이미지 로드를 확인한다.
결과는 v2 디렉터리 `BROWSER_CHECK.json`에 기록한다.
