# 종류별 보정 수도레이블 self-training 비교

2026-09-20. **일반 플라스틱과 초록의 독립 학생 학습·평가 완료. 목재는 별도 촬영의 카메라 정보 부족으로 미실행.**

결론: 이번 1 seed·320 update의 짧은 실험에서는 두 학생 모두 R0의 PCK@20을 넘지 못했다. 일반 플라스틱은 박스 매칭 성공이 늘어 혼합 결과, 초록은 정확도가 악화됐다. 기존 최종 모델을 교체하지 않았다. 이것이 모든 학습량·방법의 self-training 불가능성을 증명하는 것은 아니다.

## 사용자 승인과 범위

- 방금 수행한 영상 변형 안정성 필터는 사용하지 않는다. 면 모양 및 X 교차 필터도 사용하지 않는다.
- 승인된 경로: **R0 추론 → confidence·flip·LOO → frozen Replay 보정 → 보정된 8점 LOO → 수도레이블 → 종류별 R0 학생 학습**.
- 수도레이블 보정기는 기존 PoseFix Replay다. N2 다음에 Replay를 적용하지 않는다. Replay 자체의 새 학습도 아니다.
- 학습 전후 비교는 **R0 단독 검출기 vs self-trained 학생 단독 검출기**다. 추론 시 N2/Replay를 붙이지 않는다. 종류별 모델은 알려진 종류에 따라 선택하며, 종류 분류기를 학습한 것은 아니다.
- 기존 모델, 평가 라벨, paper release 및 이전 실험 결과를 보존했다. 새 결과는 별도 루트에 저장했다.

## 주 결과 — 평가 이미지를 걸러내지 않은 전체 집합

PCK는 평가 가능한 코너 중 해당 pixel 오차 이내의 비율이다. 전체 물체에 허용된 대칭 대응을 적용하며, 검출/박스 매칭 실패는 기존 규칙대로 image-diagonal penalty를 부여한다. AP와 다른 지표다.

| 종류 | 평가 장수 | 모델 | PCK@10 | PCK@20 | 매칭된 코너 median / P90 (px) | 박스 매칭 성공 |
|---|---:|---|---:|---:|---:|---:|
| 일반 플라스틱 | 194 | 학습 전 R0 | 60.08% | **77.86%** | 7.51 / 43.64 | 186 |
| 일반 플라스틱 | 194 | 합성-only 추가 학습 | 58.10% | 76.14% | 7.17 / 40.36 | 181 |
| 일반 플라스틱 | 194 | 해당 종류 self-training | 58.76% | **77.26%** | 7.55 / 42.48 | 190 |
| 초록 | 150 | 학습 전 R0 | 82.23% | **88.99%** | 4.58 / 9.21 | 134 |
| 초록 | 150 | 합성-only 추가 학습 | 79.00% | 86.78% | 4.21 / 11.37 | 134 |
| 초록 | 150 | 해당 종류 self-training | 74.60% | **85.02%** | 4.44 / 13.68 | 134 |

- 일반 플라스틱: R0 대비 PCK@20 **−0.59pp**, 합성-only 대비 **+1.12pp**. 박스 매칭 +4장. 기준점 평균 오차가 개선된 93장, 악화된 99장, 동일 2장. 기존 <5px 코너가 >10px로 악화된 점 28개, 기존 >20px가 <10px로 회복된 점 30개. 전체 정규화 평균 오차 E_sym은 0.06484 → 0.04596이지만 PCK는 개선되지 않아 전반적 우세로 판단하지 않는다.
- 초록: R0 대비 PCK@20 **−3.96pp**, 합성-only 대비 **−1.76pp**. 박스 매칭 수는 같지만 코너 P90이 9.21 → 13.68px로 악화. 개선 60장, 악화 75장, 동일 15장. <5px → >10px 악화 11점, >20px → <10px 회복 0점.
- 매칭된 코너만의 median/P90은 모델에 따라 구성원이 달라질 수 있으므로, 고정 평가 코너 분모의 PCK 및 매칭 수와 함께 해석해야 한다.

앞선 필터 실험의 **비초록 55장/초록 124장 수치와 비교하지 않는다.** 이번은 일반 플라스틱 전체 194장과 초록 전체 150장, 그리고 보정 전 R0/학생의 결과다. 필터 후 조건부 성능 상승을 모델 개선으로 보고한 것이 아니다.

## 학습 데이터와 동일 예산

| 종류 | 학습 후보 | 1차 필터 통과 | 보정 후 LOO 통과 | 고정 학습 목록에 실제 포함된 고유 실사 |
|---|---:|---:|---:|---:|
| 일반 플라스틱 | 1,000 | 259 | 249 | 217 |
| 초록 | 1,000 | 666 | 666 | 362 |

- 일반 플라스틱: 기존 평가 촬영과 분리된 검증된 adaptation pool을 사용했다.
- 초록: 2026-09-01의 기존 square-pallet 촬영 4개 세션에서 각 250장을 프레임 순서상 균등 구간으로 선택했다. 기존 수동 annotation 프레임은 제외했다. 현재 초록 평가는 9월 2/3/4일 촬영이다.
- 현재 DEV319+GREEN150 평가와 학습 원본 이미지 해시 중복 및 알려진 촬영 그룹 중복이 없음을 검사했다. 초록 9월 1일 자료의 이전 연구 노출은 있으므로 새로운 독립 확인 실험이라고 부르지 않는다.
- 모든 학습 arm은 **동일한 R0 가중치에서 독립적으로 시작**했다. 5 epoch × 1,024 image slots, batch16/nbs16 = 실제 optimizer update **320회**씩.
- 학생은 epoch당 합성 512 slots + 해당 종류 실사 수도레이블 512 slots를 사용했다. 미니배치마다 정확히 1:1은 아니며 epoch 전체 비율이다. 고정 예산으로 복원추출한 목록을 5회 순회했으므로, 통과한 수도레이블 모두를 사용한 것은 아니다. 실제 고유 노출 수를 위 표에 명시했다.
- 합성-only 대조군은 실사 512 slots도 합성으로 대체했다. 모든 arm의 합성 원천은 같은 512장이다. **이번 선택된 replay에는 empty-label negative가 0장이었다.** 별도의 negative 실사나 추가 합성 negative를 넣지는 않았다.
- AdamW lr 1e-4 → 1e-5, weight decay 1e-4, warmup 0, mosaic/flip 0, 고정 증강·seed42. 마지막 epoch의 `last.pt`만 평가했다. 프레임워크가 생성한 `best.pt`는 학생 선택에 사용하지 않았다.
- 학습된 가중치가 실제 R0에서 달라졌는지 및 5 epoch/320회 업데이트를 산출물로 확인했다. 학습 시간은 일반 약79초, 초록 약77초, 대조군 약78초였다(데이터 준비·추론 시간 제외).

## 수도레이블 보존과 검증

1. 원본 confidence ≥0.85, confidence ≥0.5인 유효 코너 ≥6개에 대해 기존 flip·median LOO ≤0.05를 검사했다.
2. 통과한 이미지에만 frozen Replay를 실행했다. 보정 후 낮은 confidence 코너도 포함한 유한 8점 median LOO ≤0.05를 적용했다. 두 번째 flip 검사, 추가 reprojection/면 모양/안정성 검사는 없다.
3. 통과 여부를 판단한 뒤 보정 좌표를 수정하거나 평균내지 않았다. R0의 box/score/keypoint confidence/중심점도 그대로다.
4. 학습 입력에는 기존 R0 추론과 일치하도록 reflect101 border100을 한 번 추가했다. 수도레이블 좌표에는 같은 이동·정규화만 적용했다.
5. 저신뢰·원본 화면 밖 코너는 기존 V3 true-ignore sentinel1로 학습에서 제외했다. 합성 0/2 라벨에서는 stock loss와 같으며, 실험용 합성 샘플로 ignored keypoint gradient=0 및 stock loss parity를 실측 확인했다. 새로운 보정 loss나 architecture를 제안한 것이 아니다.
6. 모델별 전체 469장(일반194+목재125+초록150) 예측을 먼저 저장한 뒤 정답 기준점으로 점수를 계산했다. 원래 R0의 저장된 222장 결과와 parity도 확인했다.
7. 새 데이터 export/필터 경계 단위 검사 4개 통과, 원본 모델·이미지·라벨·코드 해시 검증 통과. 평가 annotation을 수도레이블이나 학생의 supervised target으로 사용하지 않았다. 기존 Replay teacher의 과거 수동 실사9장 학습 이력은 그대로 유지된다.

## 목재는 왜 미실행인가

확인된 목재 촬영 `pallet_20260618_183705`, `pallet_20260618_184309`, 8월30일 주·야간 incoming은 현재 평가 원본과 같은 촬영이다. 해당 촬영의 비평가 프레임만 골라 넣어 촬영 누출을 만드는 방법은 사용하지 않았다.

별도 세로 영상 `data/pallet/raw_data/wood/selected/20260618_132917`의 225장은 있으나 카메라 K가 없다. 이전 7월9일 기록에도 해당 592×1280 영상은 별도 `--K` 또는 `--hfov`가 필요하다고 명시돼 있다. 임의 K로 LOO를 실행하거나 목재만 필터를 완화하지 않았다.

따라서 **목재 전용 학생은 학습하지 않았다.** `RESULTS.json`에 있는 목재 결과는 다른 종류 학생의 교차 평가일 뿐, 목재 self-training 결과로 해석하면 안 된다. 이 부분을 진행하려면 별도 목재 영상의 유효 카메라 정보 또는 카메라 정보가 있는 평가와 분리된 촬영본이 필요하다.

## 해석 범위와 다음 판단

이번 고정 설정은 **채택하지 않는다.** 초록은 악화됐고, 일반도 코너 정확도가 R0보다 개선되지 않았다. 단순 합성-only 추가 학습도 PCK를 낮췄으므로 악화를 모두 수도레이블 보정 탓으로 분해할 수는 없다. 다만 초록 전용 self-training은 그 대조군보다도 낮았다.

1 seed·320 update의 제한된 개발 실험이다. 모든 self-training 방법이나 충분히 긴 학습의 효과를 확정하지 않는다. 최적화·라벨 잡음·촬영 차이 중 무엇이 주원인인지는 이 비교만으로 확정할 수 없다. 평가 결과를 보고 임계값, 학습량, checkpoint를 다시 골라 구제 실험을 하지 않았다.

AP, negative false positive, 물리적 6D 성능은 이번에 평가하지 않았다. PCK 개선이나 미개선을 해당 지표 결과로 대신 주장하지 않는다.
