# 일반 플라스틱 249장 — IoU 기준 가상 선별

2026-09-20 KST. 기존 GPU 추론 캐시를 재사용한 오프라인 검사. 라벨 변경, 실제 탈락, 학생 재학습은 하지 않았다.

## 정의

- 대상: raw confidence·flip·LOO → Replay 보정 → all8 LOO를 통과한 일반 플라스틱 학습 후보 249장 전부. 평가용 194장/초록/목재 제외.
- 영역: 첫 8개 코너의 convex hull. 영상 밖 좌표도 포함한 원본 이미지 좌표계의 연속 면적. segmentation mask나 검출 박스가 아니다.
- 보정 전후: R0 원본 코너 hull ↔ 저장된 Replay 보정 코너 hull.
- 변형 전후: 저장된 Replay hull ↔ 밝기 0.85/1.15, 크기 0.9/1.1 각 입력의 Replay hull. 크기는 기존 pixel-center 역변환을 사용한다. 네 IoU 중 최소값으로 판단한다.
- IoU < threshold일 때 가상 탈락. 같으면 통과. 두 기준 결합은 OR이며 평균하지 않는다.
- GT/정답 오차를 읽거나 이를 사용해 임계값을 선택하지 않았다. 사용자에게 제안한 0.9/0.8/0.7을 그대로 비교했다.

## 장수

| IoU 기준 | 보정 전후 탈락 | 변형 전후 탈락 | 둘 중 하나라도 탈락 | 남는 장수 | 유지율 |
|---|---:|---:|---:|---:|---:|
| 0.9 | 77 | 11 | 82 | 167 | 67.1% |
| 0.8 | 0 | 0 | 0 | 249 | 100.0% |
| 0.7 | 0 | 0 | 0 | 249 | 100.0% |

0.9에서 두 기준에 동시에 걸리는 6장이 있어 77+11−6=82장이다.

- 보정 전후 IoU: 최소 0.80764, 중앙값 0.91476.
- 변형 최소 IoU: 최소 0.83899, 중앙값 0.96530.
- 249장 모두 raw/refined 검출 박스 좌표가 같음을 확인했다. 따라서 검출 박스 IoU는 보정량 판별에 쓸 수 없다.

## 해석

0.9에서는 상당수 보정 전후 변화를 제한하지만 0.8 이하에서는 이번 후보를 추가로 거르지 못한다. 낮은 IoU는 잘못된 보정의 증거가 아니다. 필요한 정상 보정도 큰 외곽 변화를 일으킬 수 있으므로 이 결과만으로 0.9를 자동 채택하지 않았다.

반대로 IoU≥0.9여도 최대 코너 이동이 20px를 넘는 이미지가 보정 전후 비교에서 7장, 변형 비교에서 6장 있다. 내부 코너 이동과 코너 index 교환은 외곽 hull에 반영되지 않을 수 있다. 이 장수는 이동량에 대한 진단이며 20px 정답 오차나 새로운 탈락 기준을 뜻하지 않는다.

안정성 검토 상위50과 이번 IoU 기준은 서로 다른 순위/조건이다. 기존 상위50 검토 화면의 사용자 선택은 변경하지 않았다. “좋은 라벨 167장”으로 해석하면 안 된다. 정확도는 아직 수동 확인되지 않았다.
