원본 RGB, 가중치, 특징 캐시, 로컬 비교 갤러리는 이 Git snapshot에 포함하지 않는다. JSON의 경로·SHA는 해당 로컬 증거를 식별하며, clone만으로 모든 대용량 산출물이 제공된다는 의미는 아니다. 기존 평가 정답은 평가·감사·시각화에만 사용했고 새로운 수동 라벨이나 태그를 요구하지 않았다.

## 가장 최근 완료 실험: `dino_tail_sampling`

동일 MID 5,000스텝 모델과 Adam 상태에서 시작하여 같은 합성 학습 이미지 8,357장으로 각각 5,000스텝을 추가했다. UNIFORM은 균등 샘플링, TAIL은 기존 큰 오류 이미지 196장에서 절반을 샘플링했다. 별도 합성 검증 77장은 학습에 포함하지 않았다.

| 측정 | UNIFORM | TAIL |
|---|---:|---:|
| 합성 학습 큰 위치 오류 복구 | 160/460 | 460/460 |
| 별도 합성 검증 큰 위치 오류 복구 | 4/36 | 2/36 |
| 실사 큰 위치 오류 복구 | 6/64 | 4/64 |
| 실사 기존 정상 코너 손상 | 53/511 | 57/511 |
| 실사 PCK20, 전체 194장 | 75.21% | 73.89% |

큰 위치 오류는 정답 40px 이내에 기존 R0의 어떤 유효 코너도 없는 경우이며, 복구는 올바른 대칭 대응에서 오차 10px 이내이다. 정상 코너 손상은 기존 오차 5px 미만이 10px 초과로 바뀐 경우다. 기존 R0의 PCK20은 77.86%이다.

**큰 오류 반복 학습은 학습 사례를 맞혔지만 새로운 사례의 복구와 정상 코너 보존을 함께 해결하지 못했다.** 원래 의자·콘 사진도 전체 자세 복구에 실패했다. 공식 대칭 대응을 적용해도 별도 합성 검증의 4/36, 2/36은 변하지 않았다. 평가 GT를 써서 좋은 점만 선택하거나 출력에 적용하지 않았다.

증거: [결과](selftrain_recovery_v1/dino_tail_sampling/RESULTS.json), [GPU 재현 감사](selftrain_recovery_v1/dino_tail_sampling/COMPLETION_AUDIT.json), [대칭/위치 원인 분해](selftrain_recovery_v1/dino_tail_sampling/SOURCE_FAR_ROLE_DIAGNOSTIC.json).

감사에서 37개 검사 통과, 실사 194장 × 2 모델 출력 재현 오차 0px를 확인했다. 이는 구현·기록 재현 근거이지 성능 성공 근거가 아니다. 반복 DEV 평가이며 독립 확증은 아니다. 최종 모델은 교체하지 않았다.

## 준비만 완료: `dino_tail_affine`

동일 큰 오류 샘플링에 특징 공간 이동·회전·확대 증강만 추가하는 코드와 프로토콜을 보존한다. RGB를 변형한 뒤 DINO를 재추출한 것과 동일하다는 주장은 하지 않는다.

push 전 확인 기준 `PROTOCOL.json`, `CACHE_COMPLETE.json`, `EVAL_PROTOCOL.json`은 있으나 `FIT_AUG.json`, `RESULTS.json`은 없으며 관련 학습 프로세스도 없다. **아직 학습·성능 검증하지 않은 준비 상태**다. 사용자 push 요청으로 이 작업을 새로 실행하지 않았다.
