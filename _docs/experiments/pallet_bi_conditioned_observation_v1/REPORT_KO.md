# B·I 조건부 국소 관측 보정 결과

판정은 **명시적 B/I 조건의 추가 가치 미확보, 새 scorer 채택 보류**다. 세 seed의 COMMON 대비 BI 성공 수 변화는0,0,−1장이며, 회복/손상은4/4,6/6,2/3이다. 대표 seed를 최고 seed로 바꾸지 않았다. N3·SubPix 및 현재 운영 기본값을 유지하고 논문을 자동 수정하지 않는다.

## 관측은 좋아졌고 자세도 좋아졌나

대표 seed의 B full 참조 802점에서 q0 오차 평균은10.996px, COMMON 10.821px, BI 10.826px였다. I 77점에서는 각각14.368→14.231 / 14.177px다. BI의 I 오차는 COMMON보다 소폭 낮고 B는 소폭 높다. 자동 B/I 조건이 두 상태 모두에서 개선한 결과는 아니다. 부분선106코너는 full점 오차 분모에서 분리했다.

가상 투영 참조에서 q0보다 좋은 후보는 B583/802점·I35/77점이었다. 같은 제한된 후보 안의 사후 최소 오차도 B10.101px·I13.745px이며, 큰 초기 대응/위치 오류까지 작은 국소 이동으로 복구할 수 있다는 근거는 없다. 이 최소값을 새 선택기의 검증 성능으로 쓰지 않는다. 대표 두 군의 적용좌표가 다른 영상111장 중 BI의 평균 코너 오차가 낮은 것은51장이고, 그중 자세 위치 오차가 높아진 것은11장, 회전 오차가 높아진 것은19장이다. 관측 위치 품질과6D 오차의 개선은 일치하지 않았다.

공통 모델에도 역할을 추론할 기하·마스크·두 cue가 있으므로 c는 새 센서 정보를 더하지 않는다. 이 설계에서 도움이 될 수 있는 것은 조건의 귀납적 편향이며, 이론적으로 성능 향상을 보장하지 않는다. 학습 목표는 개별 가상 코너의 위치 품질이고 공동6D 오차·물리 선 소속을 직접 감독하지 않는다. 이것들이 병목 후보라는 해석과 이번 데이터에서 확인한 수치를 구분한다.

## 무엇을 먼저 의심해야 하나

RAW matched와 N0는 모두108/192이지만14회복·14손상이고179개의 실제 자세가 달라졌다. 원좌표만 써도 공통 후단으로 바꾸면 위치 평균이11.306→14.149cm, 회전 평균이10.631→13.077°가 된다. 새 보정의 결과를 원 F와 같은 후단 위의 개선으로 해석할 수 없다. 대표 COMMON/BI의22fallback과 rank 분포는 같고4회복/4손상은 양쪽에서 수락된170장 안에서 생겼다. 따라서 fallback 수만 줄이면 해결된다고 결론 내리지 않는다.

합성 validation235에서 기하 역할 참조로 조건만 바꿔도44→44였다. 적용 태그가 달라진78장 중 실제 관측이 바뀐 것은3장이다. 투영 좌표만 교체하면44→69로 성공은 늘지만 위치 평균25.289→30.322cm·최대511.834→1105.873cm로 악화했다. 영상 밖의 참조점21건은 기존 guard가 거부했고 분모에 남겼다. 정확한 subset·순환성·C1·물리 주석 부재는 [DIAGNOSTIC_RESULTS](DIAGNOSTIC_RESULTS.md)에 명시했다. 실제 선 정답이나 완벽한 실사 상태를 준 실험으로 바꾸어 부르지 않는다.

다음 수정 우선순위를 한 가지로 좁히면 **원 관측을 전달했을 때도 손상이 생기는 공통 자세 후단의 수용·W/D 분기 안정성**이다. 관측 조건망을 확대하기 전에 이 경로의 손상을 분리해야 한다. 이는 저장 결과의 진단에서 나온 제안이며, 새 guard나 정책의 성능을 검증한 결과가 아니다. 이번 작업에서는 추가 학습·임계값 탐색·새 캠페인을 시작하지 않았다. [고정 출력 원인 분해](CAUSE_DECOMPOSITION.md)에 실제 family·부분선·rank·source와 예시 ID를 남겼다.

## 실행과 공정성

기존 합성 train768/validation235, 원 asset/run split과 C1/C2를 유지해2모델×3seed=6fit을 완료했다. 각 seed의 초기 tensor·optimizer·프레임 순서 prefix를 독립 검산했다. 새 실사 지도학습/백본 forward/H1 fit/렌더/튜닝은0이다. 기존 상태 분류기와 CAL 교정의 실사 감독 이력은 유지하므로 전체 시스템 실사 감독0이라고 하지 않는다.

분할 전체768/235장 중 fullpoint 감독이 있는 프레임은532/171장이었다(합계703/1003). 나머지300장은 미관측 또는 고정 부분선 경로로 위치 점수망 loss를 만들지 않았으며, 자료 분모에서 삭제하거나0오차 target으로 채우지 않았다. 유효 후보 target은8048개이고 fixed partial504개는 이 loss에서 제외했다. 실제90epoch 원 곡선은 [TRAINING_CURVES.csv](TRAINING_CURVES.csv)에 있다.

원 v2의 두 cue를 같은15×49 픽셀에서 계산했다. 최대6선·12서로 다른 incident-neighbor 교점+q0를 보존하고, 전체 교점 일치 veto만 양군에서 공통 제거했다. target은 raw 교점이 아닌 blend 후 실제 적용좌표의 log1p(error/2px)다. loss는 candidate→corner→frame 평균 SmoothL1이며 argmin 실제 후보 하나를 쓴다.

완전 후보가 없을 때만 원 FACE 부분선을 사용하고 해당 full2D 우도는 폐기했다. 부분선은 normal만 구속하며 tangent endpoint 일치를 강제하지 않는다. 알려진 동일 픽셀 source의 중복은 억제하지만 서로 다른 픽셀에서 나온 같은 물리 변의 독립성까지 인증하지 못한다. O/T/U 영역·H1·R_CONT·전역 outline 비용은 추가하지 않은 공통 가시 점/부분선 경로이며 E0 재현이 아니다.

RAW_OBSERVATION_MATCHED는 원 가시q0만 같은 새 솔버에 넣은 기준이다. LEGACY_RULE_MATCHED는 기존 D1 frozen_BI_fit+CAL/recover stages와 같은N0 FACE 관측을 넣었다. LEGACY와 새 모델 차이는 후보 생성과 선택을 함께 바꾸므로 c 하나의 효과로 귀속하지 않는다.

새 관측→exact packet→fresh pose가 모두 연결됐다. 각 W/D 표현에 원N0 시작 하나씩, 최대2회 최적화, 같은 cost/guard/fallback을 적용했다. 정확히 같은 전체 관측·covariance·state·N0·config만 캐시 재사용했다. [독립 검산](VERIFICATION.json), [관측 전체표](OBSERVATION_RESULTS.md), [짝지은 전체표](PAIRED_RESULTS.md), [진단](DIAGNOSTIC_RESULTS.md)을 함께 본다.

## 비용·오류·시각화

새 실제 optimizer 생성6회, 완료6회, 학습 실패0회, 총2160steps. 전체6fit process wall 9.064s. 실제 관측/자세 계산 비용과 모든 실행 실패는 [EXECUTION_AND_COST](EXECUTION_AND_COST.json)에 남겼다. 초기 SciPy Qhull 임시파일이 I/O guard 밖으로 나가던 실행 오류는 run-local tempdir로 수정했고, 실제 실사 자세 저장 전 실패한 로그를 보존했다. 추출 pilot의 metadata/validation 기술 수정도 원 소스와 출력 동등성 증거를 남겼다. 학습 과학 설정은 바꾸지 않았다.

[전체192장 경량 갤러리](gallery/index.html)는 같은 이미지의 COMMON·BI와 모든 시스템 numeric row를 연결한다. 자동 회복/손상/공동성공/공동실패의 고정 ID 예시, 최대 악화, B/I crop 및 6fit 실제 곡선을 포함한다. S는 직접 영상 관측이 아닌 pose projection이다. 모델 pixel view와 사람/browser 열람은 [VISUAL_REVIEW](VISUAL_REVIEW.json)에서 구분한다.

## 한계와 채택

세 seed는 한192장 데이터셋을 반복 평가한 결과다. 원 recording cluster bootstrap과 session 감도는 기술적 불확실성으로, 과거 반복 선택·domain gap·적은 recording 수를 보정하지 않는다. 물리 재료 모서리 소속은 가상 코너 오차만으로 증명하지 않는다. 결과를 근거로 운영 기본값이나 논문을 자동 수정하지 않았다. 추가 캠페인은 시작하지 않는다.
