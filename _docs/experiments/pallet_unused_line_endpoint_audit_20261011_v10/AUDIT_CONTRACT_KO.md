# V10 최신 sparse 관측의 독립 unused-line 감사 계약 초안

이번 블록은 새 자세 방법이나 성능 재실험이 아닌 **기존 V9 관측의 독립적인 대응 근거 감사**다. V9 정확도·관측·LOCAL 후보·결과·600 fresh runtime을 수정하지 않는다. 코드 작성 단계이며 own freeze·새 PnP·실사·GT 산술 실행은 아직 0이다. 이 문장은 작성 시점의 상태이며 실제 이후 실행량은 별도 protocol/STARTED/receipt가 결정한다. V9 게시 완료 뒤 원격과 local HEAD가 일치하는 새 보호 snapshot을 만들기 전에는 실행하지 않는다. 기존 V9의 `07d5...` 보호 verifier를 최신 HEAD에 잘못 재사용하지 않는다.

사용자의 실제 요청은 코너별 특성에 맞는 보정과 LOO·self-occlusion 제외가 어디까지 문제를 해결했는지 확인하는 것이다. 원 첨부 C2는 IMAGE_ROLE의 같은 관측에서 부분 선을 별도 절제로 쓰도록 요구한다. 원 첨부 자체와 이후 사용자의 쉬움·중간245 지시를 구분한다. 원 첨부의319 지시를 최신245 범위에 다시 덮어쓰지 않는다. V4의 native N3와 경계 후보를 H∪{k} LOO에 대해 엄격 비교하는 정책, V6의 native hybrid/최소4-point 선 경로 및 V7의 세 head×두 공급, V8의 같은 sparse 관측 solver/mask 대조와 V9의 최신 sparse LOCAL은 이미 실제 실행됐다. 동일 비교를 새 누락 실험으로 부르지 않는다.

남은 좁은 질문은 **최신 V9가 실제 fit에 쓴 unused line이 그 선을 보지 않은 다른 native 관측의 자세와 일치하는가**다. 최종 같은 factor-pool residual·inlier rank6은 이 독립 검증을 대신하지 않는다. 기존 V6 [solver.py:199](../../../scripts/research/pallet_partial_line_heldout_20261010_v6/solver.py#L199)의 frozen endpoint 검증을 최신 V9의 actual unused pool에만 진단으로 적용한다. V6 downstream는 V5의 actual point≥4 조건이며, 최신 sparse<4+line LOCAL pool을 평가한 것은 아니다. V10은 그 차이를 관측 감사로 제한하며 아직 downstream filtering arm을 추가하지 않는다.

[audit.py](../../../scripts/research/pallet_unused_line_endpoint_audit_20261011_v10/audit.py)의 pure `audit_packet` 입력은 정확히 `local_packet`과 `local_row`다. 앞 항목은 V9가 사용한 V7 IMAGE_ROLE_BOUNDARY_ONLY parent row·original OBS.native_N3_points·GT-free parent completion·같은 full flat ROLE observation으로 만든 기존 packet이다. 뒤 항목은 같은 ID/session의 **unscored sealed V9 geometry**다. scored prediction의 pose/GT/human mask 필드는 거절한다. 원래 V9 packet validator, source-CAL/query/line/corner identity 계약과 sparse/native/K/xyz/H/source row hash를 검사한다. driver가 whole-file SHA·전체245 순서·seal·cleanup·독립 기하 PASS를 먼저 검사해야 한다.

실제 sparse adopted point의 incident source edges를 소비하고, V5의 unchanged physical/CAL support validator가 남긴 unique line만 검사한다. sparse q를 native로 채우지 않는다. 한 source line의 point·line 중복이나 복수 픽셀을 독립 대응 수로 세지 않는다. H endpoint가 포함된 3D 선도 실제 보이는 선 관측이면 유지하되 H의 초기2D 좌표는 validation fit에서 제외한다.

각 frame에 original native N3 좌표/K/xyz/영상크기의 V4 point bank 하나를 만들고 모든 actual unused edge의 두 endpoint를 임시 제외한다. validation mask는 **H∪{a,b}**다. 양쪽 registry 치수와 유한4-ID 가설·LM·rank·다중해 처리는 원래 V4 그대로다. 같은 native 좌표/K/치수/4-ID 가설은 edge/mask 사이에서 공유한다. 검사 선·V9 선택 pose·초기 R,t·projection·치수 branch prior는 validation solve에 넣지 않는다. 매 unique unused edge당 solve request1이며 관측 부족도 typed result로 보존한다.

원 V6 `_witness_problem`을 통과한 NEW pose만 projected3D endpoints와 normalized 실제 선 사이 signed RMS를 비교한다. **기존8px 그대로** `SUPPORTED_RETAIN`, `CONTRADICTED_REJECT`를 기록하고 unavailable·ambiguous·uncheckable은 `UNVERIFIED_RETAIN`이다. 이 이름의 REJECT는 원 V6 정책의 진단 label이며 V10에서는 실제 최종 관측을 제거하지 않는다. UNKNOWN을 `NONE`/가림 정답/전체 frame 실패로 바꾸지 않는다. validation pose 자체가 잘못된 합의일 가능성도 원행에 남긴다. endpoint projection을 새2D 관측으로 만들거나 다시 fit하지 않는다.

V9의 전체 starts/candidates/양치수/best/alternatives의 원 soft-cost gap·Jacobian singular spectrum·column normalization·condition number·point/line·inlier support rank는 원래 저장 witness를 복사한다. 새 J/SVD/LOCAL objective를 계산하지 않는다. rank6은 지역 관측 가능성이고 좋은 conditioning·올바른 물리 correspondence·global uniqueness의 증명이 아니다. 실제 물리 edge/corner 소유권 정답이 없는 경우 `UNKNOWN`을 유지한다. source wire/role/cache consistency의 기존 PASS를 새 실사 소유권 인증으로 확대하지 않는다. GT score를 보고 선을 고르거나 threshold를 다시 맞추지 않는다.
