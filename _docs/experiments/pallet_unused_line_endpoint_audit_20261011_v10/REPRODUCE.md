Actual attempts, counts, completion and independent checks belong to the separate exclusive JSON artifacts. The existing V7/V8/V9 observations, numerical policies, predictions, scores and fresh runtimes remain immutable.

The population is every existing Clean153 and Moderate92 frame, in the frozen cohort order: 245 frames. Severe74 is excluded under the user's later scope instruction. The examined line, initial pose and V9 LOCAL candidate are not validation inputs. One native coordinate bank per frame shares fixed four-ID hypotheses across edge masks.
