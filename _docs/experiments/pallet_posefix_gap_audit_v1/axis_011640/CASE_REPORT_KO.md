# 기존 전체 방법 e와 N3→SubPix + F의 차이

기존 전체 방법 e는 공통 제외 후 남은 121장에서 평균 위치·회전 오차와 공동 성공 수가 가장 좋다. 전체 192장에서도 공동 성공 수는 가장 많지만, 평균 위치·회전 오차는 N3→SubPix + F보다 크다. 최소 B/I 경로의 악화를 기존 e 전체의 악화와 혼동해서는 안 된다.

## 동일 분모의 결과

성공은 위치 오차 ≤5cm와 물리 C2 회전 오차 ≤5°를 동시에 만족하는 경우다. CAL46은 이 표와 별도다.

| 분모 | 방법 | 평균 위치(cm) | 평균 회전(°) | 성공 |
|---|---|---:|---:|---:|
| 전체192 | PoseFix RAW | 13.8357 | 11.6398 | 80/192 |
| 전체192 | N3→SubPix + F | 11.3058 | 10.6311 | 108/192 |
| 전체192 | N3→SubPix + 최소 B/I | 13.3839 | 12.5337 | 108/192 |
| 전체192 | 기존 전체 방법 e | 14.1121 | 13.0011 | 114/192 |
| 공통 제외 후121 | PoseFix RAW | 5.1914 | 1.5404 | 68/121 |
| 공통 제외 후121 | N3→SubPix + F | 3.4922 | 1.6895 | 92/121 |
| 공통 제외 후121 | N3→SubPix + 최소 B/I | 3.3737 | 1.6411 | 95/121 |
| 공통 제외 후121 | 기존 전체 방법 e | 2.9598 | 1.4495 | 103/121 |

121장은 다섯 경로 중 하나라도 기존 N0 기준 IQR 상한(위치 18.728249cm, 회전 7.221970°)을 넘는 영상을 공통 제외한 사후 보조 분석이다. 제외된 71장과 모든 실패는 기존 결과·갤러리에 보존했다. 121장 결과를 전체 192장의 성능으로 대체할 수 없다.

## 경로 차이

- **N0, N3→SubPix + F:** YOLO 좌표를 N3와 SubPix로 보정하고 기존 이동 제한과 공통 F로 자세를 계산한다. F는 알려진 크기와 2D–3D 대응을 이용하는 PnP 및 후보 선택 후단이다. 여기서 멈춘다.
- **N1, 최소 B/I:** 같은 초기 경로 다음에 자체 상태·마스크·B/I 관측을 계산한다. 보이는 것으로 판정한 B/I를 보정하고 그 점들로 자세를 다시 구한다. 이 최소 실험에서는 O/T/U 영역 제약을 사용하지 않는다.
- **E0, 기존 전체 방법 e:** 같은 N3·SubPix 초기 좌표에서 상태별 B/I 관측, 부분 선 관측, O/T/U 영역과 전체 윤곽을 이용하는 별도의 기존 확장 후단이다. 폭·깊이 모델 가족을 선택한 뒤 그 가족을 고정하고 자세를 세밀하게 조정한다. 완전한 2D 점 관측이 철회된 경우 부분 제약을 사용한다.

세 경로 모두 알려진 팔렛 크기와 자세 기하를 이용한다. N1/E0에서 S는 후단 영상 관측점으로 추론하지 않고 자세로부터 투영한다. 갤러리 첫 입력 영상과 초기 좌표가 같은 것은 정상이며, 최종 상자가 비슷하다고 같은 대응·같은 3D 자세인 것은 아니다.

## 첨부 사례: plastic_day_01:011640

![실제 영상에 투영한 물리 폭·깊이 축](PHYSICAL_AXES_COMPARE.png)

등록 크기는 폭 W=110cm, 높이 H=11cm, 깊이 D=130cm다. 빨강은 물리 W, 파랑은 물리 D다. 위는 저장된 예측 자세를 실제 RGB에 투영한 그림이다. 아래는 중심을 겹쳐 N0의 폭·깊이 평면에서 방향만 비교한 그림이며 GT가 아니다.

| 경로 | 현재 고정 참조에 대한 위치 오차 | 물리 C2 회전 오차 |
|---|---:|---:|
| N3→SubPix + F | 8.504422cm | 1.035323° |
| N3→SubPix + 최소 B/I | 5.471150cm | 0.894239° |
| 기존 전체 방법 e | 22.508411cm | 84.608249° |

이 사례의 e는 SWAPPED_WD 가족을 선택했다. N0와 e의 내부 계산 좌표계 회전 차이는 5.590207°지만, 물리 폭·깊이 축으로 환산하면 C2 회전 차이는 84.680286°다. 직사각형의 90° 회전은 대칭으로 취급할 수 없다. 같은 native 코너 ID의 영상 투영 차이는 평균 6.578px라 외곽 상자가 비슷해 보인다. 저장된 자세를 실제로 그린 결과이며 최종 자세의 시각화 오류로 확인된 것은 아니다.

e의 중심은 현재 고정 참조보다 카메라 깊이 방향으로 약 21.61cm 가깝다. 따라서 회전뿐 아니라 깊이·위치 차이도 있다. 외곽이 잘 겹치는 것만으로 물리 축 대응과 깊이까지 맞았다고 판단할 수 없다.

원주석의 물리 부호 축 상태는 UNCONFIRMED_SIGNED_AXIS / MANUAL_REVIEW_REQUIRED로 보존돼 있다. 표는 기존 고정 평가참조를 그대로 적용한 값이며, 이번 분석으로 실물의 독립적인 물리 축 GT를 새로 확정한 것은 아니다. GT·대칭 규칙·정답·예측을 수정하지 않았다.

## 검증과 해석

저장된 행렬·중심·등록 크기를 이용해 그림만 새로 만들었다. 학습·seed·추론·PnP·참조 적합은 새로 실행하지 않았다. 독립 읽기 전용 대조 27항목의 최대 수치 차이는 2.22e−16이었다. 기존 병렬 갤러리의 N0/N1/E0 최종 투영은 저장 자세와 최대 0px 차이로 확인돼 있다.

현재 근거는 e가 많은 사례를 개선하지만 일부 사례의 모델 가족 선택과 자세 실패가 전체 평균을 악화시킨다는 것이다. 다음 개선 대상으로 폭·깊이 대응의 불확실성과 큰 손상 방지를 분리해서 검증할 필요가 있다. e를 버리거나 무조건 채택한다는 결론도, 이 사례만으로 모든 큰 실패의 원인이 같다는 결론도 내리지 않는다. 운영 기본값은 바꾸지 않았다.
