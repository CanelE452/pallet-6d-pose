# 산점도에서 지목한 파란 고오차 3장

[실제 이미지와 대응 비교](index.html) · [두 방법의 전체 실제 과정](process/index.html)

선정 기준은 사용자가 지정한 산점도 좌표다: e (약54cm,159°), 약208cm, 약260cm. 각 사례에 같은 이미지의 N3→SubPix+F 결과를 짝지었다. 두 야간 사례는 N0도 이미 큰 실패이므로 e만 실패한 영상으로 해석하지 않는다. 모든 상자는 저장된 예측이며 GT가 아니다. 원래 RGB SHA와 저장 오차를 대조했고, 같은 확대 범위에 두 저장 투영을 그렸다. 005249의 원래 ROI 위로 나간 예측도 보이도록 범위를 확장했다. 기존 실제 6단계 렌더러를 3장·2방법으로 제한해 함께 제공한다. 원래71장 갤러리와192장 평가를 보존했고 새 학습·추론·PnP·정답 수정·운영 기본값 변경은 없다.
