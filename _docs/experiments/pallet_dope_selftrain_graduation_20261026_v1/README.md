# DOPE 파렛트 자기학습 결과와 국문 졸업논문 초안

합성 학습 DOPE의 기본 모델과 실제 파렛트 영상을 이용한 두 차례 자기학습을 비교했다. 실제 학습 풀은 일반 플라스틱, 소형 목재, 녹색 플라스틱 각각 1,000장으로 분리했고, 합성 데이터 2,212장은 공통으로 사용했다.

LOO와 flip을 함께 사용한 2차 PCK@10px는 세 종류 모두 기본 모델보다 높았다. 동일한 학습량의 합성 추가학습 대조군보다 높은 것은 주 평가의 2차 비교에서 목재였다. 이 차이를 포함해 기본 모델, 두 자기학습 차수, 합성 추가학습 및 flip 제거 비교를 모두 보고한다.

## 주 평가 결과

PCK@10px는 원본 영상의 기준점 오차가 10픽셀 이하인 비율(%)이다. 누락 예측은 실패로 포함한다. 주 평가는 292장 및 2,274개 기준점이다.

| 평가 대상 | 기본 R0 | LOO와 flip 1차 | LOO와 flip 2차 | 합성 추가 2차 | LOO만 1차 | LOO만 2차 |
|---|---:|---:|---:|---:|---:|---:|
| 일반 플라스틱 128장 | 26.19 | 38.07 | 39.49 | 43.05 | 33.81 | 35.13 |
| 소형 목재 45장 | 29.77 | 48.27 | 60.12 | 53.47 | 49.71 | 54.91 |
| 녹색 플라스틱 119장 | 47.72 | 69.14 | 69.67 | 70.20 | 67.97 | 67.76 |

주 실험 2차의 기본 모델 대비 변화는 일반 플라스틱 +13.30%p, 목재 +30.35%p, 녹색 +21.95%p이다. 같은 차수 합성 추가학습 대비 변화는 각각 −3.55%p, +6.65%p, −0.53%p이다.

## 별도 보조 평가

일반 플라스틱 184장 전체는 기존 128장과 추가 56장을 합친 1,413개 기준점 평가이다. 기본 29.87% → LOO와 flip 1차 43.88% → 2차 47.06%이며, 합성 추가 2차는 49.89%이다. LOO만 사용한 1차와 2차는 각각 42.32%, 44.66%이다. 128장 주 평가와 독립적인 표본으로 합산하지 않는다.

녹색의 직접 클릭 기준점 600개에서는 기본 59.83%, LOO와 flip 1차 77.50%, 2차 78.50%이며 합성 추가 2차는 77.83%이다. 전체 주석 출처가 수작업이라는 뜻은 아니다.

## 해석 범위

단일 시드의 반복적인 2차원 기준점 평가이다. 주석에는 PnP 생성 및 생성 출처 미상 기준점이 포함되고 카메라 K는 제공 값을 사용한다. 목재는 별도의 물리적 FINAL과 촬영 기록을 공유하며, 추가 플라스틱 56장은 기존 FINAL 역할의 자료를 보조 평가에 포함했다. 독립 TEST 또는 독립적인 실제 6차원 자세 정확도 검증으로 해석하지 않는다. 고정 R1과 R2를 모두 보고했고 이 결과로 체크포인트나 필터 임계값을 선택하지 않았다.

이 폴더에는 결과와 문서 자료만 포함한다. 학습 코드 변경, 원본 영상, 가중치, 런타임 라이브러리와 대용량 프레임별 예측은 포함하지 않는다. 재현 절차의 절대 경로는 실험을 실행한 로컬 작업 공간을 가리킨다. 표와 문서 생성 코드는 로컬 논문 준비 폴더에 보관되어 있다.
