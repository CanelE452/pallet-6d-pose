# 공개 범위

사용자 지정 PUBLIC origin을 확인했다. 공개 범위를 설명한 승인 요청 뒤 사용자가 push를 지시했으므로 재현 경로/해시·측정 메타데이터 및 실제 평가 오버레이6장을 공개한다. 원본RGB파일·원시좌표·카메라행렬·가중치파일·전체로컬환경목록은 공개 대상이 아니다. 전체목록/좌표를 재현하려면 로컬의 비공개 입력이 필요하며 공개 benchmark 완전 배포라고 주장하지 않는다.

`WOOD_DATA_INVENTORY_PUBLIC.json`, `WOOD_TRAIN_PROTOCOL_PUBLIC.json`, `PREFLIGHT_PUBLIC.json`은 원본 전체 목록을 해시로 연결한다. 기존 상세 원본은 삭제하거나 덮어쓰지 않는다.
