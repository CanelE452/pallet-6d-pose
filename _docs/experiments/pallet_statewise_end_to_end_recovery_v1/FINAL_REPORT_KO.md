## 3. 바뀐 계산과 표준 대조

- A: globally consistent upright owner assignment와 none을 함께 갖는 정규화 component energy다. family2×C4의8 표기는 정확한 물리 owner 배열4개, 기존 C2까지 몫내면2개다. 기존 W/D+heading 공간을 넓힌 새로운8 물리 가설이 아니다. 새 차이는 전역 owner mixture와 none, 공통 G13 재평가다. reliability로 temper한 합성 energy를 교정된 joint posterior로 부르지 않는다.
- B: 동일 RGB와 자동 마스크에서 고정한 normal profile의 경계 offset 분포를 후보 전체에 공유한다. 원 RGB query/분포를 고정하지만 후보 평가는 무한 지지선 연장을 허용한다(유한변 지원 한계는 후술). B가 소비한 full/partial 및 hull을 중복 가중하지 않는다. 동일 지지의 edge 대조군과 구분해 경계 분포를 유지한 효과를 본다.
