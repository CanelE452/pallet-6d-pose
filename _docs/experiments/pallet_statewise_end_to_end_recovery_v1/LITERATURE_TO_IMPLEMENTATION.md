# Literature, actual implementation, and limits

These are exploratory single-frame cuboid experiments. No paper's benchmark
results or theoretical guarantees are transferred to this dataset. Newly
implemented conditional energies are not calibrated pose probabilities.

| Source | Principle used | Actual code in this campaign | Deliberately absent |
|---|---|---|---|

All new numerical source in this namespace is written for this campaign.
Reading a paper's equations is distinguished from importing its implementation.
Existing upstream code/weights and historical E0 remain bound and preserved.
