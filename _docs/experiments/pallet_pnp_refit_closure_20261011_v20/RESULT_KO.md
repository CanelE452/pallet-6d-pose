# 동일 관측 일반 PnP와 강건 점 합의의 후보 비교

“가림 판단이 일부 틀려도 다른 유효 대응점으로 자세를 구하고 자기 가림 코너를 재투영했을 때, 기존 단순 대조보다 실제 위치·회전이 좋아졌는가?”

현재 V19의 답은 **평균 위치·회전의 동시 개선을 확인하지 못했다**이다. 쉬움 153장과 중간 92장, 합계 245장을 유지한 V19 선 포함 경로의 평균 위치/회전 오차는 11.127270098939297 cm / 12.999761480600135 degree이고, 고정 N3→cornerSubPix는 9.754548028679153 cm / 10.914841863166323 degree다. 이는 기존 주석·카메라·등록 직육면체에서 계산한 GEOMETRIC_PROXY를 기준으로 한 결과이며 독립 측정한 물리적 R,t는 아니다. 새 자세 245/245 산출과 정확도 개선은 별개다.

이 감사는 그 실패를 설명하기 위한 **저장된 자세의 기하 비교**다. 새 자세나 성능 실험을 생성하지 않았고, 승인·기본 출력 반환 결정을 바꾸지 않았다. 원행을 열기 전에 별도의 프로토콜을 고정한 후 ROOT가 실제 실행했다.

## 실제 확인한 차이

두 비교 대상은 V17 `HYBRID_STANDARD_PNP`와 V19 `HYBRID_OBSERVED_FRAME_POINT_ONLY`다. Native ordinary는 원래 N3 좌표를 사용하므로 이번 동일 좌표 비교에 섞지 않았다. 245장 각각의 hybrid q, K, 등록 치수, 초기 H, 활성 U 및 head/CAL 계보가 정확히 같음을 확인했다.

저장된 best가 양쪽에 있는 241장에 대해, 모든 U에서 8 px inlier 수와 truncated SSE를 독립 계산했다. H와 중심 ID 8은 fit/score에 포함하지 않았다. 원래 동점 한계 1e-8 px²를 그대로 썼다.

|저장된 best의 합의 점수 관계|프레임 수|
|---|---:|
|일반 PnP의 inlier 수가 더 많음|13|
|동수이고 일반 PnP의 truncated SSE가 더 작음|169|
|강건 점 경로의 inlier 수가 더 많음|32|
|동수이고 강건 점 경로의 truncated SSE가 더 작음|27|
|일반 PnP의 저장된 best 없음|1|
|일반 PnP best가 존재하지만 강건 점 승인 후보 best는 없음|3|

일반 PnP가 자신의 대응을 더 유리하게 사용하는 별도 GT 점수로 선택된 것이 아니다. **동일 U의 강건 합의 점수에서도 우세한 저장 자세가 182장** 있었다. 이 182는 저장된 best 비교이며 모두 양쪽 NEW_POSE였다는 뜻은 아니다. 표의 부재 상태는 일반 best 없음부터 우선 분류하므로, 마지막 3은 점 best 부재 전체를 뜻하지 않는다. 실제 출력 상태는 일반 PnP NEW 244 / 기본 N3 반환 1, 강건 점 경로 NEW 240 / 기본 N3 반환 5다.

26,010개 저장된 raw 4-ID proposal 및 실제 refit 후보를 동일 기하 동등성 규칙으로 비교했을 때, 일반 PnP best와 동등한 **승인 refit이 존재한 프레임은 0**이었다. 이것은 기존 후보 생성 경로가 일반 PnP의 전체-U 해를 반드시 포함하지 않는다는 증거다. 모든 실수 근방이나 최적화 basin이 빠졌음을 증명하는 수치는 아니다.

일반 PnP의 전체 U가 모두 8 px inlier이고 저장된 전체-U 국소 rank가 6이며 weak 판정이 아닌 경우는 181장이다. 이 수치와 앞의 182장은 다른 조건의 집계이며 동일 집합으로 간주하면 안 된다. 나머지 63장의 일반 best에는 U의 일부 outlier가 남아 있어, 새 inlier 부분집합의 rank와 재적합 성공은 **UNKNOWN**이다. best가 없는 1장은 별도로 유지했다. 전체-U rank가 좋다는 이유로 새로운 부분집합을 승인하지 않았다.

## 코드에서 차이가 생기는 위치

- `pallet_cornerwise_independent_20261010_v4/pose.py:189–192`에서 전체 U의 Generic branch들을 생성하고, `:230`에서 raw L2 순서를 정한다. `:253–257`에서 그 best에 한 번 LM을 수행하며 `:263–268`은 raw와 반환된 LM 후보를 보존한다. 정확한 실행 소스 경로와 바이트는 감사 `PROTOCOL.json` 및 부모 geometry seal에 기록돼 있다.
- `pallet_factor_subset_consensus_20261011_v15/solver.py:174–202`는 두 등록 치수의 유효 4-ID branch를 열거한다. `:243–280`은 proposal의 inlier 집합을 고정해 재적합하고 fit 집합이 최종 inlier로 남아야 승인한다. `:284–287`의 viable 목록은 실제 승인 refit들이다. 전체-U 일반 Generic/LM 해를 별도 후보로 넣는 경로는 없다.
- V15 `solver.py:309–327`의 inlier 수·전체-pool truncated SSE 순위를 유지하되, `pallet_finite_support_orthogonal_audit_20261011_v19/solver.py:218–237`에서 same-support 추가 veto를 numerical tie만 거절하는 판정으로 복원한다. `:266–278`의 점 전용 수학은 부모 점 경로를 그대로 사용한다.
- V1 `_generic`은 유한·양의 깊이인 반환 branch를 모두 보존하며, V4 `(dimension, IDs)` 캐시는 그 전체 tuple을 재사용한다. 이번 감사와 소스 검토는 4-ID raw branch를 잘못 버리는 캐시·ID 오류를 확인하지 못했다.

고정 inlier 집합의 component `soft_l1`을 최소화하는 refit과 전체 U의 count/truncated SSE로 후보를 고르는 단계는 같은 목적함수가 아니다. 따라서 refit이 승인되어도 전체-U 비용이나 실제 자세 오차의 개선을 보장하지 않는다. 이것은 현 설계의 한계이며, 이번 숫자만으로 확정 구현 버그라고 바꾸어 보고하지 않는다.

## 확인된 오류와 남은 문제의 구분

1. 과거 별도 브랜치 학습에서 실제 대응이 있던 2,164 query를 ray 수치 실패 때문에 no_match로 감독한 오류는 이미 실제 메쉬 경계·깊이 근거로 수정했다. main의 N3→cornerSubPix 오류가 아니었다. 원래 읽기 전용 인수인계 당시에는 수정 감독의 재학습이 없었으며, 이후 승인된 세 조건 각 3,000, 총 9,000 업데이트는 실제 완료됐다. 이번 감사의 추가 학습은 0이다. 기존 IMAGE_ROLE 0/319는 수정 전 모델의 결과다.
2. V19는 투영 모델의 접선으로 선 support를 판정하여 긴 관측 선과 거의 수직인 짧은 모델 선을 inlier로 승인할 수 있던 별도 선 목적함수 결함을 관측 접선 기준으로 수정했다. 실제 전체 geometry 검산 232,807,611개는 PASS지만 평균 자세 오차는 좋아지지 않았다.
3. 과거 V16 전체 scalar 감사의 564 FAIL은 그대로 FAIL이다. 새 V19 PASS로 역사적 결과를 재분류하지 않았다.
4. 이번 V20 감사는 **후보 경로의 차이를 확인했지만 새로운 강건 솔버의 성공을 확인한 실험은 아니다**. 가림 분류가 틀렸다는 이유로 프레임을 실패시키거나, 가림 분류를 정확도 실패의 유일 원인으로 삼지 않았다.

## 다음에 확인할 최소 보완

성능 결과를 보고 radius, tie, head, CAL, seed를 바꾸는 반복은 하지 않는다. 하나의 결정적인 후보 보완만 소스 수준에서 검토한다. 기존 최대 70개 4-ID 부분집합 검사를 유지하고, 동일 hybrid q 전체 U의 기존 일반 PnP/LM 후보도 같은 승인 조건으로 검토한다. H 및 중심을 제외한 실제 U만 fit에 쓰고, 실제 fit U가 모두 최종 inlier로 남으며 양의 깊이·국소 rank·weak·G14 안정성 조건을 통과한 후보만 기존 합의 키로 경쟁시킨다. raw 해나 API가 제공하지 않은 LM convergence 상태를 성공한 optimizer로 꾸미지 않는다.

이 보완은 자동 정확도 개선으로 주장하지 않는다. 허용 후보의 합의 키를 보존하더라도 새로 드러난 비동등 numerical tie는 기본 출력 반환을 일으킬 수 있어 산출률의 단조 개선도 보장하지 않는다. 먼저 무GT 소형 기하 증명에서 기존 4-ID branch/cache 보존과 H 독립·새 자세 후 H 한 번 재투영을 확인한다. 그 후 하나로 고정한 경로를 같은 245장 전체에서 원행·공통 산출·전체 운용 오차와 함께 확인해야 한다. 수정 전 결과, V19 결과와 새 보완 결과를 혼합하지 않는다.
