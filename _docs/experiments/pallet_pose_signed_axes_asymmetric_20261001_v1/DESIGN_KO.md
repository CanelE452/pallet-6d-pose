# 실제보다 낮게 예측한 오차에 추가 비용을 주는 단일 손실 비교

목표는 RGB 한 장과 팔레트 물리 치수, 기존 카메라 보정 K를 입력으로 자연 가림에서 위치 T와 회전 R을 안정적으로 함께 개선하는 것이다. 이번 비교는 기존 271차원 입력·후보·타깃·최적화·판정 기준을 유지하고 회귀 손실의 과소예측 비용만 바꾼다. 원래 진단 문서의 새 학습 0회 단계는 앞서 완료했으며, 이 비교는 이후 요청한 안정적 개선 목표의 후속 작업이다.

## 관측과 반대 근거

[직전 방향18 모델](../pallet_pose_signed_axes_direction_20261001_v1/REPORT_KO.md)은 네 모델 모두 수렴했지만 source 43/45로 실패했다. 세 UNION의 실제 선택에는 R0 anchor보다 T 또는 R가 악화된 행이 108/106/101개 남았다. 선택된 후보의 두 예측 축은 0 이하이지만 실제 양의 오차 초과가 나타났다. seed 3의 unsafe 정규화 초과 최댓값은 직전 입력 추가 전 5.120580에서 29.334076으로 증가했다. [고정 선택 진단](../pallet_pose_signed_axes_direction_20261001_v1/SOURCE_FIXED_CHOICE_DIAGNOSTIC_KO.md)

기존 대칭 Huber는 같은 크기의 과소·과대예측을 같은 비용으로 처리한다. 부호 logistic 항은 개선·악화 부호를 보지만 회귀 크기의 방향별 비용을 바꾸지는 않는다. 아래 비교는 악화 후보의 오차를 낮게 예측하는 경우의 비용을 높여 실제 선택 오류를 줄일 수 있는지를 검증한다.

그러나 이 관측은 손실 비대칭이 유일한 원인이라는 증거가 아니다. 앞선 risk-margin CE·pairwise·utility 회귀·입력 변경도 실사 공동 개선을 이루지 못했다. 보수적인 예측이 R0 복귀만 늘리고 안전한 개선 선택을 잃게 할 수 있다. 표현·데이터 분포의 한계도 남는다. 이번 비교에서 threshold나 비용비를 탐색하거나 가장 좋은 seed만 선택하지 않는다.

## 유일한 변경: 고정 2:1 회귀 비용

각 축에서 `e = prediction − signed_target`으로 두고 기존 `Huber(e, δ=1)`에 `Huber(min(e,0), δ=1)`을 한 번 더한다. 따라서 같은 크기에서 과소예측 비용은 과대예측의 정확히 두 배다. 추가 항 계수는 사전에 1로 고정하며 탐색하지 않는다. 출력은 cm/도가 아닌 기존 signed-log1p 정규화 값이다.

```text
J = mean_all_2598_frames(mean_original_valid_candidates_and_two_axes(
      Huber(p−y,1) + Huber(min(p−y,0),1)
      + 1{y≠0} softplus(−sign(y)*p)))
    + (1e−4/2) * ||W271×2||²
```

각 프레임은 원래 유효 후보·두 축으로 평균하고 전체 2,598행으로 평균한다. 모든 후보가 invalid인 1행은 데이터 손실 0으로 분모에 남는다. anchor의 입력·타깃은 정확히 0이다. 추가 비용은 zero target을 포함한 원래 유효 축에 적용하며, zero target의 sign logistic은 기존처럼 상수 log2까지 전부 생략한다. `Huber` 집계는 대칭 항과 추가 항의 합이며 두 성분을 별도로 공개한다.

추가 항은 연속미분 가능한 볼록함수다. e=0에서 추가 gradient와 선택한 추가 일반화 곡률은 0, |e|=1에서 해당 Huber 곡률은 0으로 두고 logistic 곡률과 ridge를 유지한다. 모든 계수의 ridge로 λ-강볼록성이 유지되므로 기존 gradient gap 상계를 쓸 수 있다. 이는 FP64 수치 검산이며 성능 보장이나 구간 연산 증명이 아니다.

## 유지하는 조건

- 기존 271 입력, old94 정규화, context189·RBF64·고정 방향18, 후보와 R0 GEO anchor를 유지한다. 이전 모델별 9개 입력·타깃 해시가 모두 같아야 한다. 정규화·basis를 다시 선택하지 않는다.
- 동일 TRAIN 2,598행·VAL 1,024행, 원래 valid mask·치수·K·2D 좌표·scale·signed-log1p 타깃을 유지한다. 새 RGB 관측·센서·시간 프레임·실사 GT는 없다.
- R0_ONLY 및 UNION_s1/s2/s3 네 모델을 모두 271×2 영가중치에서 학습한다. 이전 가중치로 시작하거나 재시작하지 않는다. λ=1e−4, bias=0, sign 계수=1이다.
- Newton/Armijo 초기 step 1·감소율 0.5·c1=1e−4, damping 0, 최대 승인 반복 1,000·전체 objective 호출 2,000을 유지한다. 마지막 승인점에서 gradient L∞≤1e−8와 ||g||²/(2λ)≤1e−6을 함께 요구한다.
- runtime은 원래 유효 whole pose 후보의 두 예측 축 max를 최소화하고 기존 동률·실패 규칙을 사용한다. 새 margin·threshold·safe mask·GT 선택을 넣지 않는다.
- 이전 가중치는 학습 후 독립 검산에서 같은 새 목적식으로 비교한다. 과거 대칭 손실의 J와 새 J의 단순 수치 차이를 개선으로 해석하지 않는다.

## 평가와 기록

사전 입력·수식 검산 → 계약 봉인 → 실제 네 fit → 독립 수렴 검산 → 참조를 읽기 전 source 선택 고정 → 전체 source 채점 순으로 진행한다. 각 seed의 T/R 중앙값 strict 감소, P90 5% 이내, 실패 수 비증가를 R0_ONLY·R0_GEO·paired DIVERSE_GEO에 적용한 기존 45개 조건을 모두 요구한다. 실패하면 실사 선택·평가를 하지 않고 미실행 기록을 남긴다.

통과하면 natural99·clean29·wood45 전부를 평가한다. 원래 SINGLE251 대조군을 유지하며, 세 seed 공동 개선·recording×seed bootstrap 2,000회·6 recording 각각 제외·natural 꼬리와 실패·clean 보존의 5개 항목에서 original과 matched 비교를 각각 AND한다. 실패·inf 행을 버리거나 IoU로 분모를 줄이지 않는다. 반복 사용 DEV의 통과가 새 촬영의 독립 일반화 검증은 아니다.

학습 후에는 unsafe 감소뿐 아니라 safe 소실·anchor 복귀·큰 오차를 함께 기록한다. 결과·전 시드·실패 조건·전체 CSV·학습 파라미터·실제 RGB와 치수·실행 기록을 공개하고 GitHub 원격 파일을 대조한다. 비대칭 손실 자체를 새로운 학술적 기여로 주장하지 않으며, 원래 안정적 T/R 공동 개선 기준을 통과하기 전 목표를 완료 처리하지 않는다.
