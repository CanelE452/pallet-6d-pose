# 기하 정보를 활용한 active learning — 선택 파일럿

## 현재 완료 범위

새로운 라벨을 어디에 배분할지 정하는 acquisition 단계만 실행했다.
학생 학습과 성능 평가는 아직 수행하지 않았다. 정확도 개선이나 라벨 효율 향상 판정은 **UNTESTED**다.

- 기존 미라벨 개발 풀 1,000장을 출발점으로 사용했다.
- 알려진 C 학습 노출 273장 및 평가·수동 reference 중복 68장을 제외했다. 두 집합이 겹치므로 순 제외는 312장이다.
- 남은 688장, 8개 capture session에서 선택했다. 이미지 hash 중복은 제거했지만 세션 독립성은 입증되지 않았다.
- R0는 고정했다. 448차원 frozen feature와 원본/밝기0.8 입력의 기하 불안정성을 추출했다.
- 학습 업데이트는 0회이며, feature 추출은 warmup을 제외한 1,376 image forwards다.
- 선택 과정에서 GT 좌표를 읽지 않았다. 모델의 예측을 정답으로 만들지 않았다.

## 동일 예산 비교의 미리보기

| 선택 방법 | 선택 이미지 수 | 역할 |
|---|---:|---|
| 무작위 | 30 | 기본 비교군 |
| feature 다양성 | 30 | greedy k-center 비교군 |
| 기하 불안정성만 | 30 | 불안정한 예측 우선 비교군 |
| 기하 불안정성 × 다양성 | 30 | 이번 검토 후보 |

네 방법의 선택 합집합은 **97장**이다. 이는 총 30장 라벨링 예산이 아니다.
공유 이미지는 한 번만 라벨링하고, 각 방법의 학생은 그 방법이 선택한 30장만 사용할 계획이다.
30장은 실행 가능한 미리보기용 가정이며, 사용자가 승인한 실제 라벨링·학습 예산으로 간주하지 않는다.

모든 방법은 같은 capture에서 2초 이내 프레임을 중복 선택하지 않는다.
geometry-weighted diversity는 동일 k-center 거리에 기하 불안정성 순위 가중치[1,2]를 곱한다.
불안정성이 모두 같으면 기존 diversity와 같은 선택이 되도록 검사했다.
다양성 선택과 결합 선택은 17장을 공유한다. 선택이 달라졌다는 사실만으로 방법이 더 좋다는 뜻은 아니다.

## 중요한 한계

단일 밝기 변화에 대한 좌표 변동은 실제 오차 확률이나 pose 위험의 보정된 추정치가 아니다.
안정적으로 틀리는 예측은 놓칠 수 있고, 배경에 생긴 후보가 불안정할 수도 있다.
검출이 약한 이미지를 임의로 제거하지 않았으며 사람은 no-object도 정답으로 표시할 수 있다.
성능을 보고 밝기·가중치·거리·선택 예산을 튜닝하지 않았다.

이는 CLUE의 재현이나 새로운 ML 방법의 입증이 아니다. frozen feature 기반 acquisition 파일럿이다.
이전 A/B/C/D/E 판정과 C 출력 교환 진단은 변경하지 않았다.

## 다음 단계와 필요한 입력

1. 수동 정답 생성 가능 여부와 실제 총 이미지 예산을 확정한다.
2. 새 정답을 열기 전에 선택 예산, 학습 split, 동일 R0 초기값·loss·증강·업데이트·seed와 평가 규칙을 고정한다.
3. `BLIND_ANNOTATION_QUEUE_PREVIEW.json`으로 라벨링한다. 이 파일에는 모델 예측·선택 방법·점수가 없다.
4. 사람이 확인한 정답과 누락·visibility 검사를 통과한 뒤에만 학생 비교를 수행한다.
5. 동일 라벨 예산에서 무작위/기존 선택보다 나은지 검증한다. 독립 확인에는 별도 새 세션이 필요하다.

기존 DEV319를 선택·학습에 넣지 않았다. 나중에 그 DEV로 성능을 측정하더라도 repeated development 결과이지 독립 확인은 아니다.
97장 라벨링만으로 새로운 독립 평가 데이터까지 마련된 것은 아니다.
수동 라벨링이 불가능하다면 별도의 기존 정답을 이용한 retrospective 실험으로 범위를 다시 합의해야 한다.
현재 선택된 예측을 pseudo-label로 대신 채워 active-learning 검증을 완료했다고 처리하지 않는다.
