# 실제 학습 비교 결과의 의미

실행은 완료됐고 무결성 검사는 통과했다. 과학적 판정은 사전 고정 조건에 따라
`RETROSPECTIVE_AL_NO_SIGNAL`이다. 이는 모든 지표에 개선이 없다는 뜻이 아니라,
기하 가중 선택이 무작위와 단순 다양성 선택 모두를 이겨야 한다는 조건을
만족하지 못했다는 뜻이다.

| 선택 방법 | 공통 키포인트 중앙 오차 px | 공통 P90 px | 위치 오차 cm |
|---|---:|---:|---:|
| 무작위 | 4.3502 | 25.9490 | 10.2538 |
| 다양성 | 4.2481 | 24.1507 | 8.8140 |
| 불안정성만 | 4.3885 | 28.2699 | 10.7749 |
| 기하 가중 다양성 | 4.3452 | 20.6280 | 9.7425 |

표는 학생 학습 seed 세 개의 평균이다. 키포인트는 각 seed의 네 방법 공통
검출 프레임에서 집계했고 위치 오차는 동일 145장의 MAIN pose 평가다.

기하 가중 선택의 중앙 오차는 무작위 대비 약 0.005px 낮아 사실상 매우 작은
차이다. 다양성 대비는 약 0.097px 높고, 다양성을 이긴 seed도 1/3이다.
반면 P90는 무작위 대비 약 5.32px, 다양성 대비 약 3.52px 낮아 큰 오차를
줄이는 측면의 개선은 관찰됐다. 이 보조 지표를 사후 primary로 바꾸지 않는다.
다양성 대비 검출률 및 위치·방향 안전 조건도 통과하지 못했다.

같은 평가 subset의 AP50-95는 R0 0.762226, 무작위 추가 학습 0.782465,
기하 가중 선택 추가 학습 0.785874다. 추가 학습 후 일부 개선이 관찰됐지만,
이를 모두 기하 가중 선택만의 효과라고 해석할 수는 없다.

따라서 실제 머신러닝 적용과 비교는 가능했고 이번에 완료했다. 그러나 이
30-label 예산점, 고정된 한 acquisition seed, 기존 데이터의 retrospective
분리만으로 새 선택 방법의 우위나 독립 일반화를 주장할 근거는 부족하다.
기존 R0를 자동 교체하거나, 실패한 조건을 완화하거나, 추가 seed·학습·예산
탐색을 실행하지 않는다. 상세 수치와 고정 판정은 [REPORT_KO.md](REPORT_KO.md),
무결성은 [FINAL_AUDIT.json](FINAL_AUDIT.json)에 보존했다.
