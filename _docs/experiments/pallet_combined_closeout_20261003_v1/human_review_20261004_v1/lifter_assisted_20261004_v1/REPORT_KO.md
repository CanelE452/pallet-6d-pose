# 리프터 코너 검수의 C 보조와 초안 보존

기존 `scripts/annotate/annotate.py`의 실제 프레임 루프를 유지하면서 리프터 어댑터를 갱신했다. 화면의 검수 대상을 국문으로 설명하고, 현재 번호를 표시하며 클릭 후 다음 미입력 번호를 자동 선택한다. 마우스 휠 확대·휠 누르고 이동·전체 보기·C 확인·S/Q/T 저장 버튼을 사용할 수 있다. 공유 annotate.py 원본은 수정하지 않았다.

## C가 줄이는 작업

이 프레임에서 사람이 직접 확인하고 클릭한 4점 이상으로 기존 PnP와 고정 1.10×1.10×0.15 m 형상을 사용한다. 실제 기록된 카메라 메타데이터는 4개 세션 각각의 원래 SHA-256과 크기를 확인한다. 평가 대상 Base/N3 예측·박스·기존 첫 검수 좌표를 읽지 않는다.

평면 IPPE의 복수 유효 후보를 버리지 않고 모두 비교한다. 기존 기하 유효성 규약과 유한값·회전·양의 깊이 검사를 적용하며 새로운 재투영 임계값은 추가하지 않는다. 모든 후보가 동의하는 SELF/OUT 상태만 미입력 슬롯에 제안한다. 본인이 이미지에서 확인하고 C를 눌러야 상태를 기록한다. 이미 입력한 상태는 덮어쓰지 않는다. 숨은 점의 투영 좌표는 화면 도움일 뿐이며 참조 x/y는 null로 유지한다. 보이는 실제 물리 코너의 좌표는 직접 클릭한 값만 사용한다.

네 점은 계산의 최소 조건이다. 네 점만으로 자동 완성이 보장되지는 않는다. 모호한 후보가 가림 판정에 동의하지 않으면 제안을 보류한다. 외부 가림과 실제 팔레트의 구멍·다리는 직육면체로 자동 판정하지 않는다.

기하 제안을 표시한 노출과 C 확인을 별도로 기록하고 승인된 참조의 reviewer.machine_assistance를 사실에 맞게 설정한다. 보조 주석을 독립 물리 6D 정답이나 기계 도움 없는 검수로 표시하지 않는다. 독립 T/R 참조 부재는 그대로 남는다.

## 초안 보존

최초 검수 이력 확인 전에도 실제 사용자 입력과 프레임·선택점·확대·이동을 별도 VIEWER_DRAFT_RECOVERY.json에 저장한다. source_kind는 automatic_local_draft_recovery, evaluation_use는 false다. 미완료 입력을 Context의 reviewed 참조로 승격하거나 검수자 확인 답변을 생성하지 않는다. 주·반복의 초안을 별도로 보존하고 검수자가 바뀔 때 이전 사람의 좌표를 자동 복구하지 않는다.

S는 미완료이면 현재 초안을 저장하고, 완료이면 실제 이력 확인을 거친 참조 저장과 다음 프레임으로 진행한다. Q/ESC는 초안 보존 후 닫고 T는 초안 보존 후 원래 인수로 재실행한다. 재실행 시 남은 프레임 목록에서 실제 저장한 프레임을 우선한다.

## 실제 적용과 범위

구형 실제 창을 직접 확인했을 때 8개 상태 모두 미입력이고 완료 저장도 0장이었다. 이를 확인하고 새 창으로 교체했다. 사용자 제외 5장과 원래 120/24 계획은 보존하며 파생 요청은 주115·반복23이다. 기존 정적 입력 3,030점도 변경하지 않았다.
