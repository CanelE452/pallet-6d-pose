# 최신 지시문 대비 실제 완료·남은 작업

최신 통합 실행 지시와 로컬 실파일을 대조했다. ZIP 내부 실행문과 Downloads의 독립 실행문은 바이트까지 같다. 로컬 HEAD는 `39d4219a9ecd35d2eab561a805d3eeb0add7838c`, 브랜치는 `main`이다.

**전체 지시문은 아직 미완료다.** 기존 학습·평가·추론은 완료 결과를 재사용한다. 지금 우선 남은 일은 새로 저장한 분류를 모든 방법의 집단별 성능표와 실제 원고 복사본에 연결하는 작업이다.

## CLI가 마감할 순서

1. 세 native 저장 파일을 읽는 검증된 소비 코드를 연결한다. 과거 browser importer는 스키마가 다르고 직사각형 변경을 차단하므로, 이를 이용해 사람 검수 완료를 임의 선언하지 않는다. 자동 별칭과 신원·노출 미확인 상태도 보존한다.
2. 모든 기반·비교 방법에 같은 새 직사각형 집단과 기존 코너·실패 규약을 적용한다. 전체 319장의 2D/6D 수치가 이전 값과 같은지 검산한다.
3. 0918의 119장은 600/602점 모드, 한 세션, 독립 6D 참조 부재를 유지하며 재집계한다. 추가 150장은 자료·기하·선택·노출 조건을 대조해 별도 패널로 연결한다. 269는 분류 수 합계이며 혼합 성능표의 분모가 아니다.
4. 표·그림·본문·제한 문구를 검산해 보존된 LaTeX 복사본에 반영하고 통합 patch, PAPER_GAP_MATRIX, TASK_STATUS를 갱신한다. 원시 예측 → 집단 지표 → 표 → 그림 → 본문의 출처를 연결한다.

현재 통합 보고서의 직사각형 151/87/81과 정사각형 119장 대기 표시는 과거 상태다. 이전 해시 연결 receipt를 몰래 수정하지 않고 새 버전 보고서와 patch로 갱신해야 한다.

## 사람 확인이 남은 가지

- 등급의 의미를 한 번 확인해야 한다. 외부 가림 정도인지, 시점·거리·조명을 포함한 전체 난이도인지가 아직 미확인이다. 일부 직사각형 중간 예시에서 외부 가림이 보이지 않는다는 질적 관찰이 있다. 전수 재클릭을 요구하는 것이 아니다. 확인 전에도 `USER_ENTERED/SEMANTICS_PENDING` 보조 집계는 가능하다.
- 정적 코너 가시성 3,030점(직사각형 2,428 + 119장의 602)은 별도 미완료다. 기존 좌표의 상태를 확인하는 작업이며 코너를 처음부터 모두 다시 찍는 작업이 아니다. 영상 등급표 마감의 선행 조건은 아니다. 추가 150장의 681점을 자동으로 필수 검수에 추가하지 않는다.
- 리프터 가시 코너 정확도까지 넣으려면 사용자 제외 5장을 반영한 115장·반복 23장의 직접 가시 코너 참조와, 그 뒤 객체 대응 판정이 필요하다. 기존 115장 가림 분류는 코너 참조 완료가 아니다. 현재 실제 코너·객체 대응 export 파일은 없다. 새 표본으로 5장을 대체하지 않는다.
- 정지 잡음은 실제 정지 구간 확인이 필요하다. 물리 T/R 정확도는 독립 동기 참조가 없어 `x`를 유지할 수 있다. 이 참조 대기 때문에 완료된 8,910장을 다시 추론하지 않는다.
