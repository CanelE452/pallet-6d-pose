## 독립 재계산과 원 evaluator 대조

원시 L4 예측에서 별도로 다시 계산한 197개 수치가 기존 evaluator 결과와 모두 일치했다. Base/N3의 keypoints_mask도 8,910프레임에서 모두 같았고 부분 keypoint 결측 프레임은 두 방법 모두 0장이다. 이 확인은 출력 계약과 집계 재현성을 검증하며 사람 참조 정확도를 대신하지 않는다.
