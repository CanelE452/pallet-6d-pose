# 통합 수정 원고 복사본

이 디렉터리는 SHA-256이 고정된 `current_paper_source.zip`을 별도 복사한 뒤, 검산된 정적 completed319 표와 리프터 8,910프레임 연속성 수치만 적용한 검토용 원고다. 컴파일하거나 PDF를 생성하지 않았다. 실제 컴파일 입력은 `main.tex`, `supplement.tex`, `sections/`, `tables/`, `supplement_tables/`이다. `manuscript_ko.md`는 전달 ZIP의 과거 편의용 스냅샷이라 이번 통합 수치의 기준으로 사용하지 않는다. 변경 목록과 셀 출처는 상위 `paper_patch/PAPER_CELL_MAP.json`을 확인한다.
