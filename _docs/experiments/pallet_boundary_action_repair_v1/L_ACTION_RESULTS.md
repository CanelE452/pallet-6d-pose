# L 실제 행동 선택 결과와 독립 검산

대표 seed는 평가 전에 정한 20261018이다. 세 seed는 같은 영상 집합을 반복 평가한 것이며 독립 데이터 576장을 뜻하지 않는다. PRIMARY192(49 + 143)와 별도 CAL46을 모두 유지했다. 모든 L 경로는 같은 새 실사 후보·특징 238행을 입력받았다. 운영 기본값과 논문은 바꾸지 않았다.

D1 + H1은 성공 개수를 높였지만 연속 오차와 큰 실패를 함께 개선하지는 못했다. H0를 유지한 채 합성 관측만 D1으로 바꾸면 세 seed 모두 성공이 4장 감소했다. 결과는 데이터와 행동 목표를 함께 맞춰야 한다는 방향을 지지하며, 독립 실사 일반화 성능을 입증하지는 않는다.

## Full / pair / affine에서 무엇을 얻고 잃었는가

Full 실제 후보에는 151/192장에 성공 자세가 있었고 pair(N0 / 실제 E0)에는 133/192장에 있었다. Pair는 성공 가능한 18장을 행동 집합에서 잃는다. 대표 full은 120장 성공·31장 선택 실패·41장 성공 후보 부재이고, pair MLP는 117장 성공·16장 선택 실패·59장 성공 후보 부재다.

대표 pair MLP는 full보다 위치/회전 평균과 큰 오차 개수가 작지만 성공은 3장 적다. Pair role-affine 성공은 세 seed에서 118/119/118장으로 pair MLP 117/113/114장보다 높았다. Full role-affine은 114/112/114장으로 full MLP 120/117/121장보다 낮았다. 대표 affine은 더 많이 N0를 유지했으며, full MLP가 모든 목적에 일관되게 우월하다고 결론내릴 수 없다.

Full MLP의 실제 선택 출처(대표 seed)는 N0 18, E0_REGENERATED 72, OTHER 102장이다. Pair MLP는 N0 124, E0_REGENERATED 68장이다. OTHER는 기존 공통 후보 중 선택한 실제 자세이며 이번 새 B 보정이 만든 자세라는 뜻이 아니다.

이 부분집합은 각 head 자신의 실제 행동 집합으로 정의했다. Full 41장과 pair 59장은 서로 다른 집합이다. 아래는 대표 seed, PRIMARY192에서 N0와 비교한 값이며, 부호는 원래 오류식으로 엄격하게 계산했다.

H1의 다중 양성 BCE는 성공 행동의 선택을 학습한다. 모든 레이블이 0인 프레임에서는 각 점수를 낮추지만, 조금 틀린 N0와 크게 틀린 다른 자세 사이의 순서를 직접 알려주지는 않는다. 추론은 여전히 argmax로 하나를 선택한다. 실제 full H1의 이 부분집합에서는 N0 대비 위치 평균이 4.997cm, 회전 평균이 2.251° 증가했다. 이는 모든 0 레이블을 보존한 것만으로 연속 오차의 안전성이 생기지 않았다는 관측이다.

다음에 검증할 L 변경 하나로는 같은 고정 실제 행동에서 N0 대비 연속 위험의 순서를 학습하는 목표를 제안한다. 아직 구현·학습·평가한 개선 결과가 아니며 이번 결과에서 임계값이나 seed를 다시 고르지 않았다.

## 독립 검산과 재현

기존 전체 행동 검산은 6,149,427개 검사, 실패 0, 미검사 0이다. 별도 H1 실패 표 검산은 실제 catalog 항목에 대해 독립 자세 평가를 81,117회 수행했고, 3,570개 단계별 행동 집합·180개 집계·2,475개 상세 행·133,650개 scalar 검사를 모두 통과했다. Production 행동 생성·오류식·집계 함수를 import하지 않았다.

H1 표의 원래 오류식과 안정식 차이는 5,387건을 별도 보존했다. 그중 delta 차이 1,753건에서 안정식을 사용하면 90건의 부호가 달라진다. 보고된 엄격한 개선/악화/동일 개수는 독립적으로 다시 쓴 원래 norm/acos/sin(pi) 표현과 모두 일치했다. 이 차이를 0으로 덮거나 새로운 허용오차로 분류하지 않았다.

기존 D0 최초 독립 검사 FAIL 34건과 수정 전 source도 보존한다. 전체 검산에서 원래 표현의 위치값 139,582개는 bitwise 동일했고 안정식 차이 104개는 최대 2 ULP였다. 이 수치 표현 차이는 학습 레이블·성공 기준·과학 코드를 변경한 것이 아니다.

신규 fit은 총 18회, 성공 18회이며 과거 H0 3개 checkpoint를 재사용했다. fit 실패·새 backbone 학습·새 seed·새 데이터는 없었다. 실제 head 예측은 238×21=4,998회였다. 비용은 실제 배치 원장에 기록하고, D0 초기 공유 준비 시간의 미측정 공백과 RSS의 highwater 성격을 별도로 명시했다.

독립 H1 표 재검사는 모든 출력 GO·평가 seal·H1 분석 seal과 원본 hash를 검증한 뒤에만 참조를 연다. 완성 아카이브와 참조에 접근 권한이 있는 환경에서 기존 결과와 분리된 새 output으로 실행한다.

```bash
python -m scripts.research.pallet_boundary_action_repair_v1.independent_h1_failure_audit \
  --run-dir "$P_RUN" --original-score "$P_SCORE" \
  --evaluation "$P_RUN/evaluation_v1" --analysis "$P_RUN/h1_all_failure_v1" \
  --output "$P_RUN/independent_h1_failure_recheck" --scoring-GO
```

공개 수치 원장은 `COMPARISON_ALL_ARMS.csv`, `H1_ALL_FAILURE_ROWS.csv`, `H1_ALL_FAILURE_SUMMARY.json`이다. 검산 receipt는 `INDEPENDENT_H1_FAILURE_CHECK.json`, 실행·학습 provenance는 `L_EXECUTION_CLOSURE.json`과 `L_COST_AND_EXECUTION_RECEIPT.json`에 담는다. 모든 수치는 [METHOD_L.md](METHOD_L.md)의 고정된 정의에 따른다.
