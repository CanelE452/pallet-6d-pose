# DOPE·YOLO와 DHT 결합 검증

기존 합성 학습 DOPE·YOLO의 코너를 기존 DHT8이 예측한 측면 구조선으로 보정했을 때 실사 정확도가 개선되는지 실제 실행해 비교한다. 이번 방법은 **추론 후 코너–선 결합**이다. YOLO 내부 특징에 새 DHT head를 붙여 공동 학습하거나 DOPE affinity/PnP까지 결합한 실험은 아니다.

최종 결과는 `data/pallet/results/dht_pose_integration_v1/live/`다. 상위 폴더는 저장된 특징을 재사용한 최초 비교를 보존한다. `live/`에서는 원본 이미지를 batch1로 처리해 얻은 DHT 예측을 정확도 평가와 실제 처리시간 측정에 공통으로 사용한다.

## 확인 결과

연결·실행은 가능하지만 **현재 고정된 DHT8 선으로 코너를 보정하는 방식은 실사에서 유용한 전체 개선을 보이지 않았다**. DOPE는 합성 검증에서강도2가 선택됐으나 실사 평균·P90오차가 증가했다. YOLO는 합성 검증에서강도0, 즉DHT보정을 사용하지 않는 값이 선택됐다.

| 실사 DEV52 조건 | 예측된 코너 평균 오차px | 코너 P90px | 전체 정답 PCK@10px |
|---|---:|---:|---:|
| DOPE 기존 |18.10|34.46|49.52%|
| DOPE＋DHT, 합성 검증 선택강도2 |33.74|84.85|41.43%|
| YOLO 기존 |9.40|18.39|65.14%|
| YOLO＋DHT, 합성 검증 선택강도0 |9.40|18.39|65.14%|
| YOLO＋DHT, 별도 진단강도1 |24.52|68.07|54.49%|

결합 수치는3개DHT seed별 통계의 평균이다. 코너 평균/P90은 예측이 있는 코너에 대한 값이며, PCK는 결측까지 실패로 포함한다. DOPE393/416개, YOLO400/416개 코너가 검출됐고 보정은 이 결측을 복원하지 않는다. DHT만으로새롭게 코너를 만드는 방식은 테스트하지 않았다.

좌표 역변환만 고친 DOPE대조군에서도 평균19.34→33.83px, P9038.29→83.51px로 커졌다. 이 대조군의PCK@10은40.14→40.46%로 조금 높아졌지만 큰 오차 증가를 상쇄하는 전체 개선으로 해석하지 않는다. DOPE결합은 동일 계열 합성 test에서는 평균 코너 오차가 줄었고 실사 야외에서 특히 악화했다. 따라서 합성 검증의 개선을 실사 개선으로 일반화할 수 없다.

실제 결합 실행과 최종 평가 출력은 고정24장 모두 일치했다.648개 실제시간 측정을 검증했다. 실사12장×3회 반복에서 좌표 보정 DOPE는중앙값32.18→44.31ms(강도2), YOLO는10.12→18.23ms(진단강도1)였다. 강도0은DHT를 실행하지 않아 기존과 같은 계산이며, 반복측정 시간 차이를 속도 개선으로 보지 않는다.

이전 DHT의 개선 수치는 별도의Direct Hough 선 예측기와 비교한 결과였다. 이번 결과는 이미 코너를 예측하는 DOPE·YOLO에 같은DHT선을 추가했을 때의 검증이며, 두 비교를 혼동하면 안 된다. 새 YOLO특징 head 공동학습이나6D자세 개선의 결론은 아니다.

## 모델과 데이터

- DOPE: `weights/backbone_dope_final_v1/run/final_net_epoch_0060.pth`의 전체6단계 네트워크. 기존 stage0 반사100px→원영상 크기로 resize→짧은 축400 및8배수 크기→ImageNet 정규화→기존 belief local-peak decoder를 고정한다. 채널별 단일 팔레트 코너 추출이며 affinity 기반 다중 객체 연결은 하지 않는다.
- YOLO: `YOLO26N_G38_P0_TEX20K_CLEANSTART_60EP_SEED42/weights/best.pt`. 합성 팔레트55,980장으로 학습한 R0, COCO 초기화. 반사100px, imgsz640, box confidence0.25, keypoint confidence0.5, 최고 box confidence 객체를 선택한다. GT로 객체나 코너 순서를 맞추지 않는다.
- DHT: 기존 DOPE VGG 특징 기반 DHT8 최종6,000step 체크포인트 seed1/2/3. 원래의 반사100px·400정사각 입력·uint8 resize·FP16 특징 저장 후FP32 입력을 유지한다. 실제 이미지 경로는 특징과 head 모두batch1이다.
- 합성 검증256장은 보정 강도 선택에만, 합성 test256장·다른 합성128장·정본 실사 DEV52장은 고정 설정 평가에 사용한다. 총692장. 실사 학습·실사 파라미터 선택·최종 평가셋 접근은 없다. 과거 백본 사전학습과 합성 평가 간 중복은 미검증이다.

## 결합과 사전 고정

각 코너는 자기에게 연결된 두 DHT 직선과 기존 코너 위치를 함께 만족하도록2×2선형계로 보정한다. 기존 코너 위치에 양의 가중치를 두므로 선이 평행해도 해가 정해진다. 잘못된 선 자체를 올바르게 만드는 제약은 아니다. GT 마스크·가시성·코너 대응을 추론 입력에 넣지 않는다. 없는 코너는 계속 결측이고 중심점은 DHT로 변경하지 않는다.

보정 강도 후보는0,0.25,0.5,1,2,4이며, 모델별로 합성 검증의 세 DHT seed 평균을 최소화하는 값을 고른다. 선택 점수는 프레임별 코너 오차를 영상 대각선으로 나누고1에서 자른 값의 평균이며 결측은1이다. 실제 평가 전에 `SELECTION.json`을 저장·동결한다. 강도1은 별도로 사전 지정한 진단값이고 실사 결과로 고른 값이 아니다. 선택값0은 DHT 보정을 사용하지 않음을 뜻한다.

DOPE 기존 역변환은8배수로 내림한 실제 영상 폭 대신 명목 배율을 사용해640×480입력의 x좌표에0.99배 효과가 있다. 이를 분석식으로만 고친 `DOPE_exact_resize` 비교군도 정확도 분석 전에 등록했다. 기존 decoder의0.4395오프셋이나 반 픽셀 규약은 변경하지 않는다. 원래 DOPE 결과와 이 대조군을 모두 보존한다.

## 지표와 실제 실행 검증

- 코너 중앙값·P90·평균(px)은 예측이 있는 코너에 대한 조건부 값이다.
- PCK@5/10/20px는 모든 유효 정답 코너가 분모이며 결측 예측은 실패다. 예측 커버리지와8코너 모두10px이내인 프레임 비율도 표시한다.
- 원래8측면 선의 위치·각도 오차와 성공률, 실사 그룹22/12/18장을 별도로 집계한다. GT 구조적 지원 여부는 평가 마스크에만 사용하며 실제 재료 경계의 가시성 정답은 아니다.
- DHT가 없는 동일 baseline과 각 DHT seed를 대응 비교한다. seed 요약은 seed별 통계의 평균/범위이며 반복 선을 한꺼번에 합친 중앙값이 아니다.
- RTX3080에서 SHA로 고른 합성12장+실사12장, warmup5, batch1,3회 반복으로 실제 `baseline→DHT→fusion` 전체 벽시계 시간을 잰다. 모델 로딩과 디스크 읽기는 제외하며 전후처리는 포함한다. 강도0은 DHT 실행을 생략한다.

최초 캐시 재사용 경로와 실제 단일 이미지 실행의 비교에서 일부 인접 Hough bin이 달라졌다. 원인은 특징 재추출의 수치 차이와 batch 크기에 따른 head 계산 차이였다. 허용오차를 늘려 통과시키지 않고 `live/`에서692장×3seed를 다시 예측했다. 가중치·보정 후보·검증 선택 규칙을 바꾸지 않았고 최초 결과도 남겼다. 최종 정확도와 실제 실행 출력의 일치는 `live/RUNTIME.json`으로 확인한다.

## 산출물과 재실행

`CONFIG.json`, `manifest.json`, `AUXILIARY_PROTOCOL.json`, `LIVE_PROTOCOL.json`은 설정·분리·실행 경로 기록이다. `BASELINE_*.json`, `DHT_LINES.json`, `FUSED_PREDICTIONS.json`은 원본 좌표 예측, `SELECTION.json`은 합성 검증 선택, `RESULTS.json`·`FRAME_METRICS.json`은 비교 결과, `RUNTIME.json`은 실제 시간과 출력 일치 검증이다. 완료 PASS는 실행·검증 완료를 뜻하며 정확도 개선을 뜻하지 않는다.

```bash
cd /home/minjae/Documents/github/pallet-pose/data/pallet/results/dht_pose_integration_v1
/home/minjae/anaconda3/envs/pallet-yolo26/bin/python /home/minjae/Documents/github/pallet-pose/scripts/research/dht_pose_integration_v1/driver.py --run-dir .
```

이미 완료한 예측은 동일한 출처에서만 재사용한다. 최종 화면만 갱신하려면 `--report-only`, 자동 열기를 끄려면 `--no-open`을 붙인다. 로컬 HTML 연결 프로그램이Slack인 환경에서도 공용 실행기는 설치된 Chrome을 직접 연다.
