# 이번 실험으로 확인된 것

실사9장만 학습했을 때 발생한 정상 코너 훼손은 합성 GT replay를 추가하자
크게 줄었다. 같은300step과 실사2400회 노출에서 비교한 결과다. 단, 추가
합성2400회 노출에 따른 계산량 증가까지 통제한 실험은 아니다.

| 지표 | 실사만 | 실사+합성 replay | 비교 기준 |
|---|---:|---:|---:|
| DEV72 PCK10 | 45.23% | 60.18% | 현재 DIM-only59.46% |
| GREEN150 manual PCK10 | 68.14% | 77.39% | 현재 DIM-only81.35% |
| DEV 정상 코너 훼손 | 35/138 | 1/138 | 현재 DIM-only0/138 |
| GREEN 정상 코너 훼손 | 76/344 | 14/344 | 현재 DIM-only0/344 |
| 합성 heldout 정상 입력 PCK10 | 51.98% | 90.95% | 추가학습 전 PoseFix94.02% |

위 표의 새 PoseFix는 모두 이동 제한 없는 raw 출력이다. 훼손은 동일 R0의
<5px 코너가 >10px가 된 경우다. DEV의 관측 PCK10 증가는+0.72pp이지만 단일
seed의 재사용 개발 평가이며, 통계적 유의성이나 독립 일반화 성공을 주장하지 않는다.

합성 heldout에 큰 입력 교란을 가했을 때 PCK10은 기존 PoseFix19.54%에서
replay68.84%가 됐다. 따라서 모델이 주입한 큰 오차를 배우지 못하는 상태는
아니다. 다만 실제 촬영의 큰 오류는 합성한 위치 교란과 분포·코너 대응 문제가
다를 수 있으며, 이 가설은 이번 실험에서 원인별로 분리하지 않았다.

실사 큰 오차 복구는 DEV156개 중4개, GREEN의 매칭 hard4개 중1개였다.
이전 실사-only는 각각10개와3개였으므로, 정상 코너 보호가 좋아지는 동시에
큰 오류 복구 일부도 줄었다. '모든 측면이 개선됐다'고 설명하지 않는다.
GREEN의4개 분모로 보편적인 복구율을 주장하지 않는다.

사전 self-training 진입 기준10개 중6개가 미달했다. 특히 GREEN의 기존 모델
대비 PCK10 하락3.96pp와 정상 코너 훼손4.07%, 그리고 원래 합성 능력의
보존 미달이 남았다. 단순히 DEV 복구가5개 기준보다1개 적어서만 중단한 것이 아니다.
이동 상한을 넣은 결과로 조건을 대체하거나 threshold를 낮추지 않았다.

따라서 이번 실행은 여기서 완료한다. 후속 선택적 self-training, 새 pseudo-label
생성, 추가 seed/lr/가중치 탐색은 실행하지 않았다. 기존 최종 모델과 논문 표,
어노테이션, 기존 결과를 유지했다. 깊이·CAD는 사용하지 않았다.

CPU 회귀검사9개, 평가 baseline parity744개, 예측 보존888개를 통과했다.
별도 읽기 감사에서도 raw/cap 전체 per-frame 지표와 해시, 촬영/이미지 분리,
사전조건 불통과와 후속 미실행 상태를 다시 확인했다.
