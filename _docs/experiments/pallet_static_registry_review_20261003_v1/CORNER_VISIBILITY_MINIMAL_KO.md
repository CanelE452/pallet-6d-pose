화면에서 흰 고리로 선택한 코너를 보고 숫자 또는 버튼으로 고릅니다.

| 키 | 사람 판단 |
|---|---|
| `1` | 보임 |
| `2` | 다른 물체에 가림 |
| `3` | 뒤쪽·자체 가림 |
| `4` | 화면 밖 |
| `5` | 판단 보류 |

선택하면 즉시 저장합니다. 한 이미지의 입력이 끝나면 다음으로 넘어갑니다. 이미지의 기존 점이나 오른쪽 번호를 클릭하면 선택 코너를 바꿀 수 있습니다. 작은 코너는 왼쪽 아래에 확대해서 표시합니다.

`P` 이전 이미지, `N` 현재 이미지를 보류하고 다음, `Z` 현재 이미지의 마지막 입력 되돌림, `R` 현재 이미지의 새 입력 취소, `Q` 종료입니다. `,`·`.`은 코너 이동, `+`·`-`는 확대, `H/J/K/L`은 확대 이미지 이동입니다. 다시 열면 남은 점이 있는 이미지만 목록에 넣고, 이미 입력을 마친 이미지는 건너뜁니다. 한 자료의 입력이 끝났으면 위 버튼에 `입력 완료`를 표시하고 비활성화합니다. 두 자료 모두 새 입력이 없으면 `NO_PENDING_VISIBILITY_INPUT` 상태를 출력하고 창을 열지 않습니다.
