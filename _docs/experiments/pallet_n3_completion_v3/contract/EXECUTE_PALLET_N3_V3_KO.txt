## 0. 최상위 목적과 이번 작업의 범위

최상위 목적:

교수와 논문 독자가 판단할 것은 다음 세 가지다.

- 동일 N3 절차가 YOLO·DOPE·ResNet-18에 각각 적용되는가?

## 2. 모델·입력·학습의 공통 계약

2.1 모델 역할을 바꾸지 마라.
- R0/원래 추정기: 각 기반의 고정된 RGB 키포인트 추정기. R0라는 과거 ID는 원래 YOLO 기준선에 한정한다.
- P/OLD_P: 과거 치수 없는 국소 분포 보정 결과. 기존 기록을 보존한다.
- N0_BASE_REPLAY: 동일 규약에서 새로 재현했던 치수 없는 P 통제 모델.
- N1_SYM_ONLY: 치수 없는 국소 보정 + 대칭 감독.
- N2_DIM_ONLY: 국소 보정 + 치수 입력, 고정 대응 감독.
- N3_DIM_SYM: 국소 보정 + 치수 입력 + 대칭 일관성 감독. 이번 논문의 제안 방법.
- D/L/PoseFix 계열: 각각 별도 비교 방법. N3 또는 서로의 재현으로 이름을 바꾸지 않는다.

2.2 세 기반의 주 비교는 모두 다음과 같다.
원래 경로: RGB → 해당 추정기/연결부 → 원래 코너 → PnP(K, 물리적 치수).
제안 경로: 같은 RGB → 같은 추정기/연결부 → 초기 코너·특징 + 치수 → N3 → 같은 PnP(K, 물리적 치수).
기본 신경망은 세 모델 모두 RGB만 받는다. N3 보정기만 특징·초기 점·박스·물리적 치수를 받는다.
기준선도 PnP에는 동일한 치수를 사용한다. 보정기에서만 치수 입력을 뺀 것을 시스템 전체의 치수 미사용으로 서술하지 않는다.
DOPE·ResNet을 P/D만 학습한 뒤 N3 완료로 처리하는 것을 금지한다.

2.3 N3 핵심 계산을 기존 YOLO 구현과 동일하게 유지한다.
- 중심점 8은 유지, 코너 0–7만 보정.
- 13방향×17반경의 221개 이동 후보와 무이동 후보 1개, 총 222개.
- 후보 반경은 네트워크 입력 좌표의 예측 박스 대각선×0.08.
- 221개 후보 주변의 4×8 특징 표본, 1×1 채널 변환, 공유 패치 인코더, 평균·최대 집계.
- 무이동 시각 점수는 별도 후보 집계 분기. 새 패치를 추가한 구현으로 바꾸지 않는다.
- stencil_fraction은 확인된 N3 학습 lock의 값을 사용한다. 현재 기준값은 0.1310373991727829이며 클래스 기본값 0.25로 바꾸지 않는다.
- 치수는 객체 고정축의 [W,D,H]를 미터로 제공한다. 시점에 맞춰 GT pose로 W/D를 교환하지 않는다.
- 치수 특징: logW, logD, logH, log(W/D), log(H/sqrt(WD)). 학습 자료에서 고정한 동일 평균/표준편차를 사용한다.
- 5→16→16 치수 인코더, 역할8+후보변위2+무이동표시1을 결합한 27→32→1 점수 분기.
- 치수 분기의 마지막 층은 0 초기화하고 시각 logits에 더한다.
- N3에는 N4의 대칭 종류 one-hot을 추론 입력으로 넣지 않는다.
- argmax가 아니라 softmax 확률로 후보 변위의 가중평균을 계산한다.
- λ=1, 원본 영상 대각선의 1%라는 이동 상한을 유지한다.
- 실제 객체 선택·박스·점수·후보 순서·중심·결측 마스크를 보정 전후 유지한다. 결측 코너를 새로 생성하지 않는다.

2.4 기반별로 달라지는 것은 특징·좌표 연결부다.
게시본의 특징 채널/stride: YOLO (64,128)/(8,16), DOPE (256,128)/(4,8), ResNet-18 (128,256)/(8,16).
현재 모델에서 실제 shape/tap을 검증하고 코드 연결을 기록한다. 다른 채널 연결의 추가 파라미터 수를 YOLO의 20,259개로 복사하지 않는다.
DOPE의 코너 기반 bbox·확률맵 점수 및 affinity 미사용 디코딩을 그대로 명시한다. YOLO와 같은 다중 객체 검출기로 설명하지 않는다.
ResNet에 YOLO 정답 crop 또는 DOPE 예측을 입력해 독립 기반처럼 취급하지 않는다.
기본 추정기의 전처리/decoder를 고치면서 그 효과를 N3 효과에 합치지 않는다. 기본 경로 오류가 발견되면 해당 기반만 멈추고 전후 계약을 별도로 재확정한다.

2.5 좌표/상한을 다음과 같이 연결한다.
u_net = A_b u_original + a_b, A_b=diag(gx,gy).
delta_original = inverse(A_b) delta_net.
delta_capped = delta_original × min(1, 0.01×original_image_diagonal / norm(delta_original)).
u_refined_original = u_initial_original + delta_capped.
변위 역변환에는 패딩 이동 a_b를 다시 더하지 않는다. 영벡터의 나눗셈을 안전하게 처리한다.
YOLO 등방 변환에서는 기존 network-space cap 방식과 동등함을 검증한다.
DOPE/ResNet의 비등방 변환에서는 원본 공간의 같은 원형 이동 제한을 적용한다. scalar gain을 임의로 평균내거나 한 축 값을 재사용하지 않는다.
후보·목표 분포·학습 손실은 기존처럼 network 좌표에서 계산한다. cap은 추론 좌표 출력에 적용하는 것으로 구분한다.

2.6 대칭 감독은 반드시 세 기반 N3 모두 포함한다.
각 기반의 고정된 초기 예측을 기준으로, 사전에 승인한 객체 전체 GT 순열 중 평균 정규화 코너 거리가 최소인 하나를 선택한다.
GT 좌표와 마스크를 같은 순열로 옮긴다. 결측 예측 벌점1, identity-first tie, corner0–7 비교를 기존 구현과 맞춘다.
학습된 보정 출력의 손실을 보고 GT branch를 다시 고르는 min-loss 구현으로 바꾸지 않는다.
각 코너를 독립적으로 최근접 매칭하지 않는다. 기본 모델의 잘못된 90° 축 선택을 C4로 임의 면제하지 않는다.
목표 잔차에 대한 Gaussian 후보 분포, sigma=0.08×bbox_diagonal/17, 유효 코너별 평균 후 유효 영상 평균 CE 손실을 유지한다.
학습 예측은 온도1 softmax다. 학습 GT를 사용하는 대응 선택은 inference에 들어가지 않는다.
대칭이 실제로 달라져야 하는 객체는 사전 객체 계약을 확인하며, 치수 W=D만으로 C4를 생성하지 않는다.

## 5. 재집계·새 정사각형 평가의 구체적 수행

5.1 N0/N1 및 비교 방법:
기존 fit/weight/prediction이 있으면 읽어서 현재 전체 프레임·8코너 규약으로 rescore한다.
원시 예측이 없고 유효한 checkpoint만 있으면 동일 영상에 추론한다.
checkpoint와 예측이 없으면 기존 보관 위치를 먼저 찾고, 찾지 못하면 해당 행을 BLOCKED_ARTIFACT로 둔다. x를 없애려고 자동으로 과거 모든 모델을 재학습하지 않는다.
N0의 숫자를 OLD_P로 복사하지 않는다. 학습 통제는 같은 초기 상태·source 순서·예산·유효 감독을 확인한다.
N2−N0, N1−N0, N3−N2, N3−N1의 차이를 따로 보고한다. 모든 학습된 방법은 확인된 각 seed별 결과와 집계를 함께 저장한다.

5.2 유형/가림:
형상과 재질을 별도 열로 유지한다. 세션·개체 수, 영상 수, 평가 코너 수, 매칭 수를 함께 산출한다.
기존 검수한 가림 기준과 레이블이 있으면 현재319장 identity와 연결해 재사용한다.
없거나 경계가 불명확하면 미분류로 남기고 원영상 검수용 목록을 만든다. 모델 오차·신뢰도·조건부 성공 여부로 가림을 추정하지 않는다.
원본 영상으로 등급을 새로 검수해야 한다면 예측/오차를 가린 상태의 검수 자료를 만들고, 사람이 확정하기 전에는 확정 레이블로 취급하지 않는다.
외부 가림, 자기 가림, 화면 밖 잘림을 구분한다. 전체 표본=확정 각 등급+미분류를 검산한다.
실제0개인 집단은 0개라는 확인과 함께 지표를 NA/해당없음으로 둔다. 아직 모르는 집단을0으로 적지 않는다.
가시성은 직접 가시/가려진 참조/미확인으로 나누고, 참조가 직접 클릭인지 기하 보완인지 별도 기록한다.
가시성/가림 레이블이 일부만 있으면 그 일부에 대한 분모를 밝히고 나머지를 미확인으로 남겨 가능한 분석은 실행한다.

5.3 새 정사각형:
평가 영상, 0–7 코너와 중심점의 의미, 단위, 카메라, 객체 고정축 치수, 승인 대칭, 학습 노출을 먼저 잠근다.
고정된 현재 R0/P/N2/N3를 그대로 평가한다. synthetic calibration에서 이미 정한 온도를 사용하며 square에서 다시 고르지 않는다.
과거 square 보조실험의 T=1을 새 evaluation에 일괄 적용하지 않는다.
합성 주학습 모델이 square를 잘 못한다고 평가 영상으로 학습하거나 C2/C4를 결과에 맞춰 바꾸지 않는다.
원래 주석이 앞면4점 등 다른 의미라면 검증된 대응표만 사용한다. 없는 코너를 추측하거나0으로 채우지 않는다.
K/metric 참조가 없으면 가능한2D만 완료하고6D는 x로 둔다. N3의 실제 치수 자체가 없으면 N3 입력을 임의 대체하지 않는다.
새 집단 결과는 기존319장 평균에 자동 합산하지 않는다. 개체/세션/난도와 감독 이력을 별도 보고한다.

5.4 큰 오류:
주 지표는 기존처럼 방법별 허용 전체 순열 최솟값을 사용한다.
이동 상한·손상 분석은 기준 모델에서 고정한 전체 대응을 보정 후에도 사용한다. 둘의 수치를 구별하여 저장한다.
유효 초기점에 대해 cap=0.01×원본대각선, 초기오차 cap 안/밖의 수 및 개선/동일/악화를 집계한다.
고정 대응에서 e_after >= max(0,e_before-cap)인지 검산한다. 실패하면 좌표·대응·상한 오류부터 진단한다.
<5px→>10px 손상, >20px→<10px 복구, 기존 gross20 규약을 유지한다. <와 ≤ 조건을 임의 변경하지 않는다.
2D 영상별 평균오차 변화와 이동/회전 변화를 연결한다. 자세 paired 변화는 양쪽에서 유효한 같은 프레임에서 계산하고, 새 실패·복구는 별도로 전체 분모에 기록한다.
무차이 판정의 수치 오차 허용범위는 기존 코드 것을 확인해 사전 고정한다. 단순히 '가림 때문에 P90이 크다'로 판정하지 않는다.

## 6. DOPE/ResNet N3 구현과 최소 무결성 시험

6.1 기존 코드/데이터 연결을 최대한 재사용하되, 옛 실험 파일·출력은 덮어쓰지 않는다.
[신규 제안 경로] scripts/research/pallet_n3_completion_v3/ 아래 필요한 최소 wrapper/adapter/test를 둔다.
[신규 제안 경로] _docs/experiments/pallet_n3_completion_v3/ 아래 보고·표·검증을 둔다.
[신규 제안 경로] data/pallet/results/pallet_n3_completion_v3/ 아래 로컬 원시 예측·checkpoint·cache를 둔다.
이 경로는 기존 실재를 주장하는 것이 아니라 새 출력 제안이다. 충돌하면 새 suffix를 쓰고 최종 manifest에 기록한다.

6.2 N3의 모든 학습층을 학습한다. 기반 추정기는 고정한다.
N3의 시각 점수·패치·채널 연결 학습층과 치수 분기를 모두 원래 계약대로 optimizer에 포함한다.
치수 분기만 학습하거나, N3에 이미 학습한 P 가중치를 임의 warm-start하지 않는다.
기존 YOLO train.py의 초기화 방식처럼 seed별 base random state를 생성하고 metadata 마지막층0을 적용한다. 다른 초기화가 기존 로컬 N3 실행에 있었다면 차이를 보고하고 같은 실험으로 합치지 않는다.
YOLO에서 학습된 헤드를 DOPE/ResNet에 shape만 맞춰 꽂고 무학습 전이라고 주장하지 않는다.

6.3 학습 전에 synthetic/fixture 기반으로 다음을 검증한다. DEV 점수로 구현을 선택하지 않는다.
- 기반 checkpoint strict load와 hash, feature tap/shape/stride, dtype/device, 실제 coordinate transform.
- 원본↔네트워크 round trip; 비등방 크기·패딩·경계·결측·작은 박스의 사례.
- λ=0에서 좌표·중심·박스·선택·점수·결측 상태가 그대로 유지됨.
- 원본 기준 이동 상한, affine 역변환, YOLO 기존 cap과의 동등성.
- 동일 초기 시각 weights에서 치수 마지막층0이면 N3 logits가 치수 없는 base logits와 일치함.
  이 시험을 '초기 N3 좌표=원래 추정기 좌표'라는 잘못된 assertion으로 바꾸지 않는다. P 자체의 이동은 별개다.
- 첫 backward에서 시각 분기·metadata 마지막층 gradient가 존재하고 optimizer step으로 값이 바뀜.
  0초기화 때문에 metadata encoder의 첫 gradient가0일 수 있다. 이후 step에서 연결이 살아 있는지 확인한다.
- synthetic 치수 입력 변경이 학습 후 metadata logits에 전달되는지 확인. 인위적인 최종 성능 개선 기준은 요구하지 않는다.
- 동일 permutation이8개 코너와 GT mask에 적용되고 center8이 유지됨.
- 학습 target 선택은 raw 초기점만 참조하고 inference에는 GT branch 호출이 없음.
- checkpoint 재시작 때 optimizer·step·RNG·표본 순서·protocol hash가 보존됨.
- 고정 모델의 파라미터와 buffer가 학습 전후 바뀌지 않음.
기술 시험을 통과한 구현만 본학습한다. 성능이 좋지 않다는 이유로 시험 허용오차를 완화하지 않는다.

## 7. 학습 예산, 선택 규칙, 실행 순서

7.1 핵심 추가 학습 예산은 기존 v3 계약에서 가져온다.
DOPE N3: seed1/2/3 ×6,000 update ×batch16.
ResNet-18 N3: seed1/2/3 ×6,000 update ×batch16.
총 최대 신규 보정 본학습6회, 36,000 update, 576,000 표본 노출이다. 동일 계약으로 완료한 fit은 이 중에서 제외한다.
[운영 설정] 구현 smoke는 각 기반 최대100 update의 폐기용1회로 제한한다. 최대200 update이며 본학습에 합산하거나 완료로 세지 않는다. 기존100-step smoke 관행을 적용한 기술 검증 예산이지 성능 검정 기준이 아니다.
부족한 성능을 만회하려고 seed·epoch·해상도·표본 수를 확대하지 않는다.

7.2 공통 보정 학습:
seeds1,2,3 / effective batch16 / 6,000 optimizer updates / AdamW lr1e-3 / weight_decay1e-4 / betas(0.9,0.999) / warmup100 / cosine final factor0.1 / grad clip5.
FP32와 원래 precision 규약을 기록하고, 자동 AMP/TF32 변경을 하지 않는다.
최종 step6000만 평가용 checkpoint로 사용한다. best DEV 또는 가장 좋은 seed를 고르지 않는다.
source는 기존55,980 TRAIN만 사용하며 실제 유효 감독 행·코너·노출량을 기록한다. 기반별 예측 실패로 학습 지원이 달라지는 것을 숨기지 않는다.
표본 순서와 유효 TRAIN 선택 규약은 학습 전에 고정한다. 도중에 '잘 맞는 영상'으로 바꾸거나 실패 batch를 숨기지 않는다.
기존 계약과 양립하지 않는 무감독 batch/부족한 자료는 해당 학습의 데이터 문제로 보고한다.
학습 loss·gradient·실제update·유효정보량·메모리·시간을 정기 기록한다. CUDA 비결정성을 무시하고 bit-exact 학습을 약속하지 않는다.

7.3 기본 ResNet-18은 별도 조건부 작업이다.
우선 기존에 학습 완료된 독립 RGB 팔레트9점 추정기의 checkpoint/영수증을 찾고, 있으면 재사용한다.
중간 checkpoint가 있고 동일 protocol이면 이어학습한다. 검증된 완료 baseline이 없고 모든 데이터·프로토콜이 갖춰진 경우만 기존 baseline_train 경로로1회 학습한다.
이 경우 기존 문서의 ImageNet 초기화, 합성55,980장, batch16, 60epoch, 최종epoch60을 따른다.
예상 전체는209,940 optimizer updates, 실제표본3,358,800회 노출이다. 마지막 미니배치의 실제 크기를 포함해 기록한다.
이 기본 학습 비용은 N3의36,000 update와 분리한다. 모델 구조/입력384×512 등의 실제 baseline protocol을 직접 읽어 확인한다.
기존 DOPE와 YOLO 기본 모델은 다시 학습하지 않는다. 해당 checkpoint가 없다면 찾기/복구 요청으로 처리한다.

7.4 온도 선택:
학습 완료 후 synthetic calibration1,004장만 사용한다.
후보{0.5,1,2,4}, 모든 arm에 같은 fixed-index Gaussian target CE 규칙을 사용한다. 대칭 branch 기준으로 calibration 목적을 바꾸지 않는다.
최저값 동률 규칙은 기존 코드에서 확인해 고정한다. λ/cap/stencil/symmetry group은 재탐색하지 않는다.
selection/held-out/실사/square/주행 결과로 checkpoint나 온도를 바꾸지 않는다.
설정 확정 후 synthetic held-out와 DEV319, 승인된 추가 집단을 평가한다.

7.5 자원 운영과 중단:
GPU 본학습은 사용 가능한 기존 단일GPU에서1개 작업씩 실행한다. 다른 학습과 무단 동시 실행하지 않는다.
smoke/기존 완료 로그로 실제 step 시간·예상 저장량을 측정하고 학습 시간·디스크 소요를 보고한다. 근거 없는1시간/며칠 약속은 하지 않는다.
기존 사용자 자원 상한이 있으면 우선한다. 이번 fit/epoch 상한을 넘기는 학습·유료 자원·추가 장비는 별도 승인을 받는다.
메모리가 부족하면 우선 cache 처리·직렬 실행을 조정한다. batch/해상도/목적함수/BatchNorm 동작을 몰래 바꾸지 말고 해결 불가하면 BLOCKED_RESOURCE다.
학습 NaN, 잘못된 차원/축, GT 누출, base weights 변화, 실제 데이터 계약 불일치는 관련 작업을 중단한다.
성능 무차이/악화나 source T/R 개선 미달은 무결성 실패가 아니다. 구현·데이터가 유효하고 학습 예산이 완료됐으면 정해진 평가를 수행해 그대로 보고한다.
서로 다른 과거 selector의 'source T/R 모두 좋아야 실사 평가' 같은 gate를 이 N3 실험으로 가져오지 마라.
수렴 부족의 흔적은 함께 보고하되, 좋은 결과를 얻으려고 학습을 자동 연장하지 않는다.

## 8. 비교 방법과 자기학습 결과의 공정한 재사용

8.1 D/L/PoseFix:
기존 합성 감독 기반 비교의 weight/receipt/source lock을 우선 재사용한다. 같은 초기 추정·8코너 평가·자료319장으로 재추론/재집계한다.
큰 실사 감독 Replay 교사와 합성 기반 PoseFix 비교군을 같은 모델로 취급하지 않는다. PoseFix-derived의 어떤 변형인지 명시한다.
9점 요약값에서 중심점만 추정해 빼는 식으로8코너 통계를 역산하지 않는다. 원시 좌표와 참조로 계산한다.
추가 정보, 수동 감독, 학습량, trainable parameters, 초기화, checkpoint 선택을 나란히 기록한다.
다른 조건의 비교도 기술적 패키지 비교로 보고할 수 있으나, input/감독 차이를 숨긴 공정 통제라고 부르지 않는다.
없는 새 렌더링 보정 baseline을 참고문헌에 있다는 이유만으로 이번에 대규모 재현하지 않는다.

8.2 대표 업데이트 대안:
기존 source-only update, RAW pseudo student, corrected pseudo student를 같은 평가기로 재평가한다. 새 self-training을 시작하지 않는다.
기존 locked main 학생을 사용하고, 현재 실사 점수가 가장 좋게 나온 학생을 다시 고르지 않는다.
corrected teacher는 N3와 다른 모델/실사 감독일 수 있다. 실제 teacher/student 데이터 이력을 확인해 이름과 감독 예산을 구분한다.

8.3 중요한 추가 확인: 평가 집단의 감독 노출.
기존 corrected ST 보고서는 학생을 별도128장 DEV에서 평가했고 teacher는 실사9장38코너로 학습했다고 기록한다.
따라서 기존319장 전체로 평가를 넓히면 teacher fitting/학생 training/동일촬영 세션이 들어갈 수 있다. '같은319장'이라는 이유만으로 공정성이 확보되지 않는다.
각 비교군의 정확한 학습/teacher/source/session 노출을 현재319장과 교차 검사한다.
직접 또는 교사 감독 노출이 있다면 그 전체319장 수치를 비노출 성능/일반화 근거로 넣지 않는다. 필요한 경우 노출된 기술통계로 따로 남긴다.
데이터 계약만으로 정의되는 기존 안전 공통 집단이 확인되면 같은 집단의 R0·N3·모든 학생을 함께 재평가해 별도 패널로 보고한다. 새 집단임을 적고 기존319장 주표를 몰래 교체하지 않는다.
자료 계약 확인 없이 임의로 안전 집단을 만들지 마라. 대응 불명확/주요 범위 변경이면 그 표만 BLOCKED_CONTRACT와x로 남기고 이유 및 최소 확인 사항을 제시한다.
일부 ST 결과가 나쁘다고 과적합/과신을 입증했다고 쓰지 않는다.

## 9. 기록된 리프터 영상 사례

9.1 현재 보유한 실제 RAW RGB 영상과 대응 CSV를 로컬 설정/기존 기록에서 찾는다. 영상1개/CSV1개도 임의 경로로 가정하지 않는다.
원자료가 없으면 사용자에게 필요한 위치를 한번에 요청하고 이 작업만 차단한다.
파일 ID/해시/영상크기/실제 timestamp 또는 presentation timestamp/카메라/치수/주석/노출 이력을 기록한다.
CSV 컬럼은 직접 확인한다. 미열람 column 이름으로 parser를 미리 확정하지 않는다.

9.2 같은 프레임에 YOLO 원래 추정기와 고정 N3를 적용한다.
기본 모델은1번 추론해 그 같은 출력을 보정 없는 경로와 보정 경로에 공유할 수 있다. offline 속도 측정과 end-to-end runtime은 분리한다.
해상도/전처리/왜곡처리/K/치수/객체 원점/축을 공통으로 고정한다. 새로운 tracking·평활화를 한쪽에만 넣지 않는다.
미리 고정한 주행 목록을 전부 처리한다. 처리량 때문에 표본화가 필요하면 성능을 보기 전 시간기반 규칙을 명시하고, 표본화한 결과를 전프레임 결측 길이라고 부르지 않는다.
자료가 많아 새 예산이 필요한 경우에만 항목별 범위 확인을 받는다.

9.3 시간·참조:
CSV와 영상 시각은 촬영 로그/clock 정보로 맞춘다. 오차가 작아지는 offset을 결과에서 탐색하지 않는다.
운용 모델의 출력은 별도 추정, 제어 명령은 명령, 독립 계측만 정확도 참조로 구분한다.
정지 구간은 원영상·운용 기록으로 확인한다. 카메라가 움직이는 전 구간의 표준편차를 낮추는 것을 성능 목표로 삼지 않는다.
새 pose 출력과 이전 값 유지/결측을 분리한다. 팔레트가 실제 시야 밖인 구간과 시야 안 실패를 나누고 전체시간도 남긴다.
독립 top-view/거리계 참조가 실제 raw/calibration/동기화와 함께 있다면 그 검증된 범위만 평가한다. 별도 논문의 집계 수치나 시뮬레이션 곡선을 참조로 복사하지 않는다.

9.4 보고:
영상/프레임 수, 새 자세 산출률, 최장 연속 결측초, 정지 구간 전방·횡방향·방향각 변동을 비교한다.
직접 가시 코너 참조가 있는 프레임은2D median/P90/PCK를 평가한다. 없으면 수동 검수 대상 목록만 만들고 정확도는x다.
방향각 평균·변동은 각도 wrap을 처리한 기존 규약을 사용한다. 대칭 대표가 바뀌는 현상과 실제 회전을 구분하고 임의 smoothing으로 감추지 않는다.
독립 참조가 있으면 거리·방향 오차, 없으면 정확도x와 관찰 범위만 보고한다.
이 사례는 오프라인 연속 추정이다. 포크 삽입 성공률, 실제 정렬시간 향상, 더 좋은 차량 궤적을 주장하지 않는다.

## 10. 통계·비용·그림 생성

10.1 모든 평가에서 데이터 집단, GT 버전, 프레임/코너 ID, 평가 단위, 지표·집계·분모, 입력 정보, 학습량, tuning·선택 규칙을 함께 저장한다.
주 코너지표: 조건부 median/P90, 전체분모 PCK5/10/20, Esym, 실패·매칭 수. 원고의 주 지표는 그대로 유지한다.
자세지표: 이동/회전/yaw median·P90, IoU3D, 전체분모 ADDsym AUC, 자세 산출률. 단위cm/degree를 명시한다.
ADDsym은 승인 전체회전 아래 대응 cuboid8코너 거리이며 자유 최근접 ADD-S로 바꾸지 않는다. 기존0–0.1 객체대각선 정규화/1001임계 평가함수와 원시 unit을 검증한다.
전체 P90을 집단별 P90의 가중평균으로 만들지 않는다. PCK는 정답/전체 수를 함께 보존한다.
각 seed에서 계산한 통계의 평균을 쓰고 seed별 값도 내라. count를 평균낸 소수만 보고 실제 건수로 오인시키지 마라.
미실험은 수치파일에서 null+상태/이유로 관리하고, 논문표에만x를 쓴다. 실제0은0이고, 정의불가/표본0은NA로 구분한다.

10.2 paired 불확실성:
기존10,000회 세션 재표본 규약과 seed20260917을 재사용한다. 어떤 estimand의 구간인지 적는다.
중앙값 차이를 말할 때 Esym 평균 차이의 신뢰구간을 붙이지 않는다. 각 재표본에서 대상 통계를 실제로 다시 계산한다.
프레임을 독립 표본처럼 bootstrap하여 같은촬영 상관을 무시하지 않는다. 세션이 부족하면 불확실성 한계를 명시한다.
과거 개발 선택과 다중 비교를 보정하지 않은 기술통계임을 밝힌다. 새 임의 합격선이나 개선율을 만들지 않는다.

10.3 runtime:
기존 RUNTIME_PROTOCOL의 고정26장/20warmup/5repeat/seed1과 thread·동기화·측정 시작/끝 정의를 읽어 계승한다.
동일 장비에서 각 기반의 보정 없음/N3를 나란히 계측한다. 필요한 비교기 비용도 기존 측정이 호환되면 재사용한다.
캐시된 특징만 읽는 추론을 end-to-end라고 하지 않는다. image-in-RAM→preprocess→base→refiner→PnP 전체와 refiner구간을 구분한다.
GPU 비동기 동기화, batch·정밀도·I/O 포함 여부·메모리 계측범위를 기록한다.
기존 YOLO11.408/15.350ms는 과거 측정으로 보존한다. 장비가 다르면 같은 장비에서 YOLO도 재측정해 별도 표를 만들고 과거 수치를 덮어쓰지 않는다.
학습과 runtime 계측을 같은GPU에서 동시에 실행하지 않는다. Jetson에서 실제로 재지 않은 수치를 Jetson결과로 적지 않는다.

10.4 그림:
실제 원본영상/예측/참조에서만 생성한다. 새로운 image generation이나 합성 오류곡선을 결과에 넣지 않는다.
유형·가림별 전후 확대오버레이, 전체분모 오차임계 정확도곡선, paired 2D/3D변화, 실제 주행거리·방향시계열을 만든다.
개선/무차이/악화·결측 사례를 모두 포함하고 예시 선정 규칙과 seed를 사전에 기록한다. 결과로 선택한 극단 예시는 대표성 주장 없이 그 사실을 표시한다.
정량 결과와 figure의 파일ID·원시좌표·단위가 일치해야 한다. GT는 평가용임을 표시하고 prediction이 GT로 재선택되지 않게 한다.
논문 그림의 축·범례는 영어/단위로 통일하고 보고서는 한국어로 작성한다. 실제 결과가 없는 패널은x로 유지한다.

## 11. 산출물·실행 지속성·완료 판정

최소 orchestrator를 구현하되 불필요한 새 프레임워크는 만들지 않는다.
새 run entrypoint에는 상태 감사, 데이터 준비, 기술시험, 학습, calibration, 평가, 표·그림, verify 단계와 재시작을 지원하라.
아직 없는 커맨드를 이미 실행 가능한 것처럼 문서에만 써놓지 마라. 실제 --help, 최소시험, 실제 실행 로그로 검증한 명령만 최종 보고한다.
각 stage의 input hash·code hash·config hash·output hash를 저장하고 기존 완료 receipt가 모두 일치할 때만 건너뛴다.
장시간 작업은 실제 세션/tmux 등 기존 방식으로 시작하고 PID/로그/현재 step/재개 명령을 기록한다. '돌리고 있다'고만 말하지 않는다.
중단 후에는 같은 checkpoint/optimizer/RNG에서 이어가고, step0부터 몰래 다시 돌리지 않는다.

[신규 산출물 이름 제안 — 기존 파일이라고 가정하지 말 것]
- RUN_MANIFEST.json: 환경·HEAD·프로토콜·원본/모델 hash·승인 범위·실행 상태.
- TASK_MATRIX.md: v3의 각x, 실제 상태, REUSE/RESCORE/INFER/TRAIN/보류, 실행명령, 출력 위치.
- INPUT_AND_EXPOSURE_AUDIT.md: dataset/annotation/geometry/session/teacher·student 노출 대응.
- METHOD_PARITY.md: 세 기반의 N3 입력·감독·좌표·학습·PnP 일치 표.
- TEST_RESULTS.json: 기술시험, 실패원인, 무결성 판정.
- TRAINING_RECEIPTS/: 실제 fit별 step·seed·노출·checkpoint·시간·학습층.
- FRAME_METRICS.csv, CORNER_METRICS.csv: 읽은 기존 스키마와 대응을 명시한 새 정규화 결과.
- TABLES.json / TABLES.md / table_fragments/: v3에 넣을 검증된 값과x/NA.
- figures/: 실측 결과 그림·원영상 오버레이·선정 manifest.
- REMAINING_X.md: 미완료 항목, 정확한 이유, 최소 필요한 파일/판단.
- FINAL_REPORT_KO.md: 무엇을 실행했고 무엇이 개선/무차이/악화였는지, 공정성·한계·다음 판단.
- VERIFY_RESULTS.json: 원시 예측→지표→표→그림 검산과 구버전 보호 확인.
하나의 기존 산출물이 같은 목적을 만족하면 중복 파일을 억지로 만들지 말고 대응을 명시한다.

완료 상태와 성능 판정은 분리한다.
실험 완료/평가 완료/검증 완료는 실행의 사실이다. 개선/무차이/악화는 관찰된 결과다.
코드만 완성, smoke만 통과, 학습만 완료, 결과가 다른 분모인 상태를 '논문 실험 완료'로 쓰지 않는다.
필요 전제가 통과하지 못한 것은 해당 작업만 BLOCKED로 두고 의존하지 않는 작업은 계속한다.
검증된x만 수치로 바꾼다. 모든 항목을 처리하기 전 OVERALL_COMPLETE를 선언하지 말고 PARTIAL과 남은x를 보고한다.

git 처리는 원래 사용자 변경을 보존하고 이번 관련 파일만 검토한다.
원본영상/주석/대형checkpoint/자격증명은 commit하지 않는다. 필요시 코드·작은집계·검증문서의 로컬 커밋을 만들되, 이번 지시만으로 외부push/PR/공개를 새로 승인받았다고 해석하지 않는다.
기존에 별도 명시된 게시 승인이 있다면 그 범위만 따른다.
