## 상담 반영 중 그대로 유지한 것

산업적 중요성부터 시작하는 초록·서론, 문제 제기 뒤 방법·대상 범위의 순서, 기본 추정기별 보정 전후의 질문, 실제 보정 효과와 손상 분석, 학습하는 방법에 learning-free를 쓰지 않는 원칙을 유지했다. “모든 기존 방법은 구조를 안 쓴다”, “자기학습은 과적합 때문에 실패했다”, “같은 가중치로 모든 백본에 적용된다”를 확인된 사실로 쓰지 않았다.

리프터 사례는 사용자가 이후 고정한 동일 원영상의 오프라인 연속 추정 비교이다. 별도 RGB-D 정렬/단안 정렬·시뮬레이션 원고의 성공률·제어 시간·궤적 수치를 보정 성과에 사용하지 않았다.

## x를 유지한 항목

- 새 정사각형 R0/P/N2/N3 평가, 유형별·가림별·가시성별 재집계.
- 동일 8코너 규약의 N0/N1 값, D/L/PoseFix 값, 대표 업데이트 대안의 값.
- DOPE·ResNet-18의 N3 학습·평가 완료, 실제 비용.
- 이동 범위·손상/복구·2D 대 3D 변화 분해, 기록 주행 영상의 결과.

x는 해당 비교의 미실험·미집계·미확인이며 0·실패·데이터 부재가 아니다. 원고에 틀을 마련한 것이 실험을 수행한 것은 아니다.

## 새로 확인한 외부 원문

PoseFix: Model-Agnostic General Human Pose Refinement Network(2019/CVPR)의 공식 초록에서 내부 코드/특징 없이 초기 자세와 이미지로 보정하는 범위를 재확인했다. Integral Human Pose Regression(2018/ECCV), Self6D(2020/ECCV), Deep Object Pose Estimation(2018/CoRL)의 공식 서지를 재확인했다. 이 네 원문의 결과를 현재 팔레트 데이터의 성능으로 사용하지 않았다. 나머지 42편 목록은 기존 reference lock을 계승했으며 모두 이번 개정에서 새로 전문 열람했다고 주장하지 않는다.
