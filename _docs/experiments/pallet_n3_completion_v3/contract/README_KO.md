# CLI 전달 패키지

`EXECUTE_PALLET_N3_V3_KO.txt`가 실행 지시문이다. 대상은 로컬 `pallet-6d-pose` 저장소다.

이 패키지는 실험 코드나 결과가 아니라 실행 계약과 원고 근거다. `source_context`에는 기존 v3 Markdown·수정 기록·수치 출처·코드 계약을 넣었다. 논문 PDF와 대형 원자료/가중치는 포함하지 않았다.

CLI에 이 디렉터리를 전달하고 실행 지시문을 처음부터 읽게 하면 된다. 저장소의 실제 데이터 경로와 현재 프로세스는 CLI가 먼저 확인한다. 구현·학습·재집계·검증을 수행하되, 미확정 항목은 해당 작업만 보류한다. 새 PDF·외부 게시·리프터 제어는 수행하지 않는다.
