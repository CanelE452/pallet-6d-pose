# 학습 입력 검증

2026-09-19, 모델 평가 결과를 열기 전에 실행한 읽기 전용 검사.

- 최초 R0 예측 1,000장 중 272장이 1차 필터 통과.
- 272장의 2차 검사 기록이 정확히 존재하며, 최종 259장은 그 부분집합.
- 최종 259개 캐시 전부 `GT_input=False`; 원본 target은 R0 입력 좌표와 동일.
- 모든 pseudo target은 gradient가 없는 고정 텐서.
- 보정 전후 centroid는 bit-exact하게 동일.
- 259개 전체에서 `보정 input 좌표 − 원본 input 좌표`가
  `원본 해상도 보정량 × letterbox gain(640/840)`과 5e-5 이내 일치.
- 최종 보정량(8코너 pooled): median 1.7891 px, P90 4.5830 px,
  최대 8.00003 px (기존 800 px 이미지 대각선의 1% cap, float 반올림 포함).
- 평가 이미지 SHA와 학습 후보의 중복 0. 촬영 recording alias/부분 중첩도
  STAGE1 생성 시 배제. 초록 촬영 데이터는 적응 풀에 포함되지 않음.

이 검사는 입력/좌표계/분리 계약 검증이지, pseudo-label 정확도의 GT 검증은 아니다.
