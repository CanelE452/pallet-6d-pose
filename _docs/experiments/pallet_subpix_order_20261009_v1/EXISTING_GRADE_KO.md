손상은 저장된 대칭 분기 뒤의 동일 canonical identity를 맞췄다. PCK/gross는 전체 참조 분모, 코너 평균/분산은 조건부 관측 코너 풀링이다. 실제 최종 가설 전환/유지별 오차 변화와 T/R 모두 감소·반대·모두 증가 수는 모든 비교/등급의 JSON에 보존했다. 이 분석으로 등급별 새 적용 게이트나 프레임별 GT oracle 혼합을 만들지 않는다.
