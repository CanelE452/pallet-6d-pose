# 동일 PRIMARY192 공정 비교

두 PoseFix+SubPix 고정 경로를 모두 PRIMARY192에 확장했다. **E0=114/192, PF-anchor=112/192, YOLO-anchor=111/192**다. E0가 두 설정보다 각각 2장·3장 많지만 위치·회전 평균과 여러 꼬리 지표는 더 나쁘다. 성공률 차이의 군집 bootstrap 구간은 0을 포함하므로 통계적 우월성이나 동등성을 주장하지 않는다.

두 경로는 사전에 고정된 민감도 비교다. 결과를 보고 단일 대표 설정을 고르지 않았으며 `TWO_FIXED_COMPARATORS_NO_GLOBAL_WINNER`를 유지한다. 숫자상 높은 비교군과의 관측 격차는 **2장, 1.0417%p**다.

## 계약과 재현

- 동일 영상 CAL46 + TEST49 + REMAINDER143 중 PRIMARY192는 TEST49+REMAINDER143이다. CAL46은 별도이며 교정에 이미 사용된 자료다.
- 성공은 동일한 하나의 최종 자세에서 중심 위치 ≤5cm AND 물리 회전 ≤5°다. C2의 I/Y(180°)만 허용하고 직사각형의 90° W/D 전환은 허용하지 않는다.
- 미산출은 성공 분모에서 실패로 유지한다. 연속 오차는 가용 자세만 집계하며 분모·결측을 별도 표기한다. 이번 여섯 경로는 모두 238장 자세가 가용하다.
- PF RAW는 synthetic-only PRIOR1 seed1 last6000의 첫 uncapped 저장 출력이다. PF-anchor는 SubPix 이동만 PF 출력 기준 대각선1%로 제한한다. YOLO-anchor는 PF+SubPix 총 이동을 원 YOLO 기준 대각선1%로 제한한다.
- 기존 F의 W/D 선택·SQPnP·RefineLM 및 창5×5/zeroZone(-1,-1)/40회/epsilon .001을 그대로 사용했다. 새로운 NN forward·학습은0이다.
- 원95장 475개 점 배열과 475개 전체 자세 사전이 원 봉인 결과와 정확히 일치(max abs=0)했다. 별도 후채점에서 PF RAW66, PF-anchor71, YOLO-anchor70, N074, E086 /95를 실제 재현했다.
- 원 baseline952개 metric의 독립 재계산 최대 차이는 위치2.84e-14cm, 회전0°였다. E0/N0 교차89/25/19/59 hard gate를 통과했다.

참조는 기존 기하 재구성 자세이며 독립 물리 GT가 아니다. 모든 실사는 이미 개발에 노출된 탐색적 집합이다. 245장 원고·110장·다른 seed의 수치로 누락을 채우지 않았다.

## 실행 경계와 기술적 수정

정확도 계산기는 predictor와 별도 프로세스다. 새 PF predictor는 참조·성공 후보·오라클을 읽지 않고 점과 자세를 봉인했다. evaluator는 새 예측 seal을 확인한 다음 기존 참조를 해독한다. 원143 cache의 나열 순서가 두 계보에서 달라 처음의 순서 동일성 gate가 조기에 중단됐다. 두 ID 집합은 정확히 같으므로 immutable ID join만 고쳤다. 점·자세·공식·bootstrap·분모는 바꾸지 않았고 두 protocol lock과 실패 기록을 [기술 receipt](EVALUATOR_TECHNICAL_ATTEMPTS.json)에 보존했다.

Baseline 재집계0.139초, 공통 최종 평가 0.492초. 평가 최대 RSS 1055.1MiB(프로세스 high-water)였다. PF 실행 비용은 별도 predictor seal을 참조한다. 평가 Python 3.10.20, NumPy 1.26.4이며 BLAS thread=1이다.

검사4개는 C2 반회전/직사각형90° 비동등, 미산출 실패와 무보간, 같은 pose의 공동5cm5° 경계, 원 군집 프레임 가중 재표집을 확인했다. 독립 최종 수치 재집계는 별도 검산 receipt로 확인한다.

E0의 수정안 및 채택 여부는 [최종 보고서](REPORT_KO.md)의 메커니즘 감사와 단일 opt-in 결과를 함께 읽는다. 이 비교만으로 새로운 보정법이 최강 비교군을 안정적으로 이겼다고 주장하지 않는다.
