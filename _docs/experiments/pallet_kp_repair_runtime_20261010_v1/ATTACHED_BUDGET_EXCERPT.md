## 12. 실제 시간·자원·실행량

- 합성 생성 wall time45분 상한. 환경 설치·새 메쉬 제작 범위 밖.
- CPU 강건 자세·통계 실행은 먼저26장 계측; 본실험 wall time60분 상한. 초과하면 가능한 독립 블록부터 완료하고 미완료를 정확히 기록한다. 큰 문제를 무한 실행하지 않는다.
- 추론 특징 cache 생성은 별도 GPU 시간으로 기록한다. 학습60분만 전체 GPU 비용이라고 쓰지 않는다. 캐시 준비는20분의 첫 한도로 잠근다.
- 새 로컬 cache20GiB를 시작 상한으로 두고, 필요 이상 복제/대형 생성 금지. 원영상·체크포인트를 공개 git에 추가하지 않는다.

첫 소스 preflight100step으로 속도/메모리 확인한다. 학습량을 세 모델에 동일하게 줄여야 할 경우 실사 점수 전 공통 예산 변경안을 기록·보고한다. 한 모델만 더 학습하거나 먼저 좋아진 checkpoint를 고르는 것은 금지한다. 추가 비용이 필요하면 해당 블록만 멈추고 이미 완료한 것부터 게시한다.

시간 측정은 최종 최대4경로:
- Base
- 기존 N3→SubPix(5)
- 주 비교의 비학습 GEOM_NOSELF_ROBUST
- 사전 지정 IMAGE_ROLE 전체 경로(point-only)

동일26장/13세션, 준비20회+26장×5회=경로당150회, 최대600전체실행.
RAM 영상→고정 detector1회→특징/관측 선택→초기 가림용 자세→강건 최종 자세→재투영까지 실제 wall time 측정. 초기·후단 PnP와 다중가설 비용 포함. 캐시재생 시간을 전체추론시간으로 쓰지 않는다. 모델 로딩/파일decode/GT채점은 제외 여부를 명시한다. GPU동기화·CPU스레드·버전·열상태를 저장하고 다른 마감벤치마크와 겹치지 않는다.
