# 경계선과 native 키포인트의 잘못된 연결: 후속 진단

2026-10-15 후속 기록이다. [최초 공개 보고서와 전체 스냅샷](../publication_20261015_v1/PUBLICATION_COMPLETE_KO.md)은 보존했다. 최초 스냅샷 이후 CAL 관측을 46장까지 완료했고, TEST49와 추가143장을 합친 전체 238장의 관측도 완료했다. 기존 v29의 전체 자세 예측과 새 v30의 CAL46 선택 검증은 진행 중이다. 이 문서는 전체 자세 오차 개선이나 목표 달성을 보고하는 결과가 아니다.

## 왜 실제 경계를 찾고도 잘못된 선을 썼는가

큰 잔차가 났던 세 CAL 사례에서는 실제 파렛트 경계선을 검출했지만, 그 선을 다른 native 변에 연결했다. 기존 43px 탐색 폭은 모델이 예측한 선 주변에 적용됐다. 원래 보이는 B/I 키포인트와 실제 검출선 사이의 거리를 모든 단독 선에서 검사하지 않아, 원래 점에서 법선 방향으로 최대 667px 떨어진 선도 후보가 될 수 있었다. 두 선이 만나는 교점에는 점 변위 검사가 있었지만, 단독 선에는 같은 대응 검사가 없었다. [실제 사진과 원인 진단](../nonsevere_v1/statewise_joint_ot_20261014_v2/nonsevere_v4_fix/boundary_recovery_v1/CAL_geometry_guided_noise_diagnosis_summary_v4_29/REPORT_KO.md)에 원 자료를 연결했다.

타깃 마스크는 검출선이 파렛트와 배경 사이에 있는지 확인하는 데 쓰인다. 그러나 그 선이 파렛트의 어느 native 변인지는 마스크만으로 확정되지 않는다. 별도의 외부 가림 물체 마스크도 현재 자료에는 없다. 타깃 마스크가 비었다는 이유만으로 외부 가림을 확정하지 않는다.

두 폭·깊이 모델 사이의 가이드 변환도 확인했다. 같은 물리 상자 자세를 유지하는 변환과, 같은 native 번호의 영상 방향을 유지하는 변환은 서로 달랐다. 세 사례 모두 12개 변 중 8개의 3D 카메라 방향이 90° 달라졌다. [모델 좌표계 진단](../nonsevere_v1/statewise_joint_ot_20261014_v2/nonsevere_v4_fix/boundary_recovery_v1/CAL_native_guide_transport_diagnosis_v4_29/REPORT_KO.md)을 남겼다. 현재 비교용 v29와 아래 v30에서는 이 가이드 변환을 변경하지 않았다.

## 새 대응 검사

같은 native 변에 속하는 **원래 관측된 B/I 양끝점 각각**과 실제 TLS 무한 직선 사이의 법선 거리를 확인한다. 원래 설정의 43px 범위 안에 있는 후보만 기존 그래프 순위 계산에 넘긴다. 양끝이 모두 B/I이면 둘 다 검사한다.

선 방향 이동에는 별도의 거리 제한을 추가하지 않았다. 기존에 필요했던 약 19px 보정도 허용한다. S는 영상 선이나 점 관측으로 사용하지 않고 PnP와 모델 투영으로만 처리한다. U는 대략적인 영역 정보만 쓰며 정밀 좌표를 읽지 않는다. 원래 RGB 후보·마스크·키포인트 좌표·공분산·상태·모델 크기와 자세 계산 수식은 보존한다.

## 전체 평가에서 확인할 사항

새 검사는 선택되는 선의 모집단을 바꾸므로 기존 v29의 노이즈 보정값을 그대로 사용하지 않는다. CAL46 전체의 새 선택을 먼저 고정한 뒤, 정책별 선 오차와 선 방향 잔차의 보정값을 따로 맞춘다. 이후 동일한 방법을 전체 238장에 적용하고 CAL46과 주 평가192장을 분리해 비교한다. severe는 0장이다.

기준 방법과 네 가지 비교군의 전체 예측을 고정한 뒤, 독립 계산 검사와 기존 기준에 따른 위치·회전·5cm/5° 성공률을 확인한다. 일부 성공 사례나 원래 49장만으로 방법을 채택하지 않는다. 기본 방법은 `SAME_FROZEN_E`로 유지한다. 기존 데이터를 반복 사용하는 탐색 실험이며 새 독립 평가셋 결과로 표현하지 않는다.

최초 Release의 스냅샷 시점은 CAL32/46이었다. 이 후속 문서와 사진은 그 이후의 결과다. 최초 압축본에 후속 전체 원시 관측이 포함됐다고 해석하면 안 된다. 현재 main에는 후속 보고서·사진·소스를 추가하며, 진행 중인 예측과 임시 파일은 완료 결과로 게시하지 않는다.
