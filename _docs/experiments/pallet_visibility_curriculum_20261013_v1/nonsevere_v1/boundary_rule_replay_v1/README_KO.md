# 경계점 개수 규칙을 두 기존 추정기에 붙인 비교

초기 자세에서 외곽으로 예상되고, RGB 파렛트 지지와 실제 두 경계선이 확인된 점만 사용한다. 단순히 초기 기하학에서 외곽으로 분류된 점의 개수가 아니다. 다른 물체를 확인하는 별도 instance/depth 입력은 이 비교에 없으며, RGB 지지가 낮은 점은 `UNKNOWN_OR_OCCLUSION`으로 남는다.

규칙과 임계값은 CAL 단계에서 고정했다. 5개 이상과 4개는 자세 전체를 보정하되, 4개는 고정된 다중 시작점으로 모호성을 검사한다. 3개는 초기 회전을 그대로 유지하고 이동만 보정한다. 2개 이하는 초기 자세와 좌표를 그대로 반환한다. 모든 분기에서 점 배치, 수치 조건, 이동 한계와 관측 목적함수 개선을 확인하며, 조건 실패 시 초기 결과로 돌아간다. 사용하지 않은 모서리의 투영은 출력 완성용이며, 자세를 맞추는 관측으로 다시 사용하지 않는다.

`prepare`에서 코드·설정·입력·모델 해시를 고정했고, `infer`는 정답 접근 금지 canary 아래 343개 예측과 98개 관측을 저장한 후 봉인했다. N3+Sub의 기존 TEST49 관측 49개는 재사용했고, PoseFix+Sub 좌표와 자체 초기 자세에서 RGB/Tiny/MobileSAM 관측을 49회 새로 계산했다. `score`는 봉인 이후 격리된 TEST49 정답으로만 평가했다. 새로운 학습, severe, FINAL 평가 사용은 0이다.

PoseFix+Sub는 별도의 PRIOR1 PoseFix 출력에 고정 OpenCV SubPix를 붙여 이번에 재계산한 조합이다. SubPix의 1% 이동 제한은 호출한 PoseFix 좌표를 기준으로 잡았으며, TEST 결과를 보고 제한 기준을 선택하지 않았다. 원래 YOLO 좌표를 기준으로 제한한 변형도 별도 `posefix_sub_comparison_v1`에서 함께 보고한다. N3+Sub를 PoseFix+Sub로 부르지 않는다.

| TEST49 방법 | 평균 이동 오차 cm | 평균 회전 오차 deg | 5cm·5deg 성공 | 보정 수락 |
|---|---:|---:|---:|---:|
| N3+Sub 초기 | 3.3630 | 6.5271 | 40/49 | 0 |
| N3+Sub + RAW 개수 규칙 | 3.3354 | 6.5659 | 40/49 | 19 |
| N3+Sub + FUSED 개수 규칙 | 3.0655 | 6.4980 | 40/49 | 19 |
| PoseFix+Sub 초기 | 3.2161 | 6.3495 | 39/49 | 0 |
| PoseFix+Sub + RAW 개수 규칙 | 3.2477 | 6.3638 | 40/49 | 19 |
| PoseFix+Sub + FUSED 개수 규칙 | 2.7970 | 6.3166 | 42/49 | 19 |
| 기존 N3 FUSED 진행 보정 | 3.0040 | 6.5243 | 43/49 | 47 |

각 개수 규칙은 3점 이동 보정 7장, 4점 전체 보정 3장, 5개 이상 전체 보정 9장을 수락했다. 나머지 30장은 확인된 경계점이 2개 이하여서 정확히 초기 결과를 유지했다. 두 초기 추정기의 개수 분포는 각각 0:7, 1:18, 2:5, 3:7, 4:3, 5:8, 6:1이다.

PoseFix+Sub + FUSED 규칙은 자체 초기 대비 성공 3장을 회복하고 성공 손실은 0장이었다. 평균 이동 차이는 −0.4190cm이며, 4개 촬영 세션을 묶은 10,000회 paired bootstrap의 95% 구간은 [−1.5511, +0.0098]cm이다. 회전 차이 −0.0330deg의 구간도 0을 포함한다. 따라서 관측된 개선을 보편적인 우위로 해석하지 않는다. N3 FUSED 개수 규칙은 기존 N3 진행 보정의 성공 3장을 놓쳤다. RAW 규칙도 평균 오차를 항상 줄이지 않았다.

TEST49는 이전 연구에서 이미 관측된 사진이다. 이번 비교는 고정 규칙의 재사용 비교이며 새로운 독립 검증이 아니다. 점 수나 좌표 방식, 초기 추정기를 TEST 정답에 따라 사진별로 선택하는 규칙은 만들지 않았다. 기존 기본 모델은 변경하지 않았고 개수 보정기는 별도 API와 설정으로 제공한다.

실제 RGB CLI 검사 `cli_smoke.py`는 정답 없이 봉인된 CAL 예측에서 첫 3점 수락 사례를 골랐다. 실제 모델을 다시 실행한 `EXAMPLE_OUTPUT.json`은 초기 두 회전 행렬을 정확히 보존하고 이동만 변경하며, 남은 5개 모서리를 출력 투영으로 완성한다. 전체 CAL API 일치와 독립 TEST 검사는 별도 검증 파일을 참조한다.

재현 순서는 `replay.py prepare`, `replay.py infer`, `replay.py score`다. 결과 덮어쓰기를 거부하므로 이미 완료된 폴더를 직접 재실행하지 말고 입력 데이터가 있는 별도 복사본에서 실행한다. 해시가 기록된 코드와 모델이 필요하며, 원본 RGB는 Git에 포함하지 않는다.
