# W/D 대응 관계의 학습·예측 계약 감사

현재 코너 채널은 **카메라 기준 채널**입니다. 실제 60,000개 학습 3D 대응표에서 native 0→1은 물리 X축 28,070개, 물리 Z축 31,930개이며 0→3은 모두 높이 Y축입니다. 알려진 고정 XYZ 치수를 N3 문맥 입력에 넣은 수정은 이 채널 순서를 바꾸지 않았습니다.

실제 입력의 Q는 예측 코너로 두 PnP W/D 가설을 비교한 뒤 저장한 결과입니다. 독립적인 W/D 관측 정답이 아닙니다. 원본 CAL46은 I/Ry90=33/13, TEST49는 24/25, 추가143은 76/67이며 다른 Q는 없습니다. 따라서 전역 규칙 하나로 native 0→1을 항상 물리 X라고 고정할 근거가 없습니다. 반대로 이 사실이 현재 모든 대체 W/D 후보의 영상 의미를 인증하지도 않습니다. 신뢰할 영상 대응 정보가 필요합니다.

기존 native/reference 불일치 표시 TEST7·CAL2는 그대로 보존합니다. 이를 실행 시 W/D 정답으로 쓰거나 평가에서 빼지 않았습니다. 학습표의 음수 tripod 방향 36개도 별도 예외로 기록했으며 실제 실패의 원인이라고 단정하지 않습니다.

[SOURCE_AUDIT_V1.json](SOURCE_AUDIT_V1.json)에 소스 행, 실제 표 집계와 해시가 있습니다. 현재 원본 PROBE_METADATA_60K.jsonl은 없으므로 현존 NPZ 및 기존 감사표를 사용했습니다. 새 추론·PnP·학습은 실행하지 않았습니다. 이 감사는 등록된 크기·코너 계약을 확인하며 실제 영상의 물리 축이나 사후 참조 자세를 새로운 정답으로 확정하지 않습니다.

[실제 학습 두 예시 PNG](training_examples/TRAINING_CHANNEL_PROOF.png)와 [원 3D/2D 대응 JSON](training_examples/TRAINING_EXAMPLES.json)은 기존 학습 RGB/라벨/표를 연결합니다. 첫 legible X/Z 예시를 고른 시각화이며 새 추론 결과가 아닙니다.

[CACHED_PHASE_CUE_INVENTORY_V1.json](CACHED_PHASE_CUE_INVENTORY_V1.json): 238장 모두 고정 YOLO P3/P4 특징 캐시와 이미지 키/해시가 확인됐습니다. N3의 8×222 로짓은 코너별 이동/유보 후보이며 W/D 분류 확률이 아닙니다. 이 특징으로 향후 고정 backbone 위의 작은 분류기 검토는 가능하지만 학습·성능 검증은 하지 않았습니다.

[POSTSEAL_BANK_AND_WD_DIAGNOSTIC_V1.json](POSTSEAL_BANK_AND_WD_DIAGNOSTIC_V1.json): 기존 전체238 후보 51,539개 중 실제 평가192장 부분은 39,783개입니다. 참조 위치를 진단용으로만 사용한 후보집합의 5cm 이하 도달 가능 수는 TEST49/49, 추가143 중119장입니다. 추가20장은 비어 있지 않은 후보집합의 최선도 5cm를 넘고 4장은 후보가 없습니다. NMS의 새 제약을 통과한 후보집합도 같은 119장입니다. 빈 후보집합을 빼지 않았고 fallback 오차는 별도로 기록했습니다. 비어 있지 않은 집합의 최악 최소오차는 41.1847cm이며 빈 집합을 포함한 전체 최대는 Infinity입니다. 이는 오라클 진단이며 실행 시 정답 기반 선택에 사용하지 않습니다.

[FRESH_FEASIBLE_WD_AMBIGUITY_V1.json](FRESH_FEASIBLE_WD_AMBIGUITY_V1.json): 실제 제약을 통과한 두 W/D 후보가 각각 보관된 B/I 좌표 RMS 3px 이하이고 위치가 서로 5cm 넘게 다른 사진은 44/192장입니다. B/I가 4점 이상인 사진만 보면 29장입니다. 2/3/6px는 설명용 민감도 수치이며 선택된 실행 임계값이나 확률 보장이 아닙니다. 일부 보관 좌표는 partial 처리로 최종 2D likelihood에서 제거됐으므로 정확한 점 관측이라고 재해석하지 않습니다. 후보가 없다는 사실도 전역 유일성을 증명하지 않습니다.
