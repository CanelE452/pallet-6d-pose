# 실제 S/B/I/O/T 처리와 공동 PnP

등록 모서리 `X[0:8]`, 파렛트 치수, 원 이미지 카메라 K, backbone의 원 native KP와 초기 PnP를 입력한다. 초기 자세의 면 가시성이 S를, 투영 외곽선이 B/I 역할을 정한다. 초기 기하가 잘못되면 이 분류도 틀릴 수 있다. S의 원 예측은 이후 마스크 프롬프트·상태 특징·보정·영역·점 대응에서 제거한다.

| 기호 | 논문용 이름 | 사용하는 정보 |
|---|---|---|
| S | Self-occluded keypoint | 등록 모델과 최종 PnP만 사용한다. |
| B | Visible boundary keypoint | 현재 파렛트/배경 경계선의 교점을 관측한다. |
| I | Visible interior keypoint | 현재 파렛트 내부 RGB 선의 교점을 관측한다. |
| O | Externally occluded keypoint | 현재 영상에 따른 외부 가림 판정과 거친 위치 영역을 사용한다. |
| T | Truncated keypoint | 화면 밖이라는 공간 제약을 사용하고 근거 출처를 기록한다. |

U는 판정 보류 상태로 구현하며 논문의 여섯 번째 물리 상태로 제안하지 않는다. 화면 밖 detector 좌표만으로 T를 확정하지 않는다. 초기 투영의 T는 조건부이며 방향을 확정하지 않아 네 화면 밖 방향의 합집합을 검색한다. 독립적으로 알려진 T 방향은 해당 반평면을 사용한다. 현재 데이터에는 자연 T 주석이 없으며 조건부 T를 독립 실측으로 표현하지 않는다.

선택한 상태 판정기는 비-S의 실제 RGB26, 초기 기하에 따른 안쪽·바깥쪽 재질 지지와 선 연결 24개 특징, 동결 ImageNet ResNet18 공간 특징 2560개를 사용한다. 원 query와 초기 투영의 비-S 주변 RGB를 확인하되 초기 투영은 좌표 관측값이 아니다. 학습 목표는 사람의 DIRECT/EXTERNAL 분류이며 좌표 오차에 따른 usable 라벨과 섞지 않는다. CLEAN/MODERATE CAL46의 eligible DIRECT263/O7로 학습하고 CAL 세션 교차검증에서 family와 threshold를 선택했다. 표본과 세션 수가 작으므로 이 점수를 일반 성능 보장으로 해석하지 않는다.

B는 target mask의 안쪽 foreground·바깥쪽 background 전이를 두 방향에서 관측한다. I는 registered incident 방향을 따라 RGB gradient 선을 관측한다. 둘 다 실제 픽셀에서 robust line fit과 교차점을 만들고, 선 재표본 공분산에 따라 원 KP와 제한적으로 섞는다. 초기 모델은 탐색 방향만 제공한다. 지원 선이 없거나 교점이 일관되지 않으면 보이는 원 좌표를 유지한다. 둥근 모서리와 격자 구멍 때문에 관측 교점이 등록 3D 코너에 해당하는지는 별도 한계다.

보정된 관측 `q_i`와 공분산 `Σ_i`를 먼저 고정한다. 새 자세는 다음 문제로 구한다.

\[
 \min_{R\in SO(3),t}\sum_{i\in B\cup I}
 2\delta^2\left(\sqrt{1+\|\Sigma_i^{-1/2}
 (\pi_K(RX_i+t)-q_i)\|^2/\delta^2}-1\right)
\]

동시에 **각각**의 제약을 만족해야 한다.

\[
\begin{aligned}
 &\pi_K(RX_j+t)\in\Omega_j &&\forall j\in O\cup T,\\
 &\|\Sigma_i^{-1/2}(\pi_K(RX_i+t)-q_i)\|\le3 &&\forall i\in B\cup I,\\
 &\|\pi_K(RX_i+t)-\pi_K(R_{BI}X_i+t_{BI})\|\le2\;\mathrm{px}
 &&\forall i\in B\cup I,\\
 &(RX_k+t)_z>0 &&\forall k.
\end{aligned}
\]

`(R_BI,t_BI)`는 고정된 B/I만으로 구한 seed다. 두 번째 제약은 가정한 공분산의 3σ 크기이고, 세 번째는 seed 투영에서의 이동 2px다. **관측 오차 자체가 2px 이내라는 뜻이 아니다.** 공분산은 실제 키포인트 정확도의 보정된 확률이 아니다. 관측 자체를 만족하지 못한 seed를 유효한 완성 자세로 승격하지 않는다.

O의 기본 영역은 원 영상 예측 중심의 원이며, 반경은 `max(8px, 비-S query bbox 대각선 × 0.0864559283)`이다. 계수는 실제 CAL O 7개의 정규화 오차 최대값에서 얻었다. 현재 영상에 조건부인 occluder contour나 95% 공동 신뢰영역은 아니다. O query가 없으면 넓은 canvas 영역을 명시한다. T는 O 오차 모델을 재사용하지 않고 화면 밖 반평면을 사용한다. 좌/상 경계는 닫힌 안전 집합 x≤0/y≤0을 사용하므로 경계 자체를 엄격한 물리 T 증명으로 해석하지 않는다.

공동 가능 자세 집합은 `F_BI ∩ F_O0 ∩ F_O3 ∩ F_T5 ...`이다. 올바른 제약을 추가하면 집합이 커질 수 없지만, 이미 만족한 제약은 중복 정보일 수 있고 잘못된 영역은 올바른 자세를 제거할 수 있다. 영역 중심을 가짜 점 대응으로 넣지 않으며, 다른 점의 위반을 평균 벌점으로 상쇄하지 않는다.

보정 B/I의 P3P 모든 triple, SQPNP, 초기 자세와 24개 전역 회전을 시작점으로 사용한 뒤 모든 O/T를 넣어 SE(3) SLSQP를 연속 최적화한다. 3점에서도 회전을 고정하지 않는다. 기존 후보 목록의 점수만 비교하지 않는다. 방향이 불명확한 T 합집합은 최대 256개 조합을 완전히 검사하며, 한도를 넘으면 일부만 적용한 성공을 반환하지 않는다. 분석적 Jacobian은 같은 목적함수와 모든 개별 제약을 미분하며 최종 판정은 원 제약식으로 재검사한다.

최종 readout에서 B/I는 고정된 영상 좌표를 유지하고, 성공한 O/T와 S는 등록 모델의 최종 투영을 제공한다. U는 미해결로 둔다. 혼합 readout은 한 강체 투영과 같지 않으므로 별도의 `rigid_model_corners`를 제공한다. 실패하면 O/T를 미해결로 표시하고 S만 출처가 명시된 유효 B/I seed 또는 초기 PnP의 투영으로 완성한다. 모호한 해가 여러 개 남으면 대안 자세와 rank를 기록한다. 유한 다중 시작점은 전역 유일성·전역 불가능성의 증명이 아니다.
