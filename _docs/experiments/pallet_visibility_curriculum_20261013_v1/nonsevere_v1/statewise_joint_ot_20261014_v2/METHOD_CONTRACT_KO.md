# S/B/I/O/T 정의에 맞춘 새 구현

이 문서는 기존 anchored/region 실험을 새 방법의 검증으로 취급하지 않는다. 이전 구현은 S를 영역 평가에 넣었고, 제한된 기존 자세 후보를 비교했으며, 실제 O/T 공동 제약을 생성·최적화하지 않았다. 이전의 전체 방법 완성 보고를 철회한다.

1. Backbone의 원래 native KP와 초기 PnP 자세, 등록된 파렛트 치수 및 카메라 K를 받는다.
2. 초기 모델의 면 가시성으로 S를 정의한다. S는 RGB 상태 판정, 패치, 마스크 프롬프트, 보정, 영역 생성과 점 대응에서 먼저 제외한다. S의 원래 예측 좌표를 바꿔도 다른 점의 영상 관측값과 영역 폭이 바뀌면 안 된다.
3. 비-S에서 초기 기하로 B(배경 경계)와 I(파렛트 내부) 역할을 구분하고, 실제 영상으로 외부 가림 O를 판정한다. T는 화면 밖이라는 근거와 방향 출처를 기록한다. 초기 자세에 따른 T는 조건부 가설이며, detector 좌표가 화면 밖인 것만으로 T를 확정하지 않는다. 판정 보류 U는 내부 플래그다.
4. 보이는 B는 현재 파렛트/배경 경계선 두 개의 교차점, I는 현재 내부 RGB 선들의 교차점으로 각각 보정한다. 초기 모델은 탐색 방향만 제공한다. 지원 영상 선이 없으면 원래 보이는 좌표를 유지하며 보정 성공으로 세지 않는다.
5. 보정한 B/I의 좌표와 불확실성을 고정한다. 이후 PnP가 그 관측 좌표 자체를 덮어쓰지 않는다. 여러 잡음 관측값을 강체 투영과 정확히 일치시킬 수 없으므로, 관측 readout과 강체 투영 readout을 따로 제공한다.
6. 모든 O/T 영역을 한 번에 교차한다. SE(3)를 연속 최적화하며 각 O/T의 제약을 개별적으로 만족시킨다. 다른 점의 작은 위반으로 보상하는 평균 패널티를 사용하지 않는다. 영역 중심을 가짜 대응점으로 넣지 않는다.
7. O/T 공동 제약에 해가 없거나 관측 지지가 부족하면 해결 실패를 반환한다. 여러 자세가 남으면 모호성을 표시한다. 초기 자세 주변 제한만으로 다른 PnP 분기를 제거하지 않는다.
8. S의 최종 좌표는 최종 PnP 자세의 등록 모델 투영으로만 얻는다. 공동 해결 실패 시 사용하는 B/I seed 또는 초기 PnP fallback은 그 출처를 따로 기록하며 O/T 해결 성공으로 표시하지 않는다.

새 학습과 주 평가에는 CLEAN/MODERATE만 사용한다. 기존 CAL46/TEST49는 재사용 탐색 코호트이며 새로운 미관측 시험이나 SOTA 검증이 아니다. 자연 T 라벨은 없으므로 실제 RGB 자르기 검증은 별도 조건부 연구로 보고한다. CAL의 자연 다중 O 사례는 세 장뿐이다. 정확한 구조 구현과 실제 판정·자세 성능 검증은 서로 다른 완료 조건이다.
