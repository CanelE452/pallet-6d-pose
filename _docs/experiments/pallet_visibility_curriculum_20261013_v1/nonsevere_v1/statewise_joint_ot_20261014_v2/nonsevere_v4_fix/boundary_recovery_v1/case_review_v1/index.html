기존 코드는 원예측점에서 법선 방향으로 ±12px만 탐색했습니다. 오른쪽 세로 경계가 그 범위 밖에 있어 두 점 모두 세로선 표본이 0/15였습니다. 교점을 만들 두 선을 찾지 못해 원좌표를 유지한 것입니다.

오차는 사후 주석과의 2D 거리입니다. 주석 좌표는 보정 입력에 사용하지 않았습니다.

실제 SAM 외곽선까지의 거리와 기존 7px 문맥 여유로 탐색 범위를 계산합니다. 관측한 세로선에 원예측점을 수직으로 옮겨 탐색 기준을 잡고, 위·아래 선을 다시 측정합니다. 영상과 마스크가 함께 지지하는 두 선의 교점을 보정 좌표로 사용합니다.

KP2는 탐색 범위를 넓히기만 해서는 아래쪽 선의 표본이 8/15로 부족했습니다. 관측한 세로선을 기준으로 다시 탐색하니 15/15로 늘었습니다. 기존 선의 방향·표본 수·잔차 검사와 두 점이 공유하는 경계의 일치 검사를 통과한 경우만 보정합니다.

기존에 보정된 KP4·KP7은 그대로 보존했습니다. Self-occlusion 점은 보정에 조회하지 않으며, 최종 위치는 기존 방식대로 PnP를 통해 계산합니다.
