# V30 CAL46 필드 범위 보충

원 frozen 소스/관측/봉인은 수정하지 않았다. `observation.selected_physical_edges`는 원 V29 부모 개수의 상속값이다. 현재 선택은 `selected_chain_refs`, 새 `joint_graph.selected_line_names`, `row.summary.selected_physical_edges`로 읽어야 한다. 세 authoritative 개수와 membership·zero행을 CAL46 전체에서 검산해 실패0이다.

원 top count와 새 count가 같은 행 32개, 다른 행 14개다. 원 top count는46행 모두 부모 summary와 같다. `partial_line_ledger`는 원 raw 전체 partial 후보장부여서 보존이 맞으며 새선택 전용 장부가 아니다.

이 보충은 필드 해석·검증 addendum이며 모델수학 입력이나 새 관측/재순위/라벨/적합이 아니다. AUTH와 CAL metadata/noise는 실제 새 refs/plan을 사용한다. 원 파일/봉인 덮어쓰기0. 자세한46행은 동명의 JSON에 보관했다.
