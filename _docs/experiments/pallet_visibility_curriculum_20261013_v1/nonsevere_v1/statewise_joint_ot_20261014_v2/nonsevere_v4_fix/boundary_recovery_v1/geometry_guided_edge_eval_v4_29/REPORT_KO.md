## 실험과 비교 방법

동일한 CAL46·TEST49·추가143, 총 238장에 다섯 방법을 모두 적용했다. severe는 0장이며 CAL46은 학습·보정용으로 별도 집계했다. 주 평가는 TEST49+추가143의 192장 전체다. 대응 불일치·관측 부족·fallback 사례도 제거하지 않았다.

초기 모델 투영에서 선의 방향과 탐색 범위를 정하고, 보관된 실제 RGB 경계 지지점으로 선 후보를 만든 뒤 그래프에서 대응 후보를 골랐다. 최종 자세는 실제 점·선 관측과 기존 O/S 정규화 항으로 계산했다. `native`는 이 비용을 사용하고, `C`는 관측 전경을 모델 외곽이 포함하도록 하는 단방향 containment 항을 더한다. `전체 B/I`는 지원되는 관측 방향을 새 선으로 대체하며, `RGB q 보존`은 기존 nonfallback B/I 점을 보존한다. 선·접선의 분산은 각 정책의 CAL 관측으로 따로 적합했다.

S에 대한 영상 점 관측·국소 질의·2D 점 비용은 0이다. 기존의 초기 기하에서 유래한 bounded S 정규화 항은 남아 있으며 새로운 영상 관측은 아니다. U에는 대략적인 영역만 사용한다. target mask가 없는 구간만으로 다른 물체에 가려졌다고 확정하지 않는다. 별도의 other-object mask가 없는 한 그 원인은 미확정이다.

## 확인된 실패 원인과 후속 V30

CAL 실제 이미지에서 발견한 문제는 실제 경계선을 검출했어도 그 선을 잘못된 모델 모서리에 연결할 수 있다는 점이다. V29의 43px 범위는 모델 가이드 주변에 적용됐으며, 원래의 해당 B/I 관측 q와 선택된 실제 선 사이 거리를 직접 제한하지 않았다. 세 고정 CAL 사례에서는 한쪽 B/I q와 선택 선의 법선 거리가 약 323px 또는 667px까지 벌어졌다. 전체 실패가 이 원인 하나로 설명된다는 뜻은 아니다.

V30은 원래의 보이는 B/I q와 실제 무한 TLS 선 사이의 법선 거리를 기존 탐색 범위 43px 안으로 제한한다. S/U의 정밀 좌표를 새로 읽지 않는다. 선택된 관측 모집단이 바뀌므로 CAL46의 분산을 다시 적합했다. CAL 적합·저장 likelihood 재계산·첫 CAL의 실제 연속 최적화 검사는 통과했다. 이 문서 작성 시점에는 V30의 추가192 관측 재선정이 진행 중이며, V30 전체 자세 오차는 아직 계산하지 않았다. CAL의 분산 감소나 세 이미지 개선을 전체 평가 성능 향상으로 해석하지 않는다.

실제 두 사례의 V29 보고서에서도 후보 선과 최종 활성 요인을 구분했다. 목재 031426은 새 활성 선이 0개라 native 개선을 새 선의 효과로 주장할 수 없다. 의자 사례의 전체 B/I 방법은 수용된 해가 없어 초기 자세로 fallback했다. 이전 대화의 **176.5351cm는 V24 MASK_FIT 결과**이며, 같은 목재의 기존 e는 V24·V26·V29에서 모두 **208.2242cm**다.

## 검증과 해석 범위

다섯 방법의 238장 예측을 모두 봉인한 뒤 고정 참조로 점수를 계산했다. 독립 계산 감사는 238장·77,571검사·실패 0, 최대 수치차 약 1.85e−13이었다. 이는 저장된 선택 해의 비용·관측 출처·상태 사용·저장 후보 중 최소값을 확인한 것이며, 전역 최적해나 정확도를 증명하지 않는다. 방법 비교표의 독립 회계 검산도 8,448검사·실패 0이었다.

추가143의 참조는 기존 파생 참조 계약을 그대로 사용했다. 독립 물리 계측으로 새로 확보한 GT를 주장하지 않는다. 반복 확인한 TEST/CAL이므로 탐색적 결과이며, 정답·프레임 ID·오차를 이용한 추론 분기나 사례별 기본값 변경은 없다.
