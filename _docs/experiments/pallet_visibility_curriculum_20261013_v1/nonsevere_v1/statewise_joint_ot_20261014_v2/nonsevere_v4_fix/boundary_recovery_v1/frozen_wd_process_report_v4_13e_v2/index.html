④ 실제 SAM 마스크와 RGB 선 표본

⑤ B는 외곽선 / I는 내부선: 부분 관측

자홍 + = 보관된 옛 BI점. 초록 = 실제 선. 주황 □ = 법선 투영 표시, 완전한 2D KP가 아님.

⑥ O/U 영역 + 부분 B/I 접선 범위

⑦ OLD가 고른 W/D 안에서 연속 PnP

⑧ 사후 참조 비교 — GT는 이 패널만
