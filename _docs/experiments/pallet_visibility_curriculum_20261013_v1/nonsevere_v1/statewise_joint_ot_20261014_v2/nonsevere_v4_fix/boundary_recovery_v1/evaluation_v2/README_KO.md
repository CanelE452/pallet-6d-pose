실제 SAM 마스크를 원 평가의 CUDA/결정론 설정으로 다시 저장한 `../image_evidence_v2`를 사용했습니다. 기존 보정기를 재생한 95프레임·533개 B/I의 좌표, 공분산, source가 봉인된 기준과 정확히 일치합니다. 작은 차이가 있었던 v1 마스크와 재생 결과는 보존했습니다. [재생 검사](LEGACY_REPLAY_CHECKS.json)

반환된 새 α=1 공분산은 영상 선/교점의 조건부 불확실성입니다. 전체 semantic/model 오차를 새 복구기에 맞춰 보정한 공분산이 아닙니다. 기존 CAL 모델에 새 `B_ACTUAL_BOUNDARY_RECOVERY` source를 그대로 넣으면 `B:corrected`로 분류되어 기본 floor가 83.9862→39.8504px², reliability가 0.96148→0.98150으로 바뀝니다(프레임 scale 배수 전). 따라서 자세 성능을 나중에 비교하려면 좌표만 교체하고 **기존 fitΣ/reliability를 고정한 대조군**, 좌표는 원래대로 두고 새 weight만 넣은 대조군을 구분해야 합니다. 이번 결과는 좌표의 2D 평가이며 자세 개선이나 새 공분산의 보정 정확도를 증명하지 않습니다.

각 partition은 모든 예측을 먼저 봉인한 뒤 해당 annotation을 읽었습니다. 기존 결과와 source는 수정하지 않았습니다. 원 scorer의 외부 가림 문자열 철자 오류는 봉인 자료를 수정하지 않고 [canonical strata addendum](CANONICAL_STRATA_ADDENDUM_V1.json)에 바로잡았습니다. 후보 좌표, 주 평가 수치와 파라미터에는 영향이 없습니다.
