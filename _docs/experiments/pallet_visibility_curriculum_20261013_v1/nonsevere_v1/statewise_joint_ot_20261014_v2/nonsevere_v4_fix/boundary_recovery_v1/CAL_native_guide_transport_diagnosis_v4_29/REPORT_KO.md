# CAL 3사례: 물리 자세 변환과 native ID 방향은 다른 계약

고정된 기존 CAL 진단 3사례의 모델 메타데이터만 검사했다. 새 영상·정답·점수·자세 적합은 없으며, 현재 v29 관측·모델·예측은 변경하지 않았다.

기존 guide 변환은 `R_guide = R_source Q_source Q_originalᵀ`로 물리 회전 `R_source Q_source`와 모델 중심을 보존한다. 그러나 같은 native ID를 잇는 단위 변 방향은 두 XYZ 표에서 같다(`T=I`). `Q_source Q_originalᵀ`가 Y축 90°이면 같은 ID의 변을 원래 채널 방향으로 유지하는 것과 물리 자세를 유지하는 것은 서로 다른 요구다. 둘을 동시에 보존한다고 해석할 수 없다. 상자의 무순서 꼭짓점 집합이 같아도 꼭짓점 ID별 위치는 달라진다.

| 고정 CAL 사례 | source guide | 단위 native T−I 최대 | 무순서 camera 상자 차이(m) | 같은 ID 꼭짓점 최대 이동(m) | 선택 변의 투영 직선 방향 차이 |
|---|---|---:|---:|---:|---:|
| wood_184309:000925 · 4→0 | SWAPPED_WD/CACHED_227 | 0 | 1.39e−16 | 0.8 | 44.521° |
| wood_184309:000804 · 1→2 | SWAPPED_WD/CACHED_376 | 0 | 2.54e−16 | 0.8 | 28.650° |
| eval_cad:1778653017736058368 · 7→3 | SWAPPED_WD/CACHED_70 | 0 | 1.24e−16 | 1.3 | 81.866° |

세 사례 모두 12개 named 변 중 8개의 카메라 3D 방향이 90° 달라지고, 높이 방향 4개는 같다. 높이 방향이 같아도 선의 3D 위치가 바뀌므로 원근 투영에서 영상 선 방향이 달라질 수 있다(000804). 물리 회전 보존 오차는 최대 4.44e−16이다.

이 결과는 guide를 물리 자세로 옮긴 뒤 동일 native ID를 다시 읽는 과정에서 원 source 채널의 변 방향·위치가 유지되지 않음을 보여준다. 어느 영상 선 대응이나 물리 자세가 정답인지는 이 검사로 결정하지 않는다. 향후 native-channel 방향을 보존하는 별도 proposal 설계는 다른 계약과 별도 검증이 필요하다. 현재 v29의 오류 수정·새 방법 채택 또는 성능 개선 증거로 주장하지 않는다.
