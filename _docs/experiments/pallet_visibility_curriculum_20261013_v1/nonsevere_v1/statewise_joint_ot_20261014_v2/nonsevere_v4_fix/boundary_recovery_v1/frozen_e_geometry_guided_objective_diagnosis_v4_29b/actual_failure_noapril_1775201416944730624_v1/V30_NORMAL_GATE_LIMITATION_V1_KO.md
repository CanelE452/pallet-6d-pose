# V30 법선 거리 검사만으로 구별되지 않는 실제 후보

이 그림의 저장된 V29 후보를 V30의 법선 거리 조건으로만 계산하면, 원 B0/B3와 실제 무한 직선의 거리는 각각 **0.8615px / 1.8279px**라 43px 검사를 통과한다. 그러나 원 B0–B3 선분과 실제 지지점 구간은 직선 방향으로 **43.2760px** 떨어져 있다. 같은 무한 직선 위의 다른 구간을 모서리에 연결하는 문제는 법선 거리 검사만으로 보장되지 않는다.

이는 이 후보가 V30의 최종 그래프에서도 선택됐다는 뜻이 아니다. 진행 중인 V30은 바꾸지 않고 전체 평가를 마쳐 확인한다. 새 영상 측정·정답 조회·자세 적합은 없으며, [저장 좌표의 계산 원장](V30_NORMAL_GATE_LIMITATION_V1.json)과 [원래 실패 그림](REPORT_KO.md)을 근거로 한다.
