## 표시와 평가의 범위

청록·노랑은 보관된 실제 선 지지와 부분 선 후보이고, 보라 wire는 저장된 모델 투영이다. 새 정밀 코너를 만들지 않았다. O/U 도형은 위치 범위이며 실제 가림 물체의 분할 모양이 아니다. 별도 other-object mask가 없으므로 target mask가 없는 구간의 원인은 미확정이다.

S의 영상 점 관측·국소 질의·2D 점 비용은 0이다. S는 모델 투영 역할을 가지며, 새 방법의 비용에는 기존 coarse-derived bounded S 정규화 항이 계속 존재한다. 이 항은 새로운 S 영상 관측이 아니다. U는 범위만 사용한다. 그림에는 S/U 점과 정답 wire가 없다.

오차는 예측 봉인 후 기존 고정 참조·지표로 계산된 저장값이다. 추가 143장의 참조는 파생 참조 계약이며 독립 물리 계측을 주장하지 않는다. 두 사례는 전체 성능을 대표하지 않는다. TEST49의 중심 오차 5cm 이하 수는 기존 e 49장에 비해 전체 B/I native 31장, RGB q 보존 native 39장으로 감소했다. **기본값 e는 유지하며 V29를 채택하지 않는다.**

후속 V30은 원 B/I q와 실제 무한 TLS 선의 법선 거리를 기존 43px 범위로 묶는 별도 후보 대응 실험이다. 이 보고서의 V29 관측·모델·점수·그림을 수정하거나 V30의 전체 성능을 주장하지 않는다.
