TEST 후보 6점 중 개선됐던 `wood_183705:001010` KP2를 제외했고, 남은 4프레임 5점은 모두 DIRECT이며 오차가 줄었습니다. 제거·유지 후보와 모든 changed inventory는 [CAL 결과](CAL_2D_REPORT.json), [TEST 결과](TEST_2D_REPORT.json), [요약·대조군 집계](RESULTS_V1.json)에 있습니다. 각 arm에서 검사 후 유지한 관측은 이전 v2의 같은 영상 후보와 **좌표·공분산·source가 정확히 동일**하고, 거부한 관측은 frozen baseline과 정확히 동일함을 확인했습니다. 네 대조군은 FULL, 반경만 확장(REACH_ONLY), FULL에 기존 최종 이동 상한 12px 적용(FULL_CAP12), FULL의 α=.5(FULL_HALF)입니다. 이 대조군들로 새 TEST 파라미터를 선택하지 않았습니다.

반경만 넓힌 대조군은 요청 사진의 KP2를 복구하지 못했습니다. 관측선으로 검색 중심을 옮겨 다른 인접선을 다시 측정하는 과정이 필요했습니다. 기존 12px 최종 이동 제한을 적용하면 두 점 모두 보정되지 않습니다. 보정의 좌표 출처는 실제 영상 경계입니다.

CAL과 TEST는 각각 전체 예측을 먼저 봉인한 뒤 2D annotation으로 평가했습니다. 이 TEST는 이전 v2 분석에서 이미 확인한 **재사용 탐색 자료**이며 새 독립 holdout 결과로 해석하지 않습니다. 새 α=1 공분산은 조건부 선/교점 불확실성이고 전체 semantic/model 오차를 보정한 모델이 아닙니다. 기존 CAL 불확실성 모델에 새 source를 넣으면 fallback→corrected 그룹으로 바뀌므로 향후 자세 평가 시 좌표 효과와 가중치 효과를 따로 확인해야 합니다. 이번 평가만으로 자세 개선을 주장하지 않습니다.
