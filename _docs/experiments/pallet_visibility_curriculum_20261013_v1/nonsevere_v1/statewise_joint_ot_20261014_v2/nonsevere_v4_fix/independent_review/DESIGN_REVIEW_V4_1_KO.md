# v4 독립 설계·완료 조건 검토

검토 상태는 **설계 타당, 통합 문제 수정 및 실험 검증 대기**다. 이 문서는 개선 성능이나 사용자 목표 달성을 인증하지 않는다. 기존 v3, 모델, 봉인 결과, 사용자 변경 파일은 수정하지 않았다.

새 목적함수는 고정된 실제 B/I 관측의 강건 손실과 유한한 초기 자세 사전항의 합이다. 기존 B/I 잔차 하드 상한과 seed 투영 이동 제한은 제거되며, 모든 O/T 개별 영역, 양의 깊이, 최종 B/I 모델 가시성·영상 경계는 동시에 제약으로 남는다. 회전·이동 6자유도를 연속 최적화하므로 기존 유한 자세 후보의 재채점과 다르다. 현재 구현은 관측 좌표 및 관측 공분산을 보존하고 별도의 CAL 유래 fit 공분산을 사용한다. B/I 2개는 사전항이 대표 자세를 정하더라도 관측의 유일 해로 주장하지 않는다.

초기 자세 사전항은 관측을 초기 투영으로 바꾸거나 자세 이동을 하드 제한하는 수단이어서는 안 된다. 현재 솔버의 유한 가중치는 이를 만족한다. 합성 테스트에서 O 영역 이동이 prior가 있는 자세를 실제로 움직이는 것은 구조 검증이다. 실제 이미지에서도 같은 관측·fit 공분산·prior를 사용한 O/T 유무 비교, 초기 자세와의 변화, 개별 영역 slack를 보고해야 영역 정보를 사용한 정도를 확인할 수 있다. B/I 2개에서는 NO_OT가 구조적으로 미해결이므로 B/I 3개 이상 사례와 분리해 해석한다.

CAL의 reference 재투영 잔차에는 관측 오차 외에도 가상 cuboid, 카메라, 기존 reference 자세의 불일치가 포함된다. 따라서 fit 공분산은 경험적 목적함수 척도이며 실제 물리 오차 확률의 인증이 아니다. human DIRECT 좌표 잔차와 reference 재투영 잔차를 따로 보고하고, actual SELF로 잘못 분류된 B/I도 reference 적합 모집단에서 빼지 않는 현재 recipe가 선택 편향을 줄인다. B/I 및 실제 보정/원시 fallback 그룹, 세션 균형, 영상별 nonS 크기 정규화, held-session 점별·프레임별 coverage를 구분해야 한다. 공간 상관과 편향은 대각 floor와 그룹 reliability만으로 제거되었다고 주장할 수 없다.

LOGO는 각 held session을 제외해 새 floor, 크기 정규화, reliability, prior를 다시 적합해야 한다. 기존 state head와 O 모델은 전체 CAL에서 이미 적합되었으므로 이 절차는 **동결된 upstream에 조건부인 v4 구성요소 LOGO**다. 전체 RGB 파이프라인의 OOF 검증이 아니다. CAL의 고정 native 대응 호환성은 적합 진단에 사용할 수 있지만 TEST 추론에서 GT 호환성을 보고 분기·fallback·설정을 고르면 안 된다. 설정 선택은 held-session 물리 지표의 사전 고정 규칙으로 하며 optimizer 목적값을 다른 가중치 사이의 성능 지표로 사용하지 않는다.

새 state adapter는 초기 pose만 영상 밖에 놓은 점의 유효한 영상 내 raw query를 다시 RGB 분류에 허용한다. S와 독립 T는 우선한다. 기존 extractor는 새 projected-OOB 위치의 일부 RGB 특징에 경계 외삽을 사용하므로 새 eligibility는 학습 지원 밖일 수 있다. 독립 근거가 없는 conditional T는 실제 truncation 인증으로 부르면 안 된다. fresh CAL46에서 override는 0건이고 T13은 모두 미인증 조건부 T였다. 이는 수정 의도가 타당하다는 사실과 실제 CAL 영향이 있었다는 주장이 다르다는 뜻이다.

fresh CAL46은 B245/I22/O9/T13/S68/U11이었다. B/I267개 중 실제 이미지 보정은 B146+I6=152개, 원시 backbone fallback은 B99+I16=115개다. fallback도 유지된 관측이지만 성공적으로 교정된 B/I로 세면 안 된다.

초기 읽기에서 세 가지 통합 문제를 보고했다. scalar B/I floor를 solver config의 2×2 행렬로 변환해야 하며, API는 현재 nonS 영상 크기를 calibration transform에 넘겨야 한다. 또한 pure solver에도 원래 physical registration Q를 전달해야 API와 solver의 물리 자세 감사가 일치한다. 담당자에게 전달했고 검토자가 소스는 수정하지 않았다. 수정 후 최신 소스와 실제 API 호출을 다시 확인해야 한다.

완료에는 다음 증거가 필요하다.

- 새 CAL46 관측 봉인 → CAL-only LOGO 설정 선택 → 전체 CAL 최종 적합·설정·소스 봉인 → TEST49 추론 → 예측 봉인 → 좌표 GT 후평가 순서를 확인한다. 이전에 사용된 TEST임을 명시하고 새 미관측 성능으로 부르지 않는다.
- 최종 현재 API의 실제 RGB Tiny/SAM 상태·보정·영역·솔버 통합, 기존 S raw perturbation 불변성, B/I q·관측 공분산 불변성, native/Q/9번째 metadata 보존, 실패 및 모호성의 정직한 출력이 필요하다. 관측 캐시 재사용과 최종 전체 API fresh 호출은 구분한다.
- severe 없이 같은 TEST49 전부와 fallback을 유지한다. GT 조건부 생산 추론은 금지한다. 같은 upstream/input의 old RGB·boundary와 비교하고, 각 backbone의 실제 실행/지원/미해결 상태를 보존한다.
- 사전 선언한 동시 목표는 TEST49 평균 이동 오차 ≤2.6186276 cm, 5 cm/5° 동시 성공 ≥43/49, 평균 회전 오차 ≤6.60°다. 셋 중 하나라도 실패하면 개선 목표는 계속 미완료다. 통과해도 재사용한 모집단 결과이며 모든 실제 O/T·유일성·일반화가 해결되었다는 뜻은 아니다.
- 최종 선택 설정의 같은 입력 NO_OT와 prior=0 또는 coarse 결과를 함께 보존해 prior만 보존한 해와 영역의 추가 영향을 구분한다. 개별 영역 위반을 평균으로 상쇄하거나 실패 프레임을 제외해 목표를 통과시키면 안 된다.

제약이 가능한 자세 집합을 좁힌다는 사실만으로 선택한 estimator의 물리 오차가 감소하지는 않는다. prior와 fit 척도는 이 선택 문제를 개선하려는 가설이며, 실제 CAL 선택과 봉인된 TEST 비교가 결론을 정한다.
