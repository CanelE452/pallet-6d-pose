CAL 최대 오차 구간을 이용한 조건부 T 보류 규칙의 필수 소스 검토를 통과했습니다. 실제 학습·자세 계산·RGB 추론·라벨 좌표 열람은 실행하지 않았습니다. CAL 264점과 반경 비율 0.544750754221928은 현재 사전 진단값이며, 실행된 학습 산출물에서 별도로 검산해야 합니다.

원 중심에서 닫힌 영상 사각형까지의 거리가 반경보다 크면 원 전체가 영상 밖입니다. 원이 닿거나 겹치면 조건부 T를 U로 보류합니다. 이 결론은 실제 점이 그 원에 포함된다는 조건에 의존합니다. 유한 CAL 최대 오차는 미래 포함 확률이나 물리적 T 인증을 제공하지 않습니다. 남은 조건부 T도 독립 영상 증거로 승격하지 않습니다.

CAL의 실제 DIRECT/EXTERNAL 좌표와 raw 예측 사이 오차를 초기 S 제외 후 계산하며, 정상 표본과 큰 오차 표본을 모두 최대값 학습에 남깁니다. 정규화는 기존 GT 없는 nonS raw 좌표 범위의 대각선 길이를 그대로 사용합니다. λ=1, β=1, O 모델·BI 관측·연속 SE3 솔버는 고정합니다. CAL 검증에서는 해당 세션을 제외한 구간 모델과 기존 fold μ/Σ를 사용합니다.

검토 중 발견한 두 문제는 실제 학습 전에 수정됐습니다. 남은 T의 crop 유효영역이 재생성 중 사라질 수 있었던 문제는 모든 남은 T 수치 제약 비교로 막았습니다. CAL 프로토콜의 모델 바인딩 키 누락도 고정된 부모 바인딩 복사로 해결했습니다. CAL 실행은 캐시된 관측과 실제 RGB 바인딩 재검사·순수 솔버 검증이며 새 전체 RGB 실행으로 표시하지 않습니다.

CAL의 조건부 T 13개를 모두 보류할 수 있습니다. 이는 불확실한 밖 영역 제약을 적용하지 않겠다는 판단이며, 자연 T를 정확히 해결했다는 결과가 아닙니다. 원본 V4.1 실패 결과는 보존하고, 현재 수리 계획은 TEST 결과를 이미 본 뒤 세운 CAL 학습 규칙임을 공개해야 합니다. O/T 우월성이나 목표 달성을 소스 검토만으로 주장할 수 없습니다.
