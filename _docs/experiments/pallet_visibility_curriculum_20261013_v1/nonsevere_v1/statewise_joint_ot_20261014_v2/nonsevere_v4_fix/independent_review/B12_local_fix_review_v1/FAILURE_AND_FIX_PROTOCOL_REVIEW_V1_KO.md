이 프레임의 B1/B2는 보정을 조금만 적용한 상태가 아니라, 실제 선 두 개의 교점을 얻지 못해 원예측으로 돌아간 상태입니다. B1은 위쪽 선 하나만 찾았고 오른쪽 세로 선은 15개 샘플 모두 실패했습니다. B2도 세로 선은 모두 실패했으며, 아래 선의 8개 샘플은 최소 지지 비율·길이 조건을 통과하지 못했습니다. 후보 교점이 없으므로 12px 이동 한계와 alpha≤0.5는 아직 적용되지 않았습니다.

세로 탐색은 모델의 약20.57px 짧은 변을 따라 4~16.45px만 진행하고, 원예측 주변 가로 ±12px에서 이뤄졌습니다. 이 좁은 띠의 왼쪽 한계는 B1 약495.29px, B2 약498.67px인데, 기존에 영상으로 찾은 위·아래 경계 지지점은 약490~492px부터 있습니다. 실제 확대 사진도 원예측이 우측 경계보다 오른쪽에 놓였음을 시사합니다. 따라서 탐색 위치/범위가 원인일 가능성이 있지만, mask·방향·안팎 조건을 분리해서 확인해야 합니다.

고칠 때는 현재 mask와 품질 조건을 유지한 탐색 범위 변화, 범위를 유지한 영상 기반 방향 변화, mask만 바꾼 대조를 먼저 비교해야 합니다. 실제 영상에서 비평행 경계 두 개가 확인된 뒤에만 같은 후보를 가지고 이동 한계와 blending을 각각 검토합니다. 조건을 한꺼번에 풀거나 초기 모델 투영을 후보 좌표로 쓰면 보정 성공의 근거가 흐려집니다. 선 하나만 있으면 법선 방향의 부분 정보와 접선 방향의 불확실성을 기록하고, 정확한 모서리를 얻었다고 표시하지 않습니다.
