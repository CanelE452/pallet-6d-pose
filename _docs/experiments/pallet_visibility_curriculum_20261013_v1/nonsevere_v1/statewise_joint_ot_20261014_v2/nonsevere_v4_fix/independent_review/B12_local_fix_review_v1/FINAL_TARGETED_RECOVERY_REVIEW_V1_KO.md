최종 targeted 2D 복구 검토는 통과했다. 실제사진의 기존 ±12px 탐색이 놓친 SAM 경계를 영상 거리로 찾아 범위를 늘리고, 관측선으로 검색 중심을 옮긴 뒤 다른 실제 경계를 다시 측정한다. 교점은 두 관측선의 실제 inlier 지지 구간과 가까울 때만 사용하며, 실패하면 기존 좌표·공분산·source를 그대로 되돌린다. S 사전 제외, 이미 보정된 B/I와 states/O/T/Q/nonS 크기/9번 중심점 보존을 확인했다.

요청사진의 B1 오차는 13.5036→2.6831px, B2는 16.8034→4.1792px다. 최종 CAL 6점과 재사용 TEST 5점의 추가 보정이 모두 좋아졌다. 검사로 악화됐던 CAL 1점뿐 아니라 좋았던 CAL 5점과 TEST 1점도 보류한 tradeoff가 그대로 공개됐다. 페이지·표·좌표·사진/마스크/소스/그림의 SHA와 실제 그림 의미가 봉인된 결과와 일치한다.

새 관측의 공분산은 조건부 값이며 새 오차 family에 대한 전체 보정 모델은 아니다. 알려진 TEST를 재사용했고 요청사진의 native/reference 대응 불일치도 남아 있다. 따라서 이번 결과는 B1/B2의 영상 좌표 복구를 지지하며 최종 3D 자세 개선이나 일반적인 성공 보장을 입증하지 않는다. 추가 추론/학습/GT파일 조회 없이 완료했다.
