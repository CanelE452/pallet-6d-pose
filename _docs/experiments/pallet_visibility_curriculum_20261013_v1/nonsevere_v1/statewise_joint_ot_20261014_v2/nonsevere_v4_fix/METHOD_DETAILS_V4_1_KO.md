# S/B/I/O/T 관측과 불확실성을 이용한 자세 보정

초기 backbone 출력과 등록된 초기 PnP를 받은 뒤, 보이는 B/I를 실제 영상에서 보정하고 고정한다. 모든 O/T의 위치 영역은 하나의 자세에 동시에 적용한다. 초기 기하에서 S로 판정된 점은 영상의 점 관측·프롬프트·영역 생성에서 제외하며, 마지막에 선택된 PnP 또는 명시된 fallback 자세로만 투영한다.

| 기호 | 논문에서 사용할 이름 | 처리 |
|---|---|---|
| S | Self-occluded keypoint | 초기 등록 모델의 자기 가림 판정. 최종 자세의 모델 투영으로 완성한다. |
| B | Visible boundary keypoint | 파렛트와 배경의 경계 역할을 갖고 보인다고 판정한 점. 실제 경계선의 교점을 사용한다. |
| I | Visible interior keypoint | 파렛트 내부 역할을 갖고 보인다고 판정한 점. 실제 내부 RGB 선의 교점을 사용한다. |
| O | Externally occluded keypoint | 외부 가림으로 판정한 점. 대략적인 위치 영역을 공동 자세 제약으로 사용한다. |
| T | Truncated keypoint | 화면 밖 공간을 제약으로 사용한다. 독립적인 근거가 있는 판정과 초기 자세에 따른 조건부 판정을 구분한다. |

U는 판정 보류용 상태다. B/I의 기하 역할과 실제 보임 여부는 별개의 판정이다. 초기 자세가 틀리면 S와 B/I 역할도 틀릴 수 있다. 따라서 여기서 보장하는 S 제외는 **초기 기하가 S로 정한 ID**에 대한 계약이며, 사람 주석의 모든 SELF 점을 정확히 분류했다는 뜻이 아니다. S 좌표 교란 검사도 초기 자세를 고정한 이후의 처리에 대한 검사다.

## 수정한 자세 선택

보정한 B/I 관측 좌표 \(q_i\)와 원 관측 공분산은 바꾸지 않는다. CAL에서 구한 총 오차 성분을 더한 \(\Sigma_i^{fit}\)와 보임 신뢰도의 손실 가중치 \(w_i\)를 자세 계산에 사용한다. 원 관측과 계산용 오차 모형을 출력에서 구분한다.

\[
\min_{R,t}\; \sum_{i\in B\cup I}w_i\rho\!\left(\left\|\left(\Sigma_i^{fit}\right)^{-1/2}
[\pi_K(RX_i+t)-q_i]\right\|^2\right)
+\lambda\left\|C_{CAL}^{-1/2}[\delta(R,t;R_0,t_0)-\beta\mu_{CAL}]\right\|^2.
\]

\(\rho(s)=2h^2(\sqrt{1+s/h^2}-1)\)는 부드러운 강건 손실이다. 이전의 B/I Mahalanobis 3 한도로 자세를 먼저 탈락시키는 검사를 제거했다. 초기 B/I seed의 투영 위치를 지키는 clamp도 사용하지 않는다.

\(\delta\)는 카메라 좌표계에서의 상대 회전 \(\log(RR_0^T)\), 모델 중심의 정규화된 영상 방향 변화 \((x/z,y/z)\), 깊이 비의 로그로 구성된 여섯 좌표다. \(\mu_{CAL}\)는 CAL 초기 자세 오차의 중앙값이며, 초기 자세나 B/I 좌표를 직접 이동시키지 않고 사전항의 중심에만 적용한다. 같은 backbone 출력에서 나온 초기 자세와 B/I 오차 사이의 상관을 완전히 모형화한 확률분포는 아니다. 이 항은 CAL에서 정한 유한한 정규화 항이며, 물리적으로 보정된 자세 확률이라는 주장을 하지 않는다.

목적함수를 최소화하면서 **각 O의 투영은 그 점의 영역 안에**, **각 T의 투영은 허용한 화면 밖 공간에** 있어야 한다. 양의 깊이, B/I의 화면 내부와 등록 모델의 기하 가시성 검사도 적용한다. S와 U는 점 잔차와 영역 제약에 들어가지 않는다. 모든 O/T를 같은 자세에서 검사하며 영역 중심을 정밀한 대응점으로 취급하지 않는다.

현재 O 영역은 backbone 좌표와 실제 CAL 가림점의 오차로 확대한 타원이다. 가림 물체의 실제 윤곽을 새로 분할한 영역은 아니다. 조건부 T의 화면 밖 union도 깊이를 정밀하게 측정하는 정보는 아니다. 영역이 기존 관측과 사전항이 선택한 자세를 이미 포함하면 추가 자세 변화가 없을 수 있다. 이것은 O/T를 빼는 대조군과 비교해 실제 데이터에서 확인한다.

## 선택과 실패 처리

CAL46에서 한 세션씩 제외하고 계산용 오차 모형과 사전항을 맞췄다. 초기 자세 사전항 강도는 0, 0.25, 1, 4 중 성공 수, 평균 위치 오차, 평균 회전 오차 순서로 선택했다. 이어서 강도를 1로 고정하고 편향 반영 비율 0, 0.5, 1을 같은 CAL 규칙으로 비교했다. 선택된 설정은 \(\lambda=1,\beta=1\)이다. 실제 배포 계산에는 전체 CAL 모형을 사용한다.

상태 판정기·영상 보정·O 영역 모형은 기존 CAL 학습 결과를 동결했다. 위 세션 제외 검증은 새 자세 선택 부분의 조건부 검증이며 전체 영상 파이프라인의 완전한 OOF 검증이 아니다. TEST49는 반복 사용한 탐색 평가이고, reference 자세는 역사적 주석에서 파생됐다. 독립 측정한 물리 GT나 새 holdout 일반화 결과로 표현하지 않는다.

B/I가 두 점이면 O/T가 있는 경우 가능 자세를 탐색하되 항상 모호한 자세 집합으로 표시한다. 유한한 다중 시작점 탐색은 전체 가능 집합이나 전역 유일성을 증명하지 않는다. 공동 해를 찾지 못하면 검사를 통과한 식별 가능한 B/I+사전항 seed를 사용하고, 그것도 없으면 등록 초기 자세를 사용한다. 이 fallback에서 O/T는 미해결이다. S는 사용한 자세의 투영이며, B/I 보고 좌표와 아홉 번째 중심 metadata는 원 관측을 유지한다.

주 비교에는 severe를 넣지 않는다. CAL46/TEST49의 모든 실패와 fallback을 포함하고 실제 crop 세 건은 별도 보조 검사로 보고한다. 결과와 실제 사진은 최종 비교 보고서에 연결한다.
