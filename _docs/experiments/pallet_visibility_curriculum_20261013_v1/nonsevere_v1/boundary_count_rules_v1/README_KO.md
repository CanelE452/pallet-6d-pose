# CAL46 경계점 개수 규칙

확인된 외곽 경계점만 쓰는 보정기를 7개 고정 비교군으로 검사했다. 최초 프로토콜과 보정 전·후 코드, 예측을 보존했다. 입력 결속 검증 수정 전의 봉인된 예측도 `inference_before_input_binding_fix`에 보존했고, 정답 평가 전에 검증을 강화해 다시 추론했다. 실제 46장 결과의 좌표·상태·개수·보정 자세·사용 점은 모두 수정 전과 정확히 같았다. 분기나 임계값을 결과에 맞춰 변경하지 않았다.

| CAL46 방법 | 평균 이동 cm | 평균 회전 deg | 5cm·5deg 성공 |
|---|---:|---:|---:|
| 초기 N3+Sub | 3.9821 | 7.8049 | 34/46 |
| RAW 경계점 개수 규칙 | 4.1593 | 7.8109 | 34/46 |
| FUSED 경계점 개수 규칙 | 3.6606 | 7.7706 | 37/46 |
| 동일 FUSED 관측 진행 보정 | 3.6883 | 7.6348 | 34/46 |
| 동일 FUSED 관측 동시 보정 | 3.6680 | 7.6727 | 34/46 |

RAW/FUSED 모두 14장을 보정하고 32장은 정확히 초기값을 유지했다. 3점 이동 보정 9장, 4점 전체 보정 3장, 5개 이상 전체 보정 2장이었다. 확인된 경계점의 개수 분포는 0:5, 1:14, 2:13, 3:9, 4:3, 5:1, 6:1이다.

FUSED의 초기 대비 평균 이동 차이는 −0.3215cm, 4개 촬영 세션을 묶은 paired bootstrap 95% 구간은 [−1.5052, +0.0030]cm다. 동일 FUSED 동시 보정보다 평균 회전은 +0.0978deg 증가했다. RAW의 평균 이동은 악화했다. 세 점으로 회전을 고정하거나 수치 조건을 검사하는 것이 실제 좌표의 정확성을 보장하지 않는다. 이번 규칙을 자동 기본값으로 승격할 근거로 삼지 않는다.

현재 API의 캐시 관측 RAW/FUSED 92개 출력을 봉인된 CAL 예측과 비교한 `CACHED_API_VERIFICATION.json`은 전체 solution·actual_pose 차이 0을 확인한다. 3점 수락 18개는 초기의 두 회전 행렬을 정확히 보존하고, 2점 이하 64개는 초기 자세·좌표를 그대로 반환한다. 사용하지 않은 점의 투영은 출력 완성용이며 fitting에 들어가지 않는다.

봉인 후 추가한 정수 이미지 크기 검증은 `POSTSEAL_CANVAS_VALIDATION_AMENDMENT.json`에 기록했다. frozen helper와 현재 helper의 CAL46 전체 evidence 출력은 모두 정확히 같았다. frozen 프로토콜·예측·코드 snapshot은 수정하지 않았다. 새로운 학습·모델 forward·severe·TEST·FINAL 정답 읽기는 이 CAL 규칙 검사와 API 캐시 검증에 없다.
