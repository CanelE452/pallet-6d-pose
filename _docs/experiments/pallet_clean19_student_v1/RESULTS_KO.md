# Clean19 보정 수도레이블 종류별 student 학습

플라스틱10장/목재9장의 보정 수도레이블 → 각각 R0부터5epoch/320step. 합성512+실사복원추출512 슬롯. 최종last만 평가. 평가300장 학생 단독출력; 보정기/PnP/필터 없음.

보정기는19장의 수동 정답으로 이미 학습되었다. 따라서 완전 무라벨 self-training이 아닌 보정 지식 증류이다. 같은세션 적응이며 독립 일반화 검증이 아니다. AP/6D pose는 이번에 측정하지 않았다.

판정: 이번 고정320step 조건에서는 학생 단독의 PCK10이 R0보다 하락했다(플라스틱 -0.63%p, 목재 -2.74%p, 전체 -1.45%p). 보정기 수준의 정밀도를 학생에게 옮기는 데 성공하지 못했다. PCK20/일부 큰 오차의 개선은 있으나 최종모델 자동교체는 하지 않는다. 보정 없는 수도레이블 학습 대조군은 이번에 추가하지 않았으므로 보정 자체의 인과효과는 분리하지 않는다.

학습이미지19장 전부 사용, 그 중17장 숨은점 PnP 대체/2장 숨은점 R0 유지. 9개점×19장=171개 수도레이블 좌표의 정규화 왕복을 검증했다(평가는 중심점을 제외한 코너8개). 플라스틱79.8초·목재77.7초에 각각320 optimizer update 완료. 학생 평가는 원래 R0와 같은 추론 설정이며 R0 300장 재추론 좌표 차이0px를 확인했다.

아래 이미지의 mean은 매칭 실패 penalty를 포함한다. **800px은 실제 코너 이동량이 아니라 검출 box IoU<0.5에 부여된 이미지 대각선 penalty**다. 그림에서 점이 비슷해도 검출 box가 매칭 기준을 넘나들면 이 수치가 크게 달라질 수 있다. median/P90 열은 매칭된 코너만, PCK는 실패를 포함한 전체 분모 기준이다.
