# GitHub 게시 검산 기록

이번 게시물은 완료한 원시 결과·최신 재집계·원고 수정본·비교 이미지를 공개합니다. 신규 학습·모델 추론·리프터 제어·PDF 생성은 실행하지 않았습니다. 사용자께서 2026-10-06에 main push를 새로 승인했습니다. 앞선 고정 실험 영수증의 push 0은 당시 실행 범위를 기록한 값이며, 원문을 고쳐 이번 게시 사실을 소급하지 않았습니다.

[최신 결과와 이미지](../pallet_paper_review_20261006_v1/README_KO.md), [실제 소스·테스트 검산](SOURCE_AND_TEST_VALIDATION.json)을 확인하세요.

원격에 이미 있는 N3 학습·비리프터 평가 기록은 재사용했습니다. 로컬의 고유 정사각형 감사 커밋과 원격 main을 통합했으며 이미 게시된 치수 설명 정정은 그대로 유지했습니다. 원래 작업 폴더의 변경 파일은 보존했습니다.

해시로 잠긴 JSON/receipt의 로컬 절대 경로는 당시 출처입니다. 경로 문자열을 바꿔 해시를 손상시키지 않고, [압축 원시 근거와 이동 가능한 검산 도구](../pallet_paper_review_20261006_v1/portable_evidence/README_KO.md)로 연결합니다.

원래 리프터120장/반복24장 전체 참조, 정지 잡음, 독립 물리 위치·회전 참조는 미완료로 유지합니다. 별도12장·96점 보조 표를 이 항목의 완료로 승격하지 않았습니다.

게시 복사본에서 원시 예측 8,910행·12장 96점의 지표를 [29,747항목으로 독립 검산](PORTABLE_WORKTREE_VERIFICATION.json)했고 실패는 0입니다. 공개 검토 문서의 상대 링크 134개·이미지 삽입 32개와 파일 SHA 목록도 통과했습니다. fixture test 13개와 독립 검산 안전 조건 6개를 통과했습니다.

[게시 파일·크기·해시 목록](PUBLICATION_FILE_MANIFEST.json)을 제공합니다. 원본 복사 1,602파일은 staged Git blob과도 바이트 단위로 일치합니다. 이전 원고·IEEE 템플릿·patch 문맥·생성 그림에 있던 공백과 CRLF는 출처 해시를 보존하기 위해 정규화하지 않았습니다.
