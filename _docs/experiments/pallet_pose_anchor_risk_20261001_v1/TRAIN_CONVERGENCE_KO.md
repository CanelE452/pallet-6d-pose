# TRAIN 위험 margin 학습의 독립 수렴·TRAIN 진단

**독립 검산 PASS**. 수렴 인증은 실제 T/R 개선 판정을 대신하지 않는다.

고정 target·context189를 별도 scalar-loop로 복원하고, 유효 후보와 finite anchor에서만 위험 초과량과 log1p margin을 계산했다. all-invalid행에는 inf−inf를 계산하지 않고 margin0/target−1을 유지한다. target margin은 정확히0이다. START/CK/FIT/COMPLETE/PREFIT 해시를 전부 대조했다. PyTorch float64 margin CE/autograd 및189×189 전체 Hessian으로 목적함수·gradient·수렴 상한을 검산했다. 후보 없는1행도 전체2,598행 분모에 남는다.

아래 `margin CE`는 이번 학습 목표이며, `일반 CE`는 같은 weight의 margin 없는 진단값이다. 추론 선택은 일반 score의 argmin이며 margin이나 safe mask를 사용하지 않는다.

r=max((T−Ta)/sT,(R−Ra)/sR,0)이며 위험 분위수의 분모는 실제 unsafe 선택행이다. 전체·조건부 T/R 중앙값·P90, 축별 위험과 최대값은 JSON에 보존했다. 위험 수와 크기가 감소해도 anchor 선택의 증가로 strict gain을 잃을 수 있으므로 원래 source/실사 gate를 대신하지 않는다.

위반은 실제 unrestricted scorer가 선택한 후보의 T/R가 같은 프레임 R0 anchor를 초과하는지로 집계했다. 학습 target의 safe mask를 inference에 적용하지 않았다. 따라서 oracle의 pointwise 보존은 학습된 scorer에 자동으로 전달되는 보장이 아니다.

이 비교는 TRAIN 설명용이며 추가 fit·optimizer step·VAL 품질·실사 GT 읽기·선택 정책 변경은 없었다. 실질 성능 판정은 사전 고정 source VAL과 그 통과 후에만 허용되는 실사 평가로 분리한다.
