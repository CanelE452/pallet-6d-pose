# 비초록 DEV72 — P0 보정과 GT 사용 확인

2026-09-19. 새 학습/추론 없이 기존 저장 예측으로 72장 전체를 시각화했다. 기존 최종 모델, 학습 코드, 평가 라벨은 변경하지 않았다.

## 사용자 질문에 대한 답

보정 좌표는 모델이 RGB와 R0 예측점/박스를 입력받아 출력한 결과다. **평가 사진의 GT 좌표로 점을 옮기거나, GT에 가까운 출력으로 대체하지 않았다.**

단, 이 모델은 GT를 전혀 사용하지 않은 모델은 아니다. 별도 실사 TRAIN 9장의 수동 38코너와 합성 GT로 지도학습한 PoseFix이며, 학습 입력 일부는 GT+noise로 만들었다. 이번 Replay 실행은 수도레이블 student self-training이 아니다.

평가 GT는 추론 결과가 고정된 후 오차 계산, bbox 매칭, 물체 전체 C2/C4 대응, 비교 그림의 기준점 표시와 사례 선정에 사용한다. 따라서 평가/사례 선정까지 GT-free라고 부르면 안 된다.

## 비초록 비교 범위와 라벨 제한

- 저장된 비초록 평가 72장은 전부 `plastic_standard_110x130x11`. 별도 목재 평가 결과는 포함하지 않았다.
- 72장 모두 검출·매칭되며, 기존 기준점 중 555코너가 평가 가능하다.
- annotation의 첫 8코너 576개(중심점 포함 시 648개)는 **모두 source=unknown**이다. 객체 수준 `gt_source=manual`만으로 각 점이 실제 수동 클릭이었다고 확정할 수 없다.
- HTML은 이를 회색 빈 원 `L`로 표시하고 **기존 평가 기준점 / 점별 출처 미확인**이라고 명시한다. 초록 150장의 manual-only 정확도와 같은 라벨 품질로 취급하지 않는다.
- DEV72는 재사용 개발평가이며 독립 테스트가 아니다.

Replay는 R0 대비 55코너를 10px 안으로 복구하고 18코너를 밖으로 악화시켜 순증 37개다. 현재 N2 대비는 24개 복구 / 20개 악화로 순증 4개(+0.72%p)뿐이다. N2 대비 중앙값은 개선되지만 평균과 P90은 악화한다. 대칭 평가 분기 변경은 0이다.

따라서 **일부 실제 모델 출력이 기존 기준점에 더 가까워지는 효과는 있으나, 현재 최종 모델보다 일관되게 좋아졌다고 할 수 없다.**

## 45도 가설

초록 사례에서 P0가 다른 물리적 코너 쪽으로 끌리는 출력은 확인했다. 비슷한 모서리 후보가 경쟁한다는 설명은 가능하지만, ‘45도에서 주로 발생한다’는 것은 아직 가설이다.

이번에 직접 본 비초록 비스듬한 시점에서도 P0 개선과 악화가 모두 있었다. 현재의 legacy PnP pose와 미확정 canonical axis는 독립 검증된 45도 태그가 아니다. 이미지상 두 변이 보인다는 것만으로 실제 yaw=45도로 지정하거나 각도별 실패율을 보고하지 않는다.

P0는 출력 채널이지 항상 화면의 오른쪽 꼭지점이라는 이름이 아니다. 초록 C4와 비초록 C2의 평가 대응 번호를 무조건 같은 물리적 코너로 해석하면 안 된다. HTML의 P0 추적은 **native P0를 고정**하며 평가 대응 L 번호를 따로 보여준다.

## GT 사용 경로 감사

- `pallet_posefix_replay_v1/evaluate.py:126`: 저장 R0를 복사해 `C.predict(model, bgr, inference_input)` 호출.
- `pallet_posefix_large_error_v1/core.py:82`: 예측 bbox로 RGB crop, R0 점으로 초기 입력 생성.
- `core.py:116`: 네트워크 입력 `rgb, points, valid`, heatmap expectation을 원본 좌표로 복원. GT 인자 없음.
- `replay/evaluate.py:146`: 출력 생성 후 평가 target을 읽음.
- 기존 결과/코드/체크포인트 관련 SHA256 바인딩 49개 검사, 불일치 0.
- TRAIN9↔DEV72: ID, 이미지 SHA, 세션 교집합 0. 예약한 학습 후보 recording과 DEV72 recording 교집합 0.
- GREEN150↔TRAIN9 이미지 SHA 교집합 0. 역사적 개발 사용 전체가 없었다는 의미는 아님.
