# 필터 이외에 어느 코너를 보정할지 학습하는 방법

2026-09-20. 이 문서는 설계 검토이며, 선택기 학습을 실행한 결과가 아니다. 이번 실행은 고정 모델의 선택적 보정 필터 검사만 수행한다.

## 우선 후보: 보정 이득을 직접 예측하는 작은 선택 모델

모든 점을 보정한 다음 사람이 정한 기준으로 거르는 대신, **현재 점을 유지할지, 보정 후보로 바꿀지**를 학습한다. R0/N2/Replay는 고정하고 작은 비교 모델만 학습하는 형태가 가장 제한적이다.

- 입력: 코너 주변 이미지 특징, 물체 전체 점 배치, N2 점과 Replay 후보, 두 점의 이동량, 후보 heatmap 요약.
- 학습 목표: `현재 N2의 GT 오차 − Replay 후보의 GT 오차`. 양수는 보정 이득, 음수는 손해다. 또는 이득 여부를 분류한다.
- 추론: 평가 GT 없이 이미지와 두 모델 출력만 보고 유지/보정 중 선택한다. 두 점을 평균내어 새 좌표를 만드는 방식은 이번 다봉 분포 평균 문제를 반복할 수 있어 우선 제외한다.
- 8개 코너를 완전히 독립적으로 고르면 구조가 깨질 수 있으므로 수직 모서리쌍 또는 전체 점 배치의 관계도 입력으로 사용한다.
- 이는 fixed threshold를 학습된 판단으로 바꾸는 제안이지, 학습하면 반드시 성공한다는 결론은 아니다. 최종 사용 정책에는 보정 거부/기존점 유지 선택지가 여전히 필요하다.

### 근거가 되는 기존 연구와 차이

[DEKR 공식 구현(CVPR 2021)의 Scoring net](https://github.com/HRNet/DEKR#scoring-net)은 작은 완전연결망으로 예측 자세의 OKS 품질을 학습한다. 원 구현은 자세 전체의 품질 점수다. 이를 팔레트의 코너별 두 후보 비교/개선량 예측으로 바꾸는 것은 **우리 문제에 대한 확장 제안**이다.

[Mask Scoring R-CNN(CVPR 2019)](https://openaccess.thecvf.com/content_CVPR_2019/html/Huang_Mask_Scoring_R-CNN_CVPR_2019_paper.html)은 검출 confidence와 마스크 품질을 구별하고 예측 품질을 별도로 학습한다. 현재 R0 confidence가 보정 후에도 그대로 남는 것과 유사한 문제의식이다. 다만 분할 연구의 결과가 팔레트 점 보정의 성능을 보장하지는 않는다.

## 다른 후보: 위치별 불확실성/예상 오차를 함께 출력

좌표만 출력하지 않고 각 코너의 오차 분포 또는 예상 오차를 함께 학습할 수 있다. [RLE(ICCV 2021)](https://openaccess.thecvf.com/content/ICCV2021/html/Li_Human_Pose_Regression_With_Residual_Log-Likelihood_Estimation_ICCV_2021_paper.html)는 회귀 출력 분포를 학습하는 관련 근거다.

그러나 불확실성이 작다고 보정 전보다 좋아졌다는 뜻은 아니다. 잘못된 꼭지점에 확신하는 사례가 이미 있어, 이번 문제에는 막연한 confidence보다 **두 후보 중 어느 쪽의 오차가 작은지**를 학습하는 쪽이 질문에 더 직접적으로 대응한다.

## 데이터와 누수 방지 조건

1. 선택기가 평가 GT를 추론 입력으로 받지 않도록 모델 API부터 분리한다. GT는 TRAIN의 개선량 label 생성에만 사용한다.
2. 초록 GREEN150과 비초록 DEV72는 선택기 학습이나 threshold 탐색에 넣지 않는다. 특히 DEV72 점별 provenance=unknown이므로 검증된 수동 학습 정답으로 전용하지 않는다.
3. Replay는 이미 실사 9장의 38점을 학습했다. **그 9장에서의 암기된 Replay 출력을 가지고 선택기의 일반화 성능을 검증하면 안 된다.**
4. 실사 out-of-fold를 만들려면 선택기뿐 아니라 후보를 만드는 refiner도 해당 fold의 이미지를 학습에서 제외해야 한다. 선택기만 fold를 나누어서는 이 문제가 해소되지 않는다.
5. 합성 자료에서 먼저 학습할 수 있으나 일반 예측과 큰 오류 주입을 함께 다루고, 후보 모델이 학습하지 않은 분할에서 품질 label을 만들어야 한다. 합성에서 성공해도 초록 실사로의 일반화는 따로 확인해야 한다.
6. 두 모델이 다르게 예측한다는 사실은 정답이 어느 쪽인지 알려주지 않는다. 둘 다 같은 방식으로 틀리면 무라벨 consistency만으로는 구별할 근거가 부족하다.

## 실행 여부

이번 작업에서는 선택 모델을 새로 학습하지 않았다. 코너별 필터에서 놓치는 실패와 버리는 개선을 먼저 계량화하고, 그 기록을 선택 모델이 풀어야 할 목표로 사용할 수 있다. 단, 현재 평가 사례를 그대로 선택기의 TRAIN label로 재사용하지 않는다.
