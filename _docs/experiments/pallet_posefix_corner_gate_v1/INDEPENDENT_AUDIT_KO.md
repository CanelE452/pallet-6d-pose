# Corner gate v1 — 산술 재검산·출력 불변성 감사

검토일: 2026-09-20 KST. 기존 잠금 파일·모델·예측은 수정하지 않았다.
게이트/평가 구현과 별도의 검산 루프로 모든 결과를 다시 확인했다. 추론 모듈 구현에 참여한 에이전트가 수행한 내부 감사이며, 외부 블라인드 검증이나 새 독립 평가 데이터 검증을 의미하지 않는다.

## 판정

**구현·출력 보존·수치 재검산은 통과했다. 필터는 초록 팔레트에서 Replay의 일부 피해를 막았지만 현재 N2보다 정확도를 높이지 못했다.**

| 방법 | 비초록 DEV72: 10px 이내 / 555 | 초록 수동 정답: 10px 이내 / 681 |
|---|---:|---:|
| 현재 N2 | 330 (59.46%) | 554 (81.35%) |
| Replay 전체 보정 | 334 (60.18%) | 527 (77.39%) |
| 기존 프레임 필터 | 329 (59.28%) | 538 (79.00%) |
| 코너쌍 기하 필터 | 331 (59.64%) | 540 (79.30%) |
| 코너쌍 전체 필터 — 사전 지정 주 분석 | 327 (58.92%) | 543 (79.74%) |

- 초록 주 분석: Replay가 망가뜨린 34개 중 **18개 차단, 16개 잔존**. Replay가 개선한 7개 중 **5개 유지, 2개 차단**. N2 대비 순손실 11개다.
- 비초록 주 분석: Replay의 피해 20개 중 **4개 차단, 16개 잔존**. 개선 24개 중 **13개 유지, 11개 차단**. N2 대비 순손실 3개다.
- 초록의 매칭된 점 평균은 N2 5.028px → 전체 필터 4.994px, 중앙값은 4.122px → 3.901px로 조금 좋아졌지만, P90은 9.749px → 10.279px로 악화했다. 일부 지표 개선을 전체 성능 향상으로 바꾸어 말하면 안 된다.
- 모든 비교의 대칭 평가 분기 변경은 **0개**였다. 이득/피해 집계가 대칭 재매칭 변화 때문에 생긴 현상은 아니다.

## 수행한 독립 검산

1. 프로토콜·코드·런타임 변경·체크포인트·기존 예측·222개 추론 캐시·출력 잠금 등 **고유 파일 248개의 SHA256/기록된 바이트 수**를 검증했다.
2. 222장 × 5개 방법 = **1,110개 출력**에서 후보 개수·순서·선택 인덱스·박스·신뢰도·점별 confidence·비선택 후보를 기존 N2와 비교했다. 모두 그대로였다.
3. **8,880개 출력 코너**가 기존 N2 또는 저장된 Replay 코너의 float64 바이트와 정확히 일치함을 확인했다. 새 좌표 생성·평균·GT 방향 이동은 없었다. **1,110개 중심점**도 N2와 바이트 일치했다.
4. 기존 프레임 필터를 기존 `pseudo_label_filters.geometry_scores`로 **222장 재계산**했다. 저장된 통과 여부와 정확히 일치했다. 통과 시 전체 Replay, 실패 시 전체 N2이며, 새 코너별 IoU 조건을 기존 프레임 방식에 몰래 추가하지 않았다.
5. 두 코너쌍 방법의 **444개 최초 판정**을 confidence·유효점 수·개별 residual·반전 residual·mean–mode 거리·박스 IoU로 별도 재구성했다. 저장된 판정과 일치했다.
6. **362회 혼합 출력 재검사**에서 최초 선택한 W/D 가설과 최초 Replay 투영 대각선 D가 고정됨을 확인했다. 통과했던 쌍만 단조롭게 제외하고, 제외한 쌍을 재활성화하지 않았다. 각 프레임·방법의 반복은 최대 4회 이내였다.
7. 두 쌍별 방법에서 최종 수락된 **2,620개 코너**에 대해, 최종 혼합 좌표의 나머지 점으로 PnP를 다시 풀고 해당 점의 leave-one-out residual / 고정 D를 계산했다. 모두 사전 고정된 0.05 이하였고, 최종 선택 좌표도 수락 마스크와 바이트 단위 일치했다.
8. 기존 N2/Replay의 프레임별 평가 결과 **744건**을 기존 파일과 전 필드 일치 확인했다. 새 방법의 모든 PCK10 분자/분모, 매칭 평균·P90, 이득/피해·보존/차단 수를 프레임별 오류 배열에서 다시 계산했다.
9. 회귀검사 **11개 통과**: 반전 인덱스 복원, 쌍 원자성, 중앙값에 가려지는 코너 이상, 잘못된 수/유효성, PnP 실패 시 복귀, 고정 가설·대각선, 단조 재검사, 복귀 좌표·중심점 보존 등을 포함한다.

## 수락 수 재검산

| 데이터 | 기존 프레임 통과 | 기하 쌍 수락 / 한 쌍 이상 프레임 | 전체 쌍 수락 / 한 쌍 이상 프레임 |
|---|---:|---:|---:|
| DEV72 | 52 / 72 | 204쌍 / 57장 | 175쌍 / 55장 |
| GREEN150 | 115 / 150 | 490쌍 / 127장 | 441쌍 / 116장 |

수락 수는 정답 유무와 무관한 전체 모델 출력 코너 기준이다. 수동 정답 코너의 PCK 분모와 혼동하면 안 된다. 혼합 재검사에서 추가 제외한 쌍은 두 방법 합계 DEV72 5쌍, GREEN150 2쌍이었다.

## GT 분리와 실행 순서

- 추론은 고정 RGB·R0·Replay만 사용한다. 반전 결과는 실제 반전 이미지의 검출·보정 결과이며 원본 좌표를 단순 복제하지 않았다.
- 필터는 모델 좌표, source camera K, 사전에 고정된 object registry 치수만 사용한다. 평가 어노테이션 좌표·GT pose·GT 대칭 분기로 적용 코너를 고르지 않았다.
- `evaluate.apply()`는 어노테이션 경로를 다음 단계용으로 복사하지만 그 파일을 열어 목표 좌표를 읽지 않는다. 모든 선택 결과와 SHA를 저장한 뒤 `score()`가 처음으로 평가 목표 좌표를 읽는다. 소스 검증용 메타데이터/해시 접근과 GT 좌표를 선택 입력으로 쓰는 행위는 구별해야 한다.
- 기록 시각: CODE_LOCK 00:02:01 → INFERENCE 00:02:21 → OUTPUTS_LOCK 00:02:31 → 프레임별 점수/RESULTS 00:05:49 KST. 코드 구조와 실제 잠금 파일 모두 먼저 출력 고정, 나중 평가 순서를 뒷받침한다.
- 이번 실행에서 학습·pseudo-label 생성·최종 모델 승격은 없었다. 이전 사례가 설계에 사용된 재사용 개발 평가이지, 완전히 새 데이터에서의 독립 성능 확인은 아니다.

## GPU 실행 확인

사용자의 GPU 요청을 기록한 `RUNTIME_OVERRIDE_GPU.json`이 원래 CPU 런타임 계획만 대체했다. 임계값과 평가·모델은 변경되지 않았다.

- 222장 모두 CUDA, CPU 보조 스레드 4개.
- 추론 매니페스트 경과시간 13.022초, PyTorch 최대 할당 메모리 355.958MiB. GPU 전체 점유량이나 브라우저/검산까지 포함한 총 소요시간은 아니다.
- 원본 8코너 재계산 대 저장값 최대 차이 0.0001763px로 허용오차 0.01px 이내.
- 반전 검출 누락 0장.
- 기록된 GPU 온도 49–57°C. 외부 작업 강제 종료·드라이버/재부팅 변경 없음. RustDesk 제외 타 프로세스 감시가 실행 전·20장마다·해제 후 기록되어 있다.
- 기존 CPU 벤치마크들은 수정하지 않은 과거 런타임 점검 기록이다. 과거 벤치마크에 기록된 코드 SHA를 현재 GPU 코드의 SHA라고 주장하지 않는다.

## 해석상 제한

0.05는 기존 프레임 기준에서 옮겨온 단일 탐색 기준이며, 코너별 오류 확률로 보정된 수치가 아니다. 기하·반전 일관성은 실제 영상의 정답 여부와 같지 않다. 잘못된 위치끼리도 구조적으로 일관될 수 있다. 이번 결과가 실제로 그 안전성 한계를 보여 준다.

주 결과는 초록의 수동 정답 681코너이며, 모든 알려진 좌표 1,200개에는 PnP 유래 proxy가 포함되어 주 결과를 대체할 수 없다. 비초록 72장의 기존 목표 좌표에는 점별 출처 미확인 한계가 남아 있다. 카메라 K/registry 입력의 정확성은 이 감사가 새로 보증하는 대상이 아니다.

초록 스냅샷에는 150장 중 128장의 카메라 메타데이터 불일치가 이미 기록되어 있다. 이번 필터는 사전 고정한 source K를 그대로 썼으며 GT에 맞춰 재보정하지 않았다. 따라서 이 결과를 정확한 6D pose 검증으로 주장할 수 없고, 카메라 입력 오차와 코너 선택기의 오차를 이번 한 번의 실험만으로 분리할 수도 없다.
