# RGB 입력 검증기 해시 기록 형식 수정

첫 SOURCE_VAL 독립 검산(session 36903)은 exit 1로 중단됐고 검산 영수증은 생성하지 않았습니다. 첫 이미지의 SHA256은 기록과 같았지만, 기존 기록은 심볼릭 링크의 논리 경로와 SHA만 포함했습니다. 재사용 검증기가 해석된 실제 경로와 파일 크기까지 포함한 dict 전체 비교를 요구하여 거부한 검증기 결함입니다.

원래 검증기 코드를 private snapshot으로 보존했습니다. 검증기를 기록된 경로의 SHA 필수 확인·bytes가 있을 때만 크기 확인 방식으로 제한 수정했고, 경로 allowlist의 resolve 처리는 유지했습니다. 합성 심볼릭 링크·크기 유무·잘못된 SHA/크기 거부 검사는 exit 0/PASS입니다.

같은 봉인 산출물을 재검증하도록 승인받았습니다. 추출·모델·선택 경로·샘플링·정규화·허용오차는 변경하지 않았고 새 추론·학습·pose 추정·정답 조회는 모두 0회입니다.
