# 고정 RGB 특징을 추가하는 단일 비교

목표는 기존 평가 집합에서 T와 R가 안정적으로 함께 개선되는 것이다. 직전 비대칭 회귀 모델(Q)은 source 45조건 중 43개만 통과했다. 손실 비용 변경은 위험한 선택과 좋은 선택을 함께 줄였으며, 변경된 UNION 선택은 모두 R0 anchor로 돌아갔다. 다음 비교에서는 손실을 다시 조정하지 않고 후보 위치의 RGB 정보만 추가한다.

## 변경 요인

기존 271개 입력(raw94에서 만든 context/RBF 253개와 잔차 방향18개)에 고정 DINO 기반 385개 입력을 붙인다. 전체 656개이며 축별 회귀 가중치는 656×2다. DINO는 이미 보유한 공식 ViT-S/14 가중치를 고정하여 사용한다. RGB 하나에서 R0 box로 정한 동일한 crop/token을 모든 후보가 공유한다. 새로운 센서·카메라 보정·시간 정보·사람의 주석을 받지 않는다.

고정된 후보 pose의 8개 꼭짓점 투영 위치에서 token384를 읽고 지원점 평균과 지원 비율1을 합친다. 지원은 양의 깊이·crop 범위·**원본 영상 범위**를 만족하는 점이며 가시성 정답이 아니다. source에는 이미 들어 있는 반사 padding100을 표본 위치에서 제외한다. 실사 입력은 기존의 원본 RGB/native K 계약을 확인한 후 pad0을 명시한다. 준비영상 또는 K를 다시 이동하지 않는다.

이미 완료한 [입력 감사](../pallet_pose_dino_input_audit_20261001_v1/REPORT_KO.md)는 반사 영역을 직접 지원점으로 셀 위험을 드러냈다. 따라서 그 descriptor를 그대로 쓰지 않고 [원본 영상 범위로 재집계한 입력](../pallet_pose_dino_native_inputs_20261001_v1/DESIGN_KO.md)을 독립 검산한 뒤 사용한다. 원본 영역의 token도 전역 문맥을 통해 padding 영향을 받을 수 있다는 한계는 남는다. 8개 평균은 순열에 불변이지만 코너 순서 정보도 버린다.

정규화는 R0의 원래 유효 TRAIN 후보5,194개로 계산한 FP32 mean/std(std 하한1e-6)로 고정한다. 정규화 값을 float64로 옮긴 후 **모든 expert가 같은 R0 GEO anchor 특징**을 빼서 385차원 차분을 얻는다. 원래 후보 유효성과 전체 실패1행을 유지한다. 지원점이0이어도 유효 pose를 제거하지 않는다.

## 그대로 유지하는 조건

- 기존 적격 TRAIN2,598행, 4개 모델(R0_ONLY와 UNION3개), 원래 후보 풀과 순서, 타깃·스케일·기존9개 입력 해시를 유지한다.
- 대칭 Huber에 단위 과소예측 Huber를 추가한 비용2:1과 sign logistic 계수1, bias0, ridge1e-4를 유지한다.
- 모든 가중치를0으로 새로 시작한다. 기존 Q 가중치는 초기값으로 사용하지 않는다. 고정 Newton/Armijo, 최대 승인1,000회·objective2,000회, gradient∞≤1e-8 및 gradient-gap≤1e-6 인증을 유지한다.
- 추론은 두 예측 축의 최댓값으로 원래 whole pose 하나를 고른다. GT·margin·safe mask·새 동률 우선권은 넣지 않는다.
- source45조건을 모두 통과한 뒤에만 새 모델의 실사 평가를 수행한다. 원래 실사5조건과 matched 비교5조건을 각각 유지하며 해당 조건의 AND를 요구한다. 실패·원래 분모·recording bootstrap·leave-recording-out·clean 보호 조건을 줄이지 않는다.
- 특징 수가 늘어 가중치 수와 계산량도 늘어난다. ridge 계수는 유지하지만 전체 모델 용량까지 동일한 비교는 아니다. 입력 추가의 일반화 효과는 실제 검증으로 판정한다.

## 실행 순서와 완료 판정

원본 영상 입력의 독립 검산 → 순수 함수·PREFIT 입력 검산 → 학습 프로토콜 봉인 → 실제4fits → 독립 수렴·타깃·손실 검산 → VAL 입력 추출 및 후보 선택 고정 → 별도 VAL 품질 평가 → 통과 시 실사 입력·선택 고정 및 별도 품질 평가 순서다.

학습 수렴·입력 검산·문서화·push는 안정적인 T/R 공동 개선의 대체 조건이 아니다. 실사 참조는 기존2D 주석/K/치수로 만든 pose이며 물리 측정의 새 정답이 아니다. 반복 사용한 DEV이므로 독립 TEST라고 부르지 않는다. 개선 목표는 실제 전체 기준이 확인될 때까지 미달성으로 유지한다.
