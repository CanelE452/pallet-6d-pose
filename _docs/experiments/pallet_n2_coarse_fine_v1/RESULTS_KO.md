# 논문용 N2 보정기 자체 개선 — coarse/fine 단일 seed 실험

판정: **실험 완료, 미채택. 큰 오류 일부 복구는 생겼지만 정상 코너 보존과 전체 정확도를 함께 개선하지 못했다.** 기존 논문용 모델·표·가중치는 변경하지 않았다.

## 무엇을 바꿨는가

- 원래 N2_DIM_ONLY seed1의 정확한 가중치에서 시작했다. R0 검출기, P3/P4 특징, 치수 입력과 20,259개 학습 파라미터를 그대로 사용했다. DINO나 새 검출기는 추가하지 않았다.
- 같은 보정기를 두 번 적용한다. 첫 단계 후보 반경은 박스 대각선의 24%, 두 번째는 첫 예측 주변 4%이다. 각 단계는 기존처럼 13방향 × 17반경 + 무이동 후보의 222개를 사용한다.
- 전체 후보 평균 대신 가장 높은 점수의 후보 주변에서만 평균낸다. 무이동 후보가 1등이면 정확히 유지한다. 코너별 임의 GT 선택은 없다.
- 기존 1% 이미지 대각선 이동 상한을 실험판에는 적용하지 않는다. 후보 반경 자체의 상한은 남아 있다. 즉 무제한 좌표 회귀가 아니다.
- 기존 합성 정답만으로 1,500스텝, 배치8을 학습했다. 매 스텝 4장은 원래 R0 입력, 4장은 정답에서 박스 대각선 5–20%만큼 일부/전체 코너를 교란한 입력이다. 합성 학습 이미지 12,000장은 모두 서로 다른 기존 train 이미지다. 추가 실사 라벨·태그·수도레이블 학습은 없다.
- 두 단계는 파라미터를 공유한다. 각 단계에 자체 후보 CE를 적용하며, 두 번째 입력은 실제 첫 단계 예측을 detach한 값이다. GT 위치에 두 번째 탐색 창을 놓지 않는다.

원래 N2 대비 구조·디코더·학습 분포가 함께 바뀐 시스템 비교다. 세 요소 각각의 순수한 인과 효과를 분리했다고 주장하지 않는다. CF_MEAN은 같은 학습 가중치의 추론 디코더만 변경한 진단이며, 평균 디코더로 별도 학습한 통제군은 아니다.

## 합성 검증과 실제 일반화의 차이

기존 train과 시나리오·이미지 해시가 분리된 합성 heldout256장을 사용했다. 여기에는 별도 자연 발생 큰 오류13장도 포함된다. 이 모델 계열/데이터의 역사적 개발 노출까지 없는 독립 최종 검증이라는 뜻은 아니다.

인위적 큰 오류를 고치는 학습 능력은 생겼지만 깨끗한 입력 보존은 악화했고, 자연 발생 실사 큰 위치 복구는1/64에 그쳤다. **문제는 더 크게 움직일 수 없다는 것만이 아니라, 잘못된 점과 올바른 점을 구별하면서 실제 영상의 정답 위치를 찾는 것**이다. 추가 라벨의 필연성이나 N2 개선의 불가능성을 증명한 실험은 아니다.

실사에서 새 큰 위치 복구가 확인된 것은 `eval_pallet07:1778652126319943168` G3의 41.84→8.19px이다. 이 한 코너가 프레임 전체의 완전 복구를 뜻하지 않는다.

원래 의자·콘 사진은 N2 프레임 평균263.66px, CF_FROZEN263.80px, CF_TRAINED258.78px로 여전히 실패다. 이 오차에는 역할 혼동도 포함되어 있으므로 모두 순수 위치 오차라고 해석하지 않는다.

## 검증·보존

- 새로운 모델 회귀검사6개 통과. 파라미터 수/초기 가중치 일치, 무이동 후보 및 중심점 보존, 후보 반경, 서로 반대인 모드의 상쇄 방지, 두 단계 backward, 교란 시 GT 불변을 검사했다.
- 저장된 194장 × 5조건 = 970개 예측을 GPU에서 다시 계산하여 좌표 재현 오차0px 확인.
- 검출 박스·점수·키포인트 confidence·중심·비선택 검출 보존. 기존 N2 저장 예측은 1e-4px 허용오차로 확인했다.
- 모든 출력 파일을 고정한 뒤 평가 GT를 읽었다. GT는 학습/추론/필터/체크포인트 선택에 사용하지 않았다. 단, 합성 GT는 기존 감독학습의 정답으로 사용한다.
- 기존 최종 모델의 체크포인트·코드·정규화·설정 해시를 실행 전후 확인했다. 시스템/드라이버 변경, 재부팅, 원본 모델 교체, push는 하지 않았다.
- 학습 약110초, 합성 최종 probe 포함 FIT 112.65초. RTX3080 사용, 관측 학습 온도 최대58°C. 다른 CUDA 작업 없이 RustDesk 프로세스는 보존했다.
