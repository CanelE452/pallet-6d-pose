# 고정 비학습 보정 비교

기존 YOLO 319장·13세션에서 cornerSubPix와 기존 고전 후보 선택기를 실제 평가했다. 각 방법의 원형과 원영상 대각선 1% 이동상한 결과를 모두 보존했다. 추가 학습·데이터·어노테이션·리프터 분석·원고 수정은 없다.

SUBPIX는 N3 seed1보다 이동/ADD 중앙값과 처리시간이 좋지만 회전·2D 코너 오차는 나쁘다. 평균 ADD 개선은 확인되지 않았다. 이번 고정 비교는 N3의 정확도 이득 전체를 대체한다는 근거가 아니다.

| 방법 | 이동 중앙값 cm | 회전 중앙값 degree | ADD 중앙값 m | 전체 처리 중앙값 ms |
|---|---:|---:|---:|---:|
| BASE | 7.897 | 2.539 | 0.087137 | 12.082 |
| N3 seed1 | 7.039 | 2.110 | 0.080549 | 15.223 |
| PoseFix seed1 | 7.185 | 1.954 | 0.078512 | 25.829 |
| SUBPIX 원형 | 5.794 | 2.541 | 0.065734 | 12.967 |
| SUBPIX 1% | 5.794 | 2.541 | 0.065734 | 12.216 |
| CVRANK 원형 | 6.377 | 3.000 | 0.070677 | 27.293 |
| CVRANK 1% | 6.187 | 2.881 | 0.067014 | 26.936 |
