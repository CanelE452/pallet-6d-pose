# 남긴 계산과 제거한 계산

이 실험은 RAW 직접 B/I 후단의 실행 가능성과 N3/SubPix 묶음의 필요성을 분리해서 확인한다. 운영 기본값은 바꾸지 않는다. 아래는 소스·실행 동등성·실제 호출 계측에 따른 구성 판단이며, 성능에 따른 채택 권고는 RESULTS_KO.md에 있다.

| 구성 | 최소 보정 블록에서의 처리 | 이유/검증 |
|---|---|---|
| 초기 YOLO | 준비된 같은 실행/선택 candidate의 좌표를 입력받음 | 두 경로의 검출기 차이를 제거. 이 블록은 YOLO 실행시간을 측정하지 않음 |
| N3 + 기존 SubPix | R1의 필수 의존에서 제거, N0/N1 입력 경로에 유지 | R1 단독 CLI는 이 가중치/캐시 없이 실행 가능. 실행 가드와 실제 호출 계수로 추가 호출0 확인 |
| 자기 F 자세·등록 CF모델·Q | 유지 | 같은 XYZ/W/D와 물리 회전, 방향 가이드 및 S 조건을 보존 |
| 상태 가중치·임계값·ImageNet ResNet 특징 | 유지 | 최소 B/I의 실제 구성요소. 초기 검출기 ResNet과 다른 역할이며 새 fit0 |
| Tiny 전영상 마스크 | 유지 | 고정 상태 RGB 특징에 사용. 경로마다 실제 forward |
| MobileSAM 자기 non-S box | 유지 | 실제 B 경계 관측의 입력. 자기 좌표로 각자 새 프롬프트/마스크 실행 |
| B 외곽선, I 영상 기울기선 | 유지 | 실제 관측 좌표와 공분산. 초기 모델 변은 검색 방향 가이드로만 사용 |
| B 복구, RGB 지지·교점 외삽 검사 | 유지 | 기존 지지 없는 교점/과도한 외삽 거부와 원예측 fallback 보존 |
| B/I-only PnP | 유지 | 동일 시작값 생성·analytic Jacobian·공분산·보호·수락·seed/원자세 fallback |
| O/T domain 생성/저장 | 실행 핵심에서 제거 | 후단은 빈 domains를 받음. 기존10장×2의 전체 관측/자세 동등성 확인 |
| U 표시용 영역 모델·builder | 실행 핵심에서 제거 | 자세 입력에 쓰이지 않음. U는 여전히 abstention 상태로 남음 |
| V33 C 비용·과거 후보 bank·LCC 변형 | 가져오지 않음 | 현재 B/I-only 정본의 경로가 아님. 비교 결과를 V33 전체 결과로 부르지 않음 |
| HTML·그림·정답 scorer·통계 | 추론과 분리 | 전체 예측 봉인 후 별도 모듈에서 계산 |

새 모듈은 과거 파일을 삭제하거나 변경하지 않는다. 삭제한 실행 payload는 `ot_domains`, `u_region_display`이며 같은 선/스케일/공분산/solver를 만드는 필요한 순수 기하 계산은 유지한다. `joint_ot_pnp.py`라는 기존 파일 이름을 재사용하지만 domains=[]이고 O/T/U는2D 대응점이 아니다.

S를 후단 국소 질의에서 제외해도 초기 F에 S 예측 채널이 영향을 주었을 가능성은 남는다. 상태 모델의 CAL 실사 감독과 RAW 출처 전환 제한도 남는다. 작은 학습 head만 보고 전체 방법이 YOLO 한 개의 비용이라고 주장하지 않는다.

실제 비용은 TIMING.json/COST_AND_VALIDATION_KO.md의 범위를 따른다. 전체 RGB→YOLO→앞단→최종 자세를 한 호출에서 실행하지 않았으므로 전체 시간/FPS와 Jetson 속도는 NA다. N3/SubPix 제거 여부는 정확도·손상·꼬리 오차와 의존성 감소를 함께 보고 권고하며, 이 비교는 N3와 SubPix의 개별 기여를 식별하지 않는다.

남은 한 가지 핵심 병목은 B/I-only 수치 제약을 통과한 손상을 독립 촬영 군집에서도 억제할 수 있는지다. R1의5개/N1의14개 성공→실패가 모두 수락된 재계산이었다. 현재는 N3/SubPix 유지 후보를 권고하고 R1은 연구 후보로 남긴다. 이번 실행 중 모델/임계값/손실을 바꾸는 다음 실험은 시작하지 않는다.
