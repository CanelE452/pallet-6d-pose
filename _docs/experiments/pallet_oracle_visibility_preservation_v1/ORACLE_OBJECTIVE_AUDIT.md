[확인] 평균오차 oracle의 PCK10을 PCK10 상한처럼 해석한 이전 우선순위 판단은 충분하지 않았다. 과거 문서를 덮어쓰지 않고 이 추가 분석으로 구분한다. PCK10 oracle의 PCK20은 PCK20 oracle보다 낮을 수 있다. 점별 혼합은 유효 3D 형상/배포 방법이 아니다.

[추정] 선택 가능성은 열어 두되, 3pp 경계를 넘었다는 사실만으로 ROUTE A를 확정하지 않는다. 7개 후보 추론 비용, 세션별 회수 가능량, unknown 기준좌표의 신뢰도와 GT 없이 옳은 후보를 고를 신호가 아직 필요하다. 데이터 다양성 또는 catastrophic forgetting을 단일 원인으로 확정할 근거도 없다.
