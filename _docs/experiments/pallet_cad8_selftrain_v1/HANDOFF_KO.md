# CAD 8장 수도레이블 fine-tuning 결과

## 판정

이번 고정 설정에서는 occlusion 일반화가 개선되지 않았다. 기존 R0를 교체하지 않는다.

학습은 CAD 2·6·7·8·9·10·11·12번 8장으로 수행했다. N3+자기 가림 PnP와 Replay+자기 가림 PnP를 각각 고정 수도레이블로 사용했다. 두 모델 모두 R0에서 시작했고, 같은 합성512장과 실사512슬롯(8장 각각64회)을 섞어 5 epoch / 320 update / seed42로 학습했다. 실사 GT 좌표는 학습 목표로 사용하지 않았다.

CAD 세션 전체를 이번 평가에서 제외했다. 원래 전역 split과 이전 평가 결과는 수정하지 않았다. 주 평가는 기존 occlusion 태그에 해당하는 다른6세션96장이다. Replay teacher의 실사 학습 세션은 주 평가에서 제외했다. 평가에는 학생 모델만 사용했으며, 보정기·PnP·필터를 붙이지 않았다.

| 방법 | 매칭된 코너 중앙값 px ↓ | 전체 분모 PCK10 ↑ | 전체 분모 PCK20 ↑ | IoU≥0.5 매칭 |
|---|---:|---:|---:|---:|
| R0 | 11.39 | 41.79% | 62.82% | 88/96 |
| N3+PnP 수도레이블로 학습 | 12.36 | 35.69% | 58.21% | 82/96 |
| Replay+PnP 수도레이블로 학습 | 12.20 | 34.19% | 59.16% | 83/96 |

## 추가 확인

- 세 모델 모두 매칭에 성공한 동일81장에서도 중앙값은 R0 11.21px → N3 12.21px / Replay 12.20px로 악화했다. PCK10은45.61% →41.95% /39.07%. PCK20은67.94% →67.94% /68.10%로 거의 같았다. 전체 PCK20 하락에는 검출 매칭 감소가 크게 작용하며, 세밀한 코너 정확도도 개선되지 않았다.
- 별개의 탐색적 부분집합인 'occlusion이 있으나 truncation이 없는81장'에서도 PCK20은65.59% →59.57% /60.65%로 하락했다. 위의 공통 매칭81장과 같은 집합은 아니다.
- 이전 동일 예산 합성-only 학습을 주 평가96장에 재집계한 PCK20은60.11%다. 현재 두 학생의58.21% /59.16%는 이 보조 대조군도 넘지 못했다. 보조 대조군은 이번에 재학습한 결과가 아니다.
- 매칭 성공 이미지에만 제한한 P90은 낮아졌지만 실패한 이미지가 늘었으므로 전체 개선으로 해석하지 않는다.

학습 시간은 각각76.4초 /74.4초였으며, 학습 GPU 작업은 종료했다. 모든 모델/원본 데이터는 보존했다. 결과 모델은 자동 승격하지 않았다.

## 해석 한계

8장·단일 seed·재사용 DEV의 bounded screen이다. 깨끗한 수도레이블로 fine-tuning한 이 설정이 occlusion 성능을 높이지 못했다는 결과이지, 모든 self-training 방법의 불가능성을 의미하지 않는다. PnP 효과만 분리하는 raw-pseudo 학습 대조군은 이번 범위에 없다.

Optional Albumentations는 설치된 ImageCompression API 불일치로 초기화되지 않았고, 기본 Ultralytics augmentation으로 학습이 계속됐다. 두 실험에서 동일하며 패키지는 변경하지 않았다.
