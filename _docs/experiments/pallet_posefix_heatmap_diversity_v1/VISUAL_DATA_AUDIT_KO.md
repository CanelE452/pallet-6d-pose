# 학습 이미지 육안 확인과 해석 범위

학습이 끝난 뒤 실제 선택32장 contact sheet를 확인했다. 선택이나 결과를 바꾸지 않았다.

- 낮16장은 기존 사용자가 대략 clean으로 지정했던 촬영 구간이다.
- 추가한 밤16장은 낮과 촬영 조건이 뚜렷하게 다르고, 저양각·일부 프레임 가장자리 잘림을 포함한다. 이를 전부 clean/top-visible/no-truncation으로 확인한 데이터라고 부를 수 없다.
- 밤16장 중5장은 유효 target corner가6개이고 나머지11장은8개다. 실제 crop/image support mask로 범위 밖 코너를 제외했다. 낮32장의256코너와 혼합32장의246코너 차이는 유지·공개했다.
- 일부 밤 이미지에는 사각형 표식이 보인다. 표식 검출·표식 자세·표식 기반 정답을 새 target으로 사용하지 않았고, 원래 RGB와 고정 모델의 pseudo target만 사용했다.

따라서 이번 실험은 **한 세션32장 vs 낮16+밤16의 촬영조건 확장 파일럿**이다. ‘clean 여부까지 일치시킨 다중 세션 효과’나 ‘세션 개수만의 순수 인과효과’가 아니다. 작은 성능 이득을 깨끗한 다양한 실사에서의 일반화 성공으로 확대하지 않는다. 재학습이나 사후 제외로 결과를 구제하지 않았다.
