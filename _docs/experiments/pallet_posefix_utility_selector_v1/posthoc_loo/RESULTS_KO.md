# 학습 선택기 → 코너별 LOO 추가 검사

2026-09-20 KST. 사용자가 요청한 순차 조합을 기존 222장에 실행했다.

## 결론

**비초록 PCK@10은 60.00% → 59.28%, 초록 수동 PCK@10은 78.27% → 79.74%다.**
초록의 큰 오보정을 일부 제거했으나, 두 집단 모두 기존 N2보다 낮다.
기존 최종 모델은 교체하지 않았으며 셀프트레이닝은 수행하지 않았다.

## 실행한 순서

1. 저장된 GPU 추론 결과에서 학습 선택기가 만든 좌표를 읽었다.
2. 그 **실제 선택 좌표 전체**로 코너별 LOO를 새로 계산했다. 과거 Replay LOO 통과 마스크와 단순 교집합을 구한 것이 아니다.
3. 기존 confidence 0.85 / corner confidence 0.5 / 유효 코너 6개 / 정규화 LOO 0.05 기준을 그대로 적용했다.
4. 학습 선택기가 선택한 수직 코너쌍만 유지 후보로 삼았다. 두 끝점 중 하나라도 실패하면 쌍 전체를 정확한 N2 좌표로 되돌렸다. 선택기가 거절했던 쌍은 다시 살리지 않았다.
5. 선택 좌표에서 한 번 정한 치수 가설과 정규화 대각선을 고정하고, 혼합 좌표를 LOO로 재검사했다. 실패한 쌍만 단조롭게 거절했다.
6. 222장의 출력과 선택을 모두 저장·해시 고정한 뒤 GT로 채점했다.

새 학습·임계값 탐색·반전 검사·heatmap 검사는 없다. GPU 재추론 없이 고정 GPU 출력을 재사용했고, OpenCV LOO 계산은 CPU에서 실행했다. 검출 박스·점 confidence·중심점·후보 순서를 보존하고, 거절된 이미지를 평가에서 제외하지 않았다.

## 전체 분모를 유지한 결과

| PCK@10 | 비초록 DEV72 (555점) | 초록 GREEN150 수동 (681점) |
|---|---:|---:|
| 기존 N2 | 330 / 555 = 59.459% | 554 / 681 = 81.351% |
| 학습 선택기 | 333 / 555 = 60.000% | 533 / 681 = 78.267% |
| **학습 선택기 → LOO** | **329 / 555 = 59.279%** | **543 / 681 = 79.736%** |

LOO 추가로 비초록에서 틀린 점 1개를 회복했지만 맞던 점 5개를 잃어 순수 4개 감소했다. 초록에서는 틀린 점 10개를 회복했고 10px 기준 신규 손상은 0개여서 순수 10개 증가했다.

기존 N2와 비교하면 최종 조합의 개선/손상은 비초록 7/8점, 초록 4/15점이다. 초록에서 학습 선택기의 손상 25점 중 10점이 차단되고 **15점은 남는다**. 여기서 손상은 N2 오차 ≤10px가 보정 후 >10px가 되는 경우이며, 작은 연속 오차 변화 전체를 세는 지표는 아니다.

## 검증과 한계

- 새 순차 검사 4개 + 기존 코너 필터 11개 회귀검사 통과 (15개).
- N2/학습 선택기의 기존 프레임·평가 모드 채점 재현 744건 통과.
- 222장 최종 좌표를 별도 재검산: 선택 불가 쌍의 부활 없음, 각 출력은 정확한 N2 또는 기존 선택 좌표, 최종 수락 코너의 LOO ≤0.05 확인.
- 원래 모델·프로토콜 바인딩 검증 통과. 평가 대칭 분기 변경 0건.
- DEV72는 출처 미확인 기존 참조 좌표다. 수동 GT 기반 독립 검증으로 주장하지 않는다.
- GREEN150의 기존 source camera K와 등록 치수를 그대로 사용했다. 기존 스냅샷의 128/150 camera metadata mismatch 이력이 있으므로, LOO 통과를 물리적 정확성 보장으로 해석하지 않는다.
- 기존 사례를 본 뒤 요청된 재사용 평가다. 독립 시험이나 확정된 안전 필터가 아니며, 통과 데이터의 셀프트레이닝 효과도 이번 실험으로 확인되지 않았다.
