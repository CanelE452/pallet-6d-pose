# Replay 좌표 고정 → 8점 전체 LOO → 이미지 단위 필터

2026-09-20 KST. 사용자가 지적한 168.30px 오보정의 단독 진단을 전체 222장에 동일하게 확장했다.

## 고정한 방법

- 오른쪽 이미지의 **저장된 Replay(`POSEFIX_RAW`) 보정 좌표**가 대상이다. N2나 학습 선택기 출력이 아니다.
- 기존 raw R0 confidence 조건(박스 ≥0.85, kp confidence ≥0.5인 finite 코너 ≥6개)을 먼저 적용한다.
- 이를 통과한 이미지에서는 **신뢰도가 낮은 코너를 포함한 8개 예측 코너 전체**를 LOO에 넣는다. 8점 중 missing/nonfinite가 있으면 이미지 전체를 탈락시킨다.
- 앞선 해당 사진 단독 진단과 같은 `geometry_scores` 함수, 정규화 LOO **중앙값 ≤0.05**, 기존 등록 치수 가설을 사용한다. 최대값이나 코너별 AND 조건으로 바꾸지 않았다.
- 통과한 prediction 전체는 원본 그대로 복사하며, 탈락한 이미지는 통과 목록에서 제외한다. 코너 교체, N2 복귀, 추가 보정, 선택기, flip 검사, 임계값 재탐색 모두 없다.
- 저장된 GPU 추론 결과에 CPU/OpenCV 기하 검사만 실행했다. 학습·재추론·평가 데이터의 학습 전환은 하지 않았다.

좌표를 개선한 결과가 아니라 **이미지를 제외한 집합의 조건부 정확도**다. 전체 분모 성능 향상으로 주장할 수 없으며, 상승 전부를 LOO 효과로 돌릴 수도 없다. 초록의 동일 통과 집합에서는 Replay가 N2보다 여전히 나쁘다.

초록 통과 124장 중 박스 매칭 113장, 나머지 11장의 실패 벌점은 통과 집합 PCK에 그대로 포함했다. 비초록의 기존 참조 좌표는 수동 GT 출처가 확인되지 않았다. 초록 수동 GT와 같은 검증 강도로 해석하지 않는다.

## 앞선 44장과 구분

앞선 비초록 44장/73.021%는 **신뢰도 높은 유효 코너별 LOO를 검사해 하나라도 0.05를 넘으면 이미지 전체를 버린 방식**이다. 이번 55장/68.409%는 **8점 모두로 LOO를 계산하되 중앙값으로 판정**한 방식이다. 전자의 뒤에 후자를 추가한 순차 필터가 아니다. 평가를 보고 기준을 변경하지 않았고, 두 규칙을 혼동하지 않는다.
