# X자 교차만 검사하는 후단 필터

2026-09-20. 기존 physical_shape_filter 결과는 보존하되, 현재 요청에서는 해당 필터 대신 X 교차만 검사한다.

## 적용 규칙

- 기존 R0 confidence + 보정된 Replay의 all-eight-point median LOO 통과 집합에 적용한다. 이 집합에는 flip 검사가 추가되어 있지 않다.
- 육면체의 각 면에서 서로 마주 보는 두 경계 변의 내부가 교차하면 이미지 전체를 탈락시킨다.
- 서로 다른 면의 선이 겹치는 경우, 끝점 접촉, 일직선 겹침은 X 교차로 처리하지 않는다.
- 추가적인 카메라 앞/뒤 판정, 오목함, 면 방향 뒤집힘, 면 붕괴 판정은 사용하지 않는다. 기존 LOO는 유지한다.
- 보정 좌표 및 전체 prediction을 그대로 보존한다. 코너 선택, N2 fallback, 재보정은 없다.
- GT 없이 keep/drop을 먼저 고정한 뒤 저장된 기준점 오차로 평가했다.

## 해석과 범위

DEV72 기준점은 수동 GT로 검증되지 않은 기존 평가 기준점이다. 초록은 수동 표시된 코너만 평가하며, 미표시 코너 정확도를 보장하지 않는다. GREEN의 매칭 실패 오차에는 기존 평가 규칙의 penalty가 포함된다.

수치는 필터 후 남은 부분집합의 조건부 성능이며 모델 개선 결과가 아니다. 저장된 예측을 재사용한 필터 감사이고 재학습이나 self-training은 수행하지 않았다. 이 평가 이미지들을 학습용 pseudo-label로 사용하지 않는다.
