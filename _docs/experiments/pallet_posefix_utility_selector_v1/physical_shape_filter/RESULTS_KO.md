# 추가 기하 필터: 카메라 앞 8점 + 면 교차·뒤집힘·붕괴

2026-09-20 KST. 사용자가 지정한 두 종류의 검사만 기존 8점 LOO 통과 집합에 추가했다.

## 결론

**좌표는 그대로 보존했고, 비초록 11장·초록 6장을 추가 제외했다. 그러나 남은 집합의 PCK@20은 모두 낮아졌다.**

| 항목 | 비초록 DEV72 | 초록 GREEN150 수동 |
|---|---:|---:|
| 기존 8점 LOO 통과 | 55장 | 124장 |
| 카메라 뒤쪽/비정상 PnP 해로 추가 제외 | **0장** | **0장** |
| 면 검사로 추가 제외 | **11장** | **6장** |
| 최종 통과 | **44장** | **118장** |
| 추가 검사 전 PCK@20 | 357/421 = 84.798% | 513/566 = 90.636% |
| **추가 검사 후 PCK@20** | **277/333 = 83.183%** | **485/538 = 90.149%** |
| 추가 검사 후 동일 이미지의 N2 PCK@20 | 277/333 = 83.183% | 486/538 = 90.335% |

전체 통과는 179→162장이다. 이 비초록 44장은 예전 코너별 LOO 규칙의 44장/341점과 **다른 집합**이다. 이번에는 44장/333점이다.

## 무엇을 검사했나

### 1. 모든 코너의 카메라 좌표 깊이

기존 all8 EPNP가 구한 회전·이동으로 등록 팔레트의 8개 3D 코너를 카메라 좌표로 변환한다. 모든 z가 `max(1e-9 m, 물체 3D 대각선 × 1e-6)`보다 커야 통과한다. 중심점 또는 t_z 하나만 검사하지 않는다.

이 집합에서는 원래 LOO를 통과한 가설 중 물리적 깊이를 만족하는 가설이 모든 이미지에 있었다. 해당 가설들의 최소 코너 깊이는 비초록 약 1.009m, 초록 약 0.843m였다. 따라서 이 검사 자체의 추가 제거는 0장이다.

### 2. 여섯 면의 점 순서와 형태

고정 코너 연결 규약에서 여섯 면을 검사한다:

```text
near   (0,1,2,3)    far    (4,5,6,7)
top    (0,1,5,4)    right  (1,2,6,5)
bottom (2,3,7,6)    left   (3,0,4,7)
```

- **같은 면 내부의 자기 교차**와 오목하게 꺾인 꼭짓점을 거절한다. 서로 다른 면의 선이 원근 때문에 겹치는 것은 거절하지 않는다.
- 예측 면의 면적 또는 꼭짓점의 회전량이 수치적으로 0이면 붕괴 후보로 처리한다. 단, 해당 PnP 투영 면도 옆으로 완전히 누워 퇴화해 있으면 그 자체를 불가능한 형상으로 취급하지 않는다.
- 예측 면의 시계/반시계 순서를 **같은 PnP 투영 면의 순서**와 비교한다. 모든 면에 같은 화면 방향을 강제하지 않으며, 뒤쪽에서 찍은 정상 물체도 허용한다.
- 좌표는 예측 8점 대각선으로 정규화하고 면적·회전량의 수치 허용값은 `1e-8`로 고정했다. 의미 있는 최소 면적이나 새로운 픽셀 이동 임계값을 점수에 맞춰 선택하지 않았다.
- 등록된 치수 가설 중 **하나의 동일한 가설이 기존 LOO≤0.05, 양의 깊이, 여섯 면 검사를 모두 만족**해야 통과한다. 서로 다른 가설의 좋은 항목만 합치지 않는다.

이번 요청에 없었던 LOO 최대값·재투영 최대값 검사, 새 flip 검사, 다른 PnP 최적화는 추가하지 않았다. 두 검사를 통과한 prediction 전체는 기존 Replay와 동일하며, 탈락한 이미지의 좌표를 교체하거나 N2로 되돌리지 않았다.

## 실제 나쁜 수도레이블을 얼마나 제거했나

| 20px 기준 이미지 단위 진단 | 비초록 | 초록 수동 |
|---|---:|---:|
| 기존 통과 집합에서 실패 이미지 | 23 | 13 |
| 이번에 제거된 실패 이미지 | **3** | **0** |
| 평가 코너가 모두 20px 이내였지만 제외된 이미지 | **8** | **6** |
| 여전히 남은 실패 이미지 | **20** | **13** |

초록에서 제외된 6장의 수동 평가 코너 28개는 모두 10px 이내였다. 다만 각 사진의 수동 GT는 4~6개 코너에만 있어, **나머지 미평가 코너까지 정확한 이미지였다고 단정할 수 없다.** 검사 대상은 예측 8점 전체이며, 실제 탈락은 좁게 보이는 왼쪽/오른쪽 면의 오목한 꺾임 또는 PnP 대비 순서 불일치에서 발생했다.

비초록의 11개 탈락은 주로 위쪽/왼쪽 면의 교차·오목한 꺾임과 일부 PnP 면 순서 불일치였다. 비초록 기존 참조점의 수동 GT 출처는 확인되지 않았다.

앞서 보여준 비초록 `eval_pallet07:1778652124170068224`와 초록 3.08→30.25px 오보정 `capture_20260902_kimjihoon__002969`는 **이번 두 검사도 통과**했다. 사용자가 지적했던 168.30px 사례는 이미 이전 all8 LOO에서 탈락했으므로, 이번 두 검사가 새로 잡은 사례로 세지 않았다.

## 해석상의 제한

- PCK는 살아남은 이미지에서의 조건부 정확도이며, 전체 평가집합의 모델 성능 향상이 아니다. 모델·좌표는 바뀌지 않았다.
- 이번 수치만으로는 추가 필터가 self-training용 라벨의 평가된 코너 정확도를 높였다는 근거가 없다. 미평가 코너의 정확도 개선은 확인되지 않았다.
- 유효한 한 PnP 해가 없다는 수학적 불가능성을 증명한 것이 아니다. **기존 EPNP가 구한 가설들**에 대해 검사했다. 새 초기화·대안 해·비선형 최적화 탐색은 하지 않았다.
- 좁게 보이는 면은 작은 픽셀 오차로도 오목/방향 판정이 바뀔 수 있다. 또한 기존 source K·등록 치수를 그대로 사용했으며 초록 카메라 메타데이터 불일치 이력은 해결하지 않았다. 모든 탈락을 실제 물리적으로 불가능한 팔레트라고 단정하지 않는다.
- 예측 8점 전체가 기하적으로 일관되게 잘못된 위치에 놓이면 이 검사도 통과할 수 있다.

## 검증·보존

- 새 검사 회귀검사 **13개 통과**: 원근, 뒤쪽 시점, edge-on, 교차, 오목, 붕괴, 순서 뒤집힘, 일부 코너의 음의 깊이, 입력 불변성 등.

- 통과한 162개 prediction 전체의 원본 동등성을 별도 검산했다. 좌표·박스·confidence·후보를 변경하지 않았다.
