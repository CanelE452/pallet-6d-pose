# 정정 실행: N2 보정 좌표 고정 → 이미지 단위 LOO 필터

2026-09-20 KST. 사용자는 이미 보정한 좌표를 변경하지 말고 과거 수도레이블처럼 이미지 전체를 걸러 달라고 요청했다. 앞선 코너 선택·N2 복귀 실험은 이 요청과 다른 동작이었다.

## 이번 동작

**저장된 N2 보정 좌표를 그대로 고정 → raw R0 confidence 조건 → 기존 이미지 단위 LOO → 이미지 전체 keep/drop.**

- N2는 이미 치수 입력 보정을 적용한 최종 후보다. 새 보정이나 재추론은 하지 않았다.
- 학습 선택기·Replay·코너별 교체·N2 fallback·혼합 후 재검사 모두 사용하지 않았다.
- 통과하면 N2 prediction 전체를 내용 동일하게 복사했다. 탈락하면 그 이미지 prediction을 통과 목록에서 완전히 제외했다. 원본 이미지·라벨·모델을 삭제하거나 변경하지 않았다.
- 이전 수도레이블 F3 형식: raw R0 box confidence ≥0.85, keypoint confidence ≥0.5인 finite 코너 ≥6/8, N2 LOO 중앙값 ≤0.05. 기존 임계값 그대로이며 튜닝하지 않았다.
- LOO는 각 점을 제외해 PnP를 계산한 뒤 제외했던 점의 오차를 모아 중앙값을 구하고, 전체 PnP의 투영 cuboid 대각선으로 정규화한다. 등록 W/D 가설 중 기존 함수의 최소 점수를 사용한다. 코너별 최대값 검사가 아니다.
- 과거 2단계 적응 실험의 최종 F4는 LOO와 좌우반전을 모두 검사했다. **이번 요청에 따른 LOO-only는 F3 방식이며, F4 전체와 같다고 주장하지 않는다.**
- 별도 정정: 이전 대화에서 `N2 → Replay`라고 설명한 것은 잘못이다. 실제 저장 후보는 **R0 → N2**, **R0 → Replay**의 별도 결과다. 이번에는 N2만 사용했다.

## 남은 이미지에서의 정확도

| PCK@10 | 비초록 | 초록 수동 |
|---|---:|---:|
| 필터 전 N2 전체 | 330/555 = 59.459% | 554/681 = 81.351% |
| confidence만 통과한 N2 | 292/451 = 64.745% | 494/596 = 82.886% |
| 필터 후 N2 — **남은 이미지에서만** | **292/451 = 64.745%** | **488/590 = 82.712%** |
| 제외된 이미지의 N2 | 38/104 = 36.538% | 66/91 = 72.527% |
| 동일한 남은 이미지의 원래 R0 | 259/451 = 57.428% | 495/590 = 83.898% |

**좌표는 바뀌지 않았다.** 위 정확도 상승은 평가 대상 이미지와 분모가 바뀐 선별 결과이지 모델 성능 향상이 아니다. 필터 전후 전체 분모를 같게 둔 이전 실험의 60.00%와도 직접 비교할 수 없다.

LOO만의 추가 효과는 비초록 0이며, 초록에서는 confidence-only 82.886%보다 오히려 82.712%로 낮아졌다. LOO가 제외한 초록 1장의 수동 평가 코너 6개는 모두 10px 이내였다. 즉, 이번 결과는 LOO가 나쁜 라벨을 잘 구별했다는 근거가 아니다.

초록 통과 129장 중 118장만 박스가 매칭됐다. 남은 11장의 매칭 실패 벌점도 통과 집합 PCK 분모에 그대로 포함했다. 통과했다고 정답이 된 것은 아니다. 비초록은 기존 참조점의 수동 GT 출처가 확인되지 않았으며, 초록 표만 수동 정답으로 평가했다.

모든 평가 대상 코너가 10px 이내였던 통과 이미지는 비초록 15/59장, 초록 87/129장이다. 이 역시 관측·수동 라벨이 있는 평가 코너만의 결과이며, 8개 전체 좌표가 정확하다는 보장은 아니다.

## 보존과 검증

- GT 좌표를 읽지 않고 222장 keep/drop과 통과 prediction 목록을 먼저 고정했다. 이후 저장된 GT 기반 점수로 통과·제외 집합을 집계했다.
- 통과 prediction은 원본 N2와 좌표·중심점·confidence·박스·후보 순서를 포함해 동일하다. 좌표 변경 0개.
- 원래 모델·프로토콜 바인딩 검증 및 keep/drop 회귀검사 2개 통과.
- 별도 감사에서 222장 confidence 및 confidence 통과 189장의 LOO를 재계산해 모든 저장 점수와 일치했다. 통과 prediction 전체의 원본 동등성과 집합별 점수 분모도 재검산했다.
- 결과 확인 후 임계값·이미지 구성을 바꾸지 않았다. 기존 K·치수를 그대로 썼으며, 초록 source camera metadata 불일치 이력은 이번에 해결하지 않았다.
- 222장은 평가용이다. 이번 파일은 **평가 진단용 선별 목록**이며, 학습용 수도레이블로 내보내거나 셀프트레이닝하지 않았다.
- 원래 예측과 기존 연구 결과는 그대로 보존하고 `frozen_n2_frame_filter/`에 새 결과만 저장했다.
