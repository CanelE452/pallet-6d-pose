## 1. 최상위 목적과 수정 범위

### 1.1 이번 수정의 목표

**목표:** 교수와 심사자가 “어떤 초기 추정에 무엇을 추가했으며, 그 추가가 어떤 조건에서 코너와 자세를 개선했고 무엇은 해결하지 못했는가”를 원고만으로 판단할 수 있게 만든다.

**[확인]** 현재 원고의 중심은 **기반 추정기의 가중치를 고정하고, RGB 영상으로 얻은 초기 코너를 영상 특징과 알려진 물리적 치수로 국소 보정하는 방법**이다. 현재 주실험의 기반 추정기는 RGB만 받고, 치수는 후단 보정기와 자세 계산에 사용된다. [S1, pp.3–4, III.A·D·G; S4a–S4c]

**[확인]** 저장소에는 초기 키포인트 추정기에 치수를 직접 입력하는 별도 ResNet FULL 실험도 존재하고, 학습 완료 기록이 있다. 하지만 현재 원고의 ResNet+N3 주결과는 그 FULL 모델이 아니라, 치수 문맥을 0으로 고정해 학습한 CONSTANT 기반을 사용한다. [S4b–S4e]

**[추정]** 따라서 상류에서 먼저 구분해야 할 것은 “초기 추정기부터 치수를 입력하는 연구”와 “이미 나온 초기 코너를 치수로 보정하는 연구”다. 이 지침은 **현재 원고의 후단 보정 연구를 유지하는 편집안**을 기본으로 한다. FULL을 중심 방법으로 바꾸는 것은 단순 문장 교정이 아니라 연구 대상·비교표의 실질적 변경이므로 여기서 소급 적용하지 않는다.

## 4. 제목·초록과 ‘티키타카’ 수정

### 4.1 제목: 대칭을 빼는 것과 N3를 바꾸는 것은 다르다

**[확인]** 현재 제목은 “치수 정보와 대칭 일관성 감독을 활용한 단안 팔레트 자세 추정용 키포인트 보정”이다. 대칭 감독의 N2 대비 추가 이득은 작거나 지표별로 혼합돼 있다. [S1, p.1, p.10 표 VIII, p.16 VII.B]

**[추정] 권장 제목**

> 영상 특징과 치수 정보를 활용한 단안 팔레트 자세 추정용 국소 키포인트 보정

이 수정은 N3의 가중치·구성을 바꾸지 않는다. 제목이 실제 동작을 설명하도록 하고, 대칭의 효과가 핵심 원인으로 충분히 입증된 것처럼 읽히는 것을 줄인다. 대칭 감독은 방법과 절제 실험에서 정확히 남긴다.

‘강건한’, ‘무학습’, ‘임의 기반 독립’, ‘최고 성능’ 같은 표현은 현재 근거가 없는 범위까지 제목을 확장하므로 추가하지 않는다.

### 4.3 한국어 초록 수정 예시

**[추정] 편집안:** 현재 N3 주실험을 유지하고 확인된 수치를 재서술한 8문장 예시다. 독립 미사용 시험, 리프터 성과, FULL 직접 입력 모델의 결과를 추가하지 않았다. 근거는 [S1, pp.1·3–4·6–8, 표 VI·VII·X·XVI·XVII]다.

> 팔레트 자세 추정은 제조·물류 환경에서 화물에 접근하고 포크를 정렬하는 데 필요한 위치와 방향 정보를 제공한다. 그러나 RGB 영상에서 팔레트를 올바르게 검출하더라도 코너 위치와 대응의 오차가 남아 자세 추정의 정확도를 제한할 수 있다. 본 연구는 대표적인 직사각형·정사각형 팔레트를 대상으로, 영상 특징과 알려진 물리적 치수를 활용하는 국소 키포인트 보정 방법을 제안한다. RGB 영상만 입력받는 초기 추정기의 가중치를 고정한 상태에서 보정기를 학습하며, 초기 코너 주변의 다중 해상도 특징과 치수로 이동 후보를 점수화한 뒤 후보 변위의 확률 가중평균으로 좌표를 수정한다. 학습에는 객체의 회전 동등성을 고려한 코너 대응을 사용하고, 보정 전후의 자세 계산에는 동일한 카메라 정보와 치수를 적용한다. 반복 개발에 사용한 직사각형 실사 영상 319장에서 YOLO의 코너 오차 중앙값은 6.72에서 5.78픽셀로, 기하 재구성 참조에 대한 이동·회전 오차 중앙값은 각각 7.90에서 7.07cm, 2.54에서 2.07°로 감소했다. DOPE와 ResNet-18에도 동일한 구성의 보정기를 각각 학습·적용해 코너 오차 중앙값의 감소를 확인했으며, 별도 정사각형 영상 119장에서도 세 기반의 2차원 보정 효과가 관찰됐다. 다만 큰 오류의 변화와 대칭 감독의 추가 이득은 일관되지 않았으며, 결과는 평가한 영상과 참조의 범위에서 국소 보정의 효과를 보여준다.

**적용 조건과 주의**

- 이 예시는 국문 논리 검토용이다. 최종 영문 초록의 단어 수와 문장 밀도는 번역 후 별도로 확인한다.
- 마지막 학습 epoch의 고정, 3개 seed의 집계, 자세 참조의 생성 등 상세 규약은 본문에 정확히 남긴다.
- 위 수치는 반올림한 기존 결과다. 표의 원수치를 수정하거나 새로운 평균을 만든 것이 아니다.
- 독립적인 물리 계측 참조가 없으므로 ‘실측 정확도’라고 바꾸지 않는다.
- 현재 초록의 모든 기반 T/R 점추정 개선을 쓰려면 ResNet 위치 구간이 0을 포함한다는 한계를 본문과 맞춘다.
- learning-free, 모든 가림 강건성, 동일 가중치 전이, C4 학습 전이는 추가하지 않는다.

**[확인]** CONSTANT는 출력 좌표가 상수라는 뜻이 아니다. 실제 치수에 해당하는 문맥을 0으로 고정한 조건이며, 이미지에 따른 출력은 달라진다. 현재 기반은 그 고정 특징 변환을 마지막 층에 합쳐 RGB만 받도록 만든 모델이다. FULL은 치수로 키포인트 확률맵 이전의 특징을 조정한다. [S4b–S4e]

**[추정]** “이미지 입력에 합쳐지지 않는다”만으로 입력 여부를 설명하면 부족하다. 치수를 영상 채널에 붙이지 않고 중간 특징에 넣어도 치수 조건 모델이기 때문이다. 초기 코너 산출 이전인지 이후인지 명시한다.

### 5.2 권장 입력 설명

**[추정] 권장 문구 — III.A 교체 예시**

> 전체 시스템은 RGB 영상, 카메라 내부파라미터, 대상 팔레트의 가로·깊이·높이를 입력으로 사용한다. 본문의 주실험에서 초기 키포인트 추정기는 RGB 영상만 입력받는다. 제안 보정기는 초기 코너와 추정기의 영상 특징, 예측 박스, 물리적 치수를 이용해 코너 좌표를 수정한다. 보정기를 학습하는 동안 초기 추정기의 가중치는 고정하며, 원래 코너와 보정 코너에는 동일한 카메라 정보와 치수를 사용하는 자세 계산 절차를 적용한다.

근거: [S1, III.A·D·G, 표 V; S4a–S4c]

**[확인]** Perspective-n-Point(PnP)는 알려진 3차원 점과 영상의 대응점, 카메라 정보로 위치·회전을 구하는 문제다. 여기서는 팔레트 치수로 만든 3차원 코너와 영상상의 코너가 대응한다. [S1, III.G; S5]

| 단계 | 사용하는 정보 | 변화하는 것 |
|---|---|---|
| 초기 추정 | RGB 영상 | 초기 코너·영상 특징 산출 |
| N2/N3 보정 | 초기 코너·영상 특징·박스·물리적 치수 | 코너 0–7의 좌표 |
| 동일한 PnP | 원래 또는 보정 코너·카메라 정보·물리적 치수 | 3차원 위치·회전 |

### 5.3 치수는 ‘정사각형으로 강제하는 정보’가 아니다

**[확인]** 현재 N3에서는 치수를 인코딩해 각 국소 이동 후보의 점수에 더한다. 치수로 후보의 기하 위치를 직접 배치하거나 가려진 코너를 해석적으로 복원하지 않는다. 실제 출력은 후보 변위의 확률 가중평균이며, 원본 영상 대각선의 1%로 이동량이 제한된다. [S1, p.4, III.D–E]

**[확인]** 3차원 물체의 영상상 모양은 물리 치수뿐 아니라 회전·거리·카메라 파라미터에도 의존한다. 실제 정사각형도 비스듬히 보면 영상에서는 정사각형으로 보이지 않을 수 있다. [S5]

**[추정]** 따라서 다음 표현을 구분한다.

| 피할 표현 | 권장 표현 |
|---|---|
| 치수를 주면 정사각형 팔레트의 키포인트를 정사각형으로 맞춘다 | 치수 정보를 후보 점수에 반영해 초기 코너 위치를 보정한다 |
| 치수로 가려진 코너를 복원한다 | 관측 특징과 치수를 활용하는 국소 수정의 효과를 평가한다 |
| RGB만 받는 모델은 형태를 전혀 고려하지 않는다 | 초기 추정기에 실제 치수 숫자를 명시적으로 입력하지 않는다 |
| 치수 입력이 있으므로 모델이 물리 형상을 정확히 이해한다 | 치수를 사용할 수 있는 구조이며, 그 추가 효과는 통제 비교로 확인한다 |

### 5.4 방법 설명에서 보존할 기술적 사실

**[확인]** 다음은 원고에 명시된 현재 방법이다. 표현을 줄이더라도 의미를 바꾸면 안 된다. [S1, pp.3–5]

- 기본 모델의 내부 특징 두 수준을 보정기에 연결한다. 기반마다 특징 채널과 좌표 변환은 다르다.
- 국소 후보는 13개 방향×17개 반경의 이동 후보 221개와 무이동 후보 1개, 총 222개다.
- 무이동 후보는 이동 후보 패치를 하나 더 만드는 것과 다른 점수 분기를 사용한다.
- 치수 특징은 가로 W·깊이 D·높이 H와 두 비율 W/D, H/√(WD)에 각각 로그를 취한 5개 값이다. 길이는 1m 기준 수치이며, 학습 집합에서 정한 평균·표준편차로 표준화한다.
- 시각 점수와 치수 점수를 더한 뒤 확률을 계산한다. 후보 하나를 선택하는 방식으로 고치지 않는다.
- 원본 좌표로 이동량을 복원한 뒤 영상 대각선의 1% 상한을 적용한다. 축별 리사이즈·패딩 처리를 생략하지 않는다.
- 수정 대상은 코너 0–7이다. 중심점 8, 객체 선택, 박스, 점수, 결측 마스크를 보정 전후에 유지한다.
- 출력 보존은 정확도 보존을 뜻하지 않는다. 원래 정확한 코너가 조금 나빠질 수 있다.
- 초기 유효 점이나 특징 지원이 없는 코너를 새 검출처럼 완성하는 방법이 아니다.
- 대칭 학습에서는 초기 예측을 기준으로 전체 코너 순열 하나를 정하고, 정답 좌표와 유효 마스크를 함께 옮긴다. 각 점을 독립적으로 최근접 매칭하지 않는다.
- 최종 보정 손실의 모든 순열 최솟값을 직접 택하는 다른 목적함수라고 설명하지 않는다.
- 학습용 정답 대응 선택은 배포 추론에 들어가지 않는다. 평가 시 정답 기반 대칭 매칭은 별도로 정의한 평가 절차다.
- N3에는 추론용 C2/C4 코드 입력이 없다. 다른 N4 구성을 현재 방법처럼 섞지 않는다.
- 보정 전후에 같은 PnP 절차와 정보 조건을 사용한다. 코너가 바뀌면서 선택된 가로·깊이 가설은 달라질 수 있다.

**[추정] 작은 표기 수정:** III.A의 기반별 연결부와 III.B의 좌표 평행이동 벡터에 같은 a 기호가 쓰여 혼동 가능성이 있다. 연결부를 다른 새 기호로 바꾸는 것은 편집상 선택이지만, 기존 코드 변수 이름까지 바뀌었다고 쓰지 않는다.

## 6. learning-free, 대칭 감독, C2·C4, E_sym

### 6.1 learning-free는 현재 방법에 필요하지 않다

**[확인]** 현재 원고는 보정기를 합성 자료로 학습하고, 기반별로 학습한 보정 헤드를 사용한다. 기반 추정기를 고정한다는 사실만으로 전체 제안 방법이 무학습이 되지 않는다. PDF는 이미 “학습된 후처리이며 무학습 방법이 아니다”라고 정리했다. [S1, p.3 III.A, p.7 IV.E]

**[확인]** 교수는 상담 초반에 learning-free를 제안했지만, 학습 과정을 들은 후 46:09–47:09에서 용어 포기를 제안했다. [S2]

**[확인]** 문헌의 training-free는 이미 사전학습된 특징을 쓰면서 대상 과제에 추가 학습을 하지 않는 범위로도 사용된다. FreeZe(2024/ECCV)가 그런 예다. 따라서 ‘사전학습 신경망이 하나라도 있으면 절대 training-free가 아니다’라는 일반 정의도 정확하지 않다. 현재 방법에서는 **제안 보정기에 과제별 추가 학습이 존재한다는 점**이 직접적인 판단 근거다. [S10]

**[추정] 조치**

- learning-free를 만들기 위해 방법을 새로 설계하지 않는다.
- 필요한 설명은 “기반 추정기를 고정하고 별도 보정기를 학습한다”다.
- “추론 시 추가 학습이 없다”를 특별한 기여처럼 내세우지 않는다.
- 주 보정기 학습에 합성 감독을 쓴다는 사실을 전체 시스템의 모든 사전학습까지 무주석이었다는 뜻으로 확대하지 않는다.
- 현재 제목·초록에서 learning-free가 빠진 것은 유지한다.

### 6.2 C2·C4는 읽기 쉬운 이름으로 바꾼다

**[확인]** 현재 규약의 C2는 0°·180°, C4는 0°·90°·180°·270°의 전체 객체 회전 대응을 표현한다. 숫자는 코너 개수가 아니다. 교수도 직사각형·정사각형 표현을 권했다. [S1, III.F·그림 3; S2, 49:29–50:01]

**[추정] 적용 규칙**

| 용도 | 권장 표기 |
|---|---|
| 데이터 집단 이름 | 직사각형 팔레트 / 정사각형 팔레트 |
| 방법 설명 | 180° 회전 동등성 / 90° 간격의 회전 동등성 |
| 수식·엄밀한 정의 | 첫 등장에만 C2·C4를 병기하고 정의 |
| 그림 3의 큰 제목 | 직사각형의 회전 대응 예시 / 정사각형의 회전 대응 예시 |

**[확인]** 정사각형 지지면만으로 실제 객체·작업에 90° 동등성을 자동 부여하지 않는다는 제한이 원고에 있다. 포크 접근 구조·적재물·주석 규칙과 동등성의 관계를 유지한다. [S1, III.F·VII.B]

**[추정] 권장 문구**

> 객체의 구조와 주석 규칙에서 허용되는 회전 대응을 전체 코너에 일관되게 적용한다. 직사각형과 정사각형의 회전 대응 예시를 구분하되, 지지면의 형상만으로 실제 작업에서의 회전 동등성을 결정하지 않는다.

### 6.3 대칭 감독의 효과는 현재 결과만큼만 주장한다

**[확인]** 다음 비교는 동일한 직사각형 개발집합 319장, YOLO 기반, 동일한 8코너 평가에서의 N2와 N3 비교다. 주표의 학습 방법 수치는 각 seed에서 계산한 통계량을 3개 seed에 대해 평균한 값이다. [S1, IV.G·V.C·표 VII–VIII]

| 지표 | N2: 치수 보정 | N3: 치수+대칭 | 해석에 필요한 변화 |
|---|---:|---:|---|
| 코너 중앙값(px), 원고 본문 정밀값 | 5.777672 | 5.778161 | +0.000489px; 반올림하면 같음 |
| 조건부 코너 P90(px), 정밀값 | 42.459482 | 42.133754 | −0.325728px |
| PCK10(%) | 68.587 | 68.587 | 보고된 평균 같음 |
| E_sym | 약 0.0484219 | 약 0.0484191 | 약 −2.8×10⁻⁶ |
| 위치 중앙 오차(cm) | 7.011 | 7.068 | +0.057cm |
| 회전 중앙 오차(°) | 2.090 | 2.070 | −0.020° |
| 3차원 IoU | 0.6335 | 0.6309 | −0.0026 |

IoU는 두 영역의 교집합을 합집합으로 나눈 비율이며, 여기서는 방향을 고려한 3차원 상자의 겹침을 뜻한다.

**[확인]** 원고는 합성 학습에 C4 대응 행이 0개였고, ResNet N3 학습에서 원래 대응이 아닌 대칭 대응 선택은 0회, DOPE에서는 약 0.3%였다고 보고한다. [S1, 그림 3·VII.B]

**[추정] 판정**

- 대칭 감독의 존재와 실제로 정답 대응을 바꾼 빈도는 다르다.
- 정사각형 평가의 개선을 ‘C4 학습이 전이된 효과’라고 쓰지 않는다.
- 소수점 차이가 작다는 사실만으로 통계적 비유의성을 확정하지 않는다. 별도 불확실성·실용적 의미가 부족하다고 쓴다.
- 표 XVII의 N3−Base 구간으로 N3−N2의 대칭 추가 효과를 검정했다고 주장하지 않는다.
- 제목의 대칭 강조는 낮추되 N0·N1·N2·N3 대조 결과는 남긴다.
- N2를 더 단순한 최종 선택지로 논의할 수는 있다. 하지만 N3 결과·가중치를 N2로 재명명해서는 안 된다. 주 방법을 바꾸려면 방법·표·주장 전체가 그 실제 실행에 맞아야 한다.

### 6.4 E_sym은 아직 남아 있다

**[확인]** E_sym은 p.8에 정의돼 있고 표 VI·VIII·XX 등에 남아 있다. 따라서 ‘이미 삭제됐다’고 보고하면 틀리다. 이는 프로젝트가 정의한 대칭 고려 영상 오차이며, 영상별 평균 코너 오차를 영상 대각선으로 정규화한 뒤 영상 간 평균한다. 결측·매칭 실패에는 영상 대각선 길이의 벌점을 적용한다. [S1, IV.F·표 VI·VIII·XX]

**[확인]** 이 값은 표준 BOP 지표의 다른 이름이 아니다. BOP는 6D 객체 자세 평가 체계이고, 대칭을 고려하는 표준 거리들을 별도로 정의한다. 현재 E_sym과 직접 수치 호환된다고 쓰지 않는다. [S1, IV.F; S9]

**[추정] 권장 조치**

1. 주표에서 E_sym 열을 빼거나 보충자료로 이동하는 것을 우선 검토한다.
2. 그 전에 코너 중앙값·P90·전체 주석 분모 PCK·자세 산출률이 필요한 질문에 답하는지 확인한다.
3. E_sym을 내리더라도 전체 실패를 숨기지 않도록 PCK와 산출률·실패 분석을 남긴다.
4. 원수치와 정의는 재현 기록에 보존한다.
5. “E_sym이 개선돼 대칭 감독이 유효하다”는 해석은 제거한다.
6. E_sym 열 삭제를 대칭 감독의 효과 검증이 끝났다는 뜻으로 취급하지 않는다.

**[추정] 권장 결과 문구**

> 치수만 사용하는 구성과 비교했을 때 대칭 감독을 추가한 구성은 코너 중앙값과 PCK에서 거의 같은 결과를 보였다. 조건부 코너 P90은 감소했지만, 위치·회전 및 겹침 지표의 변화 방향은 일관되지 않았다. 따라서 이 결과만으로 대칭 감독의 일반적인 필요성을 결론 내리지 않는다.

## 7. 기준선과 비교 공정성

### 7.1 R0는 ‘보정 없음’으로 이름을 통일한다

**[확인]** 현재 원고의 R0는 보정 전 출력이고, 여러 기반 표에서는 Base로도 표기된다. 현재 비교의 중심은 합성 대 실사 학습이 아니라, 같은 초기 추정에 보정을 추가한 효과다. [S1, 표 IV·VI·XV·XVI]

**[추정]** 주표 이름은 **기본 추정기(보정 없음)** 또는 **Base**로 통일한다. 합성 학습 여부는 모델의 학습 이력에서 설명한다. 학습된 초기 추정기를 기준선으로 쓰는 것 자체는 후단 보정 연구의 목적과 충돌하지 않는다.

### 7.2 비교 이름과 변화 요인을 독자가 바로 알게 한다

**[확인]** 현재 구성의 의미는 다음과 같다. 모든 구성의 PnP에는 같은 치수를 준다. [S1, 표 IV·III.G]

| 기존 이름 | 뜻 | 주로 답하는 질문 |
|---|---|---|
| R0 / Base | 보정 없음 | 보정기를 붙인 전체 효과가 있는가 |
| P | 과거에 학습한 치수·대칭 없는 보정 | 기존 실행의 결과; N0와 동일 실행은 아님 |
| N0 | 통제 규약으로 다시 학습한 영상 기반 보정 | 치수·대칭의 추가 효과를 볼 기준 |
| N1 | 영상 기반 보정+대칭 감독 | 대칭만 추가한 효과 |
| N2 | 영상 기반 보정+치수 입력 | 치수를 추가한 효과 |
| N3 | 영상 기반 보정+치수 입력+대칭 감독 | 결합 구성의 효과 |

**[추정] 표 IV 수정**

- ‘치수 입력’ 열을 **‘보정기의 치수 입력’**으로 바꾼다.
- ‘대칭’은 추론 입력인지 학습 감독인지 구분해 **‘학습 시 대칭 감독’**으로 쓴다.
- 과거 P를 N0로 재명명하지 않는다.
- 통제된 구성요소 비교에는 N0를 기준으로 쓴다.
- P를 계속 본문에 두려면 N0와 다른 현재 질문에 답하는 이유를 명시한다.

### 7.3 비교마다 주장 가능한 효과가 다르다

**[추정]**

| 비교 | 주장 가능한 것 | 이 비교만으로 말할 수 없는 것 |
|---|---|---|
| Base 대 Base+N3 | 추가 학습된 보정 패키지의 전체 효과 | 치수만의 효과, 대칭만의 효과 |
| N0 대 N2 | 보정기에 치수 분기를 추가한 효과 | 치수 정보 내용과 추가 파라미터의 완전한 분리 |
| N2 대 N3 | 같은 치수 보정에서 대칭 감독 추가 효과 | Base 대비 전체 개선을 대칭 효과로 귀속 |
| N3 대 PoseFix 기반 보정 | 해당 구현·정보·학습 조건의 전체 방법 비교 | 모든 보정 방식에 대한 일반적 우월성 |
| 각 기반의 Base 대 N3 | 기반별로 별도 학습한 적용성 | 동일 가중치 전이·임의 백본 독립성 |
| CONSTANT+N3 대 별도 FULL | 조건을 맞춰 평가하면 입력 위치 선택에 관련된 비교 | 현재 R0–N3 결과만으로 이 비교가 완료됐다는 주장 |

### 7.4 다른 보정기 비교는 예산 차이를 구체적으로 써야 한다

**[확인]** 표 XV에서 PoseFix 기반 보정은 N3보다 코너 중앙값, PCK10, 위치·회전 중앙값에서 유리하고, N3는 조건부 코너 P90이 낮다. [S1, 표 XV]

| 지표 | PoseFix 기반 보정 | N3 |
|---|---:|---:|
| 코너 중앙값(px) | 5.561 | 5.778 |
| 조건부 코너 P90(px) | 43.907 | 42.134 |
| PCK10(%) | 68.707 | 68.587 |
| 위치 중앙 오차(cm) | 6.951 | 7.068 |
| 회전 중앙 오차(°) | 2.028 | 2.070 |

**[확인]** 이 표는 동일 319장 평가의 전체 방법 비교지만 입력·감독·학습 예산이 다른 비교가 포함돼 있다. 현재 주석은 차이의 존재를 설명하지만 모든 항목의 실제 예산을 완전히 나란히 제시하지 않는다. [S1, IV.D·표 XV]

**[추정] 반드시 보완할 항목**

- 같은 초기 예측을 받았는지, 원영상·내부 특징·치수 중 무엇을 받았는지.
- 추가 학습자료와 감독의 출처·양.
- 추가 학습량, seed, 모델 선택·온도 선택에 쓴 자료.
- 실제 재현한 원방법과 팔레트용으로 바꾼 부분.
- 처리시간·추가 파라미터 비교가 있는지.

PoseFix의 원래 입력·범용 설정과 현재 팔레트 적용 구현을 구분한다. 원방법에 없던 치수 조건을 임의로 붙인 뒤 원방법 그대로의 재현이라고 쓰지 않는다. 입력 조건이 다르면 ‘공정한 통제 비교’보다 ‘정보·예산 차이를 공개한 전체 방법 비교’라고 설명한다. [S6]

### 7.5 기반 비교는 ‘각 기반 안에서’ 읽는다

**[확인]** 현재 DOPE 연결은 원래 affinity 기반 다중 객체 연결과 다른 디코딩 경로이며, ResNet은 10-epoch CONSTANT 기반을 사용한다. 박스·점수·매칭·기본 학습 이력도 세 기반에서 다르다. [S1, III.A·표 V]

**[추정]** ‘백본만 바꾼 완전 통제 실험’으로 부르지 않는다. ‘같은 보정 원리를 각 기반 추정기에 적용한 전후 비교’로 쓴다. 모든 기반에 대해 같은 N3의 치수·대칭 구성은 유지하되, 헤드와 연결층은 기반별로 별도 학습했다고 명시한다.

**[확인]** DOPE와 ResNet-18의 보정기는 각 seed에서 6,000회 업데이트·96,000회 표본 노출로 학습했지만, 유효 고유 학습 행은 각각 44,063개·55,806개로 달랐다. 같은 추가 보정 학습 예산이 같은 유효 학습자료나 기반 추정기까지 포함한 동일 총학습량을 뜻하지 않는다는 설명을 유지한다. [S1, p.7, IV.E]

### 8.3 ‘심함이 가장 많다’는 128장 안에서만 성립한다

**[확인]** 가림 구성은 다음과 같다. [S1, 표 III]

| 집단 | 없음 | 중간 | 심함 | 미분류 | 합계 |
|---|---:|---:|---:|---:|---:|
| 직사각형 플라스틱 | 29 | 20 | 79 | 66 | 194 |
| 직사각형 목재 | 0 | 0 | 0 | 125 | 125 |
| 직사각형 합계 | 29 | 20 | 79 | 191 | 319 |
| 별도 정사각형 | 0 | 0 | 0 | 119 | 119 |

**[확인]** 29+20+79=128이며 전부 플라스틱이다. 191=66+125는 미분류다. 목재·정사각형의 가림 등급 0은 ‘그런 영상이 없다’가 아니라 ‘그 등급으로 확정한 레이블이 없다’는 뜻이다. [S1, 표 III 주석]

**[추정]** 가림 없음이 반드시 가장 많은 평가집합을 만들 필요는 없다. 실제 운용 평균을 주장하려면 실제 빈도를 반영하는 선정 근거가 필요하고, 가림 조건별 진단이 목적이면 어려운 사례가 많아도 그 목적을 밝히면 된다. 현재 원고에는 128장 선정 경위와 중간·심함의 구체적 판단 기준이 부족하므로, 지금 비율이 대표적이라고 확정할 수 없다.

**수정 조치**

1. 표 III 제목을 ‘실사 개발집합의 가림 레이블 확인 현황’처럼 바꿔, 전체 자연 분포로 오해하지 않게 한다.
2. 기존 직접 검수의 기준과 수행 이력을 확인해 데이터 설명에 넣는다.
3. 외부 가림·자체 가림·화면 밖 잘림을 구분한다는 원고의 원칙을 유지하고, 실제 판정 기준을 추가한다.
4. 과거 중간 21·심함 78과 현재 중간 20·심함 79의 차이가 난 한 프레임을 확인한다.
5. 변경 사유가 확인되기 전에는 정상적인 교정이었다고 단정하지 않는다.
6. 미분류 191장을 가림 없음으로 채우지 않는다.
7. 29/20/79를 합성 학습 분포나 실제 운용 빈도의 근거로 사용하지 않는다.

| 외부 가림 확인 코너 | 5 | 일반화하기에는 매우 제한된 집단 |
| 가시성 미확인 코너 | 2,428 | 2,499−66−5 |

**[확인]** 직접 가시 66점·외부 가림 5점은 기존 수동 검수의 **상태 정보만** 연결한 것이다. 재클릭 좌표로 기존 개발집합 참조를 교체하지 않았다. 따라서 표 XII는 기존 참조에 대한 오차를 가시성 상태별로 나눈 분석이며, 새 수동 클릭 정답에 대한 정확도 평가가 아니다. [S1, p.7 IV.C·p.12 표 XII]

**[추정]** 다음 등식·용어를 혼동하지 않는다.

- 53개는 참조 결측, 54개는 참조가 있으나 YOLO 조건부 예측 평가에 포함되지 않은 코너다.
- ‘유효 예측’과 ‘직접 보임’은 다르다. 원고의 ‘관측 코너’를 무조건 ‘가시 코너’로 바꾸지 않는다.
- PCK의 전체 분모는 **전체 주석 코너**다. 주석이 없는 모든 물리적 코너까지 평가했다는 뜻은 아니다.
- 602와 600은 두 개의 정사각형 영상집합이 아니다. 같은 119장에 대한 참조 포함 규칙의 차이다.
- 기반별 매칭 영상·유효 코너·자세 산출 영상은 같은 집합이나 단순한 포함 관계라고 가정하지 않는다.

**[확인]** 정사각형 전체/영상 안 모드의 유효 예측 수는 YOLO 597/595, DOPE 549/549, ResNet 592/590으로 보고돼 있다. [S1, 표 X]

**[추정]** 두 모드 중 유리한 수치가 나오는 쪽을 사후에 주평가로 선택하지 않는다. 사전 평가 규칙이 확인되면 그 규칙을 본문에 두고 다른 모드를 민감도 분석으로 옮길 수 있다. 사전 선택이 확인되지 않으면 두 모드와 그 이유를 유지한다.

### 8.5 재사용 개발자료를 독립 시험으로 바꾸지 않는다

**[확인]** 직사각형 319장은 반복 개발에 사용한 집합이다. 새 정사각형 119장은 한 세션·한 치수이며, 과거 696/155 실사지도 자료와 영상·개체·세션·학습 이력의 전체 대응은 미확인이라고 원고에 적혀 있다. [S1, IV.B·VII.E·부록 I]

**[추정]**

- ‘새 평가’와 ‘새로운 미사용 독립 시험’은 구분한다.
- 119장을 보고 파라미터를 다시 선택하지 않는다.
- 중복·학습 노출 이력이 확인되지 않으면 미관측 객체 일반화라고 쓰지 않는다.
- 가림 확정 128장과 업데이트 비교 128장은 개수·코너 합이 같다는 이유만으로 같은 집합이라고 쓰지 않는다. 영상 ID 대응을 확인한 뒤 관계를 명시한다.

### 8.6 자세 참조의 생성과 불확실성을 설명한다

**[확인]** 현재 직사각형의 코너 참조에는 수동 표시와 기하 보완이 포함되고, 자세 비교는 기하 재구성 참조를 사용한다. 정사각형 119장에는 독립적인 표준 자세 참조가 없어 6D 정확도는 X다. [S1, IV.B·IV.G·VII.E]

**[추정] 필요한 설명**

- 직접 수동 표시한 점과 기하적으로 보완한 점의 수·생성 규칙.
- 카메라 내부파라미터와 물리 치수의 출처.
- 참조 자세를 만든 과정, 코너 순서와 가로·깊이 축 규약.
- 같은 예측이나 동일 가정에 의존해 참조를 만든 부분이 있는지.
- 참조의 불확실성이 현재 관측된 작은 차이와 비교해 어떤 영향을 줄 수 있는지.

이전에 다른 개발자료에서 계산한 참조 잡음·비율을 현재 319장의 수치처럼 가져오지 않는다. 확인된 현재 집합의 기록으로 설명한다.

## 9. 평가지표와 통계 해석

### 9.1 px는 단위이고, 코너 오차는 직접적인 보정 지표다

**[확인]** 원고는 원본 영상에서 예측 코너와 대응 참조 코너의 유클리드 거리를 사용한다. 대칭을 허용할 때는 객체 전체 순열을 적용하며, 각 점을 자유롭게 최근접 대응시키지 않는다. [S1, IV.F]

**[추정]** 주표에는 다음처럼 지표의 대상·집계·단위를 함께 쓴다.

| 표기 | 정의·의미 | 주의 |
|---|---|---|
| 코너 오차 중앙값(px) | 유효 예측 코너 거리의 중앙값 | 실패가 빠진 조건부 통계임을 명시 |
| 코너 오차 P90(px) | 유효 예측 거리의 90번째 백분위수 | 상위 10% 평균이 아님 |
| PCK@10px(%) | 10픽셀 이내 코너 수/전체 주석 코너 수 | PCK는 Percentage of Correct Keypoints; 결측·매칭 실패는 정답으로 인정하지 않음 |
| 위치 오차 중앙값·P90(cm) | 참조 위치와의 3차원 거리 | 자세가 산출된 영상의 조건부 통계 |
| 회전 오차 중앙값·P90(°) | 허용 객체 대칭을 고려한 전체 회전 차이 | yaw 하나의 오차와 다름 |
| 자세 산출률(%) | 유효 자세 산출 영상/전체 평가 영상 | 정확도 100%라는 뜻이 아님 |
| ADD_sym·AUC | 대칭을 고려한 평균 3D 코너거리와 임계 범위 정확도 곡선 아래 면적 | 정의·정규화·실패 분모를 유지 |

**[확인]** 현재 ADD_sym은 8개 코너에 전체 객체 회전 동등성을 적용한 평균 거리이며, 자유로운 최근접 표면 대응을 쓰는 ADD-S와 다르다. AUC(Area Under the Curve)는 객체 대각선으로 정규화한 오차의 0–0.1 범위 정확도를 적분·정규화하고 실패를 전체 분모에 남긴다. [S1, IV.G]

**[추정]** 모든 지표를 주표에 반복할 필요는 없다. 코너 보정·최종 자세·실패 비율이라는 서로 다른 질문에 답하는 대표 지표를 주표에 두고, 세부 yaw·겹침·모든 백분위 결과를 보충으로 정리할 수 있다. 다만 결과가 유리해서 특정 지표만 남기는 선택은 피한다.

### 9.2 IEEE Sensors Journal과 팔레트 선행의 실제 확인 범위

**[확인]** 6-DoF Pose Estimation Using an End-to-End Pipeline of Neural Network With BP-n-P(2025/IEEE Sensors Journal)는 2차원 재투영 오차를 픽셀 단위로 보고한다. 원문 p.3843의 정의는 **참조 자세와 추정 자세로 3차원 모델을 각각 투영한 점들의 평균 거리**이며, p.3844의 표에서 결과를 보고한다. 팔레트가 아닌 LineMod 물체 실험이다. [S7a–S7b]

**[확인]** Pallet Detection And Localisation From Synthetic Data(2024/ACRA)는 수동 참조 코너와 예측 코너의 대응 거리 평균을 Keypoint Mean Error로 평가한다. 다만 원문의 픽셀 축척 표기가 모호하므로 숫자를 현재 px로 임의 환산해 비교하지 않는다. 이 논문은 IEEE Sensors Journal 게재 논문이 아니다. [S7c]

**[추정]** 따라서 ‘px를 쓰면 해당 저널에 맞지 않는다’고 볼 근거는 없다. 반대로 ‘IEEE Sensors Journal의 팔레트 논문도 지금과 같은 코너 지표를 쓴다’는 좁은 주장은 이번 확인에서 뒷받침되지 않았으므로 쓰지 않는다.

다음 세 지표는 구분한다.

1. 예측 코너 대 참조 코너: 키포인트 위치 정확도.
2. 추정 자세의 투영점 대 참조 자세의 투영점: 자세 기반 2차원 정확도.
3. 추정 자세의 투영점 대 그 자세를 구할 때 쓴 예측 코너: 내부 기하 적합 잔차.

**[추정]** 3번이 작아지는 것만으로 1번이나 실제 3차원 자세 정확도가 좋아졌다고 결론 내리지 않는다. 참조와의 정확도인지 내부 자기 일관성인지 명칭부터 분리한다.

### 9.4 코너 개선과 자세 개선은 별도로 확인한다

**[확인]** 심한 가림 79장에서 R0→N3의 코너 중앙값은 11.424→10.073px로 감소하지만, 위치 중앙 오차는 13.870→15.974cm로 증가한다. [S1, 표 XI]

**[추정]** 따라서 ‘코너가 더 정확하므로 자세도 당연히 좋아진다’는 문장을 쓰지 않는다. 코너의 어느 방향·어느 위치가 바뀌었는지, 대응·기하 조건·참조가 어떻게 작용하는지에 따라 자세 효과는 달라질 수 있다. 현재 자료로 원인을 모두 확정한 것은 아니므로 관측과 원인 가설을 분리한다.

**[확인]** 현재 학습 방법의 표 수치는 **각 seed에서 계산한 통계량의 산술평균**이다. 세 모델의 예측을 평균한 앙상블 성능이나, 모든 seed의 코너를 합친 중앙값이 아니다. seed는 모델 초기화·표본 순서 등에 사용한 난수 설정이다. [S1, IV.E–G]

- N3−Base 구간을 N3−N2의 대칭 효과 구간으로 사용하지 않는다.
- 한 촬영 세션뿐인 정사각형 자료에서 세션 간 일반화 구간을 얻었다고 쓰지 않는다.
- 같은 개발자료에 불확실성 분석을 추가한 것이 독립 시험을 대신한다고 주장하지 않는다.

### 9.7 처리시간은 추가 비용으로 설명한다

**[확인]** 표 XIV는 고정 26프레임, seed 1, RTX 3080에서 측정한 결과를 보고하며, 기반별 소프트웨어 환경 차이가 있다. YOLO의 전체 CUDA 중앙 시간은 11.195→15.138ms이고, 보정 단독 중앙 시간은 3.432ms다. [S1, 표 XIV·V.H]

**[확인] 계산:** 전체 중앙 시간 차이는 3.943ms이며, 11.195ms 대비 약 35.22% 증가다. 보정 단독 3.432ms와 전체 중앙값 차이 3.943ms는 다른 통계량이다. [S1, 표 XIV]

**[추정]**

- ‘더 빨라졌다’고 쓰지 않는다.
- 추가 파라미터가 적다는 사실을 전체 시스템의 비용이 무시 가능하다는 뜻으로 확대하지 않는다.
- 다른 보정기와 같은 조건의 비용 비교가 없으면 효율 우월성을 주장하지 않는다.

## 12. 관련 연구와 남는 기여

### 12.1 후처리·치수·대칭의 존재 자체를 신규성으로 삼지 않는다

**[확인]** PoseFix(2019/CVPR)는 기존 자세 예측을 정제하는 학습 기반 방법이다. Multi-Stage Domain-Adapted 6D Pose Estimation of Warehouse Load Carriers: A Deep Convolutional Neural Network Approach(2025/Machines)는 팔레트·하중 운반체에 대한 영역 적응과 다단계 자세 보정을 다룬다. 따라서 ‘기존 출력 뒤에 보정을 붙였다’는 사실만으로 새로운 연구라고 주장할 수는 없다. [S6; S8]

**[확인]** 위 Machines 논문의 실제 자료 평가는 참조 자세에 잡음을 더해 초기 자세를 만드는 조건을 사용한다. 현재 원고는 기반 추정기가 실제로 출력한 초기 코너에서 시작한다. 두 초기 오차의 생성 조건은 같지 않다. [S8, §4.3; S1, III.A·IV.D]

**[추정] 관련 연구에서 비교할 축**

| 비교 축 | 현재 방법에서 설명할 내용 |
|---|---|
| 초기 정보 | 실제 기반 추정기의 코너인가, 외부 초기 자세인가 |
| 추가 입력 | RGB·깊이·렌더링·내부 특징·물리 치수 중 무엇을 쓰는가 |
| 수정 대상 | 2D 코너인가, 6D 자세인가, 기본 신경망 가중치인가 |
| 수정 범위 | 국소 이동 상한이 있는가 |
| 학습·감독 | 합성 감독, 실사 감독, 무주석 적응, 기본 모델의 사전학습 |
| 적용 방식 | 기반별 학습인가, 동일 가중치 전이인가 |
| 평가 | 실제 초기 오류인가, 참조에 만든 잡음인가; 참조·분모·실패 처리는 같은가 |

현재와 다른 센서·초기화·참조 조건의 보고 숫자를 그대로 옆에 놓고 성능 순위를 만들지 않는다. 조건 차이가 있어 직접 비교하지 못하면 그 차이를 관련 연구에서 설명한다.

### 12.2 가장 강한 반론에 답해야 한다

**[추정] 반론 A: “보정기를 추가로 학습했으니 좋아지는 것은 당연한 것 아닌가?”**

- 답할 수 있는 부분: Base–N3는 보정 패키지 전체 효과를 보여 주고, N0–N3는 구성요소의 추가 효과를 나누려 한다.
- 남은 공백: 치수 정보의 내용과 추가 파라미터 효과는 완전히 분리되지 않았고, 대칭 추가 효과는 약하다.
- 원고 조치: 개선 전체를 치수·대칭 덕분이라고 귀속하지 않는다. 통제 대조와 제한적 결론을 유지한다.

**[추정] 반론 B: “다른 보정기가 더 좋은 지표도 있는데 이 방법을 왜 선택해야 하나?”**

- 답할 수 있는 부분: 현재 표는 지표별 장단점을 보여 준다. N3는 제한된 코너 수정과 내부 특징·치수 활용이라는 구조를 갖는다.
- 남은 공백: 그 구조가 경쟁 방법 대비 필요한 추가 가치를 제공하는지, 같은 정보·예산에서의 효율이 어떤지는 충분히 설명되지 않았다.
- 원고 조치: 낮은 P90 하나만으로 전체 우월성을 주장하지 않는다. 실제 비교 정보와 선택 이유를 쓰되, 증거가 없으면 그 부분을 한계로 남긴다.

### 12.3 남는 기여의 보수적인 표현

**[추정]**

> 이미 알려진 것은 키포인트·자세를 학습 기반으로 보정하고 물체 기하와 대칭을 활용할 수 있다는 점이다. 이 작업이 현재 조건에서 보여 주는 것은, RGB 초기 추정기를 고정한 채 내부 영상 특징과 알려진 치수로 제한된 코너 이동을 학습했을 때 여러 기반과 일부 팔레트 유형에서 어떤 개선과 실패가 나타나는지다. 대칭 감독의 일반적 필요성, 모든 큰 오류의 복구, 임의 기반에 대한 동일 가중치 전이까지 밝힌 것은 아니다.
