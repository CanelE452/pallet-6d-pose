## 고정 원칙

- 제목·저자·연도·학회/저널·DOI 또는 공식 식별 URL을 고정했다. 확인하지 못한 쪽수·DOI는 빈칸으로 두었다.
- 초록만 열람한 문헌은 초록이 뒷받침하는 입력·문제·방법 개요에만 사용한다. 원문의 전체 실험을 읽었다고 표시하지 않는다.
- 인용수·영향력 지수·다른 데이터의 보고 성능으로 순위를 만들지 않는다.
- 동일 논문의 온라인 공개연도와 권·호 연도, 학회 개최연도를 구분했다.
- 안정된 cite key가 고정 식별자다. PDF 숫자 인용은 본문 최초 등장 순서로 생성한다.
- arXiv 전용 연구를 성능 근거로 추가하지 않았다. Mueller 논문의 ACRA 2024 채택은 저자본의 명시를 근거로 하며 공개본의 arXiv 연도는 2025다.
