# Pallet N3 논문 미완료 항목 마감 — 리프터 제외

작업: 승인된 N3 실험의 재집계·누락 평가·원고 결과 연결. 경로: Phase 0 → 2 → 3.
대상 저장소: CanelE452/pallet-6d-pose.
대조한 원격 기준: a7fb68050e2207a5d8c379a1c1704f4e694b6675.
이 SHA는 비교 기준일 뿐 로컬을 그 상태로 되돌리라는 뜻이 아니다.

## 0. 목표와 승인 범위

최상위 목표는 이미 끝낸 실험을 근거로 국문 원고 v3의 미완료 칸을 정확하게 채우고,
남은 빈칸을 ‘계산 누락 / 원자료 없음 / 검수 필요 / 비교 불가’로 구분하는 것이다.
독자는 같은 N3 보정이 각 기반 추정기에서 무엇을 개선하고 무엇을 못 고치는지 판단해야 한다.
표의 x 개수를 줄이거나 모든 실험에서 개선을 만드는 것이 목표가 아니다.

이번 지시를 아래 범위의 구현·평가 실행 승인으로 사용한다. 계획이나 scaffold만 쓰고 멈추지 않는다.
- 기존 원시 예측·학습 완료 기록 재사용, N0/N1의 누락 자세 평가.
- 위치·회전 오차의 짝지은 분석과 기존 결과의 불확실성 보완.
- ResNet 실제 모델 명세 정정, 정사각형 분모·가림 주석 버전 정리.
- 이미 승인된 정지 이미지 집단의 유형·가림·가시성 집계 및 필요한 검수 자료 준비.
- 고정 가중치의 제한된 추론·시간 측정, 표/그림/LaTeX/Markdown 결과 연결.

이번 신규 학습 예산은 0회, optimizer update 0회다.
DOPE·ResNet N3 6회를 다시 학습하거나 ResNet 60epoch를 새로 실행하지 않는다.
자기학습, cap/temperature/threshold 재탐색, 새 loss, 대칭 증강, 추가 모델 선택을 하지 않는다.
리프터 영상·CSV·주행·추적·제어·시뮬레이션·관련 프레임 주석 작업은 전부 제외한다.
다만 기존 DEV319와 GREEN0918의 승인된 정지 이미지 평가는 포함한다.
PDF/PPT를 새로 만들거나 컴파일하지 않는다. 외부 업로드·Overleaf 동기화·push도 하지 않는다.

새 프로토콜이 필요한 변경이나 추가 학습이 발견되면 해당 분기만 보류한다.
완료된 독립 작업까지 멈추거나 이 범위 전체를 반복 승인받지 않는다.

## 2. ResNet의 실제 기준 모델 명세를 정정

현재 보고된 ResNet은 10-epoch synthetic CONSTANT 대조 모델의 고정 조건 연산을
접어 RGB-only 함수로 만든 모델이다. 60-epoch pure-RGB 모델로 바꾸어 부르지 않는다.
CONSTANT는 이미지 출력이 상수라는 뜻이 아니라 치수 조건이 고정됐다는 뜻이다.

실제 학습 receipt·체크포인트 해시·입력 경로·손실·디코더·학습 자료·선택 이력을 읽는다.
기존 PROTOCOL.json의 nested epoch60/argmax 등과 실제 실행의 차이를 항목별로 대조한다.
정확한 실행 사실을 담은 별도 effective-protocol/정정 기록을 만들고 원본 해시를 인용한다.
정정이 가중치·예측을 바꾸지 않았는지 확인한다. 과거 승인이나 선택 이유를 만들어내지 않는다.

논문과 표는 ‘ResNet-18 기반 RGB 모델 (10-epoch CONSTANT-fold)’처럼 실제 기반을 밝힌다.
같은 기반 내부의 Base→N3 효과와, 동일 총학습량의 백본 간 인과 비교를 구분한다.
여섯 N3 head 완료 기록을 다시 초기화하거나 동일 seed 학습을 반복하지 않는다.

## 3. N0/N1의 누락 6D 평가를 실제로 채움 — 첫 실행 우선순위

확인한 reuse.py에서는 DCP_ARMS에 N0/N1이 있지만,
need_pose = include_pose and arm in CORE_ARMS 조건 때문에
CORE_ARMS에 없는 N0/N1의 자세 평가를 건너뛴다.
REMAINING_X의 ‘pose 결과 없음’만 보고 입력 자체가 없다고 결론내리지 않는다.

N0_BASE_REPLAY와 N1_SYM_ONLY의 seed 1/2/3 원시 코너 예측,
대응 프레임, 카메라 내부 파라미터, 등록 치수, 기존 자세 참조의 실제 존재·해시를 확인한다.
입력이 맞으면 새 출력 위치에서 같은 기존 prediction-only PnP 평가를 수행한다.
N2/N3나 다른 seed의 자세 값을 복사하지 않는다. 단순히 CORE_ARMS를 전역 확장해
관계없는 전체 학습·리프터 파이프라인을 호출하지 않는다. 필요한 작업만 실행한다.

산출 항목:
- T(3차원 이동 오차, cm), R(회전 오차, 도), yaw(방향각 오차, 도)의 중앙값과 P90.
- IoU3D, 기존 정의의 ADDsym AUC, 자세 산출 수/전체 영상 수.
- 프레임별 자세·오차·선택 가설·실패 이유와 seed별 통계 및 평균.
- N2−N0, N1−N0, N3−N2, N3−N1의 동일 조건 차이.

예측에 정답 코너·정답 박스·정답 자세를 넣어 가설을 선택하지 않는다.
모든 방법에 동일한 객체 치수·좌표축·카메라·solver·대칭 평가 규약을 적용한다.
원래 8코너 DEV319 평가와 회귀 검사를 먼저 통과시킨다.
현재 319장/참조2499점, YOLO 조건부2445점 등은 기존 자료 재현 검사값이지,
다른 기반이나 새 주석 버전에 억지로 맞출 목표 숫자가 아니다.

## 4. T/R 불확실성과 큰 회전 변화 분석 — 새 학습 없이

동일 기반의 Base와 N3 세 seed에서 프레임 ID별 자세 산출 여부를 대조한다.
산출 수가 같아도 성공한 프레임 ID가 같은지 확인한다.
전체 모집단, 방법별 성공 집합, 양쪽 공통 성공 집합, 신규 실패·복구를 구분한다.

기존 계약의 세션 단위 paired bootstrap을 재사용한다.
seed/재표집 수/구간 방식은 실제 잠금 문서에서 확인하여 기록하고 재탐색하지 않는다.
보고할 T/R 및 가능한 yaw의 중앙값·P90 차이, 기존 2D 차이에 대해
seed별 결과와 seed 통계 평균·범위를 병기한다.

- ‘중앙값의 차이’와 ‘프레임별 차이의 중앙값’을 서로 대체하지 않는다.
- 차이는 제안−기준선으로 통일한다. 오차의 음수와 PCK의 양수 개선 방향을 구분한다.
- 직접적인 paired 오차 변화는 공통 성공 집합에서 계산하고 그 분모를 명시한다.
- 방법별 성공 집합 통계는 원래 주 표로 보존한다. 공통집합 결과를 전체 결과로 부르지 않는다.
- 전체 분모의 산출률·실패 수·ADDsym AUC를 함께 남긴다.
- seed 3개를 독립 촬영 세션 3개처럼, 같은 세션의 코너를 독립 환경처럼 부풀리지 않는다.
- 재사용 DEV의 탐색적 불확실성이다. 사후 분석을 사전등록·독립 시험으로 표현하지 않는다.
- 유효 세션이 하나인 집단에서 퇴화한 0폭 구간을 유의성 근거로 사용하지 않는다.

기존 가림 집단에서 회전 중앙값이 크게 달라진 프레임을 원시 R/T/yaw와
prediction-only 가설 선택 기록으로 대응시킨다.
대칭 대응 변화, 가로·깊이 가설 변화, 실제 코너 이동을 가능한 범위에서 구분한다.
기존 승인된 축/큰 오류 규칙을 사용하고 결과에 맞는 새 임계값을 만들지 않는다.
근거가 없으면 원인은 미확인으로 남기며, 중앙값 감소를 모든 프레임의 동일 개선으로 설명하지 않는다.
보정 실패·악화와 기술적 무결성 실패를 구분한다. 정상적인 악화 결과를 삭제하거나 재학습하지 않는다.

## 5. 정지 이미지의 유형·가림·가시성·정사각형 평가 정리

### 5-1. 정사각형의 분모와 자료 이력
GREEN0918_119의 manual_in_frame(600점)과 manual_declared(602점)를 각각 보존한다.
현재 감사에서 in-frame을 중심으로 해석한 이력과 최종 표의 선언점 모드를 대조한다.
한 표의 모든 방법에 같은 모드를 적용한다. 결과를 보고 더 좋은 모드를 선택하거나
그 선택을 평가 전에 확정한 것처럼 표현하지 않는다. 두 모드 결과와 선택 경위를 함께 남긴다.
두 화면 밖 코너 제외·포함은 프레임 ID와 좌표로 검증하고 다른 결측점을 섞지 않는다.

119장이 한 세션·한 치수라는 제한을 유지한다. 세 seed 예측을 합쳐 표본 수를 늘리지 않는다.
독립 6D 참조가 없다면 T/R은 x로 둔다. 모델 예측이나 추론용 PnP 결과를 정답으로 쓰지 않는다.
수동 2D에서 새로 자세 참조를 재구성하는 것은 이번 자동 마감에서 새로 시작하지 않는다.
이미 존재하는 유효 참조가 발견되면 출처·생성 이력·좌표축을 대조하고,
물리 계측과 기하 재구성 참조를 구분한 뒤 허용된 범위만 평가한다.
과거 S0/S1 실사 지도 자료와 새 정사각형 평가를 합치지 않는다.

### 5-2. 가림 주석 버전
현재 clean29/moderate20/severe79와 과거29/21/78의 원시 manifest를 ID별로 대조한다.
어떤 프레임의 주석·집단 membership이 달라졌는지, 직접 검수/자동 이전/다른 모집단인지 기록한다.
개수 차이를 맞추려고 특정 프레임의 등급을 바꾸지 않는다.

미분류191장과 코너 가시성에 이미 승인된 주석이 있는지 기존 원자료에서 먼저 찾는다.
있으면 출처와 대응을 검증하여 병합한다. 미분류를 clean으로 채우지 않는다.
없으면 기존 검수 도구 또는 간단한 표로 원본 이미지·프레임 ID·세션·판정 기준을 제공한다.
기계가 작성한 초안은 별도 제안으로만 저장하고 사람의 확정 레이블로 등록하지 않는다.
검수 화면에는 모델 오차·성능 순위·정답에 맞춘 성공/실패 정보를 노출하지 않는다.
과거 검수자의 예측 노출 여부를 확인 못 했으면 미확인으로 남긴다.

외부 가림 / 자기 가림 / 화면 밖 잘림, 코너의 가시성 / 참조 좌표 존재 / 기하 보완 여부를 구분한다.
기존 등급 기준이 불명확하면 새 경계값을 즉석에서 만들어 주 표를 채우지 않는다.
사람 확인이 필요한 부분만 BLOCKED_REVIEW로 두고 다른 계산은 계속한다.

주석이 추가되면 새 manifest 버전으로 전체 방법을 같이 재집계하고 기존 버전은 보존한다.
전체319장과 부분집합의 합, 유형·가림 교차 구성과 세션 수를 확인한다.
유형/가림/가시성별 P90을 평균해 전체 P90을 만들지 않는다.
주석 추가 후 결과는 ‘재분류한 개발 분석’이지 새로운 독립 시험이 아니다.

## 6. 비교 보정기·자기학습 표와 계산 비용

D/L/PoseFix의 이미 완료된 같은 319장·8코너 결과는 원시 근거를 재검산해 재사용한다.
추가 정보·지도량·학습량이 다른 전체 방법 비교를 순수한 구성 요소 하나의 효과라고 쓰지 않는다.
새로운 보정기 학습이나 기존 선행 모델의 구조 개조를 시작하지 않는다.

자기학습 대안은 노출 조건을 확인한 공통 플라스틱128장 결과로 별도 패널을 만든다.
그 패널의 R0와 N3도 동일한128장으로 다시 집계된 값을 사용한다.
319장 R0/N3 수치와128장 학생 수치를 같은 모집단 표처럼 섞지 않는다.
교사 수동 감독, 학생/교사 노출·선택 이력을 각주로 남긴다.
319장 공정 자기학습 표가 계약상 불가능하면 그 칸을 복사해 채우지 말고
128장 별도 표로 바꾼 이유와 원래 칸의 BLOCKED_CONTRACT를 변경 기록에 보존한다.

계산 비용은 기존 고정26장, 각 경로 warmup20회·5반복(측정130회), 대표seed1을 기준으로 한다.
동일 장비에서 YOLO/DOPE/실제 ResNet 기반의 Base/N3를 같은 계측 경계로 측정한다.
완전히 같은 조건의 유효한 현재 결과가 있으면 재측정을 생략한다.
기존 비교 보정기 시간도 같은 조건으로 확인 가능한 경우에만 함께 제시한다.

RGB가 메모리에 있는 시점부터의 전체 경로, N3 보정 구간, 메모리·추가 파라미터를 분리한다.
GPU 동기화·정밀도·배치·전처리·스레드·라이브러리·PnP 포함 범위를 기록한다.
환경을 통일하려고 작동 중인 의존성을 일괄 업그레이드하지 않는다.
공통 환경이 불가능하면 환경별 패널로 나누고 절대 속도 순위를 주장하지 않는다.
캐시된 특징으로 잰 시간을 전체 추론 시간이라 부르지 않는다.
기존1% cap을 유지하고2%/무제한 결과는 이미 있는 진단 표로만 보존한다.

## 7. 논문 칸별 연결과 출력 — 새 PDF 없이

표 번호만이 아니라 실제 table label·평가 집단·방법·seed·지표·단위·집계·분모로 대응시킨다.
다음은 새로 제안하는 산출 파일명이다. 기존 출력이라고 가정하지 않는다.

1) PAPER_GAP_MATRIX.csv 및 같은 내용의 Markdown
   각 칸/동질적인 칸 묶음의 원고 위치, 원래 x, 원시 출처, 평가 규약,
   값, 완료/보류 이유, 새 결과 경로, 본문 반영 여부를 기록한다.
   READY_TO_INSERT와 INSERTED를 구분한다. 결과가 있다는 이유로 원고 반영 완료로 표시하지 않는다.
2) RESNET_EFFECTIVE_PROTOCOL.json + PROTOCOL_CORRECTIONS.md
   원본 protocol/receipt는 그대로 두고 실제 모델과 잔여 명세를 대조한다.
3) N0_N1_POSE_RESULTS.json/CSV, PAIRED_POSE_ANALYSIS.json/CSV
   기존 프로젝트 형식을 재사용한다. 여기 제안한 파일명과 원자료의 키를 혼동하지 않는다.
4) STATIC_LABEL_AUDIT.md + 검수 필요 목록
   검수 미완료인 주석은 결과에 확정으로 쓰지 않는다.
5) generated_tables/ 및 결과 그림, PAPER_RESULTS_PATCH_KO.md
   LaTeX 표와 Markdown 표를 같은 수치 원천에서 생성한다.
   국문 v3가 실제로 존재하면 원본 보존 후 별도 결과 반영본에 적용한다.
   없으면 정확한 table label별 교체 조각만 제공하고 파일 전달 미확인으로 기록한다.
6) VERIFY_STATIC_RESULTS.json, FINAL_REPORT_KO.md, REMAINING_X.md
   출처→원시 행→seed별 통계→평균/범위→표→본문의 일치를 검증한다.

새 그림은 실제 정지 이미지·실험값만 사용하고 축/범례/캡션은 영어로 작성한다.
가림별 곡선, 기반별 전후 결과, 개선·무차이·악화 사례는 사전의 동일 선정 규칙을 적용한다.
설명 사례의 사후 선정이면 그 사실을 밝히고 정량 평가 집단 선택과 혼동하지 않는다.
리프터 표·그림·본문은 변경하지 않는다. 이번 잔여 목록에서 OUT_OF_SCOPE_USER로 분리한다.
42편 참고문헌을 불필요하게 재수집하거나 본문 구조를 다시 설계하지 않는다.

본문 반영 시 유지할 해석:
- 세 기반의 중앙 오차 개선과, 큰 P90·결측 복구는 별개다.
- 실제 ResNet non-identity 대칭 선택0회/C4 학습0행을 누락하거나 x로 바꾸지 않는다.
- 치수 logit 민감도는 경로 활성 증거이지 치수의 독립 정확도 효과가 아니다.
- N3가 N2/PoseFix보다 항상 좋다고 쓰지 않는다.
- 부트스트랩 구간으로 재사용 DEV의 선택 편향이나 독립 물리 참조 부재를 해결했다고 쓰지 않는다.

## 8. 무결성 검사·중단·완료 보고

기존 evaluator/검증 코드를 먼저 읽고 재사용한다. 계약과 원시 증거가 충돌하면 보고한다.
무결성 수정으로 숫자가 변하면 기존 수치를 남기고 원인·영향·새 버전·재계산을 기록한다.
원래 숫자에 맞추려고 임계값·정답·표본을 조정하지 않는다.
NaN/무한대의 실패 의미를 유지하고 실패를0오차로 채우지 않는다.
PCK fraction과%, 변화의 퍼센트포인트를 구분하며 중간 반올림은 하지 않는다.
seed별 정수 count와 평균한 분수 count를 구분한다.
통과 기준을 결과를 본 뒤 바꾸거나 임의의 개선율 합격선을 추가하지 않는다.

최종 숫자는 별도 검산 경로에서 원시 행으로 재계산한다.
완료 기록 존재만으로 검산 통과라고 하지 않으며, 검산 못 한 값의 수준을 명시한다.
같은 원본·가중치의 소규모 회귀 검사는 허용하지만 반복적인 전체 재추론은 하지 않는다.
GPU당 관련 실행은1개만 사용한다. 기존 사용자 작업은 종료하지 않는다.
학습0회 조건, 승인 집단, 원자료 해시가 깨지면 해당 작업을 BLOCKED_INTEGRITY로 둔다.
새 주석·독립 참조가 필요한 부분은 해당 칸만 보류한다.
학습 없이 가능한 정정·재집계·표 연결이 완료되면 멈추고 새로운 연구로 확장하지 않는다.

마지막 보고에는 다음을 포함한다.
- 새 학습0회/optimizer0회인지와 실제 실행 명령·소요시간·코드 변경.
- 재사용/새 계산/검산/원고 반영을 각각 구분한 항목 목록.
- N0/N1 추가 자세 결과, Base→N3의 T/R 중앙값·P90 변화와 불확실성.
- 정사각형 분모·가림 버전 정리, 여전히 필요한 사람 검수·참조 목록.
- 실제 모델 명세, 공정 비교의 범위, 유지/축소해야 할 논문 주장.
- x 유지, NA, 실제0, 사용자 제외를 구분한 최종 잔여 목록.
원시 계약이 다른 칸을 합쳐 임의의 완료율을 계산하지 않는다.
정상적으로 얻은 무차이·악화도 완료 결과다. 과학적 주장의 지지 여부는 별도 판정한다.

처음에는 현재 로컬 상태·재사용 범위·막힌 입력을 짧게 보고하고,
위 범위의 정정·재집계·검산을 실제로 진행하라.
