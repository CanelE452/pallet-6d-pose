# T/R 두 축 변화 회귀: 실행 전 고정 설계

목표는 자연 가림에서 위치 T와 회전 R을 안정적으로 함께 개선하는 것이다. 입력은 단일 RGB와 팔레트 치수이며 기존 카메라 보정 K를 유지한다. 합성 학습 수렴이나 보고서 공개를 이 목표의 달성으로 해석하지 않는다.

## 근거와 경쟁 설명

직전 [고정 RBF 실험](../pallet_pose_anchor_rbf_20261001_v1/REPORT_KO.md)은 source45/45를 통과했으나 실사 안정성2/5에 그쳤다. 자연99의 세 seed 중앙값과 P90은 모두 R0와 같았다. [고정 선택 진단](../pallet_pose_anchor_rbf_20261001_v1/SELECTOR_TRANSFER_DIAGNOSTIC_KO.md)에서는 RBF 입력 반응이 실사에서도 유지되지만 안전 개선 기회를 대부분 놓쳤음을 확인했다. 이것만으로 감독 문제가 원인이라고 확정할 수는 없다. 합성 지원범위, 기하 특징 및 이미지 단서의 부족도 경쟁 설명이다.

현재 best-candidate 정답과 max-risk margin은 각 후보의 T와 R이 각각 얼마나 좋아지거나 나빠지는지 연속적인 두 정답으로 전달하지 않는다. 다음 한 비교는 이미 존재하는 TRAIN의 두 물리 오차를 직접 감독하는 것이다. RBF 폭·센터 수·margin 배율을 바꾸는 탐색은 하지 않는다. 이전 signed2D utility 회귀 및 global RGB+MLP의 실패를 반대 증거로 유지한다.

## 고정 방법

- 동일 TRAIN2598행, 동일 raw94 정규화, 동일 RBF253과64센터·폭 및 후보 pose를 사용한다.
- 입력은 각 후보의253특징에서 운영 R0 GEO anchor의253특징을 뺀 값이다. 차분 자체를 새 정보나 일반적인 선형 argmin의 표현력 증가라고 주장하지 않는다.
- 두 정답은 각 축에서 `e=(후보 오차−anchor 오차)/기존 TRAIN scale`, `y=sign(e)·log1p(abs(e))`이다. scale은 T2.4636887551191258cm, R1.113474019956766°다.
- 공유 가중치253×2, bias0으로 두 변화를 예측한다. 유효 후보와 두 축에 Huber(delta1)를 평균하고, 전체2598행 평균에 `1e−4/2·||W||²`를 더한다. 실패1행은 데이터 loss0으로 전체 분모에 남는다. 무효 후보에서는 inf−inf를 계산하지 않는다.
- 추론 점수는 예측 두 변화의 최댓값이다. 기존 유효 whole-pose 하나를 argmin으로 고르고, 정확 동률은 기존 R0→가설 이름 우선순위를 유지한다. 실제 참조나 safe mask를 추론에 넣지 않는다. 다른 R0 가설의0점 동률 선택도 가능하므로 예측의 엄격 개선이나 실제 오차 비악화를 보장하지 않는다.
- 네 모델 각각0초깃값에서 L-BFGS-B1000반복/2000호출 이내의 최종 fit 하나만 사용한다. 재시작·좋은 epoch/seed 선택·예산 확장은 없다. optimizer 성공과 `||gradient||²/(2λ)≤1e−6`을 모두 요구한다.

Huber와 이전 CE의 목적함수 값은 서로 다른 양이므로 직접 성능 비교하지 않는다. λ의 값이 같아도 데이터 loss의 상대적인 척도가 같다는 뜻은 아니다. 수렴 검산은 이 목적함수를 최소화했는지 확인하며 실사 성능 보장은 아니다.

## 판정과 실행 경계

기존 source45조건을 전부 유지한다. 각 UNION seed가 R0_ONLY·기존R0GEO·대응DIVERSEGEO에 대해 양축 중앙값 엄격 개선, P90각축5% 이내 보존, 실패 수 비증가를 모두 만족해야 실사로 진행한다. 실패하면 그 원본 수치와 실사 미실행 기록을 공개한다.

실사로 진행할 경우 모든173장에 대한 네 모델의692개 선택을 참조 접근 전에 잠근다. 원래 SINGLE251/R0/PRIOR1/FULL125 조건과 matched 대조 조건을 항목별 AND하며, 세 seed 양축 개선·촬영/seed 불확실성·촬영 제외 민감도·자연 P90/실패 보존·clean 보존의 다섯 범주를 모두 통과해야 한다. wood45는 별도 stress이며 성공 기준을 대신하지 않는다. 어떤 행·seed·기준도 사후 제외하지 않는다.

반복 사용한 source VAL·실사 DEV이며 새로운 독립 촬영 TEST가 아니다. 기존 교사 계보의 수동 주석38코너/9이미지와 source 노출 중복도 이전 보고서와 동일하다. 새 실사 GT 학습은0개다. 평가 참조는2D 주석·K·치수에서 만든 pose로 독립 장비의 실측6D GT가 아니다.
