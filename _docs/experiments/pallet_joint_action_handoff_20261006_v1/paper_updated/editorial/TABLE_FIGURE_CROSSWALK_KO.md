# 원래 표 I–XX의 개정 위치

원수치나 실험 구성을 바꾸지 않고 질문별로 통합·이동했다. 아래 쪽수는 동봉 XeLaTeX PDF 기준이며 다른 엔진에서는 달라질 수 있다.

| 기존 표 | 역할 | 개정 위치 | 조치·이유 |
|---|---|---|---|
| I | 관련 연구 비교 | 본문 표 I, 3쪽 | 가까운 선행의 입력·수정 대상에 맞춰 축약; 본문 42개 인용 유지 |
| II | 자료 역할 | 본문 표 II, 5쪽 | 분할 존재와 실제 평가 사용 구분; 128장 대안 역할 추가 |
| III | 가림 구성 | 본문 표 III, 6쪽 | 검수 현황으로 변경; 등급 미확인·0의 의미 명시 |
| IV | 절제 설정 | 본문 표 IV, 6쪽 | 보정기 치수 입력/학습 시 회전 대응으로 열 이름 명시; P는 구성요소 기준에서 분리 |
| V | 기반별 세부 설정 | 보충 표 SI, 2쪽 + 본문 III·IV절 | 세부 채널·간격을 보충으로 이동; 실제 CONSTANT 기반과 FULL 분리 |
| VI | YOLO 코너 주효과 | 본문 표 V·VIII + 보충 표 SIII | 반복 Base/P/N2/N3 주표 제거; 핵심 수치는 적용성·절제·비교 표에서 보존 |
| VII | 상세 자세 | 본문 표 V·VII + 보충 표 SII, 2쪽 | 본문 위치·회전과 N0–N3 비교 유지; 전체 yaw/IoU/AUC는 보충 |

| XI | 가림별 성능 | 본문 표 X, 10쪽 + 보충 표 SVI, 4쪽 | 본문 Base/N3의 전체·각 등급·미확인 유지; P/N2는 보충 |
