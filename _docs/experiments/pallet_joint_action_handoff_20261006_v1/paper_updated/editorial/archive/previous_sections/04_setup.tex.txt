\section{실험 설정}\label{sec:setup}
\subsection{평가 질문과 원천 자료}
실험은 세 질문을 중심으로 구성한다. 첫째, 같은 추정기에서 보정 전후의 영상 좌표와 자세 오차가 얼마나 달라지는가. 둘째, 치수 정보와 대칭 일관성 감독의 추가 효과가 어떤 지표와 조건에서 나타나는가. 셋째, 이러한 보정이 다른 기반 추정기와 실제 주행 관측에서도 유지되는가. 기존 전체 평가를 유지하면서 유형·가림별 분석과 여러 추정기 비교를 확장한다. 추가 평가의 수치가 확인되지 않은 칸은 x로 표시한다.

[확인] 수치의 기준은 2026년 10월 2일 게시된 저장소 고정본 \texttt{7e136fc}의 비리프터 마감 결과이다. 기존 YOLO 주 결과는 원시 좌표 재평가에서 그대로 재현되었고, N0/N1의 누락 자세 평가, 세 기반의 자세 불확실성, 유형·가림·부분 가시성 및 추가 시간 측정을 함께 반영하였다. 수치별 원천 CSV와 Git blob 해시를 동봉해 표의 단위·분모·seed와 연결하였다. 이전 9개 점 평가와 본문의 8개 코너 대칭 평가를 혼합하지 않는다.

\subsection{학습 자료와 실사 평가 집합}
합성 자료의 등록된 분할은 학습 55,980개, 보정 설정용 calibration 1,004개, selection 1,031개, held-out 1,985개이다. 역할이 다른 분할을 실사 평가 결과를 보고 재배치하지 않는다. 주 보정기 추가 학습에는 합성 감독을 사용하지만, 기본 추정기의 이전 일반 영상 사전학습까지 포함하여 전체 시스템이 실사 레이블을 전혀 사용하지 않았다고 표현하지 않는다.

주 실사 집합은 직사각형 팔레트의 319개 영상으로 구성된 재사용 개발 집합이다. 전체 319장에서 코너 감독이 존재하며, YOLO에서 기존 객체 매칭 규약을 통과한 영상은 311개이다. 코너 0--7의 전체 감독 분모는 2,499점이고, 조건부 정밀도 계산에 사용되는 매칭·관측 가능 예측은 2,445점이다. 수동으로 표시되거나 기하적으로 보완된 참조의 성격을 고려해야 하며, 이 집합을 새로운 미사용 시험 집합으로 명명하지 않는다.

정사각형 GREEN0918은 플라스틱 팔레트의 119개 영상, 한 촬영 세션과 등록 치수 $[1.1,1.1,0.15]$m로 구성된다. 고정된 YOLO R0·P·N2·N3 및 DOPE·ResNet의 Base·N3를 동일 영상에 적용했다. 수동 선언 코너 602점의 전체 모드와, 영상 경계 안 좌표만 포함한 600점 모드를 별도로 보고한다. 두 모드를 합치거나 유리한 지표만 선택하지 않는다. 독립 표준 자세 참조가 없으므로 6D 정확도는 x로 남긴다. 과거 696장 학습·155장 개발 평가의 정사각형 실사 지도 기록은 부록~\ref{sec:historical_square}에만 남기며, 이번 결과로 대체하지 않는다. 두 자료의 개체·촬영·학습 이력 전체 대응은 미확인이다.

\subsection{유형과 가림 정도에 따른 추가 평가 설정}
추가 평가에서는 형상과 재질을 별도 속성으로 기록한다. 직사각형 플라스틱·직사각형 목재·새 정사각형을 각각 평가하고, 집단마다 동일한 고정 모델과 같은 평가 규약으로 보정 전후를 비교한다. 세션 수·서로 다른 개체 수·치수·학습 사용 여부는 원자료 목록으로 확인한다. 미사용 영상이라는 사실만으로 미관측 물체 일반화가 성립하는 것은 아니며, 새 정사각형 평가 전에 그 영상을 이용해 재학습하거나 설정을 고르지 않는다.

외부 가림은 기존 직접 검수에서 가림 없음·중간·심한 가림으로 분류한 상태를 사용한다. 이번에 연결한 128장은 각각 29·20·79장이며, 수치 결과를 보고 새 임계값을 만들거나 미분류 191장의 등급을 추정해 넣지 않았다. 현재 직접 검수 버전과 과거 분할 파일은 한 프레임의 중간·심함 분류가 다르며, 변경 시각과 사유는 미확인으로 기록했다. 자기 가림·외부 가림·화면 밖 잘림을 혼동하지 않고, 기존 검수의 사전 예측 노출 여부가 확인되지 않았다는 한계를 남긴다. 표~\ref{tab:composition}은 확정 레이블과 미분류를 모두 포함한다.

코너 가시성은 기존 수동 상태 검수의 직접 가시 66점과 외부 가림 5점을 영상 해시·코너 ID로 연결했다. 재클릭 좌표는 기존 DEV 참조와 달라 교체하지 않고, 상태 정보만 재사용하였다. 따라서 이 분석은 기존 참조 오차를 가시성 상태별로 나눈 것이며 새 수동 클릭에 대한 정확도 평가가 아니다. 나머지 2,428점은 가시성 미확인으로 남긴다. 좌표가 존재한다는 사실이나 기하 재구성으로 가시성을 대체하지 않으며, PnP 보조 검수 이력과 사전 예측 노출 미확인을 제한으로 기록한다.

\subsection{전체 방법·구성 요소·여러 추정기의 비교}
전체 방법 비교, 구성 요소 절제, 기반 추정기 적용은 서로 다른 질문이다. 주 결과에는 보정 없는 R0, 치수 없는 국소 보정 P, 치수 입력 N2, 치수와 대칭 감독 N3를 제시한다. 여기서 ``치수 없음''은 \emph{보정 신경망의 입력}에 한정되며 모든 경로의 PnP는 같은 물리적 치수를 사용한다.

전체 방법 표에서는 직접 회귀 D, 선 구조 보정 L, PoseFix 기반 보정과 N3를 비교한다. 입력, 학습 자료와 비용이 다르면 그 차이를 공개하고, 최종 오차의 차이를 구성 요소 하나의 인과 효과로 해석하지 않는다. 특히 D/P는 출력 방식과 손실이 함께 다르므로, 그 비교만으로 분포 표현만의 효과를 분리하지 못한다. 기존 선행 보정기를 임의로 치수 입력 모델로 개조한 뒤 원 방법의 재현이라 부르지 않는다.

구성 요소 비교는 같은 기본 추정기와 동일한 학습·평가 조건 안에서 수행한다. 과거 P 가중치의 결과는 보존하고, 순수한 추가 효과는 같은 초기화·표본 순서로 재현한 치수 없는 보정 N0를 기준으로 확인한다. 코드에 있는 N1(대칭만), N2(치수만), N3(둘 다)의 관계를 표~\ref{tab:ablation_contract}로 고정한다. N0/N1의 8코너 재평가와 누락 자세 계산을 완료하였다. 과거 P를 N0로 재명명하거나 다른 집계값을 복사하지 않았다.

\subsection{학습·설정 선택과 비교 예산}
확인된 YOLO N2/N3는 세 seed(초기화·표본 순서)별로 학습했다. 각 실행은 batch 16, 6,000회 업데이트, 총 96,000회 표본 노출이다. AdamW의 기준 학습률은 $10^{-3}$, 가중치 감쇠는 $10^{-4}$이며 처음 100회는 준비 구간, 이후는 코사인 감소를 사용한다. 마지막 학습률은 기준의 0.1배이고 기울기 노름 상한은 5이다. 6,000회째 최종 가중치를 사용한다.

학습 손실은 온도 1로 계산한다. 추론 온도 후보 $\{0.5,1,2,4\}$는 합성 calibration(설정 보정) 집합에서 모든 구성에 같은 고정 번호 목표 분포의 교차엔트로피를 적용해 선택한다. 대칭 감독의 정답 선택을 이 보정 기준에도 임의로 적용하지 않는다. 후보 수·이동 상한·실사 결과를 보고 온도를 재탐색하지 않는다. 새 정사각형은 고정 모델 그대로 평가하며, 과거 정사각형 보조실험의 온도 1 규약을 새 평가에 임의 전용하지 않는다.

DOPE·ResNet-18도 각각 3개 seed에서 6,000회 업데이트와 96,000회 표본 노출을 수행하였다. 두 기반의 새 보정 학습 합계는 36,000회 업데이트와 576,000회 노출이며, 기본 추정기는 고정하였다. 여섯 실행의 추론 온도는 합성 calibration에서 모두 1로 선택되었다. 같은 추가 보정 학습량이 기본 추정기까지의 동일 총학습량을 의미하지는 않는다. 유효 고유 학습 행은 DOPE 44,063개와 ResNet 55,806개로 달랐다. 이번 비리프터 마감은 이미 완료된 가중치의 평가·검산이며 추가 최적화는 수행하지 않았다.

\subsection{영상 좌표 평가}
기본 정밀도는 정답 대응 코너와 예측 코너 사이의 원본 영상상 유클리드 거리이다. 대칭을 허용하는 평가는 영상마다 하나의 전체 객체 순열을 선택한 뒤 코너들을 비교하며, 점별로 독립적인 최근접 대응을 허용하지 않는다. 코너 중앙값과 P90은 매칭된 유효 예측을 모아 계산한다. P90은 오차 분포의 90번째 백분위수이다. 같은 기반의 보정 전후에서는 고정한 객체 선택·유효성 마스크에 의한 같은 코너를 비교한다. 기반 간에는 매칭 성공 집합이 다를 수 있으므로 조건부 중앙값만으로 절대 성능을 순위화하지 않고 전체 분모 PCK와 매칭·자세 산출률을 함께 제시한다.

실패를 분모에서 제거하는 평가를 피하기 위해 Percentage of Correct Keypoints(PCK), 즉 임계 거리 이내의 정답 코너 비율을 함께 보고한다. 본문의 PCK10은 원본 영상에서 10픽셀 이내인 코너 수를 전체 감독 코너 수로 나눈 값이다. 결측·매칭 실패 코너에는 정답으로 인정하지 않는 벌점을 적용한다. 각 방법의 중앙 오차가 다른 표본을 조건부로 사용하지 않도록 분모와 매칭 수를 함께 확인한다.

$E_{\mathrm{sym}}$은 이 프로젝트에서 정의한 대칭 고려 영상 오차로, 영상별 평균 코너 오차를 해당 영상 대각선으로 나눈 뒤 평균한 값이다. 평가 코드에서는 결측·매칭 실패에 영상 대각선 길이의 벌점을 적용한다. 이 지표는 표준 BOP 지표의 다른 이름이 아니며, 정의와 실패 처리를 함께 제시해야 한다. 대칭의 평가상 모호성을 명시한다는 원칙은 BOP\cite{bop2018}와 연결되지만 수치가 직접 호환되는 것은 아니다.

\subsection{자세·집계·불확실성}
이동 오차는 추정 위치와 참조 위치 사이의 3차원 유클리드 거리이고, 회전 오차는 허용된 객체 회전 집합 안에서의 최소 geodesic 각도이다. 참조 회전 $\R^*$, 추정 회전 $\hat\R$, 허용 회전 $Q\in\mathcal G$에 대해 다음과 같이 정의한다.
\begin{align}
 e_t&=100\|\hat\tvec-\tvec^*\|_2\quad[\mathrm{cm}],\\
 e_R&=\frac{180}{\pi}\min_{Q\in\mathcal G}\arccos\!\left[\operatorname{clip}\!\left(\frac{\operatorname{tr}((\R^*Q)^\top\hat\R)-1}{2},-1,1\right)\right].
\end{align}
위 식의 이동 벡터는 미터 단위이고 회전 출력은 도 단위이다. 방향각 오차와 전체 회전 오차는 같은 물리량으로 취급하지 않는다. 방향을 고려한 3차원 교집합-합집합 비율을 $\mathrm{IoU}_{3D}$로 보고, 대응 코너 8개에 대해 객체 전체 회전 동등성을 적용한 평균 변환 거리를 $\mathrm{ADD}_{\mathrm{sym}}$으로 보고한다. 이 값은 자유로운 최근접점 대응을 사용하는 ADD-S와 다르다. AUC(정확도 곡선 아래 면적)는 객체 대각선으로 정규화한 오차에 대해 0--0.1 임계 범위의 정확도를 적분·정규화한 값이다. 자세 실패는 전체 분모에 남긴다. 이동·회전 중앙값은 해가 나온 영상에 조건부이므로 산출률을 같이 보고한다. 전체 자세 평가에는 정답 박스 매칭을 추론 입력이나 성공 게이트로 사용하지 않는다.

학습한 방법의 표 수치는 각 seed에서 별도로 계산한 통계의 산술평균이다. 세 모델 예측을 평균한 앙상블 성능이나 세 seed의 모든 코너를 한꺼번에 모은 중앙값이 아니다. 불확실성은 13개 촬영 세션을 단위로 10,000회 짝지어 재표집하고, 각 재표집 안에서 세 seed의 통계량 차이를 평균해 2.5·97.5 백분위 구간을 계산하였다. 초기 난수 seed는 20260917이고 동일한 재표집을 사용한다. $\operatorname{median}(e_{\rm after})-\operatorname{median}(e_{\rm before})$와 $\operatorname{median}(e_{\rm after}-e_{\rm before})$를 구분하며, 전자를 주 표의 변화량으로 사용한다. 각 seed의 성공 프레임 ID 집합은 보정 전후 같았으며 실패는 전체 산출률·AUC의 분모에 남겼다. 이 구간은 반복 개발 집합의 사후 기술 통계로, 다중비교나 개발 중 선택 편향을 보정한 독립 확증이 아니다. 정사각형 한 세션의 세션 간 일반화 구간은 정의할 수 없다.


\subsection{큰 오류와 연속 영상의 추가 분석 규약}
큰 오류 분석에서는 보정 전후에 동일한 코너 참조와 대응을 유지하고, 초기 오차가 허용 이동 범위 안인지 밖인지 구분한다. 범위 밖 여부는 오류 원인 진단용이며 표본 제외나 추가 학습 선택에 사용하지 않는다. 오검출·잘못된 코너 대응·참조 이상 여부는 원영상 검토 항목으로 남긴다. 같은 코너의 개선·무변화·악화를 집계하고, 점별 임의 대칭 재매칭으로 이동 상한의 효과를 바꾸지 않는다. 기존 주 지표는 각 예측의 허용 전체 대응을 사용하지만, 이동 상한 진단은 기준 예측에서 고정한 전체 대응을 보정 후에도 사용해야 한다. 두 집계를 따로 명명하고 서로의 수치를 대체하지 않는다.

주행 영상은 두 고정 모델을 동일한 프레임에 적용하는 오프라인 평가이다. 시간 대응이 확인된 CSV로 동작 구간을 구분하되, 운용 모델의 추정값이나 제어 명령을 물리 정답으로 사용하지 않는다. 정지 구간의 변동과 이동 중 실제 상태 변화를 구분하며, 자세가 새로 계산된 프레임과 이전 값 유지 프레임을 따로 기록한다. 이 실험은 제어 성공률이나 정렬 시간 개선을 측정하지 않는다.
