## 이번 작업의 범위

이 개정은 게시된 결과를 원고에 실제 삽입한 작업이다. 모델 학습, 추론, 새 PnP 실험, 부트스트랩 재실행, GitHub 변경, Overleaf 계정 동기화는 하지 않았다. GitHub CSV와 게시된 결과·감사 기록을 대조하고, LaTeX 표를 원천 CSV로부터 생성하여 컴파일했다. 실행 기록이 보고한 해시 검산·43개 테스트와 이 패키지에서 직접 수행한 원고/CSV/컴파일 검증은 구분한다.

리프터는 이전 요청의 비리프터 범위를 유지한다. `sections/06_case_study.tex`는 직전 Sensors ZIP과 바이트 단위로 동일하며, 이미 별도로 존재하는 리프터 결과를 이번에 삽입하지 않았다. 그 절의 x는 이번 개정에서 보류한 칸이지 최신 저장소에 리프터 관련 기록이 전혀 없다는 뜻이 아니다.

## 본문·그림 수정

초록·서론의 “DOPE/ResNet·정사각형 미평가” 설명을 현재 완료 상태로 고쳤다. 방법과 실험 설정의 입력·후보·손실 정의는 유지하고, 실제 ResNet이 10-epoch CONSTANT-fold RGB 모델이라는 점을 명시했다. CONSTANT는 치수 문맥이 고정된 것이며 이미지 출력이 상수라는 뜻이 아니다.

전체 과정과 내부 구조 그림의 ‘N3 완료 x / 연결 미검증’ 문구만 실제 완료 상태로 바꾸고 원본 벡터 도식을 재컴파일했다. 대칭 감독 그림의 C4 예시는 승인 대응의 개념 설명일 뿐 이번 합성 자료에 C4가 있었다는 뜻이 아님을 캡션에 명시했다.

비어 있던 가림 결과 그림은 검산된 CSV의 **PCK10 막대 그림**으로 교체했다. 이것은 GitHub의 `occlusion_pck.png`를 복사한 것이 아니며, 전체 누적분포를 재현했다고 주장하지 않는다. 해당 그림의 캡션과 소스에 단일 임계값(10px) 비교라고 명시했다. 기존 상담 사례 그림은 과거 자료로 유지하고 최신 실패 사례를 내려받아 검수한 것처럼 표시하지 않았다.

참고문헌 42편과 `references.bib`를 보존했다. 이번에는 선행 42편의 원문을 전부 재검토한 것이 아니라 이전 reference lock을 유지했다. 추가 수치는 동봉된 저장소 결과 원천으로 추적한다.

## 결과 해석에서 바꾼 부분

- 세 기반의 중앙 코너 오차·PCK10 개선을 반영했다. 기반별 조건부 매칭 집단이 달라 절대 백본 순위로 해석하지 않는다.
- YOLO/DOPE의 이동·회전 중앙값 사후 구간은 음수지만, ResNet 이동 중앙값 구간은 `[-2.077, +0.202] cm`로 0을 포함한다. 모든 6D 지표의 확증적 개선으로 쓰지 않았다.
- DOPE 코너/회전 꼬리와 ResNet 이동 꼬리의 혼합·악화 결과를 보존했다.
- 정사각형 N3는 Base보다 개선됐지만 N2 대비 추가 이득은 지지되지 않았다.
- ResNet 비항등 대칭 목표 선택0회, 합성 C4행0은 실제 관측이며 x로 바꾸지 않았다.
- 가시성71점은 상태만 재사용했다. 재클릭 좌표나 독립 수동 참조를 새로 확보한 것으로 표현하지 않았다.
- 319장 학생 비교는 동일 비노출 계약을 만족하지 않아 128장 별도 비교로 재구성했다. 해당 표의 R0/N3도 128장 값으로 변경했고 319장 기준선과 섞지 않았다.

## 검증 경계와 형식

14개 CSV는 GitHub connector에서 읽은 텍스트를 원본 줄바꿈으로 복원한 뒤 Git blob SHA-1과 바이트 단위로 일치함을 확인했다. `evidence/SOURCE_MANIFEST.json`은 원천 경로·커밋·blob SHA-1·SHA-256·크기를 보관한다. 이 검증이 로컬 전체 원시 체크포인트에 대한 독립 추론 재실행을 뜻하지는 않는다.

공급받은 `ieeecolor.cls`, `jsen.sty`, `IEEEtran.bst`를 수정하지 않았다. 권장 엔진은 XeLaTeX이고 `main.tex`가 유일한 주 문서이다. pdfLaTeX에서는 fontspec을 읽지 않는 기존 호환 경로도 유지했다. 최종 패키지의 실제 빌드·인용·글리프 검증과 렌더 점검 기록은 `audit/BUILD_VALIDATION.json`을 참조한다.

이번 파일은 결과 반영 **국문 검토본**이다. 영어 투고 원고, 저자정보 확정, 분량 조정과 독립 평가까지 완료한 최종 투고본이 아니다.
