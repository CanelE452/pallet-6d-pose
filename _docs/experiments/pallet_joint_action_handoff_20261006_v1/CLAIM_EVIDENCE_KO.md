# 주장과 증거의 범위

[확인] 새로운 A 결과는 개발자료에서의 탐색적 증거야. 최종 수치는 `results/A_summary.json`의 전체 세 seed와 `results/A_REAL_DEV_COMPARISONS.json`의 같은 세션·seed 평균 대비를 기준으로 해석해. 좋은 seed만 고르거나 전체 N3 headline을 교체하지 않아.

| 주장 | 현재 근거 | 해석 한계 |
|---|---|---|
| 기존 전체 N3 보정은 Base보다 평균적인 DEV 오차가 낮아 | 기존 319장/13세션·세 seed, C 수정 표와 그대로 보존한 evidence 42파일 | 반복 사용 DEV, 실제 독립 6D 참조 아님 |
| 치수/대칭 요소가 전체 개선을 주도해 | 치수 추가 약 −0.1662 px, 대칭 추가 +0.0004884 px, 혼합 지표 | 이 주장은 확립하지 못해. metadata와 용량 효과도 완전히 분리하지 않았어 |
| 고정 기하 후보에 최종 자세 개선 여지가 있어 | source GEO oracle positive 954/1,031, median headroom 0.011915445 m, 실제 F(q) | oracle 정답 사용·오프라인 상한, 선택 모델의 이익 아님 |
| 후보 결합만으로 practical N3/PoseFix보다 좋아져 | 최종 GEO−PERM, J−I, practical baseline 직접 대비·CI·손상·실패와 runtime | 실제·synthetic 모두 N3/PoseFix 대비 정규화 오차 악화. 실제 PERM 대비 음의 구간도 손상 보존 미충족, synthetic PERM 대비 악화. 실용 개선 주장은 기각해 |
| 2D 개선은 물리 6D 개선을 보장해 | 기존 같은 311장에 2D 개선 후 위치 악화 98/78/100장, 새 paired pose 결과 | 보장하지 않아. 원래 참조는 같은 2D+기하 재구성이야 |
| PoseFix보다 N3가 항상 정확하고 빠르게 동작해 | PoseFix 중앙값 우세, N3 P90 우세, 동일 장치 전체경로 wall-clock | 정확도의 모든 지표를 지배하지 않아. 입력·loss·감독·예산이 다른 전체 방법 비교야 |
| 실제 가림에서 독립 정확도를 평가했어 | 취득 schema/import/validate/evaluate 완료, 실제 pair 0개 | `BLOCKED_DATA`. 형식 fixture나 9,029 기존 관측으로 대체하지 않아 |
| 정사각형/다른 backbone/다른 세션의 일반화가 증명돼 | 정사각형 119장/한세션, 별도 backbone별 가중치·조건부 자세 분모 | 범용 일반화·독립 계측·물리 포크 성공으로 확대하지 않아 |
| 참고문헌과 문장의 지지가 모두 확인됐어 | 전체 46개 metadata 확인, 기존15수정, 신규4; TSV에 문장/원문 범위 구분 | metadata만 읽은 항목의 전문 구현 확인을 주장하지 않아 |
| 논문이 제출·게재 가능하고 합격이 보장돼 | 한국어 main/supplement 실제 개정·빌드·시각 검토 | 최종 영문/저자 소속·독립 물리 증거 미완료, 게재 결과 예측하지 않아 |

[확인] 실행 완료와 과학적 증거 완료는 다르게 기록해. 단순 후보 여지, 실제 선택/학습의 이익, 손상·실패·비용, 독립 참조 확보 중 어느 질문을 확인했는지 각각 상태와 원행을 보존해. 이번 고정 예산 뒤 모델·cap·loss 재탐색을 연쇄 실행하지 않아.
