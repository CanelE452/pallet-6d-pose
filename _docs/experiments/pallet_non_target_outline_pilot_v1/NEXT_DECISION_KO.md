# 다음 의사결정

**현재의 ‘비대상 끝점에 의존한 부모 전체를 결측으로 처리’하는 가설의 운영 채택을 보류한다.** 이번6장 결과를 근거로 자동 공급기 설치·학습·운영 selector 교체를 다음 작업으로 자동 진행하지 않는다.

새 입력은 실제로 공급됐다. 원 RGB만 본 별도 모델의 점/박스 지시, 고정 MobileSAM의 새 마스크3개, 원 끝점 membership, G10/G13의351개 원 retained 후보 평가와18개 최종 출력을 연결했다. 주경로는2장 후보와1장 family를 바꿨다. 따라서 실패 원인은 API가 비어 있거나 지지 필드만 추가한 데 있지 않다.

하지만 공동성공 회복은0이다. 세 경로 모두2/6이며 주경로의 위치 평균29.285cm는 정보량을 맞춘 전체 약화 대조군25.664cm보다 높다. 주경로의 회전 평균22.925°가 대조군23.018°보다 조금 낮지만, 사후 설명 사례6장의 수치이며 통계적 또는 자동 성능 우위가 아니다. 사례2는 두 경로 모두 family를 바꿨고, 사례4는 두 경로 모두 같은 더 나쁜 후보로 바뀌었다. 성공 반례2장은 입력이 없어 원 e가 유지된 사례여서 실제 censoring 후의 안전성을 시험하지 못했다.

특히 wood_day_01:005286의 주경로는 observed mass의8.897%, 최종 후보의 model arc mass8.721%만 남겼다. 실제 후보31과 참조상 성공 후보33의 G13 비용은 각각0.006629500/0.007038028로, 남은 비용은 여전히 실패 후보를 앞세웠다. plastic_day_01:020955도 같은 family의 성공 후보9보다 더 나쁜 후보1의 점수가 낮았다. 긴 부모를 함께 없애면서 유용한 지지가 줄 수 있고, 남은 전역 cuboid 외곽 비용이 참조상 성공 자세를 구별하지 못할 수 있다. 이번 자료로 어느 요인이 주원인인지 분리하지 않았다.

가장 가까운 단순 대안인 `MASS_MATCHED_CONTROL`은 이번 시험의 같은 mask·같은 후보·같은 방향별 retained mass를 사용한다. 이 대조군보다 특정 잔차를 구분한 추가 가치가 확인되지 않았으므로, 콘 검출 자동화부터 확대하면 해결될 것이라고 결론내리지 않는다. 이것은 모든 contour 처리나 모든 비대상 입력이 무용하다는 결론도 아니다. **이번 고정된 whole-parent censor 규칙의 채택 근거가 부족하다는 판단**이다.

AUTO 공급기는 확보되지 않았다. 보유 COCO80 모델에 cone 클래스가 없고, 확인한 로컬 범위에서 cone 의미 공급기의 실제 API·가중치·라이선스 조합이 없다. Grounding DINO 등의 새 도입은 별도 범위·자원 변경이므로 이번 결과를 이유로 실행하지 않는다. 향후 별도 승인이 생기더라도 입력 보조6장의 평균 개선을 AUTO238 성능으로 넘겨 쓰지 않아야 한다.

새 threshold·팽창·프롬프트·부모 분할·대체 loss를 이6장에 맞춰 탐색하지 않았다. 야간 미확정 경계, 원은행 후보 부재46장, 카메라/축/참조 한계도 남겼다. N3·SubPix·기존 e와 모든 과거 결과·논문·운영 기본값은 그대로 유지한다. 원수치와 실패를 포함한 판단 근거는 [REPORT_KO.md](REPORT_KO.md)에 있다.
