# 다음 의사결정 한 가지

**현재 VISIBLE_SUPPORT 거리 대체의 운영 채택을 보류하고, 다음에 실제로 점검·수정할 대상은 기존 full_BI covariance/reliability와 가시 외곽의 결합 계약으로 한정한다.** 상태별 처리 전체나 N3/SubPix를 이6장 결과로 기각하지 않고 운영 기본값을 교체하지 않는다.

이번은 실제 RGB 모델 보조 입력6개, 전351개 원 후보의 네 점수와24개 봉인 출력까지 실행한 결과다. 단순 같은질량 단방향1/6에 비해 가시경계2/6으로 추가 회복1·추가 이진 손상0이 있었지만 원 e2/6 대비 회복1·손상1, 순증0이다. 가시경계는 질량 대조 대비 평균 위치+0.277cm·회전+6.827° 악화했다. 따라서 자동 추출기로 같은 입력을 얻으면 전체 성능이 좋아진다는 결론은 아직 없다.

우선순위를 정한 직접 근거는 **wood_night_01:030898의 성공 손상**이다. 성공 후보0은 A_E1.334813으로 모든 실패 후보의 최저1.511654보다 낫다. 하지만 실제 선택 실패 후보2와 비교하면 가중 외곽은0.391463대0.723937로 성공에0.332474 유리한 반면, full_BI는12.409336대11.609887로 실패에0.799450 유리하다. partial와 prior는 모두0이다. 결국 총점12.800799대12.333823으로 실패가 선택된다. 즉 새 입력이 아예 없어서가 아니라 실제 점 likelihood와 경계 지지의 결합에서 성공 순위가 뒤집혔다.

full_BI는 이미 관측 공분산과 기존 CAL total-error covariance/reliability override를 사용한다. ‘불확실성 항을 새로 추가하면 된다’는 상태가 아니다. 다음 변경을 설계하기 전에 원 native corner별 measurement provenance, 실제 fit covariance override 경로·단위·coverage 미교정 표시, 해당 점과 보조 경계의 공통 RGB 출처를 고정 자세에서 연결해야 한다. 실제 데이터에 비해 과도한 확신인지, 물리 corner 의미 또는 대응이 잘못됐는지, 서로 다른 관측모델이 충돌하는지 구분하고 **확인된 계약 문제만** 고친다. 이번에는 해당 재교정·학습·weight 탐색·새 selector를 수행하지 않았다.

이 우선순위가 모든 실패를 설명하지 않는다. `005286`은 C를 빼도 A_E가 실패 후보를 선호하며, 성공 후보의 full_BI는 이미 거의0이다. `020955`는 SWAPPED_WD 내부 성공 후보를 고르지만 ORIGINAL_WD의 더 낮은 거리 때문에 G10에서 배제되고, A_E 자체도 다른 family의 실패를 더 좋아한다. 따라서 full_BI 결합만 바꿔 이6장 모두를 회복한다고 주장하지 않는다. 모델 외곽 대응·한쪽 거리의 모호성과 미검증 K/파생 참조는 별도 미해결 사항으로 보존한다.

새 관측을 고쳐 같은6장에서 맞을 때까지 반복하지 않는다. 자동 공급기·추가 contour/방향 loss·계층 변경·새 최적화를 동시에 얹지 않는다. 새 변경을 별도 승인·고정한다면 사전 고정한 같은 전체 분모에서 회복과 손상·연속오차를 함께 확인해야 한다. 현재 보고서는 이 다음 변경의 성능 검증이 아니라 수정 위치를 고른 근거다.
