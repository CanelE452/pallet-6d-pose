## 입력과 네 점수의 연결

별도 입력 작성 문맥에는 원 full RGB와 같은 RGB의 확대만 전달했다. 작성 모델은 후보/추정 코너/기존 결과/참조/옛 감사 범주·삭제 부모/비용차를 받지 않았다. 여섯 장 모두 원640×480 좌표에서 팔레트와 배경의 보이는 바깥 경계만 한 번 표시했다. 콘 접촉 경계·구멍·내부 판재·그림자·화면 잘림·가려진 연결은 사용하지 않았고 야간 미확정 영역을 별도 기록했다. 사람이 검수한 입력이나 자동 검출·독립 물리 GT로 부르지 않는다.

작성자 검토 후 root 모델도6개 원 RGB/입력 비교 sheet를 실제로 열어 봤다. 관측 동결은 `2026-10-17T12:50:08Z`, 원 실행 입력 SHA256은 `4614cc049caf4f3f3cc0c33b3aa9bf7043a6404fa37ca73511c66ff1a9bdd94c`다. 비용 결과 이전 [PROTOCOL_LOCK.json](PROTOCOL_LOCK.json)을 고정했고 이후 의미를 바꾼 contour 버전은 없다. 공개 manifest의 경로 별칭 변환이 있다면 [PUBLIC_DERIVATIONS.json](PUBLIC_DERIVATIONS.json)이 원 실행과 연결한다.

새 polyline은 consecutive raw 구간만 적분하며 끝점은 ‘관측이 끝난 위치’다. 물리 코너 입력으로 쓰거나 교차시켜2D 코너를 생성하지 않는다. 각 선분 길이 l, 원 표본 간격 s=1px에 대해 n=max(1,ceil(l/s))개의 midpoint와 질량(l/s)/n을 사용했다. 표본 수는 적분 편의이며 독립 측정 수가 아니다. r=min(1,Z_E/Z_H)는 원 observed 정규화 질량에 대한 후보 독립 길이 비율이다.6장 모두 원 G10/G13×2family 문맥의 설정과 Z_H를 각각 확인했으며 이6장에서는 문맥 간 값이 같다. 이 일치를 일반 입력에 가정하지 않는다.

`C=원 가중 full_BI+partial_normal+active prior`를 보존했다. 원 outline은 `lambda/2×(A_H+B_H)`이고 원 dense 방향 기여에는 이미 lambda/2가 포함된다. 세 대체 비용은 각각 `C+lambda/2×A_H`, `C+lambda/2×r×A_H`, `C+lambda/2×r×A_E`다. 새 outline을 추가 가산하지 않고 원 outline을 교체했다. 원 loss의 sigma=1px, delta=1.25와 pseudo-Huber 계수·lambda=1을 사용했고 방향 벌점·각도 기준을 만들지 않았다.

새 E는 열린 원 관측 그대로이며 E의 convex hull을 만들지 않는다. 후보 자기 native XYZ/R/t/K/Q의 등록 직육면체를 투영한 원 observer와 같은 convex-hull **유한 선분**이 모델 P(T)다. 관측→모델 대상 polygon은 원 관례대로 canvas clip하지 않는다. S 꼭짓점은 모델 투영에만 쓰며 S에서 영상 관측을 질의하지 않는다. full/partial 철회·O/T/U·유한 tangent·depth hard eligibility/dedup·위임은 그대로다. 원 prior는 이6장 실제 최종 후보에서 모두0이다.

전 후보를 G10 stage/family 내부의 원 comparator로 고른 뒤 accepted family의 원 비교 규칙을 적용하고 그 family의 G13을 고른다. 정확 tie의 초기화 이름/안정 순서·자체 fallback과 후보 자기 Q를 유지했다. G10과 G13 objective를 직접 비교하거나 다른 단계 은행을 합치지 않았다. 전체22/94/42/130/41/22=351개 원 후보를 모두 점수화했으며 성공 후보만 미리 고르지 않았다.

1. **plastic_night_01:038630 — C 결합과 family 선택이 남았다.** G10 ORIGINAL_WD에서 A_E 최선의 성공 후보2는1.119203, 최선의 실패는1.463053이다. 그런데 C를 포함하면 최선 성공0.961147보다 실패 winner1의0.647666이 낮다. 다른 SWAPPED_WD winner1은0.269354로 더 낮아 G10에서 선택된다. 그 family의 G13에는 성공 후보0개, 다른 family에는2개다. 최종 SWAPPED_WD/1은80.714cm/88.370°이며 단순질량 대조와 같다.
