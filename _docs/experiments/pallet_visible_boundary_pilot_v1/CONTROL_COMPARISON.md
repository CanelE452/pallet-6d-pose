# 같은 여섯 장의 이전 저장 결과와 새 결과

기존 공개 `pallet_non_target_outline_pilot_v1/CONTROL_COMPARISON.csv`의 30행을 그대로 읽고, 이번의 세 신규 경로 18행을 더했다. 같은 baseline은 중복 행으로 세지 않아 총48행·8방법×6장이다. 원 방법명을 바꾼 두 표시는 `SUPPORT_AWARE_RERANK`→`OLD_PARENT_CENSOR`, `MASS_MATCHED_CONTROL`→`OLD_MASS_MATCHED`뿐이다. 이번 `HULL_ONEWAY_MASS`와 옛 `MASS_MATCHED_CONTROL`은 다른 점수이므로 구분한다.

모두 REMAINDER에 속한 같은6장이고 같은 fixed reference SHA `d488564817a8cac8d0103350f03ac61d78bdeb56163c6a5a4daffe414f0f2af1`를 사용한다. 원 baseline과 이번 baseline의 연결은 prediction seal의 후보/family/pose 검사와 evaluator로 확인했다. 이전 N0/PoseFix를 새로 추론하거나 자세를 다시 계산하지 않았다. 행별 원 출처 SHA와 accepted/fallback 기록의 결측을 [CONTROL_COMPARISON.csv](CONTROL_COMPARISON.csv)에 보존했다. 원 입력 바인딩·모델 정의의 감사는 [이전 비교 문서](../pallet_non_target_outline_pilot_v1/CONTROL_COMPARISON.md)를 재사용한다.

N0는 **N3+SubPix→기존 공통 F**다. N3 단독·SubPix 단독·원 e를 뜻하지 않는다. PoseFix RAW는 synthetic-only PRIOR1 seed1·last6000 checkpoint의 첫 uncapped RAW pass를 기존 W/D selector+F로 처리한 저장 결과다. checkpoint SHA는 `b9670d1a42db8d4e80ae1efe55eb237f05f81f7bd089cefe4051bbedd7d0a581`이며 추가 SubPix는 없다. 이번6장 모두143장 저장 보충분에 포함된다. PF+SubPix95 또는 PRIMARY192의 다른 분모를 섞지 않았다.
