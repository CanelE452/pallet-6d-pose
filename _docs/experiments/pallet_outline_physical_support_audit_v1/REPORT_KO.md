# 저장 외곽선의 물리적 대응 감사

**이번에는 새 성능을 산출하지 않았다.** 기존 대표 실패4장·성공 반례2장의 원 RGB, 실제 저장 마스크, 유한 외곽선127개와 observed 표본3,030개, 기존 두 후보씩12개를 연결해 검토했다. 새 추론·학습·PnP·최적화·후보 생성·관측 삭제·가중치 변경·재선택은0회다.

[확인: 저장 자료/코드] 실패 사례 세 장에서는 원 SAM 이진 마스크에 콘의 일부가 포함돼 있었고, 기존 convex hull이 그 부분과 팔레트 사이를 연결했다. 마스크→외곽선 변환 오류는 발견되지 않았다. [추정: 실제 영상 해석] 그 콘 지지/연결 선분을 팔레트 직육면체의 외곽 관측으로 동일시할 물리 근거가 없다. 나머지 야간 목재 실패의 검은 영역은 팔레트 하부·측면인지 도로 그림자인지 확정하지 못했다.

성공 반례는 외곽선 전체 삭제를 뒷받침하지 않는다. 노출된 실제 외곽이 성공을 지지한 사례와, 정체가 불확실한 어두운 구간도 성공을 지지한 사례가 있었다. 이번 자료로 모든 실패와 성공을 자동 구분하는 규칙 또는 개선 성능을 얻었다고 주장하지 않는다.

검토 화면은 [갤러리](gallery/index.html), 구간 기록은 [SUPPORT_REVIEW.csv](SUPPORT_REVIEW.csv), 원정밀도 비용 집계는 [COST_SUPPORT_SUMMARY.csv](COST_SUPPORT_SUMMARY.csv), 입력 SHA와 고정 후보는 [INPUT_BINDINGS.json](INPUT_BINDINGS.json)에 있다.

## 범위와 실제 검토

원결과 `c56a4e92027a8e56f6704773f24d7c3da78082f1`, 상위 관측·후보 결과 `407de865445e4987614f50f893d2ccea78d507b6`, 실행 시작 원격 main `61343a24130c553f063e0f6ade732d5e810e6e55`를 고정했다. 원결과와 시작 main의 관련 namespace 차이는 이번 지시문 추가뿐이었다. 지시문 SHA와 Downloads 사본 SHA도 같았다. 기존 대표 목록의 순서·영상 ID·대조 후보를 바꾸지 않았다. 모든 후보는 `(image_id,candidate_id)`로 결합했다.

여섯 원 full RGB PNG를 실제 이미지 도구로 각각 열었다. 이어 오류 숫자와 새 후보 패널 없는 실제 마스크/생성 경계 화면을 먼저 검토해 판정을 기록했다. 이후 두 고정 후보, 별도 참조와 비용을 연결하고 여섯 physical-layer 화면·여섯 참조 화면·원 최대 양/음 표본을 포함하는18개 부모 선분 확대를 실제로 열어 확인했다. 최종 model→observed 화면은 root가3·6번을 열었고 다른 화면의 수치·투영·파일은 코드 검사했다. 생성 화면을 모두 사람이 검수했다고 쓰지 않는다.

검토자는 **모델**이다. 이전 결과를 이미 알고 있던 사례이므로 독립 블라인드 검증이 아니다. 비용 연결 전의 새 판정 기록은 그대로 동결했고 후보/비용을 본 뒤 범주를 바꾸지 않았다. [검토 순서와 실제 열람 기록](evidence/review/FINAL_VISUAL_REVIEW.json), [동결 판정](SUPPORT_DECISIONS.json)을 보존했다. 이 기록은 진단용이며 GT·학습 타깃이 아니다.

기존 결과의 전체 맥락은 그대로다. 원 선택 실패32장은 family10/같은-family22, 성공114장, 후보 부재46장으로 PRIMARY192장을 구성했다. 원 장부의 같은-family 실패22/22와 성공114/114가 각각 기존 선택 후보를 외곽선 항으로 지지했다는 결과를 유지한다. 원 고정후보 진단의 외곽선 삭제 결과9회복·11손상,114→112/192도 기존 결과를 인용한 것이며 이번에 다시 실행하지 않았다. [원 RESULTS](../pallet_selection_score_diagnosis_v1/RESULTS_KO.md), [원 영향 진단](../pallet_selection_score_diagnosis_v1/SCORE_INFLUENCE_DIAGNOSTIC.csv)을 참조한다. 이번6장은 이전 결과로 선택된 설명용 사례이며32/114/192 전체의 새 물리 판정·오류율 추정이 아니다. ## 원 마스크부터 실제 비용 표본까지

모든 RGB와 비용은 원640×480 좌표다. crop은 표시만 바꾸며 K/자세/치수에 offset을 넣지 않았다. 원 crop JPEG는 원 인코딩 조건으로 재현했고, 새 확대 PNG는 원 RGB의 해당 정수 crop 픽셀과6/6 정확히 일치했다. JPEG 재압축 바이트와 원 PNG 바이트를 같다고 하지 않는다. 어두운 경우 원본과 표시용 gamma0.5 사본을 함께 뒀고 gamma 사본으로 수치를 만들지 않았다.

저장 `state_pallet_mask`는 Tiny 상태 모델의 soft mask다. SAM raw/clean/tight는 별도 저장 이진 마스크이며, SAM decoder logits/soft 출력은 저장돼 있지 않아 NA다. 새 soft mask를 만들지 않았다. SAM 후보 중 원 최대 quality 인덱스와 원 tie 규칙, raw→clean 원 cleanup을 그대로 검산했다. 외곽선에 실제 쓰인 것은 원 `pallet_mask` alias와 같은 **clean mask**다. tight mask는 계보 설명에만 표시했다.

원 설정 그대로 저장 마스크에서 외곽을 재현한 결과 polygon·유한 선분·표본·순서가6/6 bit exact였다. 실제 호출 계보는1·3·4·5번 G13 v4.13,2·6번은 저장 G10 v4.10 관측을 재사용한 경우였다. 실제 observer를 구분한 최종 계보를 썼다. 화면 margin7 절단과 제외된 frame 선분도 따로 표시했다. raw→clean에서 달라진 픽셀은2번의1픽셀뿐이다. 콘 혼입은 cleanup이 새로 만든 현상이 아니라 원 raw SAM 단계부터 있었다. [생성 계보 검산](evidence/mask_lineage/MASK_LINEAGE_SUMMARY.json)을 참조한다.

`Delta = comparison_contribution - selected_contribution`이다. 양수는 기존 실제 선택 후보 s를 지지한다. 실패 사례에서는 참조상 실패 s, 성공 반례에서는 참조상 성공 s를 지지하므로 정확도 의미를 구분한다. 아래는 이미 원 outline weight와 양방향1/2가 포함된 **가중 비용**이며 px 오차가 아니다. 가중치를 다시 곱하지 않았다.

observed→model은 정확히 같은 observed 인덱스·좌표·순서에서 차이를 구했다. model→observed는 후보마다 투영 외곽·호 길이·자체 표본이 달라 **같은 인덱스끼리 빼지 않았다**. [MODEL_DIRECTION_COSTS.csv](MODEL_DIRECTION_COSTS.csv)에 각각의 원 비용·정규화를 기록하고 방향 총합만 비교했다. 전체 비용 합 최대 차이는1.244e-14로 원 허용치1e-9 안이었다. 독립 검산기도 별도 IO/합산으로 같은 결과를 확인했다. 이 검산은 영상 범주가 물리 GT라는 인증이 아니다.

## 다음 한 가지와 완료 범위

다음 제안은 **whole-outline의 각 선분에 관측 출처·지지 상태를 보존하는 계약**이다. 실제 팔레트 경계, 독립적으로 확인된 다른 물체의 지지/그 연결, 확인 불가를 구분할 입력 근거를 유지해야 한다. 현재처럼 target mask의 전체 convex hull만으로 모든 선분을 cuboid 외곽으로 인증하는 전제부터 점검한다. 새 loss/weight 제안이나 이 감사의 수동 범주를 선택기에 넣는 제안이 아니다.

가까운 기존 구현은 `edge_visibility_v4_28.py`의 독립 occluder 지지에 따른 국소 RGB query 차단이다. 다만 실제 기존 호출부는 별도 occluder mask가 없어 `None`을 전달했다. 이번 캐시에도 인증된 독립 non-target mask가 없다. target mask의 보완값·O 상태·raw/clean 차이를 독립 가림 증거로 대체할 수 없다. 국소 B/I 함수에 필요한 anchor/mate/chain도 전체 hull에는 그대로 존재하지 않는다. 입력 가용성과 성공 구간 손상 여부를 먼저 확인해야 하며 실제 변경/성능 실험은 별도 범위다.
