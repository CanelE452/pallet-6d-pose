# 미확정 구간과 필요한 확인

**실제 이미지 검토를 끝낸127개 부모 선분·3,030개 observed 표본 중, 물리 지지가 미확정인 것은25개 부모·686표본이다.** 미검토 표본은0이다. 미확정은 `UNRESOLVED`로 그대로 남겼으며 다른 범주의 오답이나 효과0으로 대체하지 않았다.

이 판정은 원 RGB·마스크·생성 계보를 본 **모델의 육안 해석**이다. 독립 블라인드 검토·사람 검수·픽셀 정답·학습 레이블이 아니다. 부모 선분 전체와 이웃 문맥을 검토했으며 같은 부모의 여러 표본을 독립 증거로 세지 않는다. 아래 IDs와 좌표는 [SUPPORT_REVIEW](SUPPORT_REVIEW.jsonl)의 원 `segment_id`, `segment_xy_original_px`, `sample_indices`를 그대로 옮겼다. 범위는 양 끝을 포함한다.

## 여섯 장 모두의 C 질문 — 수치 등록과 물리 참조 인증을 구분

원 K·XYZ·Q·중심·후보·참조 읽기 및 CF/canonical 투영은 일치했다. 그러나 **6/6의 C(영상–모델–참조의 물리적 양립성)는 미확정**이다.
