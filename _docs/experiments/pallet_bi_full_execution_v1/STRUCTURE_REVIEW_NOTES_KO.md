# 고정24장 구조 검토의 시각 점검

사전에 정한24장에 대해 기존 원영상·자동 support 패널을 AI가 실제로 열어 확인했다. 새로운 실험이나 사람의 물리 정답 주석은 만들지 않았다. 원본 패널에는 비식별 처리가 없는 RGB가 있어 비공개로 보존한다. 공개 갤러리는 별도의 승인된 비식별 결과 패널이다.

[확인] 여러 플라스틱 팔레트에는 반복 격자가, 나무 팔레트에는 평행 판재가 보인다. 야간 패널04–07·22는 낮은 대비를 보이고, 패널08–12·23에는 콘·의자가 팔레트의 일부를 가린다. 선이 존재한다는 사실과 그 선이 특정3D support에 대응한다는 판단은 구분해야 한다.

[추정] 반복되는 선은 가까운 영상 위치에 여러 대응 대안을 만들 수 있고, 외부 가림·약한 대비는 실제 지지 구간을 줄일 수 있다. 이번 시각 점검은 이 가능성을 보여 주는 정성 자료이며, 어느 요인이 성능 손상을 유발했는지 분리한 인과 실험은 아니다.

흰 숫자는 초기 native query이고, 주황·청록 overlay는 자동 proxy에 연결한 별도 재료 support다. 후자를 native 키포인트의 새 정답이나 실제 점의 인증으로 읽지 않는다. 회색 proxy 투영도 영상 관측이 아니다. 나무·플라스틱에서 보이는 overlay만으로 exact instance·축 등록의 옳고 그름을 확정하지 않는다.

물리 owner의 사람 확인 수는0, 독립 물리 주석 수는0, owner 정확도는NA다. 구조 검토 레코드의 물리 대응 상태는 UNKNOWN을 유지했다. 점검에 따라 관측·정답·문턱·생산 코드를 바꾸지 않았다.

실제 열람24개 패널의 ID·SHA와 검토 범위는 private `ROOT_STRUCTURE24_ACTUAL_AI_VISUAL_REVIEW.json`에, 원 자동 레코드 출처는 `s3_s4_structure_review/REVIEW_RECEIPT.json`에 보존했다. 최종 성능 해석에는 별도192장 전량 평가와 고정31/41/38 집합 분석을 사용한다.
