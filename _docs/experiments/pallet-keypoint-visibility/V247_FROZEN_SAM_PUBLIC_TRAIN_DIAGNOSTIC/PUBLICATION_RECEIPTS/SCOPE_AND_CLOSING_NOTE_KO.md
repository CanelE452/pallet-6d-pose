# V247 게시 영수증과 접근 범위 보충

과학 패키지와 156개 변경은 commit `0da053d7b758f638ebb3598e39647b385fcc2a99`에 반영했고 원격 main 일치를 확인했습니다. 이 폴더는 그 뒤에 생성한 실제 게시/portable 재검산 영수증입니다. 기존 MANIFEST와 152개 과학 payload는 변경하지 않습니다.

README의 현재/보호 평가자료 미접근 범위는 **새 원본 영상·개별 GT 라벨·점별 모델 출력**입니다. 인수 상태를 확인하면서 `ACTIVE_HANDOFF_KO.json`에 이미 기록되어 있던 과거 V229 혼동행렬 집계 metadata가 출력되었습니다. 새 평가를 실행하거나 개별 평가 출력/라벨을 열지 않았으며, 이 기존 집계로 모델·데이터·구조·문턱을 고르지 않았습니다. V247의 SAM2.1 선택은 이미 준비된 공식 runtime의 native 영상 크기 API와 공개 SOURCE 입력/라벨 감사에 근거하며, 규칙은 새 SOURCE 출력 전에 고정했습니다. 과거의 모든 평가 metadata를 전혀 읽지 않았다는 주장으로 읽지 않도록 이 범위를 명시합니다.

공개 TRAIN 44프레임 중 실제 모델 추론은 42회였고, 새 학습·PnP·현재 평가 추론은 0입니다. V246의 공개 혼합 INPUT_ONLY metadata에서 SOURCE_VAL 입력 metadata를 파싱/폐기했던 이력도 기존 보고서에 공개되어 있습니다. UNKNOWN과 다른 instance의 교사 라벨을 native 정답으로 승격하지 않았습니다. SAM 지원/밖 판정은 현재 평가 성능이나 해결을 뜻하지 않습니다.

portable 검산은 실제 `f3a2fc`, exit0으로 완료했습니다. 패키지 152개 파일과 42개 chosen mask의 352행을 검증했고 원본 폴더 fallback은 없었습니다. 원래 독립 QA와 재생된 조건부 표의 바이트도 일치했습니다.
