# V228: 실행하지 않은 YCB query 관측 준비

V227 이후 준비한 코드와 계약만 보존합니다. 새 사용자 지시에 따라 V229 고정 후보 실사 평가를 먼저 진행했습니다.

이 단계에서 YCB GT/depth/mask payload를 읽거나 관측 sidecar를 만들지 않았고 새 학습도 하지 않았습니다. 기존 associated-reference r의 D/E를 유지하면서 실제 jitter query q의 관측을 별도 진단하려던 준비이며, q의 픽셀 소유자를 native 키포인트 보임/가림 정답으로 바꾸는 절차가 아닙니다. 이 폴더에는 새 성능 결과가 없습니다.
