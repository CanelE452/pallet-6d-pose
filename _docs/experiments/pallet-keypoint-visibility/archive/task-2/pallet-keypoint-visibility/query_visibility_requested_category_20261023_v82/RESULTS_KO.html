남는 범위

요청 category는 instance identity가 아닙니다. 이 source에서 image/category 키가 모두 달라 같은 종류 다중 instance 분리 능력은 검증하지 못합니다. 공개 YCB q는 GT-derived source geometry와 synthetic residual을 이용한 emulated proposal이며 실제 배포 initializer 성공이 아닙니다. M0/M4는 source support proxy이고 virtual cuboid corner의 공중 위치·구멍·부분선 단서와 사람 semantic D/E/S는 다른 목표입니다. 반복 사용한 source VAL 개발 진단이며 foundation pretraining overlap도 알려져 있지 않습니다. 새 모델·동의어·문턱 탐색이나 현재 자료를 통한 재선택은 없습니다.

활성 토큰 전체의 raw FP32 logits와 같은 postprocess tensor의 FP32 probabilities, token IDs/indices/attention mask를 저장해 .4/.3 판정을 재생할 수 있습니다. padded −inf는 실제 실행 guard certificate로 보존합니다. CPU sigmoid의 ULP 차이를 허용해 판정을 바꾸는 방식은 사용하지 않습니다.
