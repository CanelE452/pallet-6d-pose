이 결과를 어떻게 해석해야 하나

  • 원래 D341개 중 중심이 대상 표면으로 지지되는 경우50, 다른 물체15, 배경146, 미확정130이다. D341개의 정답 오류율이라는 뜻이 아니다.
  • 원래 E49개 중 중심에 다른 물체가 지지되는 경우37, 대상 표면3, 배경2, 미확정7이다. 대상 표면3개도 native E의 오표기라고 단정할 수 없다.
  • query 중심이 외부 물체여도 실제 native 점은 다른 곳에서 보일 수 있다. 중심에 대상 목재가 보여도 정확한 native 점이거나 실제 native 점이 보인다는 보장은 없다.
  • 모서리·가상 외곽점은 정상이어도 중심 샘플이 바닥이나 벽일 수 있다. 배경을 외부 가림이나 좌표 오류로 바꾸면 새로운 라벨 오류가 된다.
  • 40개 두 검토 일치34/40, 세 관찰 일치30/40은 관찰 반복성이다. 정확도 검증이나 독립적인 물리 정답이 아니다.
  • 이번390개는 공개 TRAIN 중 기존 D/E와 입력이 있는 전체이며, 다른 source나 현재 평가셋의 표본을 대체하지 않는다. 별도 native8/정사각형 범위는 유지한다.

검토 일치: 두 검토 34/40, root까지 세 관찰 30/40입니다. 40개 중 최종 미확정은18개이며, 그중8개는 모두 미확정으로 일치했습니다. 나머지10개는 의견 불일치 정책 적용 사례이고, 주검토의 확정 판단에서 추가로 미확정이 된 것은3개입니다. 관찰 반복성이며 정확도는 아닙니다.

진전과 남은 문제

확인한 진전: 실제 crop을 보면서 역할 라벨과 literal query 중심 관찰 사이의 의미 차이를 정량적으로 기록했다.

아직 확인하지 못한 것: 이 의미 차이가 이전 모델의 모든 실패를 일으킨다는 인과관계, 새 방법의 성능 향상, 정확한 좌표 판별.

남은 일: native 부위 보임의 확실한 공개 실사 학습 근거, 새로운 가림 물체에 대한 전이, 정사각형/모든 native 순서의 공개 실사 범위.

성공 가능성: 현재 실험만으로 성공 확률을 수치로 정할 수 없다. 목표가 불가능하다는 근거는 없지만 실용 성능은 아직 미입증이다.

새 모델 채택 없음 · 이번 단계 새 학습/추론/PnP/좌표 변경 없음

다음에는 공개 TRAIN에서 해당 native 부위가 실제로 보이는 근거를 추가로 확인합니다. 중심에 목재가 보인다는 이유만으로 정확한 키포인트라 하거나, 중심을 덮었다는 이유만으로 native 외부 가림 정답을 만들지 않습니다. 원래 목재·정사각형·native8 목표는 유지합니다.
