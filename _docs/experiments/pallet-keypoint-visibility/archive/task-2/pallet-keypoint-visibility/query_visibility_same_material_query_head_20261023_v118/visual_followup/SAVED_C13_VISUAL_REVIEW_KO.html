반복되는 문제: 관찰과 가설 구분

  1. 남은 팔레트 재질과 해당 모서리의 보임을 혼동하는 양상. 원행325/996은 콘과 대상 재질이 함께 보이는데 보임으로 응답합니다. 기대한 부품의 대응 자체가 시각적으로 확정된 것은 아닙니다.
  2. 명확한 콘도 놓칩니다. 원행256/1021은 콘이 중심을 크게 차지하지만 보임입니다. 좌표 오차·경계·작은 crop 하나만으로 모든 오류를 설명할 수 없습니다.
  3. 공개 학습 대조의 성공이 자연 가림으로 이어지지 않았습니다. C13은 공개 목재 cover를 개선했지만 현재 외부 가림 정답 수가 늘지 않았습니다. 새 목재 대조62쌍은 모두 PALLOX 기반이며 동일 bin·부품·붙여넣기 조합으로 군집되어 있습니다.

전체 배경만 보고 답한다고 단정할 수는 없습니다. 공개 특징 대조에서는 query 부근 특징 변화에 민감했습니다. 그러나 큰 수용영역을 가진 특징이므로, 그 민감도가 정확한 점·부품의 가시성을 읽었다는 증거는 아닙니다. 위 시각적 공통점도 유일한 원인의 증명은 아닙니다.

자기 가림을 초기 기하로 제외하고, 주어진 초기 위치에서 대상의 단서가 외부 물체에 가려졌는지 판단한다는 목표가 과도하다는 근거는 없습니다. 실제 성공과 명확한 실패가 함께 있습니다. 현재 방법의 일반화 부족을 목표 자체의 불가능성으로 돌릴 수 없습니다.
