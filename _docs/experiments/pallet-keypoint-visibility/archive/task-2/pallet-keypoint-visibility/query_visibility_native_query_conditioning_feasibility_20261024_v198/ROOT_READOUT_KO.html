q8와 의미 권위의 경계

SELF_SCENE15의 원 scene q8은 불변 문맥이고 실제 crop q/L만 개별 변환됐다. 이를 새 simultaneous jittered8처럼 만들거나 다른 증강/variant mate를 합쳐서는 안 된다. 원 active anchor와 현재 q/L을 함께 주면 인공 dx/dy/scale을 답처럼 노출할 수 있다. 미래 q8 계약에서는 current selected point를 self0으로 두고 원 active anchor/state를 배제해야 하지만, 그것만으로 나머지 점의 간접 shortcut까지 제거됐다고 할 수 없다.
