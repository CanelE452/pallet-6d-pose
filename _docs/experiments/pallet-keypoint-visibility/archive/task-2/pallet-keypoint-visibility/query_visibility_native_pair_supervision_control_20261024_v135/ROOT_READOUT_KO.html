해소한 의문과 남은 문제

원본 학습 자료 6만 개 저장 순열과 475,066개 유효 학습 좌표를 확인한 규칙은 현재 합성의 192개 설정 모두에서 선언 CF 순서와 일치했습니다. 과거 area-V4와의 22개 차이는 실제 학습 순서의 불확실성이 아니었습니다. 기존 CF 라벨은 바꾸지 않았습니다.
