3. 무엇이 확인됐고, 무엇은 아직 가설인가

  • 확인: 현재 모델이 모든 자연 가림을 원천적으로 분류하지 못하는 것은 아닙니다. 기존 공개 bin/상자에서는 대부분 구별합니다.
  • 확인: source에서의 높은 점수가 다른 팔레트 구조·재질·가림 물체와 실제 초기query에 대한 신뢰성을 보장하지 않습니다. 현재 평가의 낮은 가림 검출률이 그 한계입니다.
  • 아직 분리할 것: 형상·재질·가림 물체의 변화와 query 의미/위치 대응의 영향을 각각 확인해야 합니다. 이번 공개 입력은 참조로 배치했으므로, 둘 중 하나만이 원인이라고 단정할 수 없습니다.
  • 별도 과제: 자기 가림은 초기 기하 처리, 위치 불확실성은 보류와 분리합니다. 모든 모호한 장면을100% 이진 판정하는 목표에는 RGB 관측의 한계가 있지만, 현재의 명확한 콘 누락 전체를 그 한계로 설명할 수는 없습니다.
