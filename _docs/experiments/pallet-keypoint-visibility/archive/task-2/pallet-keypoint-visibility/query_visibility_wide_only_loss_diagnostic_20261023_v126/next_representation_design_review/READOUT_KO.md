# 다음 표현 검토 — 읽기 전용

현재 특징에 공간정보가 없다고 말할 수는 없습니다. C11/C17에는 q 위치에서 뽑은 context Q, q 중심 RGB96, 중앙32, positional embedding이 이미 있습니다. 다만 head에는 격자 전체가 아니라 T/Q/F/C/P 다섯 요약벡터가 전달됩니다. P는 full96의 중앙2×2 raw patch token을 **평균한 뒤 L2 정규화**하므로 네 위치의 순서를 따로 주지 않습니다. DINO의 최종 patch token은 전역 self-attention을 거친 값이어서, 위치를 보존해도 해당 픽셀만 보거나 소유자를 증명하는 특징은 아닙니다.

V101도 이미 중앙32 CNN과 정확한 query phase(4×4 특징의1.9375)를 사용했습니다. 강한 frozen C1 prior가 있던 별도 방법이므로 그 실패가 이번 stencil의 결과를 대신하지 않습니다. V94의9×9 공간 attention도 있었으므로 “처음 공간정보를 넣는다”는 설명은 부정확합니다.

## 저장 결과가 허용하는 결론

고정1000회 C17/C18 old-loss 대조의 변화는 작고 조건별로 상충했습니다. 별도 LBFGS capacity 진단에서는 **같은1928 특징·같은221825 head로 TRAIN795/795**를 맞췄습니다. 따라서 이 TRAIN 집합의 절대적 표현 불가능은 주장할 수 없습니다. 그러나 VAL은2664/3582(74.4%), E-qOUT325/483(67.3%), SHAM-D-qIN197/394(50.0%)입니다. 학습 가능성과 새 장면 전이는 분리해야 합니다. 이 결과는 feature 불충분을 증명하지도, feature 충분성을 보장하지도 않습니다.

## 가장 작은 구체적 후보와 비교

기존1928 특징은 그대로 두고, full96 token 격자에서 q 기준3×3 **간격 샘플**을 보존하는 안입니다. token 좌표는 각 축3.5/7.5/11.5, 즉 native q±L/4/0이며 연속된3×3 token 블록과 다릅니다. 중앙은 기존 P를 그대로 쓰고 바깥8개384-D 벡터만 추가하면 입력5000, 기존 관계벡터까지 포함한 linear 입력6536이 됩니다. 폭64를 유지해도418433파라미터로 늘므로 단순 성능 차이를 순서 효과로 부르면 안 됩니다. 기존1928 cache에서 바깥 token은 복원할 수 없어, 향후 별도 승인된 같은 RGB96 encoder replay가 필요합니다.

최소 source 비교는 같은9개 노드를 추출해 두 arm에 공통으로 쓰는 것입니다. 한 arm은9개 raw token을 pool한 벡터를8칸에 반복하고, 다른 arm은 바깥8개를 순서대로 줍니다. 기존 P·head 크기·초기화·source sampler·loss·예산·raw0을 맞추고 고정1000회를 우선 비교합니다. 이 비교도 **개별 위치 정보와 aggregation이 함께 달라지는 표현 묶음**을 시험합니다. 고정 permutation은 head가 역순서를 배울 수 있으므로 순서 제거 대조가 아닙니다. 구현·fit은 이번 검토에 포함하지 않습니다.

q-alpha 밖의 E와 q-alpha 안의 SHAM D는 원래 기대 cue의 영역 가시성 라벨입니다. q 픽셀의 재질 라벨이 아닙니다. 순서 격자를 추가해도 어느 팔레트의 어느 단서를 기대하는지, q와 실제 단서의 관계가 무엇인지가 자동으로 정해지지는 않습니다. GT r·uncertainty·native ID를 모델 입력에 몰래 넣어 이 모호성을 없애면 배포 계약이 달라집니다.

TRAIN795는6cue·3원본 LOCO 이미지의 상관된 파생 입력입니다. VAL26cue·6원본 중 TOMIE4장은 한 episode이고 이미 반복 개발에 노출되었습니다. 합성 alpha 경계·조명·donor 재질 단축신호도 남습니다. 우선 기존 fold별 E-qOUT/SHAM-D-qIN과 전체/입력가용 분모를 함께 보고, 전이 주장은 별도의 새로운 capture group에서 확인해야 합니다. 기존 old18 cohort에 새 stencil이 없는데0으로 채워 점수를 만들면 공정한 비교가 아닙니다.
