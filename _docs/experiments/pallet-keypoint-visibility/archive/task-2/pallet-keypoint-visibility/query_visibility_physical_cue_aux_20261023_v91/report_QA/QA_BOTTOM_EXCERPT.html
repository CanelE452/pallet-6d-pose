source의 검증 연산도 현재 운영과 달랐습니다

저장된 VAL1,264개 FULL tile/cue 단위를 전부 사용해 각 tile의 원 uncertainty 영역만 읽어도, cue/view와 scale을 균등화한 가중 D recall은 95.50%, E recall은 97.73%였습니다. source 내 단일 tile의 원 uncertainty 영역에서도 높은 점수가 남으므로, source 성공이 전적으로 mosaic 합성만의 산물이라고 볼 근거는 없습니다. 현재는 q-centre·라벨·대상·스케일이 달라 각 요인의 기여량을 분리할 수 없습니다. 두 표의 집계 단위는 다르므로 원시 count를 합치지 않았습니다.

이1,264단위 중 q 중심이 원 uncertainty box 안에 있는 경우는 0개였습니다. 따라서 source의 높은 영역 점수는 현재가 읽는 q-centre 판정의 직접 검증이 아닙니다. 이것이 centre cell의 학습 gradient가 0이었다는 뜻은 아닙니다. 보간·공유 convolution을 통해 학습 신호는 전달될 수 있습니다.
