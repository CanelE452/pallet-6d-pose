V131: 작은 좌표 이동 진단 완료

진전은 있다. 공개 약한 cue의 작은 좌표 이동에서는 C16의 안정성을 확인했다. 실제 평가의 외부 가림 판별은 아직 해결되지 않았다.

현재 실제 평가 C16: 보임 1137/1147 (99.13%), 외부 가림 35/90 (38.89%). 외부 가림 55개를 놓친다. 이 단계의 새 실사 평가·학습·문턱 변경·PnP는 0회다.

공개 데이터 진단

원본6프레임·6cue·5take, 합성장면102개 × q조건9개 =918입력. TRAIN612, VAL306. VAL은 원본2프레임의34장면 반복이며, 자연 가림 인간 정답이 아니다. q 이동은 중심·축방향3px·대각선4.24px이고 실제 초기 추론기의 출력이 아니다. 약한 cue 위치 자체의 ±6/8px 불확실성은 남는다.

남은 문제와 성공 가능성

동일 모델이 인위적 가림의 보임/가림 차이를 구분하는 사례는 확보했다. 큰 q 이동과 형상·재질·자연 가림의 변화에서는 일반화가 부족하다. 추가 합성 학습 C23도 전체 source 기준8개중4개만 통과했다. 이 결과로 C23을 채택하지 않는다. 성공 확률을 수치로 말할 근거는 아직 없다.

다음 우선순위는 실제 초기 추론기의 q/대상 대응을 source에서 확인하고, 자연 외부 가림 감독을 보강하는 것이다. 작은 이동만 맞히는 쉬운 조건으로 목표를 바꾸지 않는다. 현재223은 학습·문턱·모델 선택에 쓰지 않는다.
