CF 카드 상단은 V161 생성 당시 증명 기록이며 하단은 V162 실제 학습 후 저장 출력입니다. C43은 CF0, C44는 CF314 owner 보조로 학습했습니다.

기존 V160 SOURCE12와 V161 CF12를 그대로 유지합니다. SOURCE의 D/E/U는 이전 약라벨 계보이며 held owner 정답은 없습니다. CF의 native 가시성·좌표품질은 UNKNOWN입니다. Controlled owner 약감독을 native 가시성 정답으로 바꾸지 않으며 이 그림은 전체 성능/모델 채택 판정과 별도입니다.
