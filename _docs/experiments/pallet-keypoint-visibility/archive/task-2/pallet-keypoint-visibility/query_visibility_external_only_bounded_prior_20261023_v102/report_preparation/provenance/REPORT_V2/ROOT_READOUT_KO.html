외부 가림 전용: C1 prior를 제한하면 달라지는가

두 후보 모두 소스 12개 조건을 통과하지 못했습니다. 새 현재 데이터 추론은 허용되지 않으며, 마지막 실제 현재 비교는 V94 C1입니다.

C6는 원래 C1 logit, C7은 그 logit을 [-2,+2]로 제한한 prior를 사용합니다. 두 후보는 같은 3개 입력(P3 ROI·RGB96·valid), 같은 q/L, 같은 새 residual 3,221개 parameter 초기값, 같은 2,000회 D32/E32 draw와 loss를 사용했습니다. C1 26,573개 parameter는 고정했습니다.

사용자 방침에 따라 학습은 보임 D 대 외부 가림 E입니다. geometric S 396행은 알려진 별도 상태로 유지하고 학습·selector·gate에서 제외했습니다. unresolved U 32,070행도 음성으로 사용하지 않았습니다. 모델은 좌표를 찾거나 보정하지 않습니다.

prior 제한의 효과와 손실을 함께 봐야 합니다. 공개실사 VAL cover E는 8/119 → 64/119, 세 장 모두 정답은 7/119 → 63/119로 증가했습니다. 두 후보의 sham D는 모두 115/119입니다.

새 합성 VAL의 보이는 D 정답은 171/209 → 133/209, 세 장 동시 정답은 26/32 → 19/32로 감소했습니다. 이 결과는 bounded prior가 외부 가림 반응을 바꾼다는 소스 증거이며, 단일 원인이나 전체 목표 해결의 증거는 아닙니다.

해석 범위

clamp 비교는 prior의 범위를 바꾼 소스 통제 실험입니다. 특정 오류의 유일한 원인, 실제 팔레트의 native8 visibility 정답, 현재 평가 성능 개선을 증명하지 않습니다. 합성은 공개실사 배경에 RGBA를 합성한 단순화된 분포이며 q는 source-emulated입니다. 기존 공개실사는 주로 한 Pallox bin의 조건부 AI cue이고 natural E VAL은 2행입니다.

자기 가림은 초기 추론의 별도 기하 필터로 다룹니다. synthetic teacher S가 그 실제 기하 필터의 품질을 검증하지는 않습니다. 원래 좌표 오차와 대상 cue 결합 문제도 별도로 남아 있습니다. 전체 목표는 아직 완료되지 않았습니다.
