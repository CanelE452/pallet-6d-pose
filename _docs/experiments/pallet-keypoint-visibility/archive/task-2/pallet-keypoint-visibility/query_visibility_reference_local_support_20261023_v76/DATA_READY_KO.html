이 상태는 참조점 주변의 예상 대상 영역이 실제 보이는지에 관한 약한 감독입니다. 사람의 semantic D/E/S 또는 중심 픽셀 정답으로 합치지 않습니다. 자기 가림 기하 proxy도 별도 필드로 유지했습니다. 위 UNKNOWN 비율은 라벨 coverage이며 모델의 보류율은 아직 아닙니다.

보이는 대상에 잘못된 negative를 주지 않도록 한 규칙

참조점 중심 3×3이 모두 예상 target이고 모두 visible이면 LOCAL_VISIBLE, 모두 예상 target이지만 visible이 없으면 LOCAL_COVERED를 먼저 적용합니다. 결정할 수 없으면 고정된 참조점 주변 Gaussian footprint의 M4/M0 support 비율을 대조합니다. 충분한 예상 support에서 0.9 이상은 visible, 0.1 이하는 covered, 그 사이는 UNKNOWN입니다. 예상 support가 없는 19,576점은 모두 UNKNOWN으로 남겼습니다.

합성 mask의 값 1·2는 배경이어서 기존 감사와 동일하게 raw>127을 사용했습니다. 공개 BOP binary instance mask는 raw>0입니다. 전체 5,203쌍에서 M4⊆M0 위반은 없었습니다.

고정 공개 사례에서 대상 full/visible mask는 같지만 virtual ray 기준 E였던 k6은 주변 예상 support가 0이어서 UNKNOWN입니다. 세 점은 지원 영역 전체가 visible이고, 다섯 점은 근거 부족입니다. 원래 참조 좌표는 그대로입니다.

v61과 같은 합성 입력을 보존했습니다

기존 N3 q9·L·P3 ROI와 ID 순서를 모두 일치시킨 입력 pack 1,003장을 생성했습니다. Local RGB96, target RGB128, native 번호와 전체 8점의 context42를 추가했습니다. GT reference·mask·label은 입력 builder가 읽지 않았습니다. 압축 용량은 193MB이며 고정 RGB 360개 지점 검산 차이는 0입니다.

ROI에 유효한 샘플이 하나라도 있는 flag는 7,833점, 중심 query가 유효한 점은 7,415점입니다. 서로 다른 조건이므로 별도 보존했습니다. 중심 유효성 7,415점은 기존 v61 규칙과 정확히 같습니다. V74의 R0 좌표와 기존 N3 ROI를 혼합하지 않았습니다.

남은 실행과 검증 범위

공개 실사 쪽은 source에서 정의한 초기 query 입력과 frozen 특징을 준비해야 합니다. GT 위치에 합성 TRAIN의 오류를 넣는 모사를 사용하면 실제 초기 모델 출력과 구분해 기록합니다. 모델·문턱 선택은 source에서만 하고, 현재 평가 223장에는 동결 모델을 적용합니다.

기존 합성 VAL 235장 중 84장은 V75 사전학습 checkpoint 선택 heldout에도 포함됐습니다. 새 독립 전체 시스템 시험으로 부르지 않습니다. YCB의 기존 scene 0–7 TRAIN, 8–9 VAL 분할을 유지했습니다.
