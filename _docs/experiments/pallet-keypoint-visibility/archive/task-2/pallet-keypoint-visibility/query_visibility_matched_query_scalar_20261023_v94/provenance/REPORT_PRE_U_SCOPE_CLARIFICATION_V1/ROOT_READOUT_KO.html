무엇을 학습하고 평가했나

C1은 원래 q/L crop의 P3 ROI + RGB96 + valid mask를 받아 가림 scalar logit 하나를 냅니다. 위치를 찾거나 키포인트를 보정하지 않습니다. z<0 → D, z≥0 → auxiliary hidden이며 입력을 읽을 수 없으면 U입니다. 외부/자기 가림 원인을 학습해 구분하는 모델은 아닙니다.

새 head의 학습행은 공개 Pallox 목재 bin의 자연 before/after conditional known-cue-set뿐입니다. TRAIN_LAB 56D+9E, VAL_HALL 81D+11E를 사용하고 나머지 643행은 unknown으로 보존했습니다. 자연 촬영쌍이지만 각 프레임의 실제 initializer q/L이 달라 동일 q/L counterfactual 짝 학습은 아닙니다. 합성·YCB·controlledV3 학습행은 이번 fit에 포함하지 않았습니다. 기존 frozen backbone/저장 입력은 유지했습니다. 2,000 update 중 source VAL 클래스별 BCE 평균이 최소인 update100을 선택했습니다.

해석과 다음 단계의 경계

현재223은 이전 개발·진단에서 반복 노출된 집합이므로 새 blind test가 아닙니다. 이번 C1의 학습·문턱·체크포인트 선택에는 쓰지 않았습니다. 자연 외부 가림의 recall이 충분하지 않고, expected target/cue 대응은 UNKNOWN이며 재질 shortcut도 배제되지 않았습니다. 따라서 전체 목표 완료는 false입니다.

controlledV3는 준비 단계이며 이번 결과에 섞지 않았습니다. 새 학습의 효과를 주장하려면 source의 target/cue 대응, 원 q/L에서 실제 관측 가능한 단서, natural foreign occlusion 전이를 계속 구분해야 합니다. 의미적 불확실성을 학습한 보류나 confidence calibration도 아직 없습니다.
