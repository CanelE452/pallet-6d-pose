GroundingDINO tiny에 모든 이미지마다 같은 YCB 21종+pallet의 22개 phrase(77 tokens)를 입력했습니다. 고정 검출 문턱 0.4 / text 0.3, 기존 initial-q box와 검출 box의 최대 IoU≥0.1로만 대응했습니다. 동률은 detector score와 원 query 순서로 정하고 NMS·GT class·GT mask로 고르지 않았습니다. 선택한 box 하나만 frozen SAM2.1 base-plus에 입력하며 point prompt와 mask quality 선택은 없습니다.

확인할 수 있는 것과 남는 차이

이 실험은 범용 object name 요청과 입력 box 대응이 target-owned visible mask를 만들 수 있는지 조사합니다. 같은 category의 다른 instance, 가린 물체를 가림 물체로 잘못 대응하는 문제, source 밖의 pallet 의미 대응은 남습니다. 문자열은 고정 caption에서 나온 predicted phrase이며 해당 instance의 GT class가 아닙니다. Source pixel mask 성능을 사람의 reference-keypoint semantic visibility 성능으로 옮겨 말하지 않습니다.

공개 YCB q는 이전 V76의 GT-derived source emulation이며 실제 배포 initializer 성능이 아닙니다. M0/M4는 source의 투영/가시 support proxy입니다. foundation pretraining overlap은 인증되지 않았고 반복 사용한 source VAL 개발 진단이므로 독립 held-out 성공 주장도 하지 않습니다. raw token full logits를 저장하지 않아 text>0.3 phrase 문자열의 독립 재생성은 감사 범위 밖이며, 실제 선택에 쓰는 raw maxscores·boxes·순서·association은 별도 감사합니다.

실행 오류와 성능 판단의 분리

Detector의 padded token은 공식 구현상 −inf인데 처음의 전값 finite guard가 맞지 않아 실제 source 실행 전에 수정·검증했습니다. 첫 SAM 실행도 공개 API가 내부 bool mask를 float32 0/1로 반환한다는 dtype 경계를 잘못 예상한 guard에서 중단했습니다. 실패 코드·잠금·로그는 보존하고, 공식 API의 정확한 0/1만 bool로 옮기도록 고쳤습니다. 새 문턱·모델·prompt·후보 선택을 도입하지 않았으며, 이 infrastructure 수정은 성능 개선 실험이나 재선택이 아닙니다.
