어떻게 정리할 것인가

  1. 가림 판단과 위치 보정 역할을 분리합니다. Heatmap은 지정 키포인트의 보정 후보만 냅니다. 보임이 별도로 확인된 점에서만 적용하고 불확실하면 초기 좌표를 유지합니다. 초기 기하의 self-occlusion 제거만으로 외부 가림이 없어지지는 않습니다.
  2. 위치 보정의 다음 검증은 정사각형에 초점을 둡니다. 목재에 같은 개선을 주장하지 않습니다. 실제 적용 승인 기준은 별도로 검증해야 하며 이번223장 결과에 맞춰 새 threshold를 선택하지 않았습니다.
  3. 가림 분류를 계속한다면 원래 기대 위치와 native 대응을 보존해야 합니다. 후보가 다른 구조로 이동했다고 원래 점을 보임으로 바꾸지 않습니다. 참조 위치 근처에서도 실패한 사례는 위치 개선으로 해결할 수 없어 가림 대상/직접 보임 목표와 전이를 별도로 다뤄야 합니다. 동일-query 합성 가림 대조는 이미 시도한 자료에 있으므로 단순 반복이 해결책이라는 근거는 없습니다.
  4. 경계 사례의 주석·대응을 재검토합니다. 작은 팔레트 조각이 보이는 것과 지정 native 꼭짓점이 직접 보이는 것을 구분합니다. G996의 사용자 이견을 포함해 자동 재라벨링하지 않았습니다.
