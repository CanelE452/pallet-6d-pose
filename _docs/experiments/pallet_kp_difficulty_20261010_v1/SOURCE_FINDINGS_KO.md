이번 source 감사에서 확인된 가장 구체적인 병목은 실사 전이 이전에 이미 존재한다. 기존 1,024개 P0 감독의 이상적인 정답 bin을 그대로 선택하고 같은 선·코너 조립을 적용해도 4코너 이상인 장면은 97개뿐이다. Source-test 128장에서는 원시 조립 13장, 영상 안의 조립 12장이다. 따라서 이 수치는 학습기가 달성하지 못한 성능만이 아니라 기존 라벨과 관측 조립이 함께 제한한 결과다. 새로운 PnP나 학습 없이 기존 캐시에서 계산했으며, 실제 자세가 산출된 비율과는 구분해야 한다. [원행과 정의](SOURCE_CEILING.json)

초기 좌표와 source 후보 정답 사이의 차이도 작았다. Source-test 양성 후보의 절대 normal offset은 평균 1.13픽셀, 중앙값 0.69픽셀, P90 2.53픽셀이다. Source GT와 초기 좌표가 모두 영상 안에 있는 915코너의 초기 오차는 평균 2.73픽셀, 중앙값 1.70픽셀, P90 5.97픽셀이다. 세 고정 모델이 실제로 수락한 동일 양성 집합에서 zero-offset 대비 평균 오차 개선은 Geometry 0.16픽셀, Image/no-role 0.21픽셀, Image/role 0.22픽셀이었다. 이 source 분포에서는 큰 좌표 이동보다 유효 경계 관측을 유지하고 코너로 조립하는 일이 더 큰 병목이었다. 영상 밖 GT를 포함한 1,024코너의 평균 7.70픽셀을 같은 난도로 해석하면 안 된다. [기하 감사](SOURCE_NO_RAY_GEOMETRY_AUDIT.json), [고정 모델 진단](SOURCE_FROZEN_HEAD_DIAGNOSTICS.json)

경계 역할 점의 소실도 source-test 자체에서 나타난다. 정답 양성 2,333개 중 BOUNDARY는 941개인데, 원래 66-way MAP에서 Geometry와 Image/role은 그 양성을 하나도 수락하지 않았다. Image/no-role만 46개를 수락했다. 이는 실사 crop·stride 차이만으로 설명할 현상이 아니다. 같은 고정 logits에서 존재 확률의 합을 비교하는 정확한 0.5 이진 MAP는 수락을 늘렸지만 Image/role의 4코너 조립은 여전히 0/128이었다. 또한 source에서 NONE·IGNORE를 선택한 점을 모두 빼면, 두 디코더와 세 모델 모두 4코너 조립이 0/128이다. 그러므로 이진 MAP의 코너 증가를 검증된 양성 대응의 증가로 동일시할 수 없다. Source CPU FP32 진단은 기존 FP16 캐시를 FP32로 읽은 고정 모델 추론이며, 기존 GPU 실행의 반올림 경계와 동일하다는 보장은 하지 않는다. 모델·체크포인트·threshold는 선택하거나 다시 학습하지 않았다. [존재 확률 진단](SOURCE_MATCH_MASS_ANALYSIS.json), [양성만 남긴 조립](SOURCE_MATCH_MASS_LABEL_GRAPH.json)

이를 확인하려고 source-test 128장에 대해 원래 실제 `scene.usd` 메시와 원래 좌표·K·R,t·치수로 정확한 광선을 재현했다. 최초 광선 실행 전에 입력 해시와 최대 실행량을 [고정 프로토콜](SOURCE_RAY_PROTOCOL.json)에 기록했다. 실제 31,875개 광선과 21,377개 closest-point 질의를 수행했으며, 원래 10,752개 POSITIVE/NONE/IGNORE 라벨은 한 개의 차이도 없이 재현됐다. 따라서 문제는 캐시와 새 감사의 불일치가 아니다. 실제 메시 위에 있고 영상 안에 있으며 전달된 visible mask가 지지하는 NONE 4,130개 중 2,164개는 원래 광선이 무한대였고, 1,966개는 목표 점보다 앞의 실제 표면에 맞았다. 앞 표면은 가림의 구체적인 증거이므로 visible mask만으로 해당 점을 가시점으로 바꾸면 안 된다. [광선 원행과 요약](SOURCE_RAY_VALIDATION.json)

원래 무한대였던 NONE 중 1,202개는 normal 방향으로 고정된 ±0.05 원본 픽셀 중 한쪽을 이동하자 실제 메시에서 원래 목표 깊이 허용오차 안의 표면과 교차했다. 그중 1,174개는 BOUNDARY 역할이다. 예를 들어 `P0__shard_00_f0717`의 query 14/edge 2는 실제 메시까지의 closest distance가 약 3e-8 m인데 정확한 광선은 무한대였다. +0.05픽셀 광선은 목표 Z=4.1531 m와 약 -0.0556 mm 차이의 표면에 맞았다. `P0__shard_04_f0942` query 15에서도 같은 방향의 교차가 약 -0.0252 mm 차이로 나타났다. 원래 target 함수의 주석은 작은 inset을 언급하지만 실제 연산은 이동 없는 경계 좌표에 광선을 쏜다. 이것은 정확한 경계 광선에 대한 수치 민감도가 경계 NONE 라벨을 만든다는 구체적인 증거다. 다만 인접 실제 메시 표면의 깊이 증거가 RGB 경계의 소유권을 완전히 증명하거나 수정된 GT를 승인하는 것은 아니다. 해결되지 않은 무한대 962개와 앞 표면 1,966개를 포함해 기존 라벨은 모두 그대로 보존했다. [실제 RGB·mask 사례](figures/08_source_ray_sensitivity.png), [가림·미해결 대조](figures/09_source_ray_controls.png), [사례 해시·query·primitive 정보](SOURCE_RAY_VISUAL_CASES.json)

숫자 조립만 하는 별도 진단에서는 원래 양성에 위 1,202개 증거점만 추가하고 원래 교차점의 단일 가장 가까운 bin을 선택했다. 4코너 이상은 13→33/128장, 영상 안에서는 12→28/128장으로 늘었다. 이 수치는 수정된 감독이나 배포 결과가 아니라 광선 민감도가 조립 제한에 기여하는 정도를 보는 기계적 진단이다. 수치 민감도만 해결하더라도 영상 안의 100/128장은 여전히 4코너보다 적다. 관측 조립, 실제로 관측 가능한 물리 경계와 역할, 대응 존재 확률을 별도로 검증해야 하며, 광선만 바꿔 원래 아이디어의 성공을 주장할 수 없다. 새 RGB, 새로운 학습, 새로운 detector/head forward, 새로운 PnP를 이 광선·조립 감사에 추가하지 않았다.
