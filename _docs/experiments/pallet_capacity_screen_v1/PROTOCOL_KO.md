# YOLO26n/m 1,000-step 용량 선별 검사

이 실험은 사용자가 승인한 빠른 대조 검사다. 본학습 전에
`PROTOCOL_LOCK.json`을 고정한다. n/m 각각 seed 1, 실제 optimizer update
1,000회이며, 결과를 본 추가 학습·seed·체크포인트 선택은 하지 않는다.

## 비교 조건

- 시작: 같은 공식 COCO pose 사전학습 계열의 n/m. 기존 팔레트 R0나 FT
  체크포인트에서 시작하지 않는다. 1클래스/9키포인트로 구성하고 shape가
  호환되는 사전학습 텐서만 로드한다. 원래 COCO 사전학습 연산량까지
  같다는 뜻은 아니다.
- 변수: YOLO 전체 모델의 n/m 크기. backbone만 바뀌는 실험이 아니다.
- 데이터: R0의 합성 train55,980장에서 seed1 균등 추출한 4,000장.
  두 모델 모두 같은 4,000장을 같은 순서로 한 번씩 기본 표본으로 사용한다.
  Mosaic 보조 이미지도 이 부분집합 안에서만 선택된다.
- 실제 영상 라벨의 학습·메타학습 사용: 0장. 역사적 DEV319 전체를 평가하고
  배경 음성2,689장도 검출 AP에 포함한다. 새 독립 확인 데이터는 아니다.
- 공통: 640px, 실제 배치4, SGD, 누적1, FP32, EMA 없음. stock E2ELoss와
  PoseLoss26을 사용하며 모든 일반 파라미터를 학습하고 DFL만 고정한다.
  BN 통계는 정상 학습한다. 실제 optimizer update는 정확히 1,000회다.
- 스케줄: 100step warmup, 1,000step cosine, 800 이후 mosaic off,
  100step마다 stock E2ELoss의 one2many/one2one 비중 갱신.
  이는 양쪽 동일한 짧은 프로토콜이지 원래 R0 60epoch 재현이 아니다.
- 공정성: 각 step의 증강 이미지·라벨 텐서 해시, LR과 표본 순서를 비교한다.
  두 크기의 초기 텐서 자체가 동일하다는 주장은 하지 않는다.
- GPU: 두 모델 순차 실행. 다른 compute 작업을 종료하지 않으며 50step마다
  상태를 확인한다. 80°C 이상이면 중단한다. 전원·드라이버·재부팅 변경 없음.

## 시간과 메모리 사전 시험

각 모델 5step은 배선·메모리·속도 검사 후 폐기한다(총10update).
본학습은 원래 초기 가중치에서 다시 시작하며 초기 상태 해시를 확인한다.
시험 peak tensor allocation은 n 약1,291MiB, m 약4,401MiB였고,
첫 step 제외 중앙 step 시간은 각각 약0.128초/0.194초다.
데이터 로딩·저장·평가 시간 및 지속 부하의 속도 변화는 포함하지 않는다.

기존 optional Albumentations의 ImageCompression API 불일치로 해당 선택
변환은 두 모델 모두 적용되지 않았다. CuDNN nvrtc fallback 경고도 관측했다.
환경을 고치거나 한쪽 조건만 변경하지 않는다. 실제 입력 일치로 확인한다.

## 고정 평가와 판정

250/500/1,000step 체크포인트를 모두 평가하되 최종 판정은 1,000step이다.
250은 학습 경향 설명용, 500은 개선 방향의 일관성 확인용이다.
가장 좋은 중간 체크포인트를 고르지 않는다.

정본 padding/좌표/점수/후보 선택 및 MAIN PnP 평가기를 재사용한다.
키포인트 비교는 각 시점의 n/m 공통 IoU50 검출 프레임에서 한다.
검출 누락을 숨기지 않도록 전체319장 검출률·AP와 포즈 산출률도 함께 본다.
P90는 감독 대상 키포인트 오차를 합친 분포의 90백분위이며,
gross20은 그 키포인트 중 20px 초과 비율이다.

다음 조건을 모두 만족해야 `SIGNAL_FOR_CONFIRMATION`이다:

- 최종 공통 검출100장 이상.
- 최종 공통 kp median/P90 각각5% 이상 개선, gross20 악화 없음.
- 최종 MAIN translation median5% 이상 개선.
- 최종 검출률·box AP50-95·MAIN 포즈 산출률 악화 없음.
- 최종 yaw median 악화10% 이내.
- 500step 공통 kp P90와 MAIN translation median도 악화 없음.

공통 검출이 부족하면 `INCONCLUSIVE_INSUFFICIENT_COVERAGE`, 나머지
미통과는 `NO_SIGNAL_WITHIN_1000_STEPS`다. 두 판정 모두 모델 용량
가설의 최종 기각이 아니다. 표본 수와 초기 수렴에 제한된 탐색 검사다.
전체 학습곡선·독립 일반화·논문 신규성은 이 실험으로 확정하지 않는다.
