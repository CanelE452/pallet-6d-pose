# 자연 가림 pose — 최소 구성 후속 실험

결론: 기존 **217장 보정 자기학습 학생 + 기존 GEO**를 유지한다. 이번에 비교한 33개 구성 중 이 대조의 위치·회전 중앙값을 모두 낮춘 구성은 없었다. 입력 가림, 새 GEO, clean78 학생으로의 교체는 채택하지 않는다. 운영 모델 파일을 자동 교체한 것은 아니다.

자연 가림 99장에서 유지 대조는 위치 **11.410cm**, 회전 **4.955°**다. 같은 GEO의 기존217장 RAW 학생보다 각각 **0.842cm / 0.087°** 낮지만, 큰 위치 오류(P90)는 악화한다. 독립 평가가 아니라 반복 사용한 DEV의 제한된 근거다.
