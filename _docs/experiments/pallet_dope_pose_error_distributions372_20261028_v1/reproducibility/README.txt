프레임별 자세 오차 분포: 초기 R0, 기존 본 실험 LOO+flip self-training R1/R2.
최근 개수 비례 비율 실험의 R2 또는 합성 대조군은 이 그림에 포함하지 않았다.
점 한 개는 한 영상의 한 모델 오차다. 회색 R0, 주황 R1, 파랑 R2.
2차원 산점도는 이동/회전 오차가 모두 있는 표본만 표시한다. 이동 전체 표본 수와 다를 수 있다.
ALL_OBSERVED는 각 오차의 전체 관측값, COMMON_FRAME은 지표별 세 모델 공통 프레임이다.
실패/NA는 오차0으로 표시하지 않았다. 누락과 가설 불일치는 data/COVERAGE.csv에 있다.
군집 수를 가정하거나 유리한 프레임을 선택하지 않았다. 전체 꼬리와 선형 축 버전도 제공한다.
오차 축의 symlog는 0~1 선형, 그 이상 로그다. 오차 수치 자체에는 jitter를 적용하지 않았다.
점 분포도의 범주 축 jitter는 종류+frame id SHA로 고정되며 세 모델에서 같은 frame offset이다.
원본 참조는 독립6D 실측이 아니라 2D 기준점·K·등록 치수에서 재구성한 보조 자세다.
추가 목재80장 K 품질 UNKNOWN/자세 부호 UNCONFIRMED 등 기존 한계는 변하지 않는다.
입력 파일은 허용된 기존 공개 파생 FRAME_ERRORS/MODEL_SUMMARY/RESULTS 세 개뿐이다.
원본 영상·원시 정답·다른 보호 FINAL·가중치 열람 없음. 새 학습·추론·기존 결과 수정 없음.
입력 SHA를 실행 전후 비교했다. population SD(ddof=0)는 원 표와 동일하다.
