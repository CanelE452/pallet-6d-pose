# 지시문에 인용된 외부 원문 재확인

2026-10-16(KST)에 원 지시문의 두 외부 논문 초록도 다시 확인했다. 이 읽기는 실험의 입력·가중치·알고리즘·점수에 변화를 주지 않는다.

PVNet은 픽셀별 방향 벡터의 투표로 키포인트와 위치 불확실성을 구하고 이를 PnP에 활용하는 접근이다. 여기서 실행한 고정 N3/SubPix/B/I 경로는 PVNet 재현이 아니다. [Peng 외, CVPR2019 원문](https://openaccess.thecvf.com/content_CVPR_2019/papers/Peng_PVNet_Pixel-Wise_Voting_Network_for_6DoF_Pose_Estimation_CVPR_2019_paper.pdf), [저자 arXiv 초록](https://arxiv.org/abs/1812.11788).

Cawley와 Talbot은 유한한 자료에서 모델 선택 기준을 반복 최적화할 때 선택 과적합과 성능 추정의 편향이 발생할 수 있음을 설명한다. 이번 고정 자료의 재집계와 예측 봉인은 과거 개발 노출을 없애지 않는다. [JMLR2010 원문 초록](https://www.jmlr.org/papers/v11/cawley10a.html).

CVF HTML 직접 열기는403을 반환했고, 같은 공식 PDF와 검색에 표시된 공식 초록 및 저자 arXiv 초록으로 내용을 확인했다. 과거 읽기 시점의 미기록 시간을 소급해 복원했다고 주장하지 않는다.
