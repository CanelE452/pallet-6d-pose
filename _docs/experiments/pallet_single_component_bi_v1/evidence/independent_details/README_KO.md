# 독립 재집계의 상세 원본

기존에 공개한 독립 검산 영수증의 상세 행별 결과를 추가했다. 원래 지표나 분모를 바꾸지 않았다. `.json.gz`는 압축 해제하면 원래 `.json` 바이트와 SHA256이 정확히 복원된다. `ORIGINAL_SEAL.json`은 원래 독립 검산의 봉인 파일을 이름만 바꿔 보존한 것이다. 원래 해시 확인 시 압축 해제한 JSON을 사용한다.

현재 결과·해석은 [결과](../../RESULTS_KO.md)와 [재현 문서](../../REPRODUCE.md)를 따른다. 새 평가·추론·학습·정답 수정은 없다.
