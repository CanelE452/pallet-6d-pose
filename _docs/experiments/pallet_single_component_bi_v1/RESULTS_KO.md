**N3 단독과 SubPix 단독까지 전체238장·8경로 평가와 독립 검산을 완료했다.** 이전952행은 RAW 대 N3→SubPix 묶음 비교였으며 개별 성분을 이미 확인한 것으로 설명하면 안 된다. 이번에 그 공백을 별도 실험으로 보충했다.

## 입력의 실제 의미

N3단독: original cached qN; no SubPix and no extra strict float64 cap. SubPix단독: existing correct(gray,q0,support,SUBPIX), then existing strict cap centered on RAW q0. 묶음: existing SubPix initialized at qN; final strict total cap centered on RAW q0, not qN. N3 단독의 기존 float32 상한 roundoff도 보존하고 추가 상한을 조용히 적용하지 않았다.

과거20261008의319장 캐시에 BASE/N3/SUBPIX/N3_SUBPIX 초기 좌표는 이미 있었다. 그것은 현재192장의 각 초기화 뒤에 같은 B/I를 독립 계산한8경로 비교를 완료했다는 뜻은 아니다. 이번에는 정확한238장 부분집합과 원래 선택한 YOLO 실행/좌표를 연결하고 누락된 자기 F만 계산한 뒤, N3 단독/SubPix 단독의 상태·마스크·B/I·pose를 각자 새로 계산했다.

자기 F 준비는 총 476회, 기존 cache 대조 257회,누락계산219회다. 새 YOLO/N3/SubPix forward는0이다.

S는 자기 초기 자세 조건부 기하 판정이며 국소 RGB·마스크 prompt·B/I 2D 대응에서 제외한다. 최종 S는 모델 투영으로만 보고하고 O/T/U도 새 정확 2D 대응에 넣지 않는다. 보정 실제 관측과 모델 투영은 다르며 투영을 다시 관측으로 넣지 않았다.

## 권고와 남은 범위

이 표는 성분별 효과를 분리한 대조실험이다. CAL 또는 PRIMARY에서 가장 높은 행을 골라 새 운영 기본값으로 승격하지 않는다. 공동 성공 증가와 손상·평균·꼬리·fallback·자기 상태 모델 전이 제한을 함께 본다. 현재 자료의 좋은 점추정만으로 모든 경로에서 N3나 SubPix가 필수라고 하거나 안전하게 제거 가능하다고 단정하지 않는다.

[성분별 판정](COMPONENT_DECISIONS.md)에 위 대비를 함께 정리했다. 운영 e 교체·논문 수정 전에는 고정한 경로의 손상과 대응 의미 문제가 독립 촬영 군집에서도 재현되는지 확인해야 한다. 기존 guarded 마무리 실험의 실패와 기존 e의 큰 오차도 덮어쓰지 않았다.
