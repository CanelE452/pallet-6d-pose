# T0 메타데이터 집계

[확인] DEV292, 종류별 학습 후보1,000장과 별도 PLASTIC184의 메타데이터를 사용하였다. 보호된 물리 FINAL은 frames.csv의 FINAL 역할만 집계하고 양성·음성을 분리하였다. FINAL_EVAL은 DEV 실행 alias이므로 물리 FINAL에 포함하지 않았다.

[확인] 녹화 ID는 명시된 ID와 기존 registry의 exact session_key 대응만 사용했다. 없는 ID는 null/없음이며 세션 이름을 녹화 ID로 대체하지 않았다. 실내·실외도 명시 조건이 없으면 없음이다. acquisition_domain은 촬영 출처 범주로 별도 표기했다.

[확인] 이미지 SHA 교집합은 CSV/manifest에 선언된 SHA의 비교이다. T0는 이미지 바이트를 새로 읽어 검증하지 않았다. RGB·annotation 본체·모델을 열지 않았고 추론이나 학습을 수행하지 않았다.

[확인] 독립6D 정답은 역할명이나 annotation 완료 여부만으로 인정하지 않는다. 외부 측정/독립 자세 참조의 명시적 메타데이터 근거가 없으면 존재 여부 미확인으로 보고한다.
