- [확인] 원래 pseudo 171좌표 중 코너152+중심19. 직접클릭87개; 새좌표감독87개. PnP대체19개는 전부 비수동 채널로 제외. 비수동코너65개(그 중PnP19)+중심19가 제외되어84개. identity_unknown 명시필드는0개이나 비수동 출처를 수동근거로 간주하지 않았다.
