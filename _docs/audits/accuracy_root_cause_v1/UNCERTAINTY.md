## 1. 앙각별 NME 실패율 — 세션 클러스터 95% CI

모집단 `PAPER_EVAL` 319, 세션 13개. 임계 NME 0.0747 `[추정][미검증]`.

```
앙각        N   세션   실패율   세션클러스터 95%CI    프레임 95%CI
<3         27    2    48.1%   [33.3, 50.0] ★      [29.6, 66.7]
3-8        63    9    52.4%   [37.2, 67.1]        [39.7, 65.1]
8-15       61    6    32.8%   [18.2, 66.7] ★      [21.3, 44.3]
15-30      83    8    16.9%   [10.0, 22.4]        [ 9.6, 25.3]
>=30       85    6    14.1%   [ 6.8, 22.4]        [ 7.1, 22.4]
```

★ 표시한 두 줄은 구간을 그대로 인용하면 안 된다.
`<3` 은 세션이 2개라 클러스터 재표집이 사실상 두 값 사이를 오간다.
`8-15` 는 폭이 48 %p 라 어떤 구간과도 구분되지 않는다.

**지지되는 진술은 이것 하나다** — `3-8도` 의 실패율 CI [37.2, 67.1] 와
`15-30도` 의 [10.0, 22.4] 가 겹치지 않는다. `>=30도` [6.8, 22.4] 와도 겹치지 않는다.
즉 **저앙각이 고앙각보다 크게 나쁘다는 것은 세션 수준에서 확인된다.**
저앙각 안에서의 순서(`<3` vs `3-8` vs `8-15`)는 확인되지 않는다.

## 2. real FT 이득 — 같은 프레임 짝지은 차이

`synth − n_ft` 의 코너 오차 중앙값 차이. 양수 = FT 가 좋음.
SEALED(FT 학습 세션에 없는) 73 프레임, **세션 4개**.

```
앙각      N   세션   중앙차 px   프레임 95%CI      세션클러스터 95%CI   프레임의 >0 비율
<8       49    4     +3.33     [+2.42, +4.69]   [+2.50, +4.69]      81.6%
8-15     24    2     +2.89     [+1.99, +3.74]   [+2.69, +3.01] ★    87.5%
전체      73    4     +3.23     [+2.49, +3.80]   [+2.72, +3.71]      83.6%
```

★ `8-15` 는 세션이 2개다. 클러스터 CI 를 신뢰구간으로 읽지 마라.

세션이 4개뿐이라 클러스터 부트스트랩만으로는 부족하다. 그래서 **세션별 개별 결과**를 함께 낸다:

```
세션              N   앙각 p50   synth med   n_ft med    차이
eval_night08     10     4.6°        9.13        4.94   +4.19
eval_night09     13     5.6°       10.34        9.36   +0.97
eval_pallet07    27     9.8°       11.20        8.08   +3.12
eval_pallet09    23     2.3°        9.27        6.81   +2.45
```

**4개 세션 전부 같은 방향**이고, 한 세션이 전체를 끌고 가지 않는다
(가장 큰 night08 을 빼도 나머지 셋의 차이가 +0.97 ~ +3.12).
이것이 세션 4개라는 약점을 부분적으로 보완한다.

## 3. ★철회 — ">=30도에서 FT 가 악화된다"

`FAILURE_DECOMPOSITION.md` 와 `MODEL_HEADROOM_AUDIT.md` 초판, 그리고 `FINAL_DECISION.md`
§3 에 "정본 140 전체로 보면 고앙각에서는 이득이 사라지거나 뒤집힌다
(>=30도 gross 11.8% → 29.4% 로 악화)" 라고 썼다. **지지되지 않는다.**

```
>=30도 프레임  N=17   세션=1 (전부 eval_cad)
짝지은 중앙차  +0.81 px  (FT 가 오히려 약간 좋다)
프레임 95%CI   [-1.54, +1.81]   → 0 을 포함
세션 클러스터   계산 불가 (클러스터 1개)
```

gross 비율 11.8% → 29.4% 는 17장 중 2장 → 5장이다. 세 프레임이 움직인 것을
"악화" 로 부른 것이고, 짝지은 비교로는 방향이 반대다.
지시문 §29 의 "작은 N subgroup 은 확정적 문장 금지" 를 내가 어겼다.

**정정된 진술**: 고앙각(>=15도)에서 real FT 의 이득은 **확인되지 않는다**(sealed 세션에
>=15도 프레임이 없고, 정본 전체의 >=30도 표본은 한 세션 17장이라 판정 불가).
"이득이 없다" 도 "악화된다" 도 이 데이터로는 말할 수 없다.

## 4. 다음 실험의 성공 임계를 다시 본다

`FINAL_DECISION.md` §5 는 `success = L 이 H 를 20% 이상 앞선다 (관측된 효과 36%)` 로 썼다.
**이 임계의 근거가 약하다.** 두 가지 이유다.

1. 36% 는 `synth → FT` 의 효과다. 다음 실험이 비교하는 것은 `FT(저앙각 라벨)` 대
   `FT(고앙각 라벨)` 이고, **두 arm 모두 real 라벨을 받는다.** 그 대비의 효과 크기는
   알려진 바가 없고, 상식적으로 `synth → FT` 보다 작다. 20% 는 과한 요구일 수 있다.
2. 위 §2 의 CI 폭(전체 +2.72 ~ +3.71 px, 기저 ~9.6 px 이므로 28~39%)은
   `synth vs FT` 의 것이지 `L vs H` 의 것이 아니다.

**제안 (`[추정][미검증]`)**: 고정 % 임계 대신 **구간 기준**으로 사전등록한다.

```
success  L − H 의 짝지은 차이가 세션 클러스터 95% CI 로 0 을 배제하고 부호가 L 우세
failure  CI 가 0 을 포함하고, 점추정 차이가 GT repeatability 이하
         (repeatability 는 아직 미측정 — GT_SEMANTICS_REVIEW_PLAN.md 의 20장 x 2회로 잰다)
```

그리고 **세션 수를 사전에 확보해야 한다.** 위 §2 가 보여준 것이 그것이다 —
세션 4개로는 클러스터 CI 가 겨우 서고, 2개면 서지 않는다.
held-out 세션이 **최소 6개** 는 되도록 split 을 짜야 한다 `[추정][미검증]`.

## 5. 이 문서가 바꾸지 못하는 것

- held-out 이 여전히 없다. 위 CI 는 전부 DEVELOPMENT 모집단 위의 것이다.
- 앙각은 여전히 **상관**이다. 세션 클러스터 부트스트랩은 세션 간 변동을 반영할 뿐,
  앙각과 세션·물체·조명의 교락을 풀지 못한다. 그 분리는 다음 실험의 설계가 한다.
- 단일 seed 다. 부트스트랩은 표집 불확실성을 재지 학습 seed 불확실성을 재지 않는다.
