## 1. 외삽 코너는 허공에 있지 않다 (§3.4)

15 프레임 · 외삽 코너 71개를 코너별로 물었다.

```
판정        n     비중
ambiguous  47   66.2%    가려지거나 흐려서 못 정하겠다
physical   24   33.8%    사진 속 팔레트의 진짜 모서리 자리에 있다
virtual     0    0.0%    ★그 자리에 모서리가 없다 — 한 건도 없다
```

클릭수별로도 `virtual` 은 전부 0 이다:

```
클릭수   물리   가상   애매
  4       8     0     17
  5       9     0     11
  6       2     0      1
```

**이건 GT 에 유리한 결과다.** PnP 로 채운 점이 물체를 벗어나 엉뚱한 곳에 찍힌 경우는
관측되지 않았다. 확인 가능한 것은 맞았고, 나머지는 **확인이 불가능**할 뿐이다.

★단 `ambiguous` 66% 를 "맞다" 로 읽으면 안 된다. 가려진 코너는 사람이 검증할 수 없고,
그래서 **그 코너로 모델을 채점하면 물리 코너가 아니라 PnP 모델과의 일치도를 재게 된다**는
`FAILURE_DECOMPOSITION.md` 의 지적은 그대로 유효하다. 이번 결과는 "틀렸다" 를 배제할 뿐
"맞다" 를 확인해 주지 않는다.

## 2. 프레임 단위로는 43% 만 깨끗하다

같은 것을 프레임 단위로 물은 답(1차 질문 2, 58 프레임 전수):

```
전부 맞다      25   43.1%
모르겠음       21   36.2%
일부 어긋난다   11   19.0%
대체로 엉뚱     1    1.7%
```

코너 단위(가상 0%)와 프레임 단위(어긋남 20.7%)가 어긋나 보이는데, 모순이 아니다 —
코너 단위 질문은 "그 자리에 모서리가 **있나**" 를 물었고, 프레임 단위 질문은
"제 자리에 **정확히** 있나" 를 물었다. **물체 위에는 있지만 몇 픽셀 어긋난** 경우가
후자에서 "일부 어긋남" 으로 잡힌다.

## 3. 재현성 — 판정은 안 뒤집히고, 확신만 흔들린다 (§4)

같은 20 프레임을 1차 답을 가린 채 다시 판정했다.

```
1차 -> 2차            n
A           -> A      6
B           -> B      6
cannot_tell -> ct     5
A           -> ct     2   불일치
B           -> ct     1   불일치
                     ──
일치 17 / 20 = 85.0%
```

**A -> B 뒤집힘은 0건이다.** 불일치 3건은 전부 "1차에 골랐는데 2차에 모르겠다" 이고,
양 회차가 모두 A/B 를 고른 12건은 **12/12 = 100% 일치**한다.
저장본 일치율도 두 회차가 같다(10/12 · 10/12).

→ **리뷰어의 판정은 재현되고, 흔들리는 것은 판정 자체가 아니라 "판정할 수 있는가" 다.**
이건 §1 의 확신도 보정(확신도 4~5 에서 저장본 17/17)과 같은 방향이다.

### 이 수치를 쓸 때의 한계 (봉합하지 않는다)

- 계획은 "최소 3일 간격, 순서 무작위" 였는데 실제로는 **같은 날 같은 세션**에서 이어 했다.
  프레임을 알아볼 가능성이 있어 **85% 는 상한으로 읽어야 한다.**
  진짜 test-retest 는 더 낮을 수 있다.
- 리뷰어 1명이다. 리뷰어 간 일치도(inter-rater)는 측정하지 않았다.
- N=20 이다. 85% 의 이항 95% 신뢰구간은 대략 [62%, 97%] 로 넓다 `[추정]`.

## METHOD_LOCK 에 대한 함의

`failure_criterion` 이 참조하던 "GT repeatability 이하" 의 그 값이 이제 있다 —
**같은 프레임을 다시 봤을 때 판정이 뒤집힐 확률 0%, 판정 불가로 후퇴할 확률 15%.**
따라서 두 arm 의 차이를 판정할 때, **부호가 뒤집히는 수준의 차이는 GT 산포로 설명되지 않는다.**
크기(px) 산포는 이 리뷰가 재지 않았으므로(축 가설은 이산 선택이다),
`failure_criterion` 은 여전히 **"CI 가 0 을 포함"** 으로 두는 것이 맞다.
