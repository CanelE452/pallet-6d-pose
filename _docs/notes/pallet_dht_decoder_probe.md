# 점·선 후보를 직접 결합하는 빠른 실험

갱신: 2026-09-09. 학습·평가·독립 감사·보고서 시각 확인·사용자 전달 완료. 등록한 후속 진행 기준은 불충족이다.

## 1. 제안 — 2026-09-09, 실행 전

목적: 기존 Deep Hough 모델이 가진 선 증거를 최종 점 계산에 직접 사용하면, 작은 결합부 학습만으로 원래 semantic ID의 실사 점오차를 개선할 수 있는지 확인한다.

직접성: 사용자가 요청한 아키텍처 결합의 예비 검사다. Self-training, pseudo-label 선택, 검출 수락 필터를 도입하지 않는다. 이전 incidence는 손실의 관계 제약이었다. 이번에는 고정된 선 분포에서 교점 후보를 만들고 영상 특징으로 후보를 가중하는 출력 모듈을 학습한다. Backbone/DHT를 고정하므로 전체 네트워크의 end-to-end 학습 검증은 아니다.

판단지표: 정본 camera_dynamic_0123_v4의 원래 점 번호와 v>0 마스크를 보존한 median/P90/mean 점오차, PCK10/20, 큰 점오차 비율, 원래 오차≤10px인 점의 악화, 검출/유효점 coverage. 위치와 번호 오류를 분리해 검토한다. 이번 빠른 검사는 2D이며 6D 포즈 향상을 주장하지 않는다.

### 실행 범위

1. 무학습: 기존 hough_joint 3seed의 동일한 고정14장(세션 SHA 표본13장+사용자 사례1장)의 저장 logits/점만 읽는다. 역할별 상위4개 선과 incident 3역할의 교점48개+원래점1개를 후보로 만든다. GT-free 점수로 고르는 결과와 GT가 최선 후보를 알려주는 oracle 진단을 분리한다. Oracle은 성능 결과가 아니다.
2. 작은 학습: 사전에 지정한 기존 hough_joint seed1의 마지막 EMA를 고정한다. 기존 합성 source train에서 SHA 순서2048장, source val에서512장을 분리해서 선택한다. 둘은 서로 겹치지 않지만 backbone 학습/validation에 사용된 pool이므로 새로운 backbone holdout이 아니다. 실사319장은 기존 DEV이며 독립 FINAL이 아니다.
3. 점 전용과 실제 선 결합의 같은 파라미터 수 모듈을 각각1000updates, batch64, 같은 샘플 순서/초기화로 학습한다. 합성 GT만 손실에 사용하고 마지막 checkpoint만 평가한다. 학습된 선 모듈에 다른 이미지의 선만 넣는 ablation을 추가한다. 영상 특징과 원래 점은 해당 이미지 것을 유지한다.

확정 출력식: `q_i=p_i+tanh(g_i)*(Σ_k softmax(s_ik)c_ik-p_i)+0.05*raw_diagonal*tanh(r_i)`. 원래8코너를 갱신하고 중심8번은 보존한다. Gate/residual 마지막 projection을0초기화해 시작 출력은 원래 점과 같다. Gate는 부호를 가질 수 있는 학습 가중치이며 보정된 불확실성이나 항상 교점으로 향하는 보장은 아니다. 총 이동을 작게 제한하지 않아 큰 번호 오류의 교정을 구조적으로 차단하지 않는다. 최종점을 선 위에 강제로 고정하는 hard constraint도 아니다.

동일 모듈은55,118parameters다. 점 전용49후보는 원래 점 자신+다른8개 예측점(중심 포함)+고정40개 국소격자점으로 구성해 점 전용도 번호 재배정이 가능하다. 40개는7×7격자에서 중심/네모서리/네축극점을 제외하고 `0.05*raw_diagonal/3` 간격을 사용한다. 선 모듈은 원래 점+48교점이다. 각 후보의 실제 frozen P4 영상특징, 전체9점/신뢰도와 영상전역특징을 사용한다. AdamW(lr0.001, weight_decay0.0001), seed1, 일정LR, 증강 없음,100updates마다 합성validation만 기록한다. 학습손실은 raw대각선으로 정규화한 SmoothL1(beta0.01), 합성GT v>0 및 최고점수 검출의 IoU≥0.5 매칭 마스크다. 정답으로 검출 후보를 고르지 않으며 미매칭 수도 남긴다.

### 사전 판단과 중단 기준

무학습 진단의 음성 결과는 후보 선택을 학습해야 할 가능성 때문에 작은 학습을 차단하지 않는다. 기하/좌표/gradient 경로 검사 실패 또는 비유한 값이면 원인을 수정하고 본 실행 전 다시 검증한다. 최종 모델/계수/후보 수를 실사 결과로 고르거나 재튜닝하지 않는다.

더 큰 실험의 근거는 실제 선 모듈이 같은 크기의 점 모듈 및 고정 원래 예측보다 median을 낮추고 P90을 악화시키지 않으며, 점 모듈 대비 프레임 평균오차 차이의 세션 cluster bootstrap 95% 구간 상한이0 미만이고, 원래 양호점의10px초과 전환율이 점 모듈보다 높지 않은 경우로 미리 정한다. Bootstrap 20,000회, seed20260909. 한 학습 seed의 탐색적 판단이며 안정적 성능 향상/독립 검증의 증거는 아니다. 잘못된 선 ablation은 입력 교란에 대한 의존성 검사이며 인과적 상보성의 단독 증명이 아니다. 이 조건을 만족하지 않으면 이번 pilot의 향상 근거 미확인으로 종료하고 이전 규모 학습으로 자동 확장하지 않는다.

### 선행 근거와 새 설계의 범위

[HAWP, CVPR2020](https://openaccess.thecvf.com/content_CVPR_2020/papers/Xue_Holistically-Attracted_Wireframe_Parsing_CVPR_2020_paper.pdf)는 선과 junction 후보의 연결 및 영상 특징을 이용한 검증을 한 파이프라인에서 다룬다. 이를 점·선 후보를 함께 활용하는 선행 근거로 참고한다. 이번 팔레트 역할별 DHT 교점/고정 backbone 결합부는 해당 논문의 재현이 아닌, 사용자가 승인한 미검증 응용 설계다.

예상 실패 모드: 올바른 역할의 선/교점이 후보에 없음, 거의 평행한 선의 불안정한 교점, semantic ID 혼동, 모호한 선 분포, frozen 영상 특징의 한계, 합성에서 학습된 선택 규칙의 실사 전이 실패. 같은 GT에서 점·선 감독을 만들었다는 사실만으로 결합 불가능을 결론내리지 않는다.

## 3. 작은 결합부 학습

두 모듈 모두 등록한 1,000 updates를 완료했다. 각 55,118개 파라미터, 신규 학습 seed 1개이며, 초기 가중치와 전체 batch·손실 마스크 순서가 같았다. 각 군은 64,000장 노출·506,159개 유효 코너 노출을 사용했고, 유효 손실이 전혀 없는 batch는 0개였다. 마지막 checkpoint만 사용했다. 초기 출력 동일성, 후보 선택기까지의 gradient 연결, 중심점·결측점 보존을 실제 스모크에서 확인했다. 고정 CNN의 가중치·상태는 전체 추출 전후 같았다.

여기서 **점 전용은 같은 joint backbone 위에 새로 학습한 점·영상 후보 모듈**이다. 이전 실험의 점만 학습한 YOLO 모델을 뜻하지 않는다. 원래 예측, 점 모듈, 선 모듈 모두 사전에 지정한 같은 joint seed1 EMA를 사용한다.

## 5. 사용자 사례와 실제 출력 구성

![같은 원본에서 GT, 고정 예측, 두 학습 모듈과 선교점 후보를 비교한 저장 보고서 화면](../assets/pallet_dht_decoder_probe/problem_case_20260909.png)

흰 테두리가 있는 GT 번호와 청색·주황색 예측 번호를 비교하면 같은 위치가 아니라 같은 ID가 맞아야 함을 볼 수 있다. 오른쪽 아래는 4번 코너의 실제 역할별 선 후보이며, 가까운 후보의 존재가 최종점 교정을 보장하지 않는다. 재추론 없이 완성된 보고서 화면을 복사한 스냅샷이다.

`eval_pallet07:1778652166837872128`의 공식 유효 8점 median은 원래 270.065px → 점 모듈 267.160px → 선 모듈 265.213px였다. 큰 번호·위치 오류가 해결된 결과가 아니다. 이 프레임의 3번 코너는 공식 GT 마스크에서 제외되며, 유효 8점에는 고정된 중심점이 포함된다.

선 모듈에는 4번·7번 GT에서 각각 10.042/5.562px 떨어진 후보가 실제로 있었다. 그러나 그 후보의 학습 가중치는 1.306%/0.848%, signed gate는 −0.01289/−0.00826이었다. 최종 이동은 1.816/0.123px에 그쳤고, 오차는 279.481/280.702px로 남았다. 특히 gate 적용 전 가중후보는 GT에서 39.901/32.701px로 원점보다 훨씬 가까웠다. 단일 최선후보의 작은 가중치만으로 선택기 전체가 유용한 위치를 찾지 못했다고 단정할 수 없다. 모듈은 후보 하나를 고르는 hard selection이 아니라 가중평균·부호 있는 gate·잔차를 합산한다. 이 두 점에서는 유용한 가중좌표가 일부 만들어졌지만 작은 음의 gate와 잔차를 거친 최종점이 큰 재배치를 실현하지 못했다. 왜 그런 gate를 학습했는지는 이 산술 분해만으로 설명하지 않으며, GT로 gate를 바꾼 성능 실험도 하지 않았다. 한편 0번은 최선 후보조차 GT에서 229.554px 떨어져 있어 후보 부족 문제도 함께 남아 있다. GT 최선 후보는 사후 oracle 진단이며 실제 선택 입력이 아니다.

실사에서 평가 가능한 2,429개 코너(고정 중심점 제외)를 분해하면, 선 모듈의 |gate| 중앙값은 0.0209였다. `gate×(가중후보−원점)` 좌표항의 길이 중앙값은 0.245px, 작은 잔차항은 1.096px, 최종 이동은 1.278px였다. 벡터 방향이 다르므로 두 길이의 합이 최종 이동 길이는 아니다. 이 실험에서 많은 점을 소폭 조정했다는 관찰이며, 잔차를 제거한 인과적 ablation은 하지 않았다. 원래 이미지 대신 다른 선을 넣는 검증도 이 한계를 없애지 않는다.

저장된 FP32 중간값으로 식을 다시 계산한 최대 좌표 차이는 0.000015px 미만이었다. 추가 모델 forward 없이 저장 예측을 읽어 확인했다. 근거: [예측과 실제 후보 가중치](../../data/pallet/results/pallet_dht_decoder_probe_v1/PREDICTIONS.json), [사례·좌표항 분해](../../data/pallet/results/pallet_dht_decoder_probe_v1/provenance/docs_interpretation/RESULTS.json).

### 사후 성분 진단: gate를 모두 1로 열면

위 사례만 보고 gate를 제거하면 된다고 결론내리지 않기 위해, 동일 319장 전체에서 저장된 가중후보·잔차를 고정하고 `q=가중후보+잔차`를 계산했다. 계산 전에 gate=1 한 값과 전체 모집단을 고정했으며, GT로 gate나 후보를 선택하지 않았다. 새 모델 forward·학습은 없고 중심점도 보존했다. 등록된 주 평가·후속 판단을 대체하는 실험이 아니다.

## 6. 확인한 범위와 전달 상태

이번 빠른 실험은 점·영상·선교점 후보를 최종 좌표에 직접 연결하고 작은 모듈을 학습할 수 있음을 확인했다. 그러나 이 고정 backbone·후보 구성·손실·1,000-update 설정에서 실사 향상 기준과 문제 사례 해결은 확인하지 못했다. 후보가 일부 유용하다는 oracle 결과, 모듈이 선에 반응한다는 교란 결과, 실제 정확도 개선은 서로 다른 주장이다.

신규 학습 seed는 1개이고, 비교군 모두 같은 기존 joint backbone을 공유한다. Backbone/DHT end-to-end 재학습, 독립 FINAL, 6D 포즈, 실사 음성 이미지 검출 성능은 이번 검증 범위에 없다. 후보 누락·역할 혼동·학습된 선택/이동의 한계 중 무엇이 지배적인 원인인지는 이 결과만으로 확정하지 않는다.

학습·평가·독립 감사와 실제 화면 검토를 완료했고, 보고서 브라우저 창 확인 및 요청된 Discord 알림 전송(HTTP204)까지 완료했다. [완료 기록](../../data/pallet/results/pallet_dht_decoder_probe_v1/COMPLETION.json)의 PASS는 실행·검증·전달의 완료를 뜻하며 성능 향상 판정이 아니다.
