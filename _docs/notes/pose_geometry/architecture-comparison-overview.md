# 기존 대비 아키텍처 개선량 비교

2026-09-11 저장 결과 대조. 새 학습 없이 기존 수치로 계산했다. 대표 구조와 최신 검증을 요약하며, 모든 실험을 같은 평가셋의 순위표로 합치지 않는다.

오차는 작을수록 좋다. **개선율=(기준 오차−방법 오차)/기준 오차×100**이며 양수는 개선, 음수는 악화다. 아래 실사와 V44 표는 보고서에 표시된 반올림 수치로 산출한 근삿값이다. 최신 치수 표는 SUMMARY.json의 원시 수치에서 계산했다.

## 최신 치수·대칭 네 군

동일 합성512장, 학습군3시드 평균. 마지막 점/sigma 출력층 및 FiLM만 학습했다. 검출 실패1장을 대각선 벌점으로 포함했다. 모든 군에 같은 유효 대칭 평가를 적용했다.

| 방법 | 평균 오차 px | 기존 YOLO 대비 오차 감소 | P90 px |
|---|---:|---:|---:|
| 기존 YOLO | 5.0551 | +0.000% | 6.3392 |
| A 같은 예산 추가 학습 | 5.0744 | -0.382% | 6.2089 |

치수만의 효과로 앞서 제시한0.29~0.58%는 정규화 주 지표에서 C 대 A의 시드별 개선이다. 위 표는 원래 YOLO 대비 원본 픽셀 평균 오차의 감소율이므로 기준과 집계가 다르다. C/D의 seed1은 기존 YOLO보다 나빴으며 전체 안정성 기준은 통과하지 못했다. D의 P90은 평균2.70% 개선됐지만 이것만으로 전체 안정적 향상이라고 판정하지 않는다.

초기 C2 학습 객체1,364개 중 공동 대칭 로스가 다른 정답 배치를 선택한 것은2개다. 치수 입력의 작은 효과와, 대칭으로 바꿀 감독이 적다는 사실을 분리한다.

## 실사 기반 조건별 대표 구조

실사297장·9촬영 세션의 재사용 DEV, 수동 GT에 인공 가림/잘림을 적용한 평가다. 각 셀은 **오차px (원래 YOLO 대비 개선율)**. 원본은 검출 프레임 평균, 가림/잘림은 해당 대상점 평균이다. 코너 가림280점, 잘림20/40%의 화면 밖558/571점을 대상으로 하며 열들을 합쳐 전체 점수로 만들지 않는다. 조건별 후보의 최고값을 모아 하나의 배포 모델처럼 해석하지 않는다.

## 새 합성 장면 V44 검증

같은2CAD의 새24그룹 중8최종 그룹,200관측 중 검출137관측의1,096점에 한정한다. 미검출은 아래 점 오차에서 제외된다. 기준은 원래 YOLO가 아니라 공통 V34 기준점이다. 보정기는 HGB 회귀이며 신경망 재학습 결과가 아니다.

| 구조 | 평균 px | 같은 V34 기준 대비 오차 감소 |
|---|---:|---:|
| V34 기준점 | 9.058 | +0.00% |
| 고정 V41 직접 회귀 | 9.025 | +0.36% |
| 새 장면 학습·점 특징 | 8.767 | +3.21% |
| 새 장면 학습·점+선 특징 | 8.674 | +4.24% |

점+선8.674px의 V34 대비 평균 개선은약4.24%다. 그러나 점 대조8.767px 대비 선 추가 감소는약1.06%이며, 그 차이95% 구간[-0.1798,+0.0026]px가0을 포함했다. 쉬운 잘림에서는 약3.0→4.0px 피해도 남아 안정성 실패였다. 고정 V41의 작은 효과는 새 장면에 재현됐지만0.36% 수준이다.

## 성능으로 세지 않은 결과

- 초기 v6 공동 점·선·자세 모델은 새 점 head의 정확도가 기존 YOLO보다 낮아 채택하지 않았다. [실제 v6 결과](../../../data/pallet/results/pallet_point_line_decisive_v6/INTERPRETATION_KO.md).
- GT로 선·후보·이동량을 선택한 oracle 수치는 실제 아키텍처의 성능 표에 넣지 않았다.
- Hough 의사라벨의8.5156→8.1114px는 라벨 품질 검사다. 학생 모델 재학습 결과가 아니므로 아키텍처 개선에 합산하지 않았다.
- 기존41.49px는 초기 평가의 P90이며, 최신 평균px와 평가셋·대상·정의가 달라 차감해 개선량을 만들 수 없다.

현재까지 검증된 결론은 특정 조건의 실질적 개선, 새 장면에서의 작은 보정 효과, 최신 치수 입력의 작은 효과다. 모든 조건을 지키면서 기존 모델을 안정적으로 대체할 단일 구조는 아직 검증되지 않았다.
