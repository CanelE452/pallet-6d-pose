## 1. 핵심 요약

강한 기존 YOLO의 점 출력을 시작점으로 사용하고, 알려진 팔레트 치수와 점 주변 출력 특징을 이용해 좌표를 작게 보정한다. 큰 번호 대응 오류는 작은 좌표 이동과 분리해 다룬다. 이 구조에는 영상 선 검출기, Deep Hough Transform, 선 loss가 없다. 점 사이 거리·면적은 예측점에서 계산한 기하 특징이다.

새 합성 장면에서 번호 대응을 제외한 위치 오차는 본 종류 6.24→5.30px, 학습에 없던 두 종류 8.29→7.07px로 감소했다. 새 종류의 감소율은 세 시드에서 14.48~14.85%였다. **이 수치는 고정 모델의 사후 대응 진단이며, C4 loss로 통합 학습한 모델의 최종 자세 성능이 아니다.**

현재 논문에서 가장 직접적인 근거는 작은 점 보정 효과와, 코너 번호 오류가 공간적 성공·실패를 크게 왜곡할 수 있다는 분석이다. 객체별 허용 대칭을 반영한 loss는 올바른 문제 정의로 유지하되, 그 기본 원리를 신규 발명으로 주장하지 않는다.

| 항목 | 현재 상태 |
|---|---|
| 선 없는 치수 조건부 코너 후보 선택 + 작은 보정 | 구현·학습·저장 예측 검증 완료 |
| 객체 전체에 같은 대칭을 적용하는 loss | 실물 C4, 별도 합성 C1/C2 계열에서 구현·학습 완료 |
| 위 보정 구조 + 객체별 C1/C2/C4 loss의 통합 모델 | 아직 동일 모델로 학습·검증하지 않음 |
| 현재 보정 모델의 독립 실물·새 촬영 세션 성능 | 미검증 |

## 2. 초록 초안

팔레트 키포인트 추정에서는 코너의 공간적 위치 오류와 번호 대응 오류가 하나의 지표에 혼합될 수 있다. 본 연구는 사전 학습된 YOLO 키포인트 출력을 유지하면서, 알려진 치수와 관측 특징을 이용해 코너 대응 후보와 제한된 좌표 보정을 분리하는 방법을 분석한다. 제안한 구현은 객체 전체의 네 가지 순환 대응 후보를 구성하고, 별도 파라미터를 갖는 오차 예측기와 잔차 보정기를 학습한다. 네 가지 후보는 대응 오류 가설이며 모든 팔레트의 물리적 C4 대칭을 가정하지 않는다. 두 학습 메시와 두 미학습 메시로 생성한 새 합성 576관측에서 공통 매칭된 대상의 예측을 비교했다. 사후 번호 대응 제외 진단에서 세 시드 평균 오차는 본 종류 6.24px에서 5.30px, 미학습 종류 8.29px에서 7.07px로 감소했다. 반면 번호 고정 주 지표의 사전 안정성 기준은 통과하지 못했다. 이 결과는 후보별 잔차 보정의 위치 개선 가능성을 지지하며, 후속 비교에서 객체별 허용 대칭을 학습과 평가에 일관되게 적용할 필요성을 보여준다. 실제 환경 일반화와 통합 대칭 loss 모델의 효과는 향후 검증 대상으로 남는다.

## 3. 문제 정의와 입력

입력은 RGB 이미지 I와 알려진 치수 d=(W,D,H)이다. 8개 상자 코너와 중심점 1개를 다루되, 현재 보정 loss와 주 위치 평가는 **8개 코너**에 적용한다. 네 대응 모두 중심점의 인덱스 8을 유지한다. 현재 보정기는 중심점 잔차도 출력하지만 그 잔차에 직접 GT 손실은 주지 않았으므로, 중심점 정확도 개선을 결과로 주장하지 않는다.

치수는 고정된 물체 축 기준으로 기록한다. 합성 파일의 `dims_xyz`는 X/Y가 바닥, Z가 높이이고, 다른 실물 레지스트리는 Y가 높이인 경우가 있다. 입출력 단계에서 이를 명시적으로 변환해야 하며 카메라 시점에 따라 W/D를 임의로 교환하지 않는다.

통합 목표에서는 객체의 허용 대칭 집합 G도 필요하다. 치수만으로 진입면의 방향성을 알 수 없으므로, G는 등록된 종류 또는 제한된 지원 범위에서 결정한다.

| 지원 조건 | G |
|---|---|
| 정사각이며 네 방향이 작업상 동등 | C4: 0/90/180/270도 |
| 직사각이며 앞뒤가 작업상 동등 | C2: 0/180도 |
| 방향을 구별해야 하는 종류 | C1: 지정 방향 |

**현재 v2 보정 모델에는 G 입력이 없다.** 치수 조건화와 대칭 타깃 선택은 서로 다른 기능이다. G는 학습·평가 계약으로 반드시 전달하고, 신경망에도 입력할지는 별도 설계 선택이다. 치수만으로 모든 객체의 대칭을 추론했다고 주장하지 않는다.

## 4. 완료한 점 개선 아키텍처

![실제 구현된 점 보정 구조](../../../../data/pallet/results/pallet_point_only_paper_v1/architecture.svg)

### 4.1 기존 점을 보존하는 시작점

기존 YOLO26n의 백본·검출기·점 head는 동결한다. 가장 높은 confidence 검출에서 기존 점 P₀, 가시성 출력, 예측 박스를 얻는다. 기존 전처리인 100px reflect101 border와 640 letterbox를 모든 비교군에 동일하게 유지한다.

해당 검출이 나온 스케일의 **YOLO pose 출력 맵 45채널**에서 9개 예측점과 7×7 ROI 격자의 특징을 보간 추출한다. 이는 임의의 고차원 백본 특징이나 attention 시각화가 아니라 캐시 코드가 실제로 사용하는 출력 특징이다. 예측 박스 기준 정규화 좌표와 알려진 로그 치수를 함께 사용한다.

### 4.2 코너 대응 가설과 작은 잔차의 분리

9점을 네 가지 순환 대응 H={π₀,π₁,π₂,π₃}로 재배열한다. 각 후보에서 점 좌표·점 특징·가시성은 같은 순서를 따른다. 위/아래 및 상자의 연결 관계를 보존한다.

```text
후보 점:         Pₖ = πₖ(P₀)
후보별 보정:     Δₖ = 16 · tanh(f_res(후보 특징, ROI 특징, 치수))
보정된 후보:     Qₖ = Pₖ + Δₖ
추론 후보 선택:  k̂ = argminₖ [s · rₖ + 2 · 1(k≠0)]
최종 점:         Q = Q_k̂
```

s는 예측한 8점 범위의 대각선 길이이며 최소 32px다. 2px는 원래 순서에서 전환할 때의 고정 비용이다. 잔차의 각 x/y 성분은 ±16px로 제한되며, 2D 이동 거리 전체가 16px 이하라는 뜻은 아니다. 초기 출력층을 0으로 설정해 처음에는 원래 점과 순서를 재현한다. 학습 뒤 정상점 비악화를 보장하는 장치는 아니다.

오차 예측기는 점 특징·ROI 특징·치수 외에 예측점의 12개 연결 길이, 6개 면적, 가로세로 비율을 사용한다. 잔차 분기는 점 특징·ROI 특징·치수를 사용한다. 두 MLP는 입력을 공유하지만 학습 파라미터는 독립적이다. **총 94,331개 파라미터: 오차 예측 계열 47,829개, 잔차 계열 46,502개.** hard argmin을 통과하는 gradient는 사용하지 않는다.

이는 기존 네트워크에 학습 가능한 정제 모듈을 추가한 아키텍처 변경이다. YOLO 전체를 새로 학습한 결과나 필터 기반 pseudo-label selftraining은 아니다. 추론에는 GT를 사용하지 않는다. 알려진 치수와 K를 이용한 PnP는 별도 이동 오차 진단이었으며 학습 가능한 공동 pose head가 아니었다.

### 4.3 H와 G를 구분해야 하는 이유

H는 **예측 코너 번호가 잘못 붙었을 가능성**이고, G는 **물체에서 정답으로 인정할 물리적/작업상 회전**이다. 현재 구현은 모든 메시에서 네 H 후보를 사용했다. 이것을 모든 메시가 C4라는 뜻으로 해석하면 안 된다. 새로운 loss는 객체별 G를 사용해야 한다.

## 5. Loss: 실제 사용한 식과 통합 목표

### 5.1 현재 결과를 만든 실제 loss

최종 `foreground_train.py`에서는 각 후보의 보정 전 평균 코너 오차를 계산한다.

```text
eₖ = meanᵢ₌₀…₇ ||Pₖ,ᵢ − Yᵢ||₂
k* = argminₖ eₖ
L_risk = meanₖ (rₖ − eₖ/s)²
L_res  = SmoothL1(Q_k*, Y; beta=4) / 16
L_actual = L_risk + L_res
```

잔차 loss는 8점의 x/y 성분 전체 평균이다. 직접 점 보정 대조군은 k*=0이고 L_risk를 끈다. 선택 후보의 감독에 GT를 사용하는 것은 학습 단계에 한정된다. 최종 구조의 오차 예측 loss는 MSE이며, 초기 단계의 Huber 선택기와 구분한다.

이 loss는 GT에 가장 가까운 후보로 잔차를 학습하지만, 오차 예측기는 여전히 **번호 고정 GT**에 대한 오차를 학습한다. 객체별 C1/C2/C4 최소 공동 loss를 통합한 모델과 같지 않다.

### 5.2 논문에서 유지할 대칭 loss 정의

선 없는 키포인트 모델에서는 다음을 기본 타깃 정의로 사용한다.

```text
L_sym-point = min(g ∈ G) [λ_xy L_xy(Q, Y_g) + λ_v L_visibility(V, M_g)]
```

Y_g와 M_g는 하나의 허용 회전 g에 따라 함께 바꾼 좌표와 가시성 타깃이다. 한 객체의 모든 점과 해당 손실 항은 같은 g를 사용한다. 점마다 다른 정답을 고르거나 네 정답의 좌표를 평균내지 않는다. 학습 가능한 pose head를 추후 추가할 때만 같은 g를 공유하는 pose 항을 더한다. **현재 점 구조에 선 loss나 학습 pose loss가 있는 것처럼 쓰지 않는다.** λ 값과 세부 좌표 loss는 통합 모델의 후속 프로토콜에서 고정할 항목이며, 현재 8.29→7.07px의 학습 설정으로 소급하지 않는다.

주의할 설계 문제가 하나 있다. C4 객체에서 네 후보가 같은 좌표 집합의 순열뿐이면, 대칭을 인정한 보정 전 오차가 모두 같아진다. **이 경우 선택기에 ‘올바른 절대 번호’를 고르라는 loss를 유지할 이유가 없다.** 통합 설계에서는 동등한 번호의 대표 하나를 유지하거나, 실제 보정 후 위치 품질이 다른 후보를 선택하도록 목적을 바꿔야 한다. 어느 방식이 나은지는 아직 비교하지 않았다. 현재 선택기의 타깃에 C4만 붙여 통합이 끝났다고 주장하지 않는다.

## 6. 완료한 실험과 비교표

### 6.1 점 개선 구조: 같은 새 합성 집합

학습 메시: `scene.usd`, `scene_1.usd`. 새 종류: 해당 YOLO 및 보정 학습에 없는 `scene_2.usd`, `scene_3.usd`. 색은 종류와 독립적으로 무작위화한다. 네 메시 모두 가로·세로를 독립적으로 변형했으므로 이 집합은 정사각형을 유지한 C4 검증셋이 아니다.

학습 1,536관측 중 GT 박스 IoU≥0.5인 1,400개에 코너 감독을 줬다. 136개의 잘못 연결된 검출 후보를 GT 객체처럼 학습시키는 문제를 수정한 최종 단계다. 학습 시 confidence 필터는 사용하지 않았다. AdamW, lr=0.0003, weight decay=0.0001, batch=32, 군별 1,200업데이트, 시드 1/2/3. 마지막 checkpoint를 사용하고 검증으로 시드를 고르지 않았다.

평가 576관측은 각 메시 12개 무작위 장면 그룹 × 4시점 × clean/panel/crop25로 구성된다. 본 종류 216/288장, 새 종류 208/288장이 confidence≥0.25 및 GT box IoU≥0.5를 충족했다. 아래 모든 방법은 이 공통 모집단의 8코너를 사용한다.

| 방법 | 본 종류: 번호 고정 | 본 종류: 대응 제외 | 새 종류: 번호 고정 | 새 종류: 대응 제외 |
|---|---:|---:|---:|---:|
| 기존 YOLO | 23.92 | 6.24 | 25.14 | 8.29 |
| 직접 점 보정 | 22.49 | 7.19 | 23.74 | 8.75 |
| 후보 선택 + 작은 보정 | 17.82 | **5.30** | 24.40 | **7.07** |

단위 px, 학습군은 3시드 평균. 서로 다른 데이터셋의 평균/중앙값을 합치지 않는다. 대응 제외 값은 네 가지 H 중 GT와 가장 가까운 대응으로 **평가만** 수행한 사후 위치 진단이며, 직사각 메시의 90도 자세를 정답으로 인정한 물리 C4 지표가 아니다. 독립적인 8점 일대일 최적 대응도 새 종류에서 8.276→7.061px로 유사했다.

| 3 | 8.287 | 8.701 | 7.057 | 14.84% |

후보+보정의 대응 제외 오차는 본 종류 5.297±0.038px, 새 종류 7.067±0.014px다(±는 3시드 모집단 표준편차이며 통계적 신뢰구간이 아니다). 새 종류의 시드 평균과 기존 YOLO 간 차이는 −1.22px, 장면 그룹 paired bootstrap 사후 95% 구간은 [−1.65,−0.85]px다. 이는 해당 두 메시와 장면에 조건부이며 독립 실물 일반화 신뢰구간이 아니다.

| 평가 범위 | 기존 YOLO | 후보+보정 평균 | 해석 |
|---|---:|---:|---|
| 새 종류 매칭 대상, 대응 제외 평균 px | 8.287 | 7.067 | 약 14.73% 위치 개선 |
| 새 종류 전체, 미검출 포함 대응 제외 정규화 오차 | 0.285705 | 0.284543 | 약 0.41% 개선, 검출기는 동일 |
| 새 종류 전체, 원래 번호 고정 주 지표 | 0.302299 | 0.301972 | 원래 사전 안정성 기준 미통과 |

사후 위치 진단의 개선으로 원래 주 지표 미통과 판정을 바꾸지 않는다. 최종 단계에 치수 제거군과 선택 전용군을 다시 학습하지 않았으므로 14.73%를 치수 단독이나 선택기 단독의 효과로 해석할 수 없다.

### 6.2 시각적 사례: 번호 개선과 위치 개선의 차이

![기존 실패 사례를 번호와 위치로 분리](../../../../data/pallet/results/pallet_role_symmetry_audit/previous_failure.png)

이전에 실패로 제시했던 `a2_test_g009_v2_crop25`, seed1이다. 기존 YOLO 19.59px, 후보+보정의 번호 고정 오차 253.62px. 같은 예측 좌표의 번호만 정렬하면 17.49px다. 가운데와 오른쪽은 같은 좌표이며 오른쪽의 GT 대응은 진단용이다. 초록 GT·분홍 예측. 흰 부분은 원본에서 잘려 보이지 않는 영역이다.

![이전 큰 개선 사례의 실제 공간 효과](../../../../data/pallet/results/pallet_role_symmetry_audit/previous_gain.png)

`a2_test_g009_v0_clean`, seed1. 번호 고정으로 257.76→10.40px였던 큰 개선은 대응 제외 기준 10.38→10.40px로 공간적 개선이 거의 없다. 기존 보고서가 선택했던 두 사례를 그대로 사용했다. 양쪽 사례를 함께 제시해 번호 오류가 개선과 악화 모두를 과장할 수 있음을 보인다.

### 6.3 별도 대칭 loss 실험: 합쳐서 성능으로 세지 않음

| 별도 실험 | 대조 | 대칭 적용 | 확인된 범위 |
|---|---|---|---|
| 실물 C4 초기, val 155장 | F0 C4 인정 중앙값 1.96px / P90 4.32px | F1 2.08px / 3.60px | 큰 위치 오류 2→0장, 단일 시드로 안정성 확정 불가 |
| 실물 라벨 정리 후, 같은 val 155장 | 일반 loss stage1 중앙값 1.79px | C4 추가 학습 stage2 1.88px | 추가 위치 개선 미확인, 순차 학습 비교 |
| 치수×대칭 2×2, 합성 val 512장 | 기존 YOLO 평균 5.0551px | 치수+C1/C2 평균 5.0540px | 3시드 안정성 기준 미통과; 확인된 C4 표본 없음 |

실물 C4의 결과는 같은 촬영 세션에서 나눈 검증이며 새로운 촬영 세션 일반화 결과가 아니다. 2×2의 초기 C2 객체 1,364개 중 대체 GT 후보가 더 낮은 손실을 준 것은 2개였다. 이때 대칭 loss가 바꿀 초기 감독은 적었다. 이 세 결과를 현재 점 보정 구조의 통합 학습 성능으로 인용하면 안 된다.

## 7. 지금 주장할 기여와 주장하면 안 되는 것

현재 근거로 쓸 수 있는 기여 후보는 **기존 점 출력을 유지하는 후보별 잔차 정제 구조의 구현·분석**, **번호 대응과 위치 오차를 분리한 평가**, **두 미학습 합성 메시에서 세 시드에 걸친 위치 개선 관측**이다. 이것만으로 학술적 신규성이 확정된 것은 아니며 구조·손실 대조와 관련 연구 비교가 더 필요하다.

객체별 유효 대칭 중 최소 loss를 선택하는 원리는 Pix2Pose의 transformer loss 등 선행 연구가 있다. C1/C2/C4를 조건에 맞게 사용하는 것 자체를 새 loss로 주장하지 않는다. [Pix2Pose, ICCV 2019](https://openaccess.thecvf.com/content_ICCV_2019/html/Park_Pix2Pose_Pixel-Wise_Coordinate_Regression_of_Objects_for_6D_Pose_Estimation_ICCV_2019_paper.html)

대칭 물체의 영상 대응 모호성도 EPOS 등에서 다룬다. 여기서의 차별화 질문은 알려진 치수와 제한된 팔레트 구조를 이용한 **강한 키포인트 기준선의 정제와 종류 일반화**다. 이 적용 범위만으로 기존 방법과의 차별성이 입증되는 것은 아니다. [EPOS, CVPR 2020](https://cmp.felk.cvut.cz/epos/)

다음 주장은 현재 증거로 쓸 수 없다: 선/Hough의 기여, 치수 입력만의 14.7% 효과, 새 C4 loss의 발명, 완전한 6D 자세 개선, 독립 실물 일반화, 모든 조건의 비악화, 통합 대칭 모델 학습 완료. 입력 G를 등록 정보로 제공하면 이를 모델이 스스로 알아냈다고 표현하지 않는다. 전체 평균 px 향상만이 기여 기준은 아니지만, 지표의 대응 규칙만 바꿔 수치가 낮아진 것을 학습 효과로 세지 않는다.

## 8. 논문을 완성하기 위한 최소 검증

### 동일한 대칭 조건을 가진 구조 대조

모든 군에 같은 객체별 G와 평가 규칙을 적용한다. 대조군에도 같은 치수·대칭 정보를 제공해 추가 정보의 효과와 구조 효과를 구분한다.

| 군 | 역할 |
|---|---|
| A 기존 YOLO의 점 head | 같은 데이터·대칭 loss로 학습하는 기준 |
| B 기존 점 + 직접 잔차 | 후보별 구조 없이 작은 보정의 효과 |
| C 기존 점 + 현재 후보별 잔차 | 후보별 처리의 추가 효과; 동등 후보의 선택 목적 수정 필요 |
| D C의 치수 조건화 제거 | 신경망 치수 입력의 효과; 평가와 기하 계산에는 같은 치수 제공 |

학습 범위·초기 checkpoint·데이터·업데이트 예산을 고정하고 차이를 기록한다. 이 표는 후속 비교 계획이며 이번에 실행한 실험이 아니다. 먼저 작은 학습 집합에서 대응 선택 빈도와 위치 loss의 실제 변화, 기존 점 정확도 유지 여부를 확인한다. 과거와 같은 C4 loss를 이유 없이 반복 학습하는 것으로 실험을 대체하지 않는다.

### 필요한 평가와 중단 판단

정사각형은 렌더링 중 W=D를 유지하고, 직사각형 및 방향성 종류는 각각의 등록된 G를 사용한다. 메시 단위 미학습 종류와 촬영 세션 단위 독립 실물을 분리한다. clean·occlusion·truncation 결과 및 GT 가시성·화면 밖 코너 정책을 함께 기록한다. 실물 GT에는 번호 오류와 수작업 위치 오차를 별도로 감사한다.

최종 비교는 대칭 인정 위치 오차, 검출 실패 포함 지표, 어려운 조건별 오류, 정상점 피해, 필요 시 허용 대칭을 반영한 회전·이동 정확도로 한다. 동일 대칭 기준의 강한 대조군을 이기지 못하면 대칭 규칙 자체의 필요성은 유지하면서 새 보정 구조의 성능 기여 주장은 보류한다.

## 9. 결론 초안

현재 점 기반 정제 구조는 학습에 없던 두 합성 메시의 매칭 대상에서 세 시드에 걸친 작은 위치 개선을 보였다. 동시에 번호 고정 오류와 공간적 위치 오류의 분리가 결과 해석에 필수적임을 확인했다. 객체별 대칭은 이 문제의 타깃 정의로 사용해야 하며, 기여의 중심은 기존 강한 점 출력을 보존하면서 알려진 치수로 위치를 개선하는 구조와 그 검증에 둔다. 통합 대칭 loss 학습 및 독립 실물 평가를 마치기 전까지 이 초안을 최종 아키텍처의 검증 완료 논문으로 제시하지 않는다.
