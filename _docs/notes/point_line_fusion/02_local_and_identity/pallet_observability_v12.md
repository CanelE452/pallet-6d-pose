# V12: 기존 점 보정 억제와 별도 amodal 복원

2026-09-10. 사용자 요청에 따라 V11의 가려진 점 회귀를 고치는 구조와 화면 밖 점 복원을 구현하고 실제 학습/검증했다. 상태: `SUPPRESSION_PASS_RECOVERY_PARTIAL_CROP20_REGRESSION`.

## 구조

YOLO와 V10 local refiner는 고정한다. 점별3×3 영상 패치, 기존 보정량, 점/상자/영상 경계 좌표, 고정 point ID를64차원 token으로 만든다. 전체 ROI8×8 특징으로 cross-attention, 8개 point token 사이 self-attention을 적용한다. intact/hidden/outside의3가지 soft routing과 두 개의 복원 residual을 예측한다.

출력: `stock + q_intact * local_delta + q_hidden * hidden_residual + q_outside * outside_residual`.
복원 residual 각 성분은 관측 box diagonal의25%로 제한한다. 기존 local 보정 자체를 억제한다는 점이 V11과 다르다. Hough 없이 관측 가능성 및 복원 경로의 효과를 분리한 실험이다. 모델 입력에 GT, 가림 마스크, 조건 이름은 없다.

대조군: scalar_gate(입력과 무관한 스칼라 축소), learned_gate(학습한 억제만), gated_amodal(억제+복원), always_amodal(기존 보정 및 복원을 항상 적용). 전체 네트워크 초기값과 학습 순서는 동일하지만 비활성 파라미터가 있어 실효 용량은 다르다.

## 학습/평가

4군×3시드×2000업데이트=24,000업데이트. 합성3609관측: 원본1775 + V11 네 변형의 검출1451 + 새 코너 가림383/384. 합성 점 손실과 인공 노출 상태의 class-balanced CE. 실제 학습/튜닝 없음. 원본 YOLO/PnP/selftraining 필터는 변경하지 않았다.

V11의 동일한 합성505/실제297장과6가지 조건을 그대로 재사용했다. 실제는 수동 클릭1251점만 평가한다. 모든 모델이 동일한 검출 성공/실패 및 관측을 공유한다. 관측은 해당 변형 이미지에서 다시 추론했던 캐시다. 검출 실패는 전체 정규화 점수에서 failure1로 포함했다.

## 결과

실제 점별 조건부 평균 오차, 3시드 평균(px):

| 대상 | 점 수 | YOLO | 기존 local | 학습한 억제 | 억제+복원 |
|---|---:|---:|---:|---:|---:|
| 코너 가림: 가려진 점 |280|16.446|17.040|16.539|13.554|
| 잘림20%: 화면 밖 점 |558|12.335|12.531|12.372|16.496|
| 잘림40%: 화면 밖 점 |571|27.771|27.837|27.771|19.921|

보정 억제는 가려진 점에서 기존 local보다 평균0.500px 개선(세션95%CI -0.741~-0.250), scalar 축소보다도0.448px 개선(-0.667~-0.222), 모든 시드 같은 방향. 원본 실제 성능 유지 기준까지 통과했다. 억제만으로 원래 YOLO보다 더 정확해지는 것은 아니며, 주로 local 보정이 만든 악화를 줄였다.

복원은 가려진 점에서 YOLO 대비 시드별7.9~26.1%, 잘림40%의 화면 밖 점에서26.4~30.9% 개선했다. 그러나 잘림20%에서는29.3~37.0% 악화했다. 약한 잘림의 세션 구간은0을 포함하여 모집단 이질성이 크다. gated_amodal 한 시드가 원본 실제에서 local보다 약1.06% 악화해, 사전 원본 유지 상한1%도 근소하게 미달. 전체 복원 통과로 처리하지 않았다.

실제 검출 프레임 평균은 원본 local5.534 / 억제5.538 / 억제+복원5.542; 코너 가림9.626 /9.490 /8.533; 잘림20%8.691 /8.622 /10.651; 잘림40%16.789 /16.777 /12.848이다. 대상 점 표와 집계 단위가 다르다.

## 원인 진단

원래 예측을 저장한 뒤 GT 노출 상태로만 routing을 교체하는 특권 진단을 했다. 약한 잘림의 화면 밖 점은 정상 routing15.95~16.90px보다 오히려17.38~19.64px가 됐다. 노출 분류 문제만 고치면 해결된다는 가설은 지지되지 않는다. 이 oracle 결과는 정상 추론/성과 수치에 포함하지 않는다.

같은 모델에서 복원항만 빼고 비교하면 약한 잘림558점 중317~391점이 악화했고, 그중299~369점은 정답 방향과 반대로 움직였다. 단순 overshoot만의 문제가 아니다. 이 조건의78.9~79.0%는 안쪽 이동이 필요한데 모델은56.5~72.6%를 더 바깥으로 보냈다. 큰 잘림은 안쪽 이동 필요27.7~28.0%, 모델 바깥 이동74.6~84.1%로 바깥 복원 경향이 더 적합했다.

같은 모델의 복원 전<=5px인 점이 복원 후>20px가 된 경우: 잘림20%0/2/0점, 잘림40%4/3/2점. 평균 개선이 모든 점의 안전한 개선을 뜻하지 않는다. 조건 사이 구도·촬영 차이도 있으므로 잘림 비율만으로 작동 여부를 결정하는 규칙을 만들지는 않았다.
