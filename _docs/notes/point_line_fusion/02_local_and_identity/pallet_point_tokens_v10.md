# V10: per-point line association and directional refinement

Completed 2026-09-09. Result: `POINT_REFINEMENT_IMPROVES_STOCK_NO_INCREMENTAL_HOUGH_GAIN`.

## Question and implementation

Can separate point identities, local image evidence and directional line guidance improve the original YOLO predictions without forcing points onto potentially incorrect lines?

The original YOLO and the existing DHT encoder remain frozen. Train only the refinement module using original camera-facing point IDs and point supervision. Each of eight point tokens samples local image features and attends to 36 independently predicted DHT line candidates plus a null candidate. Lines are not generated by connecting predicted points. Line role IDs are not assumed to correspond to point IDs.

A learned bounded residual proposal is projected by `A = sum(weight * normal * normal.T)`. This guides the direction of correction; it does not force a point to lie on a line. The zero-initialized residual head exactly preserves original predictions at initialization. No selftraining or test-time GT filter is used.

## Controlled pilot

- Four arms: local image only, isotropic line conditioning, directional line conditioning, and wrong-image donor lines.
- Three seeds, 2,000 updates per arm, batch 16, AdamW 3e-4; 12 models and 24,000 updates total.
- Identical full module parameter count: 58,787. The local arm has inactive association parameters, so effective active capacity is not identical.
- Final fixed-budget checkpoints; no post-evaluation tuning.
- Train/calibration/validation matched frames: 1,775 / 253 / 505.
- Primary metric: mean per-frame Euclidean point error in original pixels, preserving original point IDs. Validation contains 3,997 valid corners; seven missing detections are additionally included in the full 512-frame normalized metric.

| Arm | Seed 1 mean px | Seed 2 | Seed 3 |
| --- | ---: | ---: | ---: |
| Original YOLO | 4.821061 | 4.821061 | 4.821061 |
| Local image only | 4.607945 | 4.605352 | 4.600835 |
| Isotropic line conditioning | 4.614116 | 4.616481 | 4.619836 |
| Directional line conditioning | 4.620323 | 4.632364 | 4.637603 |

Directional refinement improves the original by 3.81–4.16% across all seeds. Median, P90 and the full denominator metric also improve. No new corner catastrophe (original error <=5 px becoming >20 px) occurs. This does not mean every point improves: many small individual regressions remain.

Directional minus original mean difference is -0.190964 px (paired frame bootstrap 95% interval -0.237628 to -0.146174). Directional minus local-only is +0.025386 px (0.006435 to 0.044980). These intervals are descriptive on reused synthetic validation, not independent real-world confirmation.

The same directional model performs worse with wrong-image lines in all three calibration seeds, showing the input influences useful corrections. Holding proposals and attention fixed while replacing the directional matrix by an isotropic matrix yields no reliable directional advantage. Line attention is not a calibrated correctness probability.

## Audit and limits

Original YOLO label coordinates agree with the renderer point set within 0.001 px after coordinate conversion. Point-set assignment was used only for this label audit, never for model targets, inference or scoring. This does not certify manually annotated real GT.

Preflight verifies exact initialization parity, off-projection parity, horizontal-line motion restriction, candidate-order/sign invariance, PSD matrices and finite gradients. All 24,000 training updates completed. Independent numerical replay audits 9,095 frame-condition rows, reproduces point errors exactly, reconstructs corrected coordinates within 0.000061 px, and reconstructs directional matrices within 0.000000206. Same-model isotropic intervention preserves proposals and attention exactly.

The registered full pilot gate fails because the directional arm does not beat the local or isotropic controls. Coexistence with improved original point accuracy is demonstrated in this pilot; incremental Hough benefit is not. Frozen DHT does not establish the outcome of joint end-to-end training. Real images, final 6D pose, and deployed model behavior remain untested. This metric is not comparable to the earlier real-image 41.49 figure or unordered/oracle correspondence metrics.
