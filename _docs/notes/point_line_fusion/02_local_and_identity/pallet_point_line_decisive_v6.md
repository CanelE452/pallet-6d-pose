## 2. 기존 작업과 구분

`pallet_point_line_v5_local`은 별도 실행 중이다. 원본 소스·로그·체크포인트는 수정하지
않는다. 전달되지 않은 외부 v5 번들의 재현을 주장하지 않는다. 본 실험은 로컬 구현을
별도 디렉터리에 복사하고 아래의 확인된 수치/기하 문제를 수정한 독립 비교다.

- theta를 가장 가까운 격자로 반올림할 때 pi→0이면 rho도 반전해야 한다.
- theta 경계의 mode 이웃은 rho 축을 반전해서 연결하고, 동차 선의 부호를 정렬한 뒤
  평균해야 한다. 이는 서로 떨어진 선의 전역 평균과 구분한다.
- 기존 solver의 선 잔차 곡률은 같은 normalized 잔차의 점 좌표보다 endpoint당
  1/sigma²=2500배다(sigma=.02). 비교군의 선 mask에 sigma²/3을 곱해,
  3개 incident edge가 있는 코너 기준 점과 선의 총 이차 영향 크기를 맞춘다.
  이는 보정된 불확실성이라는 주장이 아니라, 단위와 중복 계수를 명시한 고정 설계다.

## 3. 한 번 고정할 실험

1. **실행 타당성**: 선의 부호·각도 seam·sub-bin 입력, 투영/solver 미분,
   최종 자세 손실만으로 Hough 분기에 gradient가 전달되는지 검사한다.
   합성 GT의 pose→corner 재투영과 split의 이미지 SHA 비중복을 확인한다.
2. **원인 분리**: 같은 예측점과 같은 초기 자세에 선 없음/예측 선/역할을 섞은 선/
   정답 선을 넣는다. 정답 선은 원인 진단용이며 실측 성능 표에서 제외한다.
   실제 초기값과 GT 근처 초기값도 구분한다. 전자는 실사용 조건, 후자는 국소 solver
   작동 검사이며 후자의 성공을 실사용 성공으로 세지 않는다.
3. **학습 비교**: 점 전용, 점+직접 선 예측, 점+Hough를 seed 1/2/3에서 각각
   2,000 update, batch 4, AdamW lr=1e-4로 실행한다. 총 18,000 update 상한.
   같은 backbone 캐시·공통 초기화·샘플 순서를 사용한다. 최종 checkpoint만 평가한다.
   합성 train만 학습에 사용한다. 결과를 보고 lr/선 가중치/threshold를 다시 고르지 않는다.
4. **합성 평가**: 기존 512 frame 모집단을 유지한다. export된 505 frame 조건부 지표와
   누락 7 frame을 실패로 포함한 512 frame 지표를 모두 보고한다. 실패를 분모에서
   제거하지 않는다. 같은 물체에 유효 C1/C2 하나를 적용한다. C4는 데이터에서 검증 불가.
5. **실사 진입**: 합성 gate를 통과한 경우에만, 기존 허용 DEV에서 강한 원래 모델과
   동일 기준으로 비교한다. 새 실사 annotation/self-training/FINAL 개봉은 하지 않는다.
   실사 데이터 계약을 만족하지 못하면 실사 개선을 주장하지 않는다.

## 4. 고정 판정 기준

- Hough 대 점 전용: 모든 seed에서 normalized 8-corner mean이 1% 이상 개선,
  프레임 평균 raw-pixel 오차의 median/P90 및 coverage 비악화.
- catastrophic: 점 전용 frame mean≤10px가 Hough>50px 또는 pose 실패로 바뀐 frame 0.
  각 frame의 실제 pixel 오차를 쓴다. 임의의 900px 공통 대각선으로 대신하지 않는다.
- Hough 대 직접 선: 위 기준을 따로 보고한다. 이것을 통과해야 Hough의 추가 이득으로
  부른다. 직접 선만 좋으면 선 융합 가능성은 인정하되 Hough 채택 근거는 없다고 판정한다.
- 예측 선을 제거/섞었을 때 개선이 유지되면 선의 증거를 활용한 개선으로 인정하지 않는다.
- 정답 선으로도 actual-start 결과가 개선되지 않으면 초기화/대응/solver 병목으로 분류한다.
- 합성만 통과한 것은 GO_TO_REAL이고 최종 성공이 아니다. 실사에서 원래 강한 baseline
  대비 개선과 정상 frame 보존까지 확인해야 채택 후보라고 한다.
- 학습 loss 하락만으로 성능 성공을 판단하지 않는다. train/cal/val 격차와 마지막 loss
  추이를 함께 보고하여 예산 부족과 일반화 실패를 구분한다.

이 수치들은 이번 예산 결정을 위한 운영 기준이다. 안전 인증이나 보편적 임계값이 아니다.
기존 DEV와 합성 val은 이미 재사용되었으므로 독립 최종 일반화 검증으로 포장하지 않는다.

## 5. 조건별 결과와 산출물

정면에 가까운 시점/비스듬한 시점, 낮은/높은 시점, 긴/짧은 edge의 line-normal 오차,
좋은/나쁜 점의 손익을 분리한다. GT 카메라 자세는 사후 stratification에만 사용한다.
가시성 GT가 없으면 영상 경계와 amodal 구조선 일치를 단정하지 않는다.
원래 GT는 변경하지 않는다. 실사 손 annotation은 원래 strict 지표를 유지하고 오차 허용
감도는 별도 보고한다. 수치를 개선하기 위한 annotation 재대응/교정은 하지 않는다.

결과 JSON, 재현 명령, 원인별 판정, 원본·점·선·공동 자세 overlay HTML을 남긴다.
HTML 생성 시 실제 브라우저 창 열림을 확인한다. 완료 알림은 이전 명시 승인 범위에서
최종 판정과 핵심 수치를 전달한다.
