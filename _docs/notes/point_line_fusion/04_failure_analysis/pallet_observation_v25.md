# V25 관측 조건 보강과 보정 방향 변경

상태: 실행 완료. 사용자가 요청한 1→2→3 단계의 결과를 순서대로 기록한다.

## 1. 제안

- 기존 캐시로 잘리는 쪽·화면 밖 거리·박스 투영비·잔존율에 따른 방향 오류를 분해한다. 점 ID와 초기 오차 구간을 통제하고 공통 지원 수를 공개한다.
- 결과를 보고 실제 이미지의 잘림 조건 한 가지를 보강한다. 원본별 split을 유지하며 YOLO·Hough·점 부모를 모두 다시 추론한다. 실사 GT는 학습하지 않는다.
- 같은 데이터·시드·학습량에서 고정 방향 적용률, 점 특징으로 방향도 바꾸는 보정, 선의 추가 관측을 쓰는 보정을 비교한다. 구체적 대조와 예산은 1단계 후 학습 전에 고정한다.
- 성공 기준: 각 시드 원본 및 잘림10/20/30% 악화≤1%, 코너 가림·잘림40% 기존 V18 이득≥90% 유지. 선 추가 효과는 각 시드≥1%와 세션 쌍대95%구간 상한<0. 전부 재사용DEV이며 독립 배포 검증은 아니다.
- 실패 모드: 조건 분해가 진짜 가시성을 대신하지 못함, 데이터 변화가 실사로 이전되지 않음, 새로운 방향도 잘못 학습함, 선이 중복 정보만 제공함. 좌표/GT 불일치·비유한 학습은 즉시 중단·수정한다. 실패한 대조도 모두 보고한다.

## 2. 단계별 결과

[실험 산출물](../../../../data/pallet/results/pallet_observation_v25/)에 기록한다.

### 1단계 완료·후속 설계 등록

실사 약한 잘림에서 안쪽 이동이 필요한 점은 약79%, 신규 합성512에서는 약40%. 실사 오른쪽 잘림에서 방향 오류가 더 크며, 점ID·오차구간·잘리는 쪽을 통제해도 차이가 유지됐다. 이는 단독 원인 증명이 아니다. 같은 원본의 반대쪽20% 잘림을 추가 관측으로 검증한다.

학습 전에7대조×3시드×2000업데이트(42,000)를 고정했다. 기존/짝지은 입력의 적용률3대조, 점/선2D보정×실제 영상 미분 특징 유무4대조. 2단계가 실패하더라도 사용자가 요청한3단계는 한정된 진단으로 끝까지 실행하며 실패 대조도 공개한다. 가시 경계·끝점 GT는 확보됐다고 가정하지 않는다.

## 무엇을 실행했는가

1. 기존 캐시에서 잘리는 쪽·화면 밖 거리·투영비·잔존율별 방향 오류를 분해했다. 신규 합성512/확인128과 실사297을 사용했다. 원래253은 이 분해에서는 제외했으며 학습에는 모두 유지했다.
2. 동일 원본을 반대쪽에서20% 잘라640개 입력을 만들고, YOLO·Hough·점 부모를 세 시드 재추론했다. 기존6조건은 전부 유지하고 추가 잘림 슬롯의 기존/짝지은 관측을 비교했다.
3. 같은 짝지은 데이터에서2D 방향 보정의 점/선 대조와 실제 픽셀 미분 특징 유무를 비교했다. 새 가시 경계·끝점 GT를 만든 실험은 아니다.

## 기존 원인의 확인

약한 잘림에서 안쪽 보정이 필요한 비율이 신규 합성 약40%, 실사 약79%로 달랐다. 오른쪽 잘림의 실사 보정 방향 오류가 더 컸고, 점ID·5px 오차구간·잘리는 쪽을 맞춰도 차이가 남았다. 카메라 자세나 실제 가시 경계가 단독 원인이라고 확정한 것은 아니다.

![기존 방향 차이](../../../../data/pallet/results/pallet_observation_v25/figures/direction_gap.png)

반대쪽 입력을 실제로 만든 뒤에도, 합성에서 안쪽 이동이 필요한 비율은 기존 40.23% → 반대쪽 39.48%였다. 실사의 약79%와 가까워지지 않았다. 따라서 양쪽 잘림을 더 관측하는 것만으로 필요한 방향 분포 차이가 해결됐다고 볼 수 없다. 원본과 반대쪽은 화면 밖 대상점이 달라 전체 분모와 동일점 비교를 [개입 진단](../../../../data/pallet/results/pallet_observation_v25/INTERVENTION_DIAGNOSIS.json)에 분리했다.

픽셀 미분을 포함한 점+선은 같은 점 전용 대조보다 약한 잘림에서 16.354 → 16.225px였다. 세 시드 개선율은 0.79%, 0.59%, 0.97%이며 세션95%구간은 [-0.207, -0.048]px다. 세 시드에서 같은 방향의 작은 추가 신호가 있지만, 사전 기준인 각 시드1%에는 못 미쳤고 점 기준12.372px의 악화도 해소하지 못했다. 다중 비교 보정은 하지 않은 재사용DEV 결과다.

방향을 자유롭게 한 점+선+픽셀 모델은 기존 벡터의 방향이 잘못됐던 점 중 48/356, 50/334, 9/290개를 각 시드에서 GT 쪽 방향으로 바꿨다. 따라서 방향 변경 경로가 무효였던 것은 아니다. 하지만 그 기존 실패 집합의 평균 오차 변화는 +6.13px, +8.98px, +11.65px로 여전히 악화됐다. 일부 방향을 바로잡는 것과 전체 오차를 줄이는 것은 다르다.

방향 보정이 고정 적용률보다 좋아져도 출력 공간과 손실이 함께 달라진 결과다. 방향 자유도 하나만의 원인 효과라고 해석하지 않는다. 반면 방향 보정 안의 점/선 대조는 같은 초기 파라미터·학습 배치·손실을 사용한다. 기존/짝지은 관측 대조는 같은2,000업데이트와 원본 그룹 순서를 쓰지만 새 관측의 검출 여부 때문에 실제 관측 노출 수가 시드별48개(약0.12%) 더 많다. 자세한 분모는 AUDIT.json에 있다.

## 판정 범위와 다음 결정

등록한 대조 중 쉬운 조건 보존과 어려운 조건 이득90% 유지를 모든 시드에서 동시에 통과한 구조는 없다. 이번 관측 변화·방향 보정·픽셀 미분 조합만으로 안정적인 융합이 해결됐다고 말할 수 없다. 이것이 모든 점·선 아키텍처의 불가능성을 뜻하지는 않는다.

이번 개입은 잘리는 쪽의 관측 보강이다. 실제 카메라 이동·정면 자세의 신규 렌더링, 실제 가시 경계·끝점 감독, 독립 실사 촬영은 실행하지 않았다. 기존 박스 투영비를 실제 yaw나 가시성 정답으로 취급하지 않았다. 픽셀 미분은 질감·배경 경계도 포함할 수 있다.

다음 원인 판단에서는 조건부 추가 이득과 전체 안정성을 분리하고, 반대쪽 관측에서도 남는 오차를 먼저 보아야 한다. 정답 감독이 가능한 가시 경계/끝점의 관측 유무 또는 새 촬영 조건을 바꾸는 실험은 이 결과와 별도로 등록해야 한다.
