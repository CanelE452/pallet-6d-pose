# V17: RGB 세부 정보와 가시 실루엣 보조 정답을 분리한 실험

V16은 심한 잘림에서 선 주변 영상 정보의 부분 이득을 보였지만, 약한 잘림에서 잘못된 복원을 선택했다. 짧은 높이선의 역할 분류도 부정확했다. V17은 세부 영상 정보 부족과 보조 정답 불일치를 2×3 비교로 검사한다.

## 비교 구조

| 입력 세부 정보 | 보조 정답 없음 | 기존 cuboid 경계 | 가시 마스크 지지 경계 |
|---|---|---|---|
| RGB96을 24로 축소 후 96 복원 | low_none | low_proxy | low_mask |
| 원본에서 직접 추출한 RGB96 | high_none | high_proxy | high_mask |

모든 모델에 동일한 RGB CNN(3→16→8, 3×3 convolution 두 개)을 추가한다. 기존 고정 YOLO의 24×24 특징과 원본 RGB 특징을 동일한 후보별 선 좌표에서 읽어 더한다. CNN 입력 크기와 수용 영역, 파라미터 수는 같고 저해상도 입력은 세부 정보만 줄인다. V16 대비 단순 업샘플이 아니라 추가 RGB 분기이며, high/low 비교가 해상도 효과를 분리한다. YOLO/DHT 자체를 고해상도로 재학습하는 실험은 아니다.

기존 점·복원·DHT 부모와 8개 후보는 고정한다. 선의 상위3연관, 선을 따라7개/가로3개 샘플, 최대5% 대각선 보정, 유지 후보를 포함한 점수 argmax는 V16과 같다. GT 필터, self-training, GT 기반 추론 투영은 없다.

## 마스크의 의미와 대응

G38 원본의 `mask_visible`는 렌더러가 저장한 보이는 물체 영역이다. 원본과 준비된 학습 RGB169장의 픽셀 일치를 확인했다. 마스크는 해당 원본 라벨/이미지와 연결하고 좌표 이동을 적용한다. 모든 이미지의 기존 해시와 크기를 확인한다. 저장된 배경은0/1/2, 전경은254/255이므로 기존 데이터 로더의 규약대로127보다 큰 값을 전경으로 읽는다. 해독한 전경 픽셀 수를 렌더러의 `mask_area_visible` 기록과 전수 비교한다.

기존 cuboid 선 샘플에서 원본 가시 마스크 contour까지2.5px보다 멀면 해당 샘플의 역할을 배경으로 바꾼다. contour는3×3 morphology gradient로 추출한 실제 영역의 테두리다. 인공 가림/잘림으로 새로 생긴 경계는 긍정 정답으로 넣지 않는다.

이 수정은 **마스크가 지지하는 물체 실루엣**으로 학습 목표를 좁힌다. 실제 물체 내부의 판자 경계나 두 가시 면 사이의 접힌 선까지 알려주는 정답은 아니다. 더 정확한 전체 side-edge GT라고 부르지 않는다. cuboid와 실제 물체의 차이를 일부 걸러도 모든 선 의미/가시성 문제를 해결하지 않는다.

공정한 비교를 위해 proxy와 mask 모두 같은 G38 마스크 가용·8점 유효 이미지/ROI 안 샘플만 보조 CE에 쓴다. 약한 GT를 버리는 self-training이 아니라 명시적 보조 감독의 관측 범위 설정이다. 전체253장의 모든 유효점은 여전히 점 보정 손실에 사용한다. 클래스 가중치는 proxy 빈도로 계산한 값을 두 보조 정답에서 공통 사용한다.

## 학습과 평가

6구조×3시드, 각2000업데이트, batch16, AdamW3e-4/weight decay1e-4, float32/gradient clip5, 마지막 체크포인트 고정. 총36,000업데이트. 보정 pinball tau0.2, 보조 CE 계수0.25. 같은 시드의 초기 파라미터·배치 순서를 일치시킨다. 기존 합성253장·6조건·1462개 검출 관측만 학습한다.

평가는 기존 실제297장·9세션·수동1251점 및 합성505장, 총8조건을 보존한다. 원래 point ID, 검출 실패, 부모 reflect100 입력, crop10/30 평가 전용 비율을 유지한다. 실제 GT나 마스크를 학습/추론/시드 선택에 사용하지 않는다. 자연 가림은unknown이며 새 현장 독립 검증은 아니다.

전체 안정성은 모든3시드에서 원본 및 잘림10/20/30%가 기준 오차101% 이내이고, 코너 가림·잘림40%의 기존 복원 이득80%를 유지해야 통과한다. 같은 다른 요인을 유지한 high-low 또는 mask-proxy 비교에서 모든3시드1% 이상 개선과 실제9세션 paired95% 상한<0을 추가 효과 기준으로 삼는다. 다중 비교 보정 없는 탐색적 검증이다.

동일 high_none/high_mask 모델에 저해상도 RGB 또는 다른 이미지 RGB를 넣어 기존 YOLO 정보/후보를 유지한 채 RGB 세부 정보의 기여를 진단한다. 분포 밖 개입으로 실제 효과를 단독 입증하지 않는다. 보조 분류는 모든 모델을 동일 proxy와 동일 mask 정답 둘 다에 평가하여 서로 다른 정답의 F1을 직접 비교하는 오류를 피한다. 독립 float64 정답 재계산, 원래 GT/좌표 검산, 통합 모델과 캐시 예측 비교, 원본/RGB/마스크 시각화를 함께 수행한다.
