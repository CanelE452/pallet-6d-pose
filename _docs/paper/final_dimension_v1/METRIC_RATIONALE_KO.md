# 평가 지표 선택 근거 — 선행연구와 자체 규약의 구분

작성: 2026-09-19. 신규 150장 후보 추론 전. 기존 DEV 결과는 이미 확인한 상태다.

## 결론

비표준이라는 이유만으로 필요 없는 것은 아니다. 다만 선행연구와 비교 가능한 지표와
이 보정기의 실패를 설명하기 위한 보조 분석을 구분해야 한다. 자체 규약을 BOP 표준이나
로봇 안전 기준으로 포장하지 않는다. 논문 한 편의 수치를 인용하는 것만으로 우리의
임계값이나 정답 데이터가 타당해지는 것도 아니다.

| 항목 | 직접 답하는 질문 | 문헌 근거 / 자체 선택 |
|---|---|---|
| 대칭 고려 corner8 평균 오차 E_sym | 동등한 코너 배치를 인정하면 얼마나 가까운가? | BOP의 전역 대칭 처리 원리를 참고. 우리의 8점 평균·영상 대각선 정규화는 자체 규약이며 MSPD가 아님 |
| PCK@5/10/20px | 지정한 영상 오차 안에 들어오는 점의 비율은? | PCK 계열은 선행연구에 있음. 세 픽셀 임계값은 기존 실험과의 일관성을 위한 자체 고정값 |
| matched 중앙값 / P90 | 검출·매칭된 사례의 전형적인 오차 / 큰 오차는? | 일반적인 기술통계. P90을 특정 자세평가 표준이라고 주장하지 않음 |
| 검출·매칭 수와 coverage | 오차 표에서 빠진 대상은 얼마나 되는가? | 전체 정답을 분모로 보는 평가 원칙과 연결. 영상 대각선 누락 벌점은 자체 규약 |
| 개선 / 악화 및 good→bad 건수 | 보정이 원래 좋은 결과를 훼손하는가? | 보정기 특유의 회귀 점검. good<5px→bad>10px는 자체 보조 기준, 안전 인증 아님 |
| 조건별 결과 | 전체 평균에 가려진 취약 조건은 무엇인가? | Ronchi·Perona의 조건별 오류 분석에서 방법론적 동기를 얻음. 우리의 잘림/저녁 구분은 별도 정의 |

## 실제 확인한 원문

1. **Hodan et al., BOP Challenge 2020 on 6D Object Localization, ECCVW 2020.**
   §2.2–2.4, 식 (3), Appendix A.2: 전역 대칭을 고려하는 투영 오차와 전체 정답 인스턴스 기반 recall,
   여러 허용 오차에서의 평가를 정의한다. MSPD는 투영된 모델 정점의 최대 거리다.
   우리의 자유로운 2D 코너 예측 평균과는 계산 대상·집계가 다르다.
   [원문 PDF](https://arxiv.org/pdf/2009.07378.pdf),
   [저자 공식 평가 설명](https://bop.felk.cvut.cz/challenges/bop-challenge-2019/#evaluationmethodology).

2. **Andriluka et al., 2D Human Pose Estimation: New Benchmark and State of the Art Analysis, CVPR 2014.**
   평가 설명에서 PCK의 정답 위치와 예측 위치 간 허용 거리 원리와 머리 길이의 50%를 쓰는 PCKh를 설명한다.
   이는 임계값의 기준 길이를 명시해야 한다는 근거이지 팔레트에서 5/10/20px를 써야 한다는 근거는 아니다.
   [원문 PDF](https://www.cv-foundation.org/openaccess/content_cvpr_2014/papers/Andriluka_2D_Human_Pose_2014_CVPR_paper.pdf).

3. **Ronchi and Perona, Benchmarking and Error Diagnosis in Multi-Instance Pose Estimation, ICCV 2017.**
   위치·점수·배경 오류를 분해하고 크기·보이는 점 수 등의 조건에 따른 성능 차이를 분석한다.
   이것이 전체 평균 외에 조건·실패 유형을 보고할 근거다. 우리의 P90이나 good→bad 픽셀 기준을 제안한 논문은 아니다.
   [논문 및 공식 초록](https://openaccess.thecvf.com/content_iccv_2017/html/Ronchi_Benchmarking_and_Error_ICCV_2017_paper.html).

4. **Moon et al., PoseFix, CVPR 2019.**
   학습된 자세 보정과 오류 유형별 접근의 선행연구다. 사람 관절 보정 결과를 팔레트 효과의 증거로 대체하지 않는다.
   [논문](https://openaccess.thecvf.com/content_CVPR_2019/html/Moon_PoseFix_Model-Agnostic_General_Human_Pose_Refinement_Network_CVPR_2019_paper.html).

## 정확한 계산과 제한

주 비교는 기존 구현의 E_sym을 유지한다. 이미지 i에서 평가 가능한 코너 집합 V_i와
허용된 전체 물체 순열 G에 대해, 코너와 유효 마스크를 함께 순열 적용한 평균 2D 거리의
최솟값을 이미지 대각선 D_i로 나눈다. 프레임별 값을 같은 가중치로 평균한다.
각 코너마다 제각각 가장 유리한 순열을 선택하지 않는다. C4는 등록된 코너/기하 등가성에
대한 점수 규칙이며, 정사각형 치수만으로 포크 진입 방향이나 외형 전체의 대칭이 입증되지는 않는다.

PCK는 같은 대칭 정렬 이후의 평가 가능한 코너를 합쳐 `거리 ≤ 임계값`의 비율을 센다.
프레임 평균 E_sym과 코너 풀링 PCK는 가중치가 같지 않으므로 분모를 보고한다.
검출/IoU 매칭 실패 또는 유효하지 않은 예측점에는 기존 규약대로 D_i를 부여해 PCK 분모에 남긴다.
matched 중앙값/P90은 조건부 결과이므로 그것만 보고 성공을 주장하지 않는다.
누락 벌점 D_i는 이 연구의 선택이며 실제 작업 비용 또는 모든 화면 밖 점의 최대 가능한 오차가 아니다.

현재 제안 150장의 메타데이터 해상도는 모두 640×480이다. 대각선 800px에 대해 5/10/20px는
각각 0.625/1.25/2.5%다. 정규화는 해상도 차이를 다루는 데 도움이 되지만 물체의 거리·영상상 크기를
정규화하지는 않는다. 해당 임계값은 미세/중간/큰 영상 오차를 함께 보여주기 위한 고정값일 뿐,
물리적 5mm/10mm나 삽입 성공률로 변환할 수 없다.

악화 분석은 평균 개선의 보완이다. 예를 들어 일부 큰 오차가 크게 줄어도 원래 정확했던 몇 점은
악화할 수 있다. 모든 프레임의 paired 오차 변화와 기존 good<5→bad>10 건수를 함께 보존한다.
임계값을 넘었다고 곧바로 로봇 작업 실패라고 해석하지 않는다. P90은 보조/부록으로 둘 수 있다.

## 원고 배치

- 본문: E_sym, PCK@5/10/20px, coverage, 조건별 비교. matched 중앙오차를 읽기 쉬운 보조 수치로 제시.
- 보조표/부록: P90, seed별 수치, 개선/악화 건수와 고정 임계값 전이, 전체 프레임 결과.
- 새 결과를 본 뒤 유리한 임계값으로 교체하지 않는다. 보조 지표 중 유리한 것만 본문 결론으로 올리지 않는다.
- 독립적인 물리 6D GT가 없으므로 ADD(-S)/MSSD/VSD나 mm·degree 정확도를 검증했다고 쓰지 않는다.
  표준 6D 지표를 추가하려면 적합한 모델·정답·필요 센서 데이터가 먼저 있어야 한다.
- 어노테이션에서 PnP로 채운 점은 독립 관측이 아니므로 label source를 분리해 보고한다.
- 사진 선별·정답 검수 승인 전에는 새 평가를 실행하지 않는다.
