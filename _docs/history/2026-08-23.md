## ASC — Annealed Symmetry Curriculum Loss (EXPLORATORY_METHOD_SCREEN)

A1_USD_ONLY 에서 관찰된 **초기 수렴 가속 / 후기 canonical 성능 저하** trade-off 를
직접 제거하는 단일 후속 가설을 1회 screen 했다.

### 변경 파일

- **`pallet_yolo_loss/symmetry.py`** (수정)
  - +`CURRENT_EPOCH` / `ROLE_CALLS` 모듈 전역, +`asc_beta(epoch, full_end, ramp_end)`
  - `A1Config` +`asc_enabled` / `asc_full_end=20` / `asc_ramp_end=30`
  - `a1_stats` 에 beta·epoch·d_id·d_180·sym_min·n_total 추가 (epoch 로거용)
  - **Before**: `pos = torch.where(is_sym, soft, d_id); kpts_loss = pos.mean()`
    **After**: `base = self.keypoint_loss(pk, gt, m, area)` (부모와 동일 단일 reduction)
    + `beta>0` 일 때만 `corr = where(is_sym, soft-d_id, 0).mean()` 를 더한다.
    **이유**: 2단계 reduction(`mean(dim=1).mean()`)이 forward 는 비트단위 같은데
    **gradient 를 5.63e-03 어긋나게** 했다(잡음바닥 1.9e-4). A0 가 control 이라
    beta=0 에서 그래프가 A0 와 동일해야 한다.
  - **Before**: `d_id`/`d_180`/`soft` 를 항상 계산
    **After**: `need_sym or need_role` 일 때만 계산.
    **이유**: 쓰이지도 않는 텐서가 GPU workspace 를 바꿔 cuDNN algo 선택이 흔들렸다
    (grad 1.49e-04 → **3.24e-05**). 부수효과로 후반 30 epoch 연산도 준다.
- **`pallet_yolo_loss/trainer.py`** — +`ASCTrainer`. `__init__` 에서
  `on_train_epoch_start` 로 `CURRENT_EPOCH` 주입, `on_train_epoch_end` 로
  `CONVERGENCE.csv` 기록. 처음엔 `_setup_train(world_size)` 를 override 했다가
  **시그니처가 `(self)` 뿐이라 첫 기동이 죽었다** → `__init__` 방식으로 교체.
- **`runs_pallet_loss/test_asc.py`** (신규) — 15 테스트. T2 잡음바닥은 1회 표본이
  불안정해(실측 3.8e-5~1.9e-4) **3회 반복 최대**로 잡는다. T3 은 reduction 순서가
  의도적으로 달라 비트단위 대신 fp32 오차(1e-4)로 판정.
- **`runs_pallet_loss/asc_driver.py`** (신규) — train → A0/A1/ASC 21개 체크포인트
  동일 evaluator 재측정 → gate → notify. 학습 중 `projective_loss`·role 호출을
  실제로 세어 0 아니면 실패 처리.
- **`runs_pallet_loss/a1_measure.py`** (재작성) — 진단셋을 v1 val 133 으로 교체,
  corner 픽셀 오차(median/p90)와 pose mAP50-95 추가.
- **`runs_pallet_loss/a1_driver.py`** (재작성) — `save_period=10`, ep별 수렴 비교,
  PC 호출 카운터.
- **`runs_pallet_loss/make_final_a1_config.py`** (신규) — GLB contract 도착 시 FINAL
  A1 config 생성. UNRESOLVED 남으면 BLOCK, CASE_MIXED 는 margin 미지정 시 거부,
  resume 금지.
