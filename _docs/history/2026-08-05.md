## PFDR (Pallet Far-Decoupled Refinement) 구현 — 학습 진행 중

목적: static E2(near H6 / far H5)가 corner 를 15~16% 줄이고도 pose 로 전환되지 않은
문제를, far 채널만 학습하는 residual adapter 로 뚫는지 확인.

### 1. `Deep_Object_Pose/common/pfdr_adapter.py` (신규)

- `PFDRAdapter`: 입력 171ch(F50 128 + H4 9 + H5 9 + H6 9 + A6 16, 전부 detach)
  → Conv3x3 64 → GroupNorm → ReLU → Conv3x3 64 → GroupNorm → ReLU → Conv1x1 4.
  마지막 Conv **zero-init**.  BatchNorm/sigmoid/tanh/clamp 없음.  **136,004 param**.
- `fuse_far` / `fuse_near`: N1·N2 는 far 만, N3 는 near 만 수정.
- `local_soft_argmax`: 학습 loss 전용 미분가능 좌표 디코더
  (gaussian sigma 2 → argmax detach → 11x11 window → raw belief softmax T=0.1).

⚠ **작성 중 버그 3회, 전부 판정 전 수정**:

```
1) grid_sample 로 window 를 뽑으니 채널이 섞여 좌표가 엉뚱했다.
   Before: grid_sample 후 대각 인덱싱
   After : padded[bi, ci, ry, rx] 명시적 advanced indexing
2) padding 값 0 이 배경(-3)보다 커서 softmax 를 오염시켰다.
   After : pad value=-1e4
3) ★결정적 — conv2d 의 zero padding 때문에 배경이 음수인 belief 에서
   테두리가 들려 argmax 가 (0,0) 에 고정됐다.
   Before: conv2d(..., padding=size//2)
   After : F.pad(mode="replicate") 후 padding=0 으로 conv2d
```
수정 후 검증: 단일 peak 4/4 정확 복원, 동률 셀에서 subpixel 30.5, 경계 (0,0),
gradient finite·nonzero.

## PDG-Net Stage 1 — trainer 연결 중 설계 블로커 2건 확인, 학습 미착수

Phase O 순서대로 state recovery → loader/모듈 연결 지점 점검 중 **구현 전에 확정해야 할
설계 사실 2건**을 발견. 이걸 모르고 trainer 를 쓰면 잘못된 배관을 만들게 되어 먼저 기록.

### 블로커 1 — TACA 는 batch-level transform 이 될 수 없다
```
canonical loader:  img 400x400 (squash 완료), beliefs 50x50, imagesize 400, sigma 2.0
TACA:              출력 캔버스 640x480, envelope border -64~+16px, width ratio 0.65~1.05
```
envelope 은 **640x480 소스 픽셀 기준**인데 loader 는 이미 640x480 → 400x400 으로
**비등방 squash**(x는 400/640, y는 400/480)를 끝낸 상태. squash 된 이미지를 다시 crop+squash
하면 비등방이 중첩되고, 400-space px 로 잰 border 는 envelope 을 유도한 양이 아니다.
→ TACA 는 **squash 이전 소스 프레임**에서 돌아야 하고, 이는 batch transform 이 아니라
이미지·JSON 을 다시 읽는 **Dataset wrapper** 를 의미한다.

### 블로커 2 — A1 도 A2 와 같은 target 재생성이 필요하다
`utils_belief.CreateBeliefMap` 은 9채널 전체에 **단일 sigma** 를 받고 canonical loader 는
`sigma=2.0` 으로 설정돼 있다. Stage 1 target policy 는 corner 2.0 / centroid 2.5 이므로
centroid 채널을 loader 에서 그대로 받을 수 없다.
→ A1 은 "loader 설정만 바꾼 control" 이 아니라 **TACA 만 끈 동일 재생성 경로**가 필요.
(`pdg_targets.build_targets` 가 role-specific 부분은 이미 담당, 먹여줄 wrapper 가 없음.)

### wrapper 가 해야 할 일 (다음 세션 착수 지점)
소스 이미지·JSON 로드 → (A2만) TACA 640x480 → 키포인트 투영 → belief 재생성(2.0/2.5)
→ affinity 재생성(GenerateMapAffinity) → off-screen mask(belief 0, affinity 2i·2i+1 0)
→ visibility 3-state → palletness → squash+normalize → DiffPnP 필드(전부 in-frame 일 때만).

기존 커밋된 모듈은 변경 불필요. 빠진 건 모듈과 trainer 사이 연결층뿐.

### 상태
optimizer step 0 / checkpoint 0 / **E44·W45 추론 0, SEALED 유지**.
Stage 1 gate(FULL_PASS·PARTIAL_GO·STOP) 는 판정할 데이터가 없어 미판정.
