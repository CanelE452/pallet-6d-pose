## PFDR (Pallet Far-Decoupled Refinement) 구현 — 학습 진행 중

목적: static E2(near H6 / far H5)가 corner 를 15~16% 줄이고도 pose 로 전환되지 않은
문제를, far 채널만 학습하는 residual adapter 로 뚫는지 확인.
near·centroid 는 ep57 H6 로 bit-exact 고정.

### 1. `Deep_Object_Pose/common/pfdr_adapter.py` (신규)

- `PFDRAdapter`: 입력 171ch(F50 128 + H4 9 + H5 9 + H6 9 + A6 16, 전부 detach)
  → Conv3x3 64 → GroupNorm → ReLU → Conv3x3 64 → GroupNorm → ReLU → Conv1x1 4.
  마지막 Conv **zero-init**.  BatchNorm/sigmoid/tanh/clamp 없음.  **136,004 param**.
- `fuse_far` / `fuse_near`: N1·N2 는 far 만, N3 는 near 만 수정.
- `local_soft_argmax`: 학습 loss 전용 미분가능 좌표 디코더
  (gaussian sigma 2 → argmax detach → 11x11 window → raw belief softmax T=0.1).

⚠ **작성 중 버그 3회, 전부 판정 전 수정**:

```
1) grid_sample 로 window 를 뽑으니 채널이 섞여 좌표가 엉뚱했다.
   Before: grid_sample 후 대각 인덱싱
   After : padded[bi, ci, ry, rx] 명시적 advanced indexing
2) padding 값 0 이 배경(-3)보다 커서 softmax 를 오염시켰다.
   After : pad value=-1e4
3) ★결정적 — conv2d 의 zero padding 때문에 배경이 음수인 belief 에서
   테두리가 들려 argmax 가 (0,0) 에 고정됐다.
   Before: conv2d(..., padding=size//2)
   After : F.pad(mode="replicate") 후 padding=0 으로 conv2d
```
수정 후 검증: 단일 peak 4/4 정확 복원, 동률 셀에서 subpixel 30.5, 경계 (0,0),
gradient finite·nonzero.

### 2. `Deep_Object_Pose/train/pfdr_pose_loss.py` (신규)

9-point(8 corner + centroid) pose consistency.  GT pose seed 에서 GN 4 step
(damping 1e-3 / clip 0.5 / cond 1e8 / positive-depth·finite guard),
GT geometry 와 비교하는 `L_3d` + `0.25 * L_reproj_gt`.
**predicted 2D 자기적합 목적함수 아님** — 그게 앞선 predseed DiffPnP 실패 원인이었다.
유닛 검증: exact GT → 0.000e+00, far corner 1개 +25px → l3d 1.8e-3, 음수 depth → usable 0.
