### 확인된 사실 [확인]

1. **H1 target semantics defect = 실재.** `CreateBeliefMap(clip_at_border=False)`은
   `full_support_inside` 거짓이면 `centre_inside`여도 채널을 all-zero로 만들고,
   `belief_channel_mask`는 JSON `pseudo_keypoint_valid` 부재 시 all-ones이며
   **spatial transform 이전**에 계산된다 → mask=1 + all-zero target으로 MSE 감독.
   측정: 263,772 kp 중 **10,463 (3.967%)**, 그중 mask=0은 **0건**(예외 경로 없음).
   ep57은 sigma=2 → `w=4` → 400px 입력의 바깥 32px 테두리가 데드밴드.
   border-distance bin에서 0~3px = C2 100%, 4px 이상 = 0% (결정론적).

2. **H2 truncation aug mismatch = 실재, 설계에 기인.** `utils_dataset.py:104-114`가
   `_TRUNC_MARGIN_FRAC=0.20`으로 모든 코너를 중앙 [0.20,0.80] 밴드에 reflect-pad
   (= H1 데드존 회피 목적). 결과: aug_trunc_v2 in-band 96.5% / 화면밖 0.0% vs
   real truncated(17) in-band 43.1% / 화면밖 27.5%.

3. **H3 DiffPnP coverage = 0.0%.** ep57이 소비한 index 기준 aug_trunc_v2 /
   aug_squash_v2 / aug_scale_v2 전부 `pnp_valid_3d=0` (V8은 100%/95.9%/96.0%).
   → "DiffPnP가 truncation을 regularize했다"는 서술 **금지 확정**.

4. **H4 기각.** C2 최대는 kp2(6.58%)/kp3(6.50%), kp5=3.75%, kp7=2.50% 최소.
   near(5.82%) > far(3.10%). kp5 특이 버그 가설 폐기.

5. **H5 강등.** D0(training clamp) vs D1(border-safe) = **0.000px**, clamp
   duplicate는 783개 중 3개(0.4%). 단 D2(eval) vs D3 = 7.030px =
   `0.4395×hypot(12.8,9.6)` 상수 offset → train/eval convention 별건 이슈.

6. **clip=True 반사실.** C2 761개 전부(100%) peak 복구(중앙값 0.979),
   C1 control은 T0==T1 완전 동일, 화면 밖 keypoint는 T1도 0.
