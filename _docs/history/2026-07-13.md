## internet_pallet_infer.py — 고정 HFOV=60° K 폐기 → fx-search 로 교체 (깔때기 왜곡 수정)

### 원인 (3d-expert 진단)
인터넷 파렛트 이미지 PnP 큐보이드의 "깔때기(윗면 안쪽 수축)" 왜곡 원인 확정:
- 사용자 가설 "upside-down flip" = **반증**. 선택 포즈의 deck 법선 `R@(0,-1,0)` 이
  모든 clean 케이스에서 카메라 향함(z<0), tb/fr/lr_viol=0, tilt 정상. 후보 풀에
  뒤집힌 해는 cheirality+fr_viol strict 로 0개 생존.
- 진짜 원인 = **고정 HFOV=60° 근사가 너무 넓음**. product 사진은 실효 HFOV ~25~50°.
  K 가 틀리면 PnP 가 오차를 포즈 기울임(윗면 foreshorten)으로 흡수 → 깔때기.
  HFOV 스윕 시 reproj 가 참 FOV 에서 급락(09: 16.6px@60°→3.9px@36°).

### 변경 (`scripts/stage0/internet_pallet_infer.py`)
- `est_K`(고정 HFOV_DEG=60°) 삭제 → `K_from_hfov(w,h,hfov)` + `fit_K(pred8,pred_c,dims,shape)`.
  - fit_K: HFOV 25~75° 5° coarse → best±5° 1° fine 스윕, 각 K 로 `solve_pose` 돌려
    reproj_error_px 최소 focal 채택 (fitted magic 상수 없음, 원리 탐색).
  - under-det(검출<N_DET_MIN) 이면 skip → HFOV_FALLBACK=60° 무의미 K(큐보이드 안 그림).
- process() 가 f7(posdepth)·pnp_cuboid 에 쓰는 K 를 fitted K 로 일관 사용.
- panel 헤더/로그에 채택 FOV·reproj 표기.
- `annotate_pnp.solve_pose` 는 미수정(공유 eval 20+곳 import).

## PAPER_S2 RGB 1장 히트맵/PnP 개선 퀵 스크린 — full 재학습 보류

### 목표와 고정 조건
- 뎁스·영상·시계열 없이 RGB 단일 이미지만 사용.
- 입력 `400×400`, belief/heatmap `50×50`, sigma 2를 고정. 히트맵 해상도는 늘리지 않음.
- 시작 체크포인트는 `weights/paper_s2_stageB/net_epoch_0057.pth`.
- 기존 Stage-B training data 6종만 사용. `raw_data`와 `scan`은 학습 경로에 포함하지 않았고 수정하지 않음.
- 선택은 synthetic q1_500 + filterval123만 사용. handannot17은 report-only, sealed final-test는 열거하지 않음.

### 구현
- 경계 안쪽에 center가 있는 keypoint의 Gaussian tail을 50×50 맵 경계에서 clip하는 border target 옵션 추가. 기본값에서는 기존 target과 동일.
- segmentation mask feature와 belief를 결합하는 zero-init residual fusion과, 예측 히트맵이 mask extent를 덮도록 하는 loss 추가.
- 9개 keypoint의 spatial log-sigma를 예측하는 uncertainty head와 weighted LM PnP 추가. uncertainty input은 detach해 core belief gradient를 바꾸지 않게 함.
- PnP에 geometric candidate, W/D ambiguity reject, topology/invariant check, 7-corner minimum, explicit reason code를 추가.
- 학습된 W/D prior는 true safe-solver label이 모두 한 class로 나와 타당하지 않아 제거. offset head도 이전 실험에서 큰 회귀가 있어 제외.
- evaluator는 baseline을 실제 rank pool에 포함하고, under-coverage·safe accept/yield·accepted gross·legacy PnP guard를 통과한 arm만 선택하도록 구성.

### 재현성/무결성 조치
- 첫 quick control에서 optional head 초기화가 global RNG를 소비해 arm별 sampler 순서가 달라지는 문제를 발견. 결과를 `_invalid_rng_prepatch` 안으로 격리하고 sampler/DataLoader 전용 seed-42 generator를 사용해 control부터 전부 재시작.
- 5 arm × ep58~63 = 30 checkpoint와 final checkpoint 5개, 총 35개의 모든 floating tensor가 finite. ep63 final은 같은 arm의 `net_epoch_0063`과 tensor 단위로 동일.
- arm 별 architecture strict load, 400/50·seed42·ep57 init·data 6종·60:40 replay·DiffPnP/mask 설정이 header/config와 일치.
- ep57 SHA-256: `c0055fe7…bc896`; config snapshot SHA-256: `d5264494…cf445`.
- `challenge/tests/test_annotate_pnp_safe.py` 5개 통과, 변경 Python 파일 py_compile과 runner `bash -n` 통과.

### Quick protocol
- arm: `control`, `border_target`, `mask_extent`, `uncertainty`, `full`.
- 각 arm을 ep57에서 ep63까지 6 epoch, epoch당 6,000 sample, seed 42, batch 12, LR 5e-5로 학습.
- q1_500에서 arm 별 epoch를 선택한 후 그 checkpoint만 filterval123에서 baseline과 비교.

## Frozen mask-fusion 단기 학습 — core 보존 성공, under-coverage 개선 실패

### 실험 이유와 설계
- 위 quick에서 전체 미세조정은 real-domain detection/accept를 손실했다. 사용자의 GPU 사용 승인 후, 그 회귀를 막기 위해 전체 학습 대신 frozen-core 단기 실험을 수행.
- 시작은 동일한 ep57. `vgg`, belief, affinity, segmentation을 모두 고정하고 `m_mask_belief_fusion.*` 4 tensor, 74,953 parameter만 학습.
- 신규 CLI `--trainable_scope {all,mask_fusion}`를 추가. `mask_fusion`은 mask fusion·base checkpoint를 필수로 하고 encoder unfreeze/LR scale·border/quality 혼용을 fail-closed로 금지.
- frozen core는 `eval()`, fusion branch만 `train()` 모드. optimizer는 requires-grad 파라미터만 받음.
- mask BCE는 segmentation이 frozen이므로 weight 0. DiffPnP flag는 aspect-resize/data pipeline을 유지하되 lambda 0으로 두어 추가 PnP gradient를 제거. belief loss + extent loss만 fusion으로 gradient를 전달.
- 500/1,000/1,500 step = ep58/59/60을 사전 지정. 모든 checkpoint를 q1_500과 filterval123에서 평가하고, detection/PnP/accept 보존 후 UC 5장 이상 개선을 성공 조건으로 사전 등록.

### 구현/검증
- config: `config/paper_s2_rgb1_frozen_fusion_v1.json`
- namespace:
  - `weights/paper_s2_rgb1_frozen_fusion_v1/`
  - `data/pallet/results/paper_s2_rgb1_frozen_fusion_v1/`
  - `data/pallet/eval_results/paper_s2_rgb1_frozen_fusion_v1/`
- evaluator에 `trainable_scope` provenance/cache metadata, all-real-checkpoint 평가, count 단위 preservation policy를 추가.
- cache hit 전 checkpoint discovery에서 ep57 core tensor를 모두 `torch.equal`로 비교. candidate의 추가 key는 fusion 4개만 허용.
- 2-batch smoke 통과: core bitwise equal, fusion finite/실제 update, trainable 74,953 assert 통과.
- 본 학습 1,500 step은 19:57:38~20:02:16, 4분 38초. raw/scan 미사용.
- ep58/59/60 모두 core bitwise equal, 모든 tensor finite. `final_net_epoch_0060` = `net_epoch_0060` tensor 단위 동일.
- TensorBoard scalar 전부 finite. training extent gap은 0.256→0.102→0.060 cell, extent/belief 비율은 2.92%→2.83%→1.68%.

### 판정
- 장점: core freeze로 기존 detection/legacy PnP 94/123을 정확히 보존. ep59/60은 safe accept 62→64, safe good 7→8이 되어 real-domain forgetting은 막았다.
- 실패: 학습 mask extent gap은 줄었지만 filterval UC는 23→23/25/24로 줄지 않았다. accepted gross도 27→28로 1장 증가.
- paired UC는 ep58 `1 resolved / 1 new`, ep59 `0 / 2`, ep60 `1 / 2`. 공통 신규 gross는 night frame `1779449234136754176`으로, baseline의 6-corner reject가 fusion에서 7-corner accept로 바뀌었지만 honest8은 34.56~34.93px였다.
- 사전 조건 `UC <= 18`, `accepted gross <= 27`을 어느 checkpoint도 만족하지 못해 `BEST_ARM=baseline`, `BEST_CKPT=weights/paper_s2_stageB/net_epoch_0057.pth`.
- 1,500 step에서 UC 개선 추세가 없으므로 사전 계획대로 3,000 step 연장은 하지 않음. ep58~60은 배포 모델이 아니며 연구 산출물로만 보존.
