
## STAGE11 16k — B3 replay-mix anti-forgetting finetune

- 목적: B0/B1(v3/addon만 finetune)이 catastrophic forgetting으로 real 검출 붕괴(challenge0123 67%→B0 2.4%/B1 19.5%, diag8 확정: old-synth raw corner도 101→174/110px·score도 붕괴 = confidence아닌 forgetting). 처방 = **원본 base + v3 + addon replay-mix** 재학습(B3)으로 real recall 보존하며 v3/addon 커버리지 추가되나 검증 = "addon 6k 실제 가치".
- init = `weights/challenge0123/final_net_epoch_0060.pth` (real 67% baseline). 산출 = `weights/stage11_16k_B3_replay/`.
- 데이터 = base(mixed_v8_train 9000 + v1 9986 + v2 9982 = 28968) + v3(batch_000..008, 9000) + addon_v1_train(5400). **draw 비율 2:1:1 강제**.
  - ★held-out(학습 제외, ckpt선택용): `v3/batch_009`(Val-v3 1000), `addon_v1_val`(Val-addon 600, addon 005400~005999 symlink), `training_data/val`(Val-Old). addon train/val = symlink 분리(`addon_v1_train`/`addon_v1_val`).
- recipe: batchsize8, imagesize448, lr1e-4, sigma4.0, epochs75(=60+15 누적 [[dope-finetune-cumulative-epoch]]), save_every1(에폭별 ckpt → 3-set 추이), heatmap+affinity only, seed2657.
  - **discriminative LR**: encoder(VGG) lr=1e-5(=lr×0.1), head lr=1e-4. forgetting 방지.
  - **encoder freeze 첫 750 step** 후 해제(저LR). 750step≈에폭61의 13.8%(5421 batch/epoch).
- **train.py 변경(default 불변, 3개 인자 신설)** — `Deep_Object_Pose/train/train.py`:
  - `--balance_groups "g1a|g1b:r1,g2:r2,..."`: N-way 비율 sampler. group=`|`로 묶은 substr들, ratio. group총weight=ratio, 그룹 내부는 image당 uniform(`ratio/n_g`)→큰 sub-source가 비례적으로 더 뽑힘. 첫 매칭 group 귀속, 미매칭=weight0 제외. default None=불변(기존 `--balance_substr` 2-group은 그대로, balance_groups가 우선).
  - `--encoder_lr_scale`: encoder=lr×scale, head=lr param-group Adam. None/1.0=단일LR 불변. `net.vgg`로 encoder 식별.
  - `--encoder_freeze_steps N`: 첫 N global step encoder requires_grad=False 후 1회 해제. 0=불변. `_runnetwork`에 global_step/encoder_freeze_steps kwarg 추가(default off), 반환값=global_step(에폭 간 누적).
  - NaN-guard: loss non-finite면 RuntimeError(에폭/배치/step 출력).
  - 검증(런타임 로그): `Number of Training Images: 43368`, `[BALANCE-N] counts={28968,9000,5400} unmatched=0`, `[LR] encoder lr=1e-05 head lr=0.0001`, `Starting at epoch 61`, `[FREEZE] encoder frozen for first 750 steps`. Monte-Carlo draw=0.499/0.250/0.251(2:1:1 확인).

B3 학습 완료(ep75, 19:47) → select_ckpt(3-set val) → real eval(baseline/B0/B1/B3). 자율워처가 select+eval 자동수행(agent 세션한도 사망 대비). ⚠워처 self-kill 버그 1회(pkill 자기매칭)→학습 무사·워처만 재실행.

- **★ B3가 forgetting 회복 + baseline 초과**: V=8 det 67.0→71.7%(+4.7%p), worst-2 corner 26.8→23.7(어려운 코너 개선), corner med 유지(11.3≈11.4). ALL det 58.5→62.6%. B0/B1(교체)의 붕괴를 replay-mix로 완전 회복하고 넘어섬.
- **addon 보강축 효과**: size=large(=근접) det 37.5→53.1%(+15.6%p★, baseline 최약점), mid 72.2→77.8%, good% mid 42→46. 즉 addon의 large/근접/저카메라 보강이 baseline 약점 구간 검출을 끌어올림. (small은 81.6 vs 86.8 소폭↓.)
- **V<8(truncation) 불변**(5.9%) — addon이 V<8 보강 안 했으니 예상대로. → 다음 레버=track B partial-keypoint.
- ckpt 선택(select_ckpt_B3.txt): 전 epoch Old 유지(det 76~78%)+v3(31.8→~60%)+addon(29→~70%) 동시개선. ep0074가 균형 최선(Old 78.5/v3 62.5/addon 69.3)이나 0075f로 평가(이미 +4.7%p). 향후 ep0074로 재선택 여지.
- ⚠ caveat: real 123 소표본, V=8 det +4.7%p는 modest하나 worst2·large와 일관. 
- ★ 결론: **"새 6k는 교체하면 망치지만(forgetting), 원본에 replay-mix로 추가하면 baseline 넘는 실질 개선"**. 데이터 추가 = 작동되게의 유효 레버 확정. 다음=(a) ep0074 재선택+B2 mask aux, (b) track B partial-keypoint(V<8), (c) truncation 보강 데이터.
