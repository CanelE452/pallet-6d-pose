## [12:5x] detection 열 채우기 — 내 제외 판단이 틀렸다

### ★ 정정 — DOPE 를 AP 표에서 뺀 근거가 틀렸다

앞서 `mc_ap_dump` 에 "score_4kp 는 box conf 와 의미가 달라 같은 곡선에 못 올린다" 고

얼마나 갈라내는가" 이고, 점수 정의가 달라도 비교가 성립한다 — threshold-free 지표를
쓰는 이유가 그것이다.

키를 넣어 상속시켰다. 표에서 P2 와 yolo26n_synth 의 detection 3열이 동일한 것은

```
                     readout 이 버리나                    안 버린다 (linear 0.951 vs actual 0.972)
                     → OBJECTIVE_BOTTLENECK

P26 TAL TARGET       assigner 가 순서를 뒤집나             아니다 (RW target 항상 정확히 0)
                     target 에 pose 품질이 있나            없다 (target ≡ IoU, rho +0.97~0.99)
                     → T3 WITHIN_IMAGE_RANKING_OBJECTIVE

P26 PAIRWISE SIGNAL  source 에 배울 hard pair 가 있나       거의 없다 (delta 중앙값 12, hard 6.6%)
                     그 hard 가 real 과 같은 종류인가       아니다 (source 87~95% duplicate,
                                                            real 75~87% distractor)
                     → PAIRWISE_SIGNAL_TOO_WEAK_OR_MISMATCHED
```

**결론이 세 번 이동했다.** representation → objective → **데이터**.
pointwise BCE 가 within-image ranking 을 못 가르친 게 아니라,
**source 가 그 선택을 거의 제시하지 않고 제시할 때조차 real 과 다른 종류를 제시한다.**

세 audit 모두 M0 parity 를 exact 0 으로 통과시킨 뒤에만 해석했고,
provenance 는 `sigmoid(class_logit) == final conf`(7.04e-08)로 독립 검증했다.
