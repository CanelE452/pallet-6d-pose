## Phase 1c + Q0: DiffPnP3D 파이프라인 통합 + 32-sample overfit 검증 (3d-expert)

Phase 1b loss 모듈(`diffpnp3d_loss.py`, self-test PASS)을 실제 학습 파이프라인에 배선하고 Q0 overfit으로 end-to-end 검증. **Q0 PASS (통합 정상)**.

### 변경 파일
- `Deep_Object_Pose/common/utils_dataset.py`: `CleanVisiiDopeLoader`에 `aspect_resize`, `diffpnp_index` 파라미터 추가. aspect 모드 = plain 프레임 `A.RandomCrop(400)`→`A.Resize(400,400)`(belief↔orig 고정 anisotropic 12.8/9.6). eligible(pnp_valid∧V8∧interior) 프레임은 **A.Rotate skip**(중심회전≠카메라roll). 프레임별 `diffpnp_{valid,X,K,R,t,diag}` emit(비적격=fallback+valid0). **flag off=바이트 불변**(OFF smoke test: diffpnp 키 없음, RandomCrop 유지).
- `Deep_Object_Pose/train/train.py`: `--diffpnp/--diffpnp_lambda/--diffpnp_warmup/--diffpnp_ramp/--diffpnp_temp/--diffpnp_index_dir/--diffpnp_root` 인자 + `_runnetwork` 배선(soft-argmax→DiffPnP3DLoss, λ linear ramp, mask 패턴 정규화, tensorboard). 전부 `if opt.diffpnp` 게이트 → off=불변.
- `scripts/stage0/diffpnp3d_q0_overfit.py`: 신규. 32 interior-valid 프레임(mixed_v8/v4/paper 혼합), 실 로더+실 DopeNetwork로 λ∈{0,0.001,0.003,0.005} 각 600 iter overfit.

### ★ Q0가 잡은 통합 버그 (self-test는 못 봄)
`CreateBeliefMap`은 keypoint가 belief 경계 `2σ`px 미만이면 **채널을 빈 상태로** 그림(edge corner=empty→soft-argmax garbage). `V8`(이미지 안)로 부족. v4/paper의 front-left corner(x~15)가 belief 2채널 empty→K-proj 대비 17~51px 어긋남(mixed_v8만 0.1px OK). **fix=belief-interior gate**(변환된 8 corner가 `[2σ,size-2σ)` 안일 때만 valid). 게이트 후 GT-belief soft-argmax=K-proj(X_i) <0.5px 전 도메인. self-test는 synthetic gaussian 직접 심어 edge-drop 우회했기에 놓침 = Q0(full integration)의 존재 이유.
- DiffPnP pool(interior gate 후) = **14,329**(valid&V8의 76.3%: mixed 94%/v4 71%/paper 70%). 커버리지 충분.

### Q0 결과 (600 iter, scratch, 32 frame)
- L_heatmap↓(0.074→0.009~0.012), L_pnp3d↓(0.036→0.001~0.004). NaN 0/0. positive-depth 1.000. pnp grad가 belief head param 도달(>0). heatmap 폭발 없음(λ0.003은 오히려 0.0089<control 0.0122 — 기하 loss가 corner 정합 당김).
- **λ 캘리브레이션**: raw belief-grad ratio ~1097% → 5~30% effective λ∈[0.0046,0.0273]. λ=0.005=5.3%(band), 0.003=2.5%(약함). **Q1 권고 λ≈0.005~0.008**(train.py default 0.003은 약간 약함; Q1 sweep이 커버).
- sa_err 수렴 ~4.5~9.2 orig px = 0.4~0.7 belief px = **belief 해상도 floor**(1 belief px≈12.8 orig px). <1 orig px는 완벽 analytic gaussian(self-test)에서만 가능, trained 50×50 belief에선 불가(정상). λ>0가 sa_err 개선(4.5 vs 9.2)=3D loss가 2D 기하 sharpen.
- 산출: `data/pallet/results/paper_s2_scratch_diffpnp/q0_overfit_results.md`.

### 다음 (P3 Q1)
1k screen(λ 0/0.001/0.003/0.005/0.01, 2~3ep) → **rear_med·honest8 go/no-go**. Q0 권고 λ=0.005~0.008 중심. 개선 없으면 PLAN대로 STOP→Windows 데이터 트랙.
