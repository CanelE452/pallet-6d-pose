## [07:2x] JS 수식 immutable lock — HOUGH_JS_NUMERICALLY_VALID

calibration 재실행 전에 4회 수정된 `js_divergence` 를 독립 float64 oracle 로 동결.

### 최종 구현 (이후 수식 수정 금지)
```
p = softmax(masked scores_a).clamp_min(1e-30)     ← p·q 에 **대칭** floor
q = softmax(masked scores_b).clamp_min(1e-30)
total = p + q
JS = mean_supported[ 0.5·( Σ p·log(2p/total) + Σ q·log(2q/total) ) ]
```
대칭 floor 가 핵심: p==q 면 clamp 후에도 같아 비율이 정확히 1 → log 정확히 0,
동시에 분모 하한이 생겨 d(ratio)/dp = 2/(p+q) 가 오버플로하지 않음.

### 4회 결함 이력 (내 실수, 매번 forward 만 보고 backward 를 안 봄)

