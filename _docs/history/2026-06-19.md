## loss 수렴 테스트 — 단계적 계획 (보류, 발표 후 실행. PHASE 2 다음 단계)

> ⚠ **미실행 plan**. 지금 안 돌림(GPU 점유→발표준비 방해). 우선순위 ① 발표 PPT(내일 정오) > ② 발표 > ③ 이 테스트.
> ⚠ **finetune 결과 ≠ 최종 결론** — 1단계는 "loss 필요한지" 싼 스크리닝일 뿐(과소평가 내장). 절대 최종 base로 오해 금지.

**배경**: sigma2 ep66 = 8.50px로 base 11px 천장 이미 깸(PHASE 2a). loss(coord/edge)는 "추가 이득 있으면 넣을 후보"지 필수 아님. 4월 coord+edge 시너지는 **v8(object-frame)** 산물 → camera-facing 재현 미보장. edge λ는 868%→0.0012(40x↓) 인하해야 안 터짐 → 그 값에서 효과 잔존 자체가 불확실. 그래서 테스트 목적 = **"loss가 필요한가" 판정**.

**L0/L1 출발점**(PHASE1): coord λ=0.10(MSE grad 15.7%, 건강) / edge λ=0.0012(868%→정상 환산) / flip 제외(4월 악화). geo_loss_struct.py convention 정합 ✓.

**finetune vs scratch 차이**: finetune=빠름이나 이미 수렴한 belief에 얹어 loss 효과 **과소평가**(StructuralLoss는 belief 형성기에 효과). scratch=belief 형성 전과정 관여로 정확하나 full 60ep+ 비쌈.

**단계적 설계**:
```
1단계 (싼 finetune 스크리닝 — "효과 있나"):
  공통 base : weights/paper_base_v2_s2 / ep66 (★8.50px)
  arm A     : plain 계속 (loss 0) = sigma2 단독 drift 대조군 (ep66→69 악화 known = 이게 control)
  arm B     : --struct_loss --struct_coord 0.10 --struct_edge 0 --struct_flip 0
  arm C     : --struct_loss --struct_coord 0.10 --struct_edge 0.0012 --struct_flip 0
  공통       : --struct_warmup 66  ★필수 (finetune은 epoch 66부터 이어받음 → warmup 기본10이면
              ramp 첫 step부터 1.0 = edge 868% 즉발. warmup=66 이라야 ramp 0→1 을 ep66→76 분산)
              sigma=2, --finetune, ~ep80 (14ep = ramp10 + 풀강도4)
  평가       : ep69/72/75/78/80 마다 val200f aspect order-free corner median + 검출 + PnP (=/tmp/phase2_eval 방식)
              + 학습로그 struct/edge·MSE 곡선(수렴/발산)
  판정       : 매칭 epoch에서 B/C corner < A 유의미(>0.5px)?
               안 내림 → loss 효과 없음/미미 → 빼고 종료 (scratch 불필요)
               내림    → 유망(finetune이 과소평가하므로 scratch선 더 클것) → 2단계
2단계 (1단계 유망 시, scratch full — "확정 + 최종 base"):
  sigma2 + coord(+edge) 처음부터 켜고 full 학습 vs sigma2 단독. 진짜 효과 측정.
```
스크립트 미작성(발표 후). 배선 확인됨: train_dope.sh --struct_loss/--struct_coord/--struct_edge/--struct_flip/--struct_warmup → train.py StructuralLoss(geo_loss_struct.py). 산출 base ep63/66 존재.
