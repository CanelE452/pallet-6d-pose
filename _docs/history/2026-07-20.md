## 7. GT/평가 출처 조사 (Gate 0/0.5, 무결성 근거)
- **GT 출처 = 전 도메인 `gt_source:"manual"`(수동 어노)**. noapril도 manual(AprilTag 아님). 평가는 manual GT 프레임에만(누수 없음, unlabeled 제외).
- **`projected_cuboid` = camera-facing 0123 3D 큐보이드 8코너 투영** — 표면점 아님(뒷코너 허공). 프레임당 **~6개 정수클릭 + ~2개 PnP 외삽(float)**. JSON에 `pose_transform`(GT 6D)·`reproj_error_px` 저장 = **GT 자체가 PnP 산물**.
- **중앙점(kp8) = 클릭 아님**, 전 도메인 float·`projected_cuboid_centroid`와 동일 = 코너평균 PnP 투영(annotate_pnp.py:93). → "PnP 우회 2D 지표" 불성립.
- **dimensions_m 프레임마다 W/D 스왑**((1.1,1.3,0.11)↔(1.3,1.1,0.11), H=0.11 고정). `solve_pose` auto_swap = **min-reproj로 선택** → GT/pred 다른 스왑 고르면 yaw 오염 위험 → 측정 시 `auto_swap_dims=False`로 차단.
- **GT reproj_error_px 분포**: outside med1.24(max220 이상치1건)·night2.42·noapril0.64·cad1.87. → reproj>5 프레임 제외 근거.
