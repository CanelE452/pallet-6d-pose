### ★ 편차 2건 (둘 다 사용자 결정, METHOD_SPEC 기록)

1. **채점 ckpt** — spec 은 Y0 고정·Y0E 금지였으나 사용자가 Y0E 를 요청해 충돌.

2. **lambda_neg 보정 regime** — 시점에 따라 **1,600배** 갈렸다.
   init r=2.43e-07 -> lambda 412,330 / Y0 r=3.91e-04 -> lambda **255.626**.
   init 은 anchor 99.86% 가 p<0.01 이라 negative 항이 사실상 0 이고, 그 상태에서 10% 를
   맞추면 학습 중 발산한다. Y0 regime 채택.
   ⚠️ r 이 학습 중 크게 변하므로 **어떤 고정 lambda 도 어느 시점엔 어긋난다.**

   거의 같은 두 norm 을 빼면 gradient 가 달라도 0 이 나온다. 첫 결과가 lambda=1.05e7 로
   나와서 잡았다. loss 가 두 항을 따로 노출하도록 고쳐 각각 backward 하는 방식으로 교체.
2. **pickle 지뢰 2곳** — HF arm 이 epoch 1 체크포인트 저장에서 죽었다.
   `AttributeError: Can't pickle local object 'HNTrainer.get_model.<locals>.init_criterion'`

확인하니 그 15장 전부 `dR=0.0도 / dt=0.0m` — 저장 pose 가 점에서 푼 해와 정확히 같았다.
2~6px 잔차는 저장 버그가 아니라 **클릭 정밀도**였다.

판정을 상대 비교로 교체:
```
STORED_POSE_MISMATCH  dR/dt + excess(T2-T3) — "저장 pose 가 점이 허용하는 최선보다 나쁜가"
GROSS_RESIDUAL        절대 임계는 10px 로 상향 (gross 만 hard)
중간 구간             T5 robust z 가 상대 판정
```
수정 후 같은 폴더 27/27 GREEN.
**교훈: 절대 임계로 어노 품질을 판정하면 정상을 대량 오탐한다.**
