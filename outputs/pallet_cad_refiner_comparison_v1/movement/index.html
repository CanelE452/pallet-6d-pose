어느 점을 어느 방향으로 얼마나 옮겼는가 — CAD 전체 18장

화살표는 저장된 R0 좌표 → 보정기 출력 좌표입니다. 정답 쪽으로 임의 이동시킨 그림이 아닙니다. 확대창은 사진과 좌표를 함께 확대하며, 이동량을 과장하지 않습니다. 각 패널에서 P0–P7을 선택하면 해당 코너를 확인할 수 있습니다. 기본 확대 코너는 화면 안 평가 코너 중 가장 많이 움직인 점입니다.

DIM-SYM은 이렇게 보정했습니다

R0의 영상 특징 + 초기 점·박스 + 알려진 치수 [W,D,H]=[1.10,1.30,0.11]m → 각 코너 주변 221개 이동 후보와 제자리 후보에 점수 → 확률 가중 평균 이동량 → 현재 점에 더하기.

현재 설정은 최종 이동을 영상 대각선의 1%로 제한합니다. 640×480 영상에서는 코너당 최대 8px입니다. 대칭 정답 처리는 학습에 쓰였고, 추론 때 이 이미지의 정답을 보지 않았습니다.

Replay PoseFix는 이렇게 보정했습니다

R0 박스로 잘라낸 RGB + 초기 9개 점을 표시한 Gaussian map → 기존 PoseFix 네트워크 → 좌표 예측을 원본 영상으로 환산.

기존 실사+합성 replay로 학습된 모델의 raw 출력입니다. 여기에는 8px 제한을 적용하지 않았습니다. 두 방법 모두 중심점 P8은 R0 그대로 유지하며, 서로 연달아 적용하지 않았습니다.
